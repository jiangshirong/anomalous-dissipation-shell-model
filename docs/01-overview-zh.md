# 01 研究导读：能量如何跨过尺度

## 1. 这个项目计算什么

壳模型不直接计算空间中每一个速度矢量，而用一列振幅表示不同尺度的活动。这里每层有两个非负实振幅 `w_n,z_n`，波数为 $`k_n=2^n`$；层号越大，代表的尺度越细。每层能量为 `(w_n²+z_n²)/2`。它是人为设计的数学级联，不是标准 Sabra，也不是三维 Navier–Stokes 的严格投影。

核心问题：在固定外力、共同零初值和固定观察窗下，黏性趋零时，真实黏性耗散是否仍不消失？不能把有限系统的非守恒、末端流出或数值误差算作异常耗散。

## 2. 能量转移怎样设计

每条正系数边 `i→j` 贡献 `(-c u_i u_j,+c u_i²)`；乘各自振幅后能量变化相消。模型有强纵向边 `z_n→w_(n+1)`、弱纵向边 `w_n→z_(n+1)`，以及两条同层交换边。强边系数为 `2^n`，弱边为 `2^(-n)`，正向同层交换为

```math
h_n=\eta2^{n/2}(n+1)^\alpha,\qquad \eta>0,
```

反向交换为 `βh_n`，基础版本 `0≤β≤1`。由于 `n=log₂k_n`，幂因子 `(n+1)^α` 是波数的对数修正；所有系数静态且不依赖黏性。两个根各受单位外力，实际输入功率为 `w_0+z_0`，不是预设常数。

## 3. 当前得到什么

以下是内部解析结果，不是文献优先权认证。设置与解类见[模型与基础](02-foundations-zh.md)，完整推导见[结果与证明](03-results-zh.md)。

| 参数 | 共同零初值、固定窗口的黏性耗散 | 有限能量无黏稳态 |
|---|---|---|
| `α≤1/2` | 每个固定有限窗口耗散趋零 | 不存在 |
| `1/2<α≤3/4` | 未解决 | 不存在 |
| `α>3/4` | 每个足够长且与黏性无关的固定窗口有正下界 | 存在稳态极限子列 |

明确正侧实例是 `α=η=β=1`。主证明先在每个正黏性下构造稳态，证明其能量一致有界，再通过相对能量比较控制同一零初值轨道；输入下界减去储能才得到真实耗散。它没有先令时间趋于无穷。

稳态不存在并不能决定固定窗口耗散。对所有有限壳数先令黏性趋零，也不能代替无限系统的零黏极限。有限黏性平台同样不能决定答案：已知无耗散的 `α=1/2` 在现有扫描范围内也有近似平台。

更一般的[结果篇 §7](03-results-zh.md#7-一般非单调交换可求和条件与稀疏瓶颈)把交换序列的未来加权几何平均转成比较剖面 r_n。它是否平方可求和，恰好决定所列系数类的有限能量无黏稳态是否存在；可求和时还保证固定窗口异常耗散。每隔一层设置弱交换的明确实例仍能耗散，证明旧逐层判据并非必要：不能只看一个瓶颈，还要看相邻排列。强原创性仍未确认；该稳态判据不解决所有动态分类，也不表示瓶颈总是无关紧要。

[长弱块对照](03-results-zh.md#78-稀少但成块的弱交换一个动态无耗散对照)进一步说明：即使弱层极少，连续长块也可阻断耗散。甚至两个弱层比例同为 1/2、只在零密度层集合不同的模型，一个耗散，另一个每个固定窗耗散趋零。这里的“少数层改动”不等于“小幅改动”；结论来自动态预算，不是稳态障碍或数值外观。

[冻结随机排列](03-results-zh.md#79-一次抽样后冻结的二值排列)是确定性判据的概率应用。2026-10-03 新[四次根弱块估计](03-results-zh.md#711-真实通量的四次根递推较短弱块及两类完整动态分类)闭合原先的动态空档：弱层概率 p<1/4 几乎必然耗散，p≥1/4 几乎必然每个固定窗无耗散。抽样后固定，改变黏性时不重抽，也不在动力学中加噪声。[整体评估](04-evidence-zh.md#89-已有候选的原创性评估裁定)后，用户批准的[限定核查](04-evidence-zh.md#810-同密度动态对照的限定去留核查)保留同密度动态对照为优先贡献候选，并说明最近旧证明为何不能直接给出它；新结果的证据范围见 §8.12，不宣称全球首创。

### 3.1 当前选定模型及原创贡献

建议描述性称为“非均匀交换双通道壳模型”，不是另造模型。当前选定实例固定 β_n=1；n≥0、负下标项删除，K_n=2^n、e_n=2^(−n)，方程为

```math
\begin{aligned}
\dot w_n={}&K_{n-1}z_{n-1}^2-e_nw_nz_{n+1}
+h_n(z_n^2-w_nz_n)-\nu K_n^2w_n+\delta_{n0},\\
\dot z_n={}&e_{n-1}w_{n-1}^2-K_nz_nw_{n+1}
+h_n(w_n^2-w_nz_n)-\nu K_n^2z_n+\delta_{n0}.
\end{aligned}
```

w_n、z_n 是每尺度的两个非负振幅，初值全零，两根各受单位力；所有交换系数独立于时间、黏性。有限封闭无黏无迫时 E=∑(w_n²+z_n²)/2 严格守恒。无限层固定正黏性下，真实累计耗散为 Q_ν(T)=ν∫₀ᵀ∑K_n²(w_n²+z_n²)dt，精确预算为 E(T)+Q_ν(T)=∫₀ᵀ(w_0+z_0)dt。不是用方程错误或末端吸收制造耗散。

**耗散模型 A。** h_n=√K_n（偶数层）、h_n=K_n（奇数层）。其同层相对弱交换密度为 1/2，内部证明给出与黏性无关的 T_*、ε>0，使每个 0<ν≤1、每个 T≥T_* 都有 Q_ν^A(T)/T≥ε。

**同密度负对照 B。** 令 N_j=2^(2^j)、L_j=2^(j+1)，j≥2；在所有块 [N_j,N_j+L_j] 内的奇数层，将 A 的 h_n=K_n 改为 √K_n，其余完全不变。差异集合密度为零，弱层密度仍为 1/2，却有每个固定 T>0 的 Q_ν^B(T)→0。各同层交换仍趋于无穷，没有断边；这不是小幅改动，也不是保持系数多重集合的纯重排。完整证明和量词见[结果篇 §7.8](03-results-zh.md#78-稀少但成块的弱交换一个动态无耗散对照)。

**最值得认领的贡献是结果，而非新基本作用律：**

1. **零密度系数改动下的耗散非稳定性。** 明确构造上述 A、B，在共同设置与相同弱层密度下得到相反的真实零黏耗散结论，说明密度与同层交换系数的绝对增长都不足以分类。这是主贡献，不能同时拆成“同密度”“零密度”两个独立突破。
2. **长弱块的定量动态阻断判据。** 在所有同层边仍增长的情况下，由块内积分递推和四阶预算选出通量消失切面，证明每个固定窗无耗散；不是由稳态不存在猜测动力学。它支撑主贡献，不另宣称全新通量方法或最优弱块长度。
3. **配套的一般系数结果。** 用未来加权几何剖面 r_n 的平方和 P 控制完整图的正黏性稳态和零初值轨道，得到非单调交换的固定窗耗散充分条件。正文另有稳态充要判据，但不把 P 当作动态充要条件；归一化递推和增长反证已有先例。

这些是本项目形成、当前已读最近先例未直接提供的具体增量，不是已经确证全球优先权。[Tao §5.1](https://arxiv.org/html/1402.0290v3#S5.SS1) 已有本模型逐边使用的 pump；[BMR (2014) Eq. (1)、Theorem 5](https://arxiv.org/html/1403.2852v2) 已有有界变系数非线性及固定耗散下的正则性。不能认领 pump、双通道、变系数或能量守恒概念首创。其与本结果的具体短推断点见[验证篇 §8.10](04-evidence-zh.md#810-同密度动态对照的限定去留核查)，内部证明审查范围见 §8.11。

概括为：**本项目构造一类保守双通道壳模型，证明真实黏性异常耗散可被零密度集合上的非小幅系数改动消除，从而展示弱交换的聚集结构与密度统计不能等同的动态效应，并给出正侧充分条件与长弱块阻断判据。** “密度不是充分分类指标”有严格反例；“全新基本机制”“最优阈值”“世界首次”尚不属于本项目已证结论。

### 3.2 投稿后新增的动态分类

2026-10-03 续研还得到一个明确块长族的完整分类：块长 ℓ_j=⌈c log₂N_j⌉、N_j=2^(2^j)，块外保持周期正例时，c<1/2 耗散，c≥1/2 每个固定窗无耗散。新增关键是控制回流后使用真实通量的四次根递推，不是从 P 发散猜动态。证明见结果篇 §7.11；一般 P=∞ 的动态和对数中间区间仍开放。该结果尚未加入当前已投稿论文。

随后[结果篇 §7.12](03-results-zh.md#712-单层振幅和与加权弱块阻断)进一步给出加权阻断条件：全弱块的起点各异且趋于无穷，若 ∑_j2^(−2J_j4^(−ℓ_j)) 发散，则每个固定窗无耗散。单层振幅和控制真实时间积分，正缺陷会迫使各块共同耗尽有限四阶预算。它覆盖原一致条件之外的 ℓ_j=2j、N_j=2⌈16^jlog₂(j+1)/2⌉ 候选；这个候选已排除，不再待判。一般 P=∞ 的必要性仍未证明。

对数族 α=2/3 的后续集中度筛选得到更强时间积分包络，但没有填补动态空档；一个保守四节点真实脉冲排除了仅靠局部能量和正通量闭合集中度的路线。它采用不同初值及封闭边界，不是原零初值轨道反例。随后 §3.8 已研究整链起动历史，得到精确首次到达关系，但延迟下界可求和，故本批停止，动态仍开放。不能再次把这一已执行的任务列为尚未开展。

最新[结果篇 §7.13](03-results-zh.md#713-实际交换系数的纯置换对数位移的锐利门槛)进一步保持实际 h 的多重集合：在可容许界 √K_n≤h_n≤K_n 内，位移不超过 c log₂(n+2)+C、c<1/2 的所有置换都保留异常耗散；临界尺度存在零密度支撑的纯置换，使每个固定窗耗散趋零。这是最坏情形的锐利门槛，不是所有临界置换均无耗散。它补上 §3.1 已投稿改值对照未保持多重集合的限制；最新内部证明及审查边界见验证篇 §8.15，尚未加入投稿稿件，也未认证全球优先权。

[结果篇 §7.14](03-results-zh.md#714-无迫自由衰减中的纯置换耗散对照)又完成一项不同设置的动态对照：去掉全部外力，两个模型共同只在两根取初始振幅 1。周期配置在一个黏性无关固定窗真实损失超过初始能量的一半；临界纯重排配置每个固定窗损失趋零。正侧用辅助受迫稳态、前向路径与尾部实际黏性取得一致估计，实际轨道始终无迫；不由无黏失能推断 Q 的下界。新证明的限定独立检查和方法先例见验证篇 §8.16，投稿源稿未改，强原创性仍需按具体结果评价。

最新[结果篇 §7.15](03-results-zh.md#715-层能量与角度的精确分解广义框架的包含范围)与[验证篇 §8.17](04-evidence-zh.md#817-完整图的多分量覆盖与纯置换结果的增量边界)进一步确定覆盖边界：完整图沿轨道的层能量归约可纳入 BMR 的既有有界变系数框架，因此不能认领多分量能量归约首创。交换排列作用留在通道角度中，旧包络的实际收缩因子在零黏极限退化；所核原定理没有直接给出实际 h 多重集合保持下的双侧动态对照。应认领具体排列结果及其黏性一致估计，不把有限来源核查升级为全球原创性认证。这批覆盖核查已完成，不再作为待办。

对数族又取得新的轨道信息，见[结果篇 §3.9–3.10](03-results-zh.md#39-零初值轨道的接收屏障与-z-通道黏性一致强尾)及[验证篇 §8.18](04-evidence-zh.md#818-零初值通道强尾与整体预算路线的有限结果)：η=β=1、共同零初值下，z 通道有黏性一致的指数能量尾，沿坐标零黏子列在 C([0,T];ℓ²) 强收敛。正缺陷下的两个积分相对余项趋零，但误差可求和性和时间相关性未闭合。一个自然整体预算仍仅是条件命题；指定的全状态能量吸收测试已被反例排除。α=2/3 和一般 P 发散动力学仍开放。

最新[结果篇 §3.11–3.12](03-results-zh.md#311-z-通道真实黏性损失消失及强尾的三次根改进)进一步证明：所有固定 α>0 的对数族均有 Q_(z,ν)(T)→0，任何可能的异常损失来自 w 通道；在已知 α>3/4 范围内，w 的异常损失成立。接收截幅与正黏性尾预算给显式 ν^(1/14) 对数修正上界，并非强收敛的短推。黏性一致点态尾亦收紧为三次根，另有全层正黏性积分包络。实际有限与独立核查见验证篇 §8.19；该通道任务已完成，总耗散中间区间仍开放。

[结果篇 §3.13](03-results-zh.md#313-α23-的低层-w-损失定位与移动切面残项)又将 α=2/3 的可能损失定位到 n>⌊½log₂(1/ν)⌋ 的 w 坐标：以下层损失有对数消失上界。移动切面通量等于总黏性损失加更高层 w 末端储能，误差趋零；这两个高层量仍未控制。指定的粗截幅／远尾拼接无共同截点，本有限路线停止，总耗散仍未分类。

随后结果篇 §3.15–3.16 给有限壳块的带权时间相关性障碍和实际端点累计条件。固定 α=2/3，正缺陷强迫终点 w 不属于 ℓ¹；若正黏性同一终点有统一振幅绝对和界，则真实 Q→0。尚未证明这个上界实际成立，不据条件判据分类对数空档。定量相关性任务已完成，实际核查见验证篇 §8.22；下一增量须来自新的轨道端点或迁移控制。

## 4. 哪些说法已纠正


后续旧稿把时间均值、均方根与四阶矩混用，并错误声称只凭根均值不小于 1 就能补齐未解区间。这条归约已撤回；MB 控制四阶时间集中度，在指定指数范围推出的是**耗散趋零**。详见[验证与原创性](04-evidence-zh.md)。

同层交换可旋转为已有 Tao pump 单元，不能当作新基本作用律。尚未找到完整边图和参数配置完全相同的发表模型，不等于已确认原创；一般变系数网络与已有定理仍须对照。
