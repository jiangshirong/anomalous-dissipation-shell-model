# 03 当前结果与完整证明

## 1. 结论、量词与证明依赖

§2–6 针对[基础篇式 (L)](02-foundations-zh.md)；§7 在相同边图上推广交换系数。全篇使用固定参数、单位双根强迫、共同零初值、封闭截断极限、非负能量类解。证明是内部解析推导，不是有限测试认证或同行审定。

| 范围 | 固定观察窗、黏性趋零 | 依据 |
|---|---|---|
| α≤1/2 | Q_ν(T)→0，任意固定 T | §3 的切面预算和逐层积分 |
| 1/2<α≤3/4 | 动态结论未解决 | §3.3 仅为条件定理；§4 不存在无黏稳态并不决定动态耗散 |
| α>3/4 | 存在与黏性无关的 T_*、ε>0，使所有固定 T≥T_* 有 liminf Q_ν(T)/T≥ε | §2 的稳态包络、基础篇相对能量、根输入下界 |

依赖顺序：先固定正黏性构造解和稳态，再证明黏性一致的包络，最后比较共同零初值轨道。正结果不依赖旧证明汇编的根均值归约、漏迫项估计或总变差命题。MB 是四阶时间矩条件；满足 §3.3 的指数条件时推出的是**无耗散**。

以下按证明的逻辑顺序迁入旧对数篇的有效段落；§5 保留具体方法对照，§6 保留逐层倍率的稳健性证明。出处、删除段落及原文恢复方法见[迁移索引](06-process-zh.md)。

## 2. 正侧：平方可求和包络给出异常耗散

以下取 $`\alpha>3/4`$。定义有限常数

```math
D_\alpha=\sup_{n\ge0}(n+1)^{2\alpha}2^{-n},\qquad
H=\eta\sqrt{D_\alpha},\qquad h_n\le HK_n.
```

固定黏性，先按前篇构造正的有限能量稳态，记 $`I=w_0+z_0`$。这一步没有使用黏性一致界。有限切面及全局预算给强边通量不超过 $`I`$，各坐标黏性耗散不超过 $`I`$。

### 2.1 强出口包络

[附录 A4 §A4.5.1](appendices/legacy-models-zh.md)所用的下一层平衡仍给

```math
\max(z_{n+1},z_{n+2})\ge
\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}+e_{n+1}}.
```

令 $`A_z^3=8(1+H)`$。若 $`z_n>A_z(I/K_n)^{1/3}`$，分子为正；用 $`h_{n+1}+e_{n+1}\le2(1+H)K_n`$，较高层振幅超过 $`2z_n`$。阈值递减，迭代与已构造的固定黏性有限能量矛盾。因此

```math
z_n\le A_z I^{1/3}2^{-n/3}.
```

### 2.2 弱出口包络

选择

```math
A_w^3=1+8A_z^3D_\alpha+\frac{8(H+D_\alpha+1)}{\eta^2}.
```

假设 $`w_n>A_wI^{1/3}(n+1)^{-2\alpha/3}`$。由于 $`A_w^3>8A_z^3D_\alpha`$，强出口包络保证 $`w_n>2z_n`$。净交换通量及稳态预算给

```math
\frac12h_nw_n^2z_n\le h_nw_nz_n(w_n-\beta z_n)\le I.
```

强出口平衡于是给与前篇相同的下界

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{h_n}{K_n}w_n-\frac{I}{K_nw_n^2}.
```

这里 $`h_n^2/K_n=\eta^2(n+1)^{2\alpha}`$，故超阈值时

```math
\frac{w_{n+1}}{w_n}
>\frac{\eta^2A_w^3}{2}-H-\frac{D_\alpha}{A_w^3}>2.
```

最后一步由 $`A_w^3\ge1`$ 及定义中最后一项直接保证。阈值因 $`\alpha>0`$ 递减，增长反证得到

```math
w_n\le A_wI^{1/3}(n+1)^{-2\alpha/3}.
```

### 2.3 能量闭合及固定时间窗

当 $`\alpha>3/4`$，两个包络都可平方求和。可取

```math
C=\frac{A_z^2}{1-2^{-2/3}}
+A_w^2\left(1+\frac1{4\alpha/3-1}\right),\qquad
\|b^\nu\|_2^2\le CI^{2/3}.
```

用 $`I\le\sqrt2\|b^\nu\|_2`$ 闭合得 $`\|b^\nu\|_2\le B=2^{1/4}C^{3/4}`$，独立于黏性。包络还给稳态尾部一致小，逐坐标子列极限是正的有限能量无黏稳态。

相对能量非扩张性给零初值轨道 $`\|u^\nu(t)\|_2\le C_0=2B`$。根部 $`h_0=\eta`$，所以对 $`0<\nu\le1`$，$`s=w_0+z_0`$ 满足

```math
s'\ge2-Ls,\qquad L=1+(1+2\eta)C_0.
```

根输入下界减去末端储能，得到

```math
\frac{Q_\nu(T)}T\ge\frac2L-
\frac{2/L^2+C_0^2/2}{T}\ge\frac1L>0
\quad\text{若 }T\ge2/L+LC_0^2/2.
```

此为共同零初值的固定窗口黏性异常耗散，不需要先取长时间极限。常数很粗，不能当作实际起始时间预测。

**一个明确实例。** 取 $`\eta=\alpha=\beta=1`$，即 $`h_n=(n+1)2^{n/2}`$。有 $`D_1=9/4`$、$`H=3/2`$，可直接用更小的 $`A_z^3=20,A_w=8`$：$`8^3>8\cdot20\cdot9/4`$，增长下界 $`256-3/2-9/2048>2`$。故本节给出一个具体满足异常耗散的候选。

## 3. 低侧：先作基础估计，再推进到二分之一

### 3.1 基础估计与四分之一范围

若 $`\alpha\le0`$，$`h_n\le\eta\sqrt{K_n}`$，附录 A4 §A4.2.1 原证明直接适用。以下只取 $`0<\alpha\le1/4`$。

固定 $`T>0`$，由正黏性轨道提取逐坐标时间一致的无黏极限，范数不超过 $`R=\sqrt2T`$。定义

```math
Y_n=K_n\int_0^Tz_n^2\,dt,\qquad
V_n=\frac{Y_n}{(n+1)^{2\alpha}}.
```

积分下一层弱出口方程、舍弃非负反向输入，得

```math
Y_n\le A+B(n+2)^\alpha\sqrt{Y_{n+1}},\quad
A=R+TR^2,\ B=\eta R\sqrt T,
\qquad
V_n\le A+B2^{2\alpha}\sqrt{V_{n+1}}.
```

同时 $`V_n\le2^nTR^2`$。附录 A4的四倍增长反证给 $`V_n\le C_T`$，其中可取 $`C_T=2A+16B^2 2^{4\alpha}`$。

对包含前面整层及本层弱出口的有限切面，正交换通量的时间积分为 $`F_n=h_n\int_0^T w_n^2z_n\,dt`$。于是

```math
F_n^2\le\eta^2C_T(n+1)^{4\alpha}\int_0^T w_n^4\,dt,
\qquad \sum_n\int_0^T w_n^4\,dt\le TR^4.
```

因为 $`\sum(n+1)^{-4\alpha}=\infty`$，必有趋于无穷的切面子列使 $`F_n\to0`$；否则上式迫使四次积分之和发散。反向通量由 $`\eta RC_T2^{-n/2}(n+1)^{3\alpha}\to0`$ 控制，两条弱纵向边通量也趋零。沿该子列写有限预算并穷尽坐标，得到极限解的能量等式。再用正黏性精确预算、根输入收敛及末端能量下半连续，得整族 $`Q_\nu(T)\to0`$。

这里仅需要一个切面子列，不声称所有切面通量都趋零；也没有假定无黏解唯一。

### 3.2 保留逐层积分，将无耗散区推进到二分之一

上节对 $`V_n`$ 的一致上界实际上对每个固定 $`\alpha>0`$ 都成立；只有最后使用发散级数时才限制到 $`1/4`$。下面先对任意固定 $`\alpha>1/4`$ 证明加权积分可求和，再在最后一步使用 $`\alpha\le1/2`$ 得到无耗散结论。始终研究同一无黏极限轨道，不使用任何稳态估计。

令 $`W_n=\int_0^T w_n^2\,dt`$，则 $`S_W:=\sum W_n\le TR^2`$。积分弱出口方程时不再将 $`w_{n+1}`$ 全部用 $`R`$ 代替，得到

```math
V_n\le d_n+c_\alpha\sqrt{W_{n+1}V_{n+1}},\qquad
c_\alpha=\eta2^{2\alpha},
```

其中

```math
d_n=\frac{w_{n+1}(T)}{(n+1)^{2\alpha}}
+\frac{e_{n+1}}{(n+1)^{2\alpha}}
\int_0^T w_{n+1}z_{n+2}\,dt\ge0.
```

这里用的是 $`h_{n+1}/\sqrt{K_{n+1}}=\eta(n+2)^\alpha`$，以及归一化后 $`((n+2)/(n+1))^{2\alpha}\le2^{2\alpha}`$。末端能量界和 Cauchy–Schwarz 给

```math
D_T:=\sum_nd_n
\le R\left(\sum_{n\ge0}(n+1)^{-4\alpha}\right)^{1/2}+TR^2<\infty.
```

注意此处恰好要求 $`\alpha>1/4`$，端点已由 §3.1 处理。取有限部分和 $`S_N=\sum_{n=0}^NV_n`$。先前 $`V_n\le C_T`$ 控制求和右端多出的边界坐标，因此

```math
S_N\le D_T+c_\alpha\sqrt{S_W(S_N+C_T)}
\le D_T+\frac12(S_N+C_T)+\frac12c_\alpha^2S_W.
```

从而 $`S_N\le2D_T+C_T+c_\alpha^2S_W`$，独立于 $`N`$。令 $`N\to\infty`$ 得到新的可求和信息

```math
\sum_{n\ge0}\frac{K_n}{(n+1)^{2\alpha}}\int_0^Tz_n^2\,dt
=\sum_{n\ge0}V_n<\infty.
```

这不是把一个无穷和预先假定有限再吸收：先对有限部分和操作，多出的一项由已证一致上界控制。

现在再次估计正交换通量：

```math
\frac{F_n}{(n+1)^{2\alpha}}
\le\eta\sqrt{V_n}\left(\int_0^T w_n^4\,dt\right)^{1/2}
\le\eta R\sqrt{V_nW_n}.
```

对层号求和，右侧不超过 $`\eta R\sqrt{(\sum V_n)S_W}<\infty`$。另一方面，$`\alpha\le1/2`$ 使 $`\sum(n+1)^{-2\alpha}=\infty`$，所以仍必有切面子列满足 $`F_n\to0`$。反向通量、弱边通量和返回黏性族的步骤完全按 §3.1 进行，得到 $`Q_\nu(T)\to0`$，包括 $`\alpha=1/2`$。

结合 §3.1，现已证明全部 $`\alpha\le1/2`$ 无固定窗口异常耗散。仍未证明 $`1/2<\alpha\le3/4`$ 的动态结论；稳态不存在性不能填补这个缺口。

### 3.3 未解区间中的必要条件：时间集中度不能太低

本节不改变式 (L)、外力或初值，也不解决 $`1/2<\alpha\le3/4`$ 的无条件分类。新增的是可用于筛选机制的条件命题：若该区间真的有固定窗口异常耗散，则传输不能始终保持受控的逐壳时间集中度。以下仍取固定 $`T>0`$，先分析任一黏性子列的逐坐标时间一致极限。

对弱出口定义

```math
W_n=\int_0^T w_n^2\,dt,\qquad J_n=\int_0^T w_n^4\,dt,
\qquad \mathcal I_n=\frac{T J_n}{W_n^2}\quad(W_n>0).
```

若 $`W_n=0`$，约定 $`\mathcal I_n=1`$，此时 $`F_n=0`$。Cauchy–Schwarz 给 $`\mathcal I_n\ge1`$。它是未中心化的四阶／二阶时间矩之比，不是中心峰度，也不是常通量假设。例如振幅只在长为 $`\ell`$ 的矩形脉冲中非零时，$`\mathcal I_n=T/\ell`$；一般情况下 $`T/\mathcal I_n`$ 只是有效持续时间，不等同于真实支撑长度。

对所有 $`\alpha>1/4`$，§3.2 已给

```math
S_W:=\sum W_n<\infty,\qquad
S_V:=\sum V_n<\infty,\qquad
V_n=\frac{K_n}{(n+1)^{2\alpha}}\int_0^T z_n^2\,dt.
```

保留四次积分，而不用粗界 $`J_n\le R^2W_n`$，可得

```math
F_n=h_n\int_0^T w_n^2z_n\,dt
\le\eta(n+1)^{2\alpha}\sqrt{V_nJ_n}
=\frac{\eta}{\sqrt T}(n+1)^{2\alpha}
\sqrt{\mathcal I_n}\,W_n\sqrt{V_n}.
```

取 $`2/3`$ 次幂，先对有限层号求和，再用指数 $`3/2`$ 和 $`3`$ 的 Hölder 不等式及单调极限，得到

```math
\sum_{n\ge0}
\frac{F_n^{2/3}}{(n+1)^{4\alpha/3}\mathcal I_n^{1/3}}
\le \left(\frac{\eta^2}{T}\right)^{1/3}
S_W^{2/3}S_V^{1/3}<\infty.\tag{TI}
```

**与能量缺陷的对应不能跳过。** 令

```math
\Delta(T)=\int_0^T(w_0+z_0)\,dt
-\frac12\sum_n(w_n(T)^2+z_n(T)^2)\ge0.
```

对包含所有低层及本层 $`w_n`$ 的切面写无黏积分预算。其向外净通量为 $`F_n`$ 减反向交换，再加两条弱纵向边；反向交换的时间积分至多
$`\eta R C_T2^{-n/2}(n+1)^{3\alpha}\to0`$，弱边项至多 $`TR^3(e_{n-1}+e_n)\to0`$。初值为零且该切面最终包含两个根，所以有限部分能量穷尽后确有

```math
F_n\longrightarrow\Delta(T).
```

因此若 $`\Delta(T)>0`$，式 (TI) 强制

```math
\sum_{n\ge0}(n+1)^{-4\alpha/3}\mathcal I_n^{-1/3}<\infty.\tag{NC}
```

这是正能量缺陷的必要条件，不是充分条件。反之，若这个级数发散，必有 $`\Delta(T)=0`$。

**可直接用于黏性族的条件结论。** 若存在 $`C\ge1`$、$`\delta\ge0`$，使所有充分小黏性和所有充分大层号均满足

```math
T\int_0^T (w_n^\nu)^4\,dt
\le C(n+1)^\delta
\left(\int_0^T(w_n^\nu)^2\,dt\right)^2,
```

其中 $`C,\delta`$ 和起始层号都独立于黏性，并且 $`4\alpha+\delta\le3`$，则 $`Q_\nu(T)\to0`$。证明：逐坐标时间一致收敛将矩不等式传给每个极限轨道；(NC) 的级数因 $`(4\alpha+\delta)/3\le1`$ 发散，故每个极限的 $`\Delta(T)=0`$。正黏性精确预算、根输入收敛和末端能量下半连续性给该子列 $`\limsup Q_\nu(T)\le\Delta(T)=0`$；子列反证得到整族结论。不在这里假定无黏演化唯一或末端能量强收敛。

### 3.4 保留正黏性：一个可计算但很粗的消失上界

本节固定 $`1/4<\alpha\le1/2`$，直接估计正黏性轨道，不经过无黏子列，也不使用 §3.3 的额外时间矩假设。仍取 $`R=\sqrt2T`$，暂略各量的上标 $`\nu`$。结论加强的是已知无耗散侧的定量控制，不扩大无条件分类区间。

**第一步：在黏性尚可控制的有限壳带内建立积分上界。** 令

```math
J_\nu=\left\lfloor\frac12\log_2(1/\nu)\right\rfloor,
\qquad N=\lfloor J_\nu/2\rfloor-1,
```

以下令黏性充分小，使 $`J_\nu\ge10`$、$`N\ge4`$。对 $`0\le n<J_\nu`$ 有 $`\nu4^{n+1}\le1`$。积分下一层弱出口方程时保留正黏性项，得到

```math
V_n\le A+B\sqrt{V_{n+1}},\qquad V_n\le2^nTR^2,
```

```math
A=R+TR^2+TR,\qquad
c_\alpha=\eta2^{2\alpha},\qquad B=c_\alpha R\sqrt T,
\qquad C=2A+16B^2+TR^2.
```

其中 $`TR`$ 是新保留的 $`\nu4^{n+1}\int w_{n+1}\,dt/(n+1)^{2\alpha}`$ 的上界；不是把黏性项丢掉。若某个 $`n\le\lfloor J_\nu/2\rfloor`$ 满足 $`V_n>C`$，则递推连续给 $`V_{n+1}>4V_n`$，并一直推到 $`J_\nu`$。于是

```math
V_{J_\nu}>4^{J_\nu-n}C
\ge2^{J_\nu}C\ge2^{J_\nu}TR^2,
```

与终端的粗界矛盾。因此 $`V_n\le C`$ 对 $`0\le n\le N+1`$ 成立。这里特意留出外层壳带作为增长反证的余量；没有将无黏无限层递推直接照搬到正黏性。

**第二步：有限积分和的统一控制。** 用与 §3.2 相同的有限求和，但增加黏性余项，记

```math
D=R\sqrt{1+\frac1{4\alpha-1}}+TR^2,
\qquad
\mathcal E_{\nu,N}
=\sum_{n=0}^N\frac{\nu4^{n+1}}{(n+1)^{2\alpha}}
\int_0^T w_{n+1}\,dt
\le\frac{16}{3}TR\nu4^N.
```

幂级数的积分比较给上式 $`D`$ 中的显式常数。设 $`S_N=\sum_{n=0}^N V_n`$，则

```math
S_N\le D+\mathcal E_{\nu,N}
+c_\alpha\sqrt{TR^2(S_N+C)},
```

从 Young 不等式和 $`\nu4^N\le1`$ 得

```math
S_N\le S_*:=2D+C+c_\alpha^2TR^2+\frac{32}{3}TR.
```

因此正向交换通量的有限加权和满足

```math
\sum_{n=0}^N\frac{F_n}{(n+1)^{2\alpha}}
\le L_*:=\eta R\sqrt{TR^2S_*}.
```

所有常数只依赖固定的 $`T,\alpha,\eta`$，不依赖黏性、所取壳带或 $`\beta\in[0,1]`$。

**第三步：切面预算直接控制全系统黏性耗散。** 对 $`1\le n\le N`$，把全部前层及本层 $`w_n`$ 列入内侧。全局预算减去内侧预算，得到外侧储能加黏性损失等于净跨面输入。舍弃外侧储能和负的反向交换，低壳黏性用 $`4^n`$ 控制，便有

```math
Q_\nu(T)\le\nu4^nTR^2+F_n
+TR^3(e_{n-1}+e_n)
\le\nu4^nTR^2+F_n+3TR^3 2^{-n}.
```

这是整个无限系统的真实黏性耗散上界，而不是只对低壳耗散的估计。任取 $`1\le m\le N`$，用 $`(n+1)^{-2\alpha}`$ 归一化平均，得到可计算的有限参数界

```math
0\le Q_\nu(T)\le
\nu4^NTR^2+3TR^3 2^{-m}
+\frac{L_*}{H_{m,N}},\qquad
H_{m,N}=\sum_{n=m}^N(n+1)^{-2\alpha}.\tag{QV}
```

另有平凡上界 $`Q_\nu(T)\le T^2`$，可与 (QV) 取较小者。整个论证只做有限层求和和精确预算，不假定末端能量强收敛。

**渐近读法。** 令 $`m=\lfloor\sqrt N\rfloor`$，则 $`\nu4^N\le\sqrt\nu/4`$，且 $`N`$ 与 $`\log(1/\nu)`$ 同量级。若 $`1/4<\alpha<1/2`$，积分比较给 $`H_{m,N}`$ 与 $`N^{1-2\alpha}`$ 同量级；若 $`\alpha=1/2`$，有 $`H_{m,N}\ge\log[(N+2)/(m+1)]`$。故

```math
Q_\nu(T)=
\begin{cases}
O_{T,\alpha,\eta}\!\left((\log(1/\nu))^{-(1-2\alpha)}\right),
&1/4<\alpha<1/2,\\
O_{T,\eta}\!\left(1/\log\log(1/\nu)\right),
&\alpha=1/2.
\end{cases}
```

这里都是充分小黏性下的**上界**，不是渐近等价式、下界或最优速度。不能说实际耗散一定按双对数下降，也不能仅凭此归因数值平台。

**切面位置：$`m=1`$ 已近最优，指数无法由此改进（2026-09-29 审计）。** (QV) 中 $`m`$ 是唯一自由参数。三项代价里 $`\nu4^NTR^2`$ 与 $`m`$ 无关，$`3TR^32^{-m}`$ 随 $`m`$ 指数减小，$`L_*/H_{m,N}`$ 随 $`m`$ 增大。在验证篇 §6 的既有算例 $`T=50,\eta=1,\alpha=1/2,\nu=10^{-14}`$（$`J_\nu=23,N=10`$）上按精确有理数逐项计算，取 $`m=1`$ 得总上界 $`1.01\times10^8`$，而取 $`m=\lfloor\sqrt N\rfloor=3`$ 得 $`1.34\times10^8`$；$`m=1`$ 即本例最小值。

更重要的是，**不能指望由此改进指数**。因为 $`H_{m,N}\le H_{1,N}\le\log(N+2)`$，而本节取 $`N=\lfloor J_\nu/2\rfloor-1`$ 故 $`N`$ 与 $`\log(1/\nu)`$ 同量级，于是

```math
H_{m,N}\le\log(N+2)=O\!\left(\log\log\frac1\nu\right)
\qquad\text{对一切 }1\le m\le N.
```

这正是 $`H`$ 的硬上界，故 (QV) 给出的 $`O(1/\log\log(1/\nu))`$ 在本证明结构内已是最优；想再收紧必须改进 $`L_*`$ 或 $`D`$ 中的常数或不等式本身，而不是重选 $`m`$。这也解释了为什么本例的界永远弱于平凡界 $`T^2`$：$`L_*\asymp T^{19/4}`$ 而 $`H`$ 只有对数增长，上界要优于 $`T^2`$ 需 $`\log(1/\nu)>T^{2.75}`$。所以本节确实证明最终消失，却仍不能预测本次计算范围内的耗散大小或平台消失位置；这也是一条负面结论——**在该框架内改善定量速率此路不通**。

这是 §3.2 的有限正黏性版本与加权切面预算的组合，方法仍属已有能量估计框架。定向检索双对数／零黏收敛速度没有形成对本条精确估计的充分文献排重，不将无命中当作原创性证据，也不因有了定量界就宣称达到强研究原创性目标。

### 3.6 对数族的新时间积分包络及集中度缺口

固定式 (L) 中 η=β=1、α>0，初值、外力与极限顺序不变。以下对任一固定窗无黏分量极限成立，既有存在性、紧性和 §3.1 的粗包络作为前提。新增结论是

```math
Y_n=K_n\int_0^Tz_n^2dt\le C_{T,\alpha}(n+1)^{2\alpha/3}.
```

这改善原来的 O((n+1)^(2α)) 上界，但本身不扩大已经证明的动态分类区间。特别是 α=2/3 时得到 Y_n≤C_T(n+1)^(4/9)，尚未得到 §3.3 所需的时间集中度。

**证明。** 记 R=√2T。旧包络给 Y_n≤C_old(n+1)^(2α)，因此

```math
G_n=h_n\int_0^Tw_nz_n^2dt
\le RC_{\rm old}(n+1)^{3\alpha}2^{-n/2},
\qquad \Gamma_\alpha=\sup_{n\ge1}(n+1)^{3\alpha}2^{-n/2}<\infty.
```

有限半切面预算给 F_n≤I_T+G_n≤L:=2T²+RC_oldΓ_α，n≥1。积分真实 w_n 方程，并像 §7.11 一样保留三次通量作 Cauchy–Schwarz，得到

```math
Y_{n-1}\le A+B_0(n+1)^{\alpha/2}Y_n^{1/4},
\qquad A=R+TR^2,\quad B_0=L^{1/2}T^{1/4}.
```

取 ρ=2α/3、U_n=Y_n/(n+1)^ρ。因 α/2+ρ/4=ρ，有

```math
U_{n-1}\le\frac{A}{n^\rho}
+B_0\left(\frac{n+1}{n}\right)^\rho U_n^{1/4}
\le A+BU_n^{1/4},\qquad B=2^\rho B_0.
```

置 C=max(1,2A,(2B)^(4/3))、X_n=U_n/C。固定 m，先进行有限 k 次后向迭代：

```math
X_m\le\max(1,X_{m+k}^{4^{-k}}).
```

末端只使用粗能量界 Y_(m+k)≤TR²2^(m+k)，故 log⁺X_(m+k)=O_(T,α,m)(1+k)，乘 4^(−k) 后趋零。令 k→∞ 得 X_m≤1，证明完成；常数不依赖 m 或所取极限，没有预设无穷和有限。

**真实下降估计仍留下两个缺口。** 记

```math
\lambda_n=h_nz_n+e_nz_{n+1},\qquad
\Lambda_n=\int_0^T\lambda_n^2dt,\qquad
W_n=\int_0^Tw_n^2dt,\quad J_n=\int_0^Tw_n^4dt.
```

正源项给 w_n′≥−λ_nw_n。将平方振幅的不等式从 t 积至 T，再用 Cauchy–Schwarz，得 w_n(t)²≤w_n(T)²+2√(Λ_nJ_n)。乘 w_n(t)² 并积分，随后用 Young 不等式，严格得到

```math
J_n\le2w_n(T)^2W_n+4\Lambda_nW_n^2,
\qquad
\mathcal I_n\le2T\frac{w_n(T)^2}{W_n}+4T\Lambda_n\quad(W_n>0).
```

新包络只能给

```math
\Lambda_n\le2(n+1)^{2\alpha}Y_n+2e_n^2TR^2
\le C_{T,\alpha}(n+1)^{8\alpha/3}.
```

在 α=2/3 上，这一幂次是 16/9，仍高于目标 1/3。末端 ℓ² 尾也不能直接控制 w_n(T)²/W_n，因为分母可能更快趋零。即使假设正缺陷 d>0，现有 F_n→d、F_n²≤(n+1)^(4α) V_nJ_n 和 J_n≤R²W_n，仅结合新包络只能给 W_n≥c_(T,d)(n+1)^(−16/9)，仍不足以消除这个比值。本节没有将均值、均方根或不同阶时间矩互换。

### 3.7 局部真实脉冲：仅凭正通量不能控制时间集中度

本节给一个有限、无黏、无迫的真实轨道反例，精确排除“只用局部方程、有界能量及正累计通量即可推出集中度界”的中间路线。它改变了原问题的初值及局部边界，**不是**共同零初值无限强迫模型的反例，不决定 α=2/3 的动态，也不产生黏性耗散。

固定 A,T>0，在高层 n,n+1 取封闭两层，保留双向同层交换、强纵向边及弱旁路。令 K=2^n、a=(n+1)^(2/3)、h=√K a、e=K^(−1)、g=h_(n+1)，四个坐标满足

```math
\begin{aligned}
w'&=h(z^2-wz)-ewb,&z'&=h(w^2-wz)-Kzy,\\
y'&=Kz^2+g(b^2-yb),&b'&=ew^2+g(y^2-yb),
\end{aligned}
\qquad (w,z,y,b)(0)=(A,0,A,A).
```

逐边守恒给能量恒等于 3A²/2，所有坐标非负且不超过 √3A；在 y=A 或 b=A 的边界上导数向内，故 y,b≥A。后层初始已有储能是本例的明确条件。

**不变区间与衰减。** 有限时间内 w>0，记 r=z/w，则精确有

```math
r'=hw(1-r)(1+r^2)-Kry+erb.
```

取 n 充分大，使 2h/K≤1/2 且 K²>2√3。在区域 w≤A、0≤r≤2h/K、y,b≥A 的边界 r=2h/K 上，利用 (1−r)(1+r²)≤1，得到 r′≤hA(−1+2√3/K²)<0；边界 w=A 上 w′≤0。故该区域不变，w 单调不增，并有 z≤(2h/K)w。

设 λ=A(h+√3K)、τ=(log 2)/λ。由 z′≥h w²−λz、z(0)=0 和 w 单调性，

```math
z(t)\ge\frac h\lambda(1-e^{-\lambda t})w(t)^2.
```

h/K≤1/4 使 λ≤2KA。因此 t≥τ 时，w′≤−h w z/2≤−a²w³/(8A)；另一方向始终有 w′≥−A(2a²+√3/K)w。令 W=∫₀ᵀw²、J=∫₀ᵀw⁴，对固定 T 和充分大的 n 得

```math
W\le\frac{A\log2}{K}
+\frac{4A}{a^2}\log(1+a^2AT/4),
\qquad
J\ge\frac{\log2}{16(2+\sqrt3)}\frac{A^3}{a^2}.
```

第一式由 w(t)²≤A²/[1+(a²A/4)(t−τ)]（t≥τ）积分得到；第二式在长为 (log 2)/[A(2+√3)a²] 的起始时段使用 w≥A/2，该时段在充分大 n 上包含于 [0,T]。于是

```math
\frac{TJ}{W^2}\ge c_{T,A}\frac{(n+1)^{4/3}}{\log^2(n+1)},
```

其增长快于任何固定常数乘 (n+1)^(1/3)。这是解的时间矩，不是人为拼接的时间函数。

**脉冲承载正通量。** 定义 F=h∫w²z、G=h∫wz²、B=e∫w²b、H=K∫z²y。w 能量预算精确给

```math
F-G=A^2/2-w(T)^2/2-B,
\qquad 0\le G\le(2h/K)F.
```

上面的衰减式给 w(T)→0，且 B≤√3A W/K→0。由 2h/K→0 得 F→A²/2、G→0；z 能量预算给 H=F−G−z(T)²/2→A²/2。这排除了“集中度很大只是因为没有有效传输”的解释。但整个四节点系统始终守恒，正通量不能称为能量耗散。

因此目标集中度证明必须增加来自整链起动历史的实际约束，不能将本节所用局部信息当作充分条件。原共同零初值轨道能否形成相应的下游储能及输入脉冲，仍未证明。新增结论和限定文献读取见[验证篇 §8.14](04-evidence-zh.md#814-对数时间矩筛选及局部脉冲障碍)。

### 3.8 首次通量到达：精确阈值桥及停止点

本节只处理 η=β=1、α=2/3 的既定零初值问题，固定 T 和无黏分量极限，记 R=√2T。令整层累计通量 C_n(t)=∫₀ᵗΦ_n，首次到达时间 τ_n(q)=inf{t:C_n(t)≥q}。C_n 连续非减，零初值有限预算给 C_(n−1)−C_n=(w_n²+z_n²)/2≥0，所以 τ_n(q) 随 n 非减。这一排序是原预算的直接推论；新增量化关系如下。

设 D(T)>q+ε>q>0，取 s=τ_(n−1)(q)、t=τ_n(q+ε)，n≥1。令 c=C_n(s)≤q，则 C_(n−1)(s)=q、C_n(t)=q+ε，且 (w_n(s)²+z_n(s)²)/2=q−c。将 [s,t] 上的 z_n 能量预算与此式相减，精确得到

```math
F_n[s,t]=\varepsilon+\frac{w_n(s)^2}{2}
+\frac{z_n(t)^2}{2}+G_n[s,t]-B_n[s,t],
```

其中 B_n 包含弱输入 e_(n−1)∫w_(n−1)²z_n 与弱出口 e_n∫w_n²z_(n+1)，没有遗漏根历史、回流或旁路。由 §3.6 的 Y_n≤C_T(n+1)^(4/9)，置 δ=t−s，得

```math
\varepsilon\le R^2\sqrt{C_T}(n+1)^{8/9}\sqrt\delta
+3R^3\,2^{-n}\delta.
```

若 ε≥6TR³2^(−n)，便有真实延迟下界

```math
\tau_n(q+\varepsilon)-\tau_{n-1}(q)
\ge\frac{\varepsilon^2}{4R^4C_T}(n+1)^{-16/9}.
```

它使用了整链零初值，却仍不足以排除有限累积到达：∑n^(−16/9) 有限；固定 ε 的差值又跨不同阈值，不能直接望远镜求和。若改用递增阈值 q_n=q_(n−1)+ε_n<D(T)，则必须有 ∑ε_n<∞，所得下界之和仍有限。同阈值 ε=0 时只剩实际端点暂存量，尚缺 w_n(τ_(n−1)(q)) 等沿移动时刻的联合下界；固定时刻的 ℓ² 预算不能直接控制这些不同时间的分量之和。

**局部预存单元不能直接拼接。** 若原零初值全链在某时刻有 w_n≥A、w_(n+1),z_(n+1)≥A，则 C_n≥A²、C_(n−1)≥3A²/2。以 §3.7 单元新增传输量 q=A²/2 计，该状态已经越过 τ_n(2q)、τ_(n−1)(3q)，不能拿来估计首次同阈值差。

此外，全链若在 [s,s+L] 上有 z_(n+1)≥A，令 K=K_n、x=w_(n+2)，真实方程给

```math
x'\ge2KA^2-D_nx,\qquad
D_n=R\left[2\sqrt K(n+3)^{2/3}+\frac1{4K}\right].
```

由 x(s)≥0、x≤R 得 (2KA²/D_n)(1−e^(−D_nL))≤R。若 ρ_n=RD_n/(2KA²)≤1/2，则

```math
L\le\frac{-\log(1-\rho_n)}{D_n}\le\frac{R}{KA^2}.
```

每个固定 A,R 在充分大 n 上均满足此条件。接收强出口坐标维持 A 的时间至多为 O(2^(−n))，不能像封闭单元那样持续整个 O(n^(−4/3)) 脉冲期；完整方程中的 −K_(n+1)z_(n+1)w_(n+2) 正是破坏原下界的不省略项。该结论不排除移动的多层脉冲或衰减中的接收量。

本批停在上述真实时序关系和明确的可求和障碍，α=2/3 动态仍开放。不继续仅用相同预算尝试 MB，也不将不同时间的预存成本相加冒充无穷能量矛盾。

### 3.9 零初值轨道的接收屏障与 z 通道黏性一致强尾

固定式 (L) 的 η=β=1、α>0、双根单位力、共同零初值及既有极限顺序，不改变模型。记 a_n=(n+1)^α、h_n=√K_n a_n、K_n=2^n、M_n=K_n²。正黏性无限层解的共同基础作为前提。以下是新轨道估计，不是新的异常耗散分类。

**命题。** 对每个 T>0，令 R=√2T。存在只依赖 α 的 C_α，使所有 ν>0、n≥1 和 0≤t≤T 满足

```math
z_n^\nu(t)\le C_\alpha R
\left(\frac{a_n}{\sqrt{K_n}}\right)^{1/4}.
```

特别地，整个正黏性族的 z 能量尾满足

```math
\sup_{\nu>0}\sup_{0\le t\le T}
\sum_{n\ge N}(z_n^\nu(t))^2
\le C_\alpha^2R^2\sum_{n\ge N}(n+1)^{\alpha/2}2^{-n/4}
\longrightarrow0.
```

因此，沿任何已经逐坐标在 [0,T] 一致收敛的零黏子列，z^ν→z 于 C([0,T];ℓ²)。不要求无黏极限唯一，不声称整族共享一个极限。对每个无黏分量极限还有更快的点态界

```math
z_n(t)\le C_\alpha R
\left(\frac{a_n}{\sqrt{K_n}}\right)^{1/3}.
```

**第一步：一般接收屏障。** 设非负 C¹ 函数 z,x 满足 z′≤A、x′≥Kz²−Bx，其中 A,K>0、B≥0。定义

```math
f(z)=\frac{Kz^3}{3(A+Bz)},\qquad
f'(z)=\frac{Kz^2(3A+2Bz)}{3(A+Bz)^2}\ge0.
```

直接计算给出

```math
Kz^2-Bf(z)-Af'(z)
=\frac{KBz^3(3A+2Bz)}{3(A+Bz)^2}\ge0.
```

故 F=x−f(z) 满足 F′≥−BF；若 x(0)≥f(z(0))，Gronwall 给 x(t)≥f(z(t))。这是有限坐标微分比较，不涉及无限求和。

**第二步：保留完整图与黏性。** 固定 n≥1，取 z=z_n^ν、x=w_(n+1)^ν。共同能量界给所有坐标≤R。真实方程因此满足

```math
\begin{aligned}
(z_n^\nu)'&\le A_n-\nu K_n^2z_n^\nu\le A_n,
& A_n&=(h_n+e_{n-1})R^2,\\
(w_{n+1}^\nu)'&\ge K_n(z_n^\nu)^2-B_n^\nu w_{n+1}^\nu,
& B_n^\nu&=(h_{n+1}+e_{n+1})R+\nu M_{n+1}.
\end{aligned}
```

接收坐标的同层损失和弱纵向出口均计入 B_n^ν，额外正源只改善下界。两坐标初始为零，满足屏障初始条件。结合 x≤R、z≤R，得到

```math
K_n(z_n^\nu)^3
\le3R(A_n+B_n^\nu z_n^\nu)
\le3R(A_n+B_n^\nu R).
```

置 p_n=a_n/√K_n、d_n^ν=νK_n/R。对 n≥1，有 e_(n−1),e_(n+1)≤h_n 及 h_(n+1)/h_n≤√2(3/2)^α。可取 c_α=3[3+√2(3/2)^α]，于是

```math
\left(\frac{z_n^\nu}{R}\right)^3
\le c_\alpha p_n+12d_n^\nu.
```

12 来自 M_(n+1)=4K_n²，不能把这个黏性项直接删去来宣称统一尾界。另一方面，保留 z 方程的实际阻尼并用零初值比较，得到

```math
\frac{z_n^\nu(t)}R
\le\frac{(h_n+e_{n-1})R}{\nu K_n^2}
\le\frac{2p_n}{d_n^\nu}.
```

**第三步：两个黏性区间合并。** 当 p_n≤1、d_n^ν≤p_n^(3/4) 时，p_n≤p_n^(3/4)，屏障给 z_n^ν/R≤(c_α+12)^(1/3)p_n^(1/4)。当 d_n^ν≥p_n^(3/4) 时，阻尼界给 z_n^ν/R≤2p_n^(1/4)。p_n>1 时直接用 z_n^ν/R≤1≤p_n^(1/4)。取 C_α=max(1,2,(c_α+12)^(1/3))，证明黏性一致命题。

先固定 n 沿坐标零黏子列取极限，屏障中的 d_n^ν 消失，再对所得同一极限的全部层号使用点态界，可得 p_n^(1/3) 版本。这个顺序没有删去正黏性高层的阻尼贡献。

尾界的右侧是层号多项式乘指数衰减，故可求和。沿坐标一致收敛子列，先以这个统一尾压低 ∑_(n≥N)|z_n^ν−z_n|²，再在有限头部取极限，得到 C([0,T];ℓ²) 强收敛。根层由有限坐标收敛处理。z 的末端能量因而实际收敛；w 的黏性一致强尾仍未证明。本节尾界本身不控制含 K_n² 的累计黏性积分，不能单凭它推出 Q_z→0 或全向量强收敛；后续 §3.11 另用真实通道预算证明 Q_z→0。

```math
Q_{w,\ge N}\le\frac{C_T}{\nu K_N}Q_{z,\ge N-1}
\le C_T\left(\frac{a_N}{\nu^2K_N^{5/2}}
+\frac1{\nu K_N^2}\right)
```

（N 充分大）。这份远尾界要求 b>4/5，两者无共同截点。此处只说明指定估计不足，不是原轨道反例或所有方法不可能。实际被粗化的量是接收端 K_nw_(n+1)(t) 的时间占有；新的头部定位没有消除该信息缺口。本批停在上述真实定位与残项，不继续重复同一预算、调截点或分类全部中间区间。限定验证见[验证篇 §8.20](04-evidence-zh.md#820-w-通道头部定位与未闭合的移动通量)。

### 3.14 精确饱和积分数组与点态能量不相容

本节是一次有限可实现性排除，不是原方程反例或 α=2/3 的动态分类。固定时间区间 (0,1)、a_n=(n+1)^(2/3)，置 τ_n=a_n^(−2)、c_n=τ_n/τ_(n+1)。考察以下拟议标量数组：

```math
W_n=J_n=\tau_n,\qquad Y_n=c_n^2,\qquad
F_n=H_n=c_n,\qquad
\mathcal R_n=c_{n-1}^2-c_n\ (n\ge1),\qquad\varepsilon_n=0.
```

这里 ℛ 只是拟议余项，不是另已构造出的轨道端点；c 也不是 §7 的几何剖面。数组有 ∑W_n=∑J_n<∞、F_n,H_n→1、ℛ_n>0、nℛ_n→4/3，因而 ∑ℛ_n²<∞ 且 ℛ_n/Y_(n−1)→0。若只检查这些数值及 §3.10 的两条相关式，它看似容许非零尾通量。但实际函数定义带来额外约束。

**命题。** 不存在非负可测函数列 w_n,v_n，使上述 W=∫w²、J=∫w⁴、Y=a²∫v²、F=a²∫w²v 同时成立，且对 n≥1 有

```math
a_n^2\langle w_n,v_n\rangle=Y_{n-1}-\mathcal R_n=c_n,
\qquad\langle v_n,w_{n+1}\rangle=W_n=\tau_n,
\qquad\mathop{\mathrm{ess\,sup}}_{t\in(0,1)}\sum_nw_n(t)^2<\infty.
```

**证明。** ∫v_n²=c_n²τ_n，而 〈w_n,v_n〉=c_nτ_n 正好达到 Cauchy–Schwarz 等号，故 v_n=c_nw_n 几乎处处。F_n=c_n 又给 ∫w_n³=τ_n。于是

```math
\int_0^1w_n^2(w_n-1)^2dt
=J_n-2\int_0^1w_n^3dt+W_n=0.
```

因此 w_n=1_(E_n)，|E_n|=τ_n。第二相关式使 c_n|E_n∩E_(n+1)|=τ_n，故交集测度为 τ_(n+1)=|E_(n+1)|；E_(n+1)⊆E_n 相差零集。对任意有限 M≥1，正测度集合 E_M 上，w_1,…,w_M 全为 1，所以 ∑w_n²≥M。M 任意，否定统一点态能量界。只需有限交集，不需要无限交集有正测度。证毕。

平移或拆碎时间支撑不能修复这个精确数组，因为嵌套是相关式强迫的。H_n=c_n 在嵌套实现中也自动成立，却不消除矛盾。形式选择 w_n=1_[0,τ_n]、v_n=c_nw_n 的确实现上述积分值，但违反点态能量；它亦没有满足原方程的零初值、端点及真实 ε 定义。撤回用此数组证明“全部已知必要信息仍不足”的尝试。一般带误差的矩列和实际轨道仍未裁定，不能从精确饱和的排除推出总耗散消失。限定核查见验证篇 §8.21。

### 3.15 有限壳块的带权时间相关性障碍

本节先给一个有限函数不等式，再接入 §3.10 的实际无黏轨道。非负函数 w_k,v_k∈L²(0,T)，块为 [n,m]，假设各 W_k=∫w_k²>0、∫v_k²>0，且几乎处处 ∑_(k=n)^m w_k²≤R²。令 J_k=∫w_k⁴、q_k=w_k/√W_k、p_k=v_k/||v_k||₂，定义

```math
\rho_i=\langle q_i,p_i\rangle,\qquad
\sigma_i=\langle p_i,q_{i+1}\rangle,\qquad
\delta_i=(1-\rho_i)+(1-\sigma_i),
\quad S_{n,m}=\sum_{k=n}^mW_k,
\quad B_i=\frac{\sum_{k=i+1}^m(k-n)W_k}{S_{n,m}}.
```

ρ,σ∈[0,1]，0≤B_i≤m−n。没有假设 W 的相邻比值。有限块估计为

```math
\frac{J_n}{W_n}
\le 2R^2\frac{W_n}{S_{n,m}}
+8R^2\sum_{i=n}^{m-1}B_i\delta_i.
```

**证明。** 按 W_k 加权 q_n²≤2q_k²+2(q_n−q_k)²，得

```math
S_{n,m}q_n^2\le2R^2+2\sum_{k=n}^mW_k(q_n-q_k)^2.
```

乘 w_n² 积分，使用 w_n²≤R²，有 J_n/W_n≤2R²W_n/S+2R²∑W_k||q_n−q_k||₂²/S。而

```math
\|q_i-q_{i+1}\|_2^2
\le2\|q_i-p_i\|_2^2+2\|p_i-q_{i+1}\|_2^2
=4\delta_i,\qquad
\|q_n-q_k\|_2^2\le4(k-n)\sum_{i=n}^{k-1}\delta_i.
```

交换有限求和即得命题。它量化了同时活跃的容量与时间波形迁移，不要求精确 Cauchy–Schwarz 等号。

**接入真实通量。** 使用 §3.10 的 v_n=√K_n z_n/a_n，实际 F_n=a_n²∫w_n²v_n 满足 F_n²≤a_n²Y_nJ_n。因此每个高层有限块有

```math
\sum_{i=n}^{m-1}B_i\delta_i
\ge\max\left(0,
\frac{F_n^2}{8R^2a_n^2Y_nW_n}
-\frac{W_n}{4S_{n,m}}\right).
```

若正缺陷 d>0，则充分高层 F_n≥d/2、Y_n≤Ca_n^(2/3)，右侧第一项至少 d²/(32CR²a_n^(8/3)W_n)。原轨道的内积和余项没有被替换；不据此假设相关系数趋 1 或块容量趋无穷。

**带误差的排除范围。** 任意具有统一点态能量界的函数列，若 W_(n+1)/W_n→1 且 ρ_n,σ_n→1，则 J_n/W_n→0。证明是先固定块长度 M=m−n+1，S/W_n→M，相关损失项趋零，得到 limsup J_n/W_n≤2R²/M；再令 M→∞。因此 §3.14 的精确数组，以及保持这些渐近条件且 liminf J/W>0 的扰动，均被排除。该数组的 σ=c_n^(−1/2)<1，不能误写成相关损失精确为零。实际 α=2/3 轨道尚未证明上述渐近前提，不能用这个推论分类耗散。

### 3.16 α=2/3 的端点累计量与条件能量守恒

只固定 α=2/3、η=β=1、共同零初值、双根单位力及一个 T>0。对既有无黏分量极限，记 d(T)=I_T−E(T)≥0。若 d>0，§3.10 的下界保证高层 W_n,Y_n 和两条内积均正。置

```math
b_n=W_nY_{n-1}^2,\qquad
r_n=\frac{\mathcal R_n}{Y_{n-1}},\qquad
s_n=\frac{\varepsilon_n}{W_n},\qquad
\ell_n=-\log(\rho_n\sigma_n)\ge0.
```

这里 r_n 是本节归一化余项，不是 §7 的几何剖面。真实两条相关式精确给出

```math
\frac{b_{n+1}}{b_n}
=\frac{(1-r_n)^2(1-s_n)^2}{\rho_n^2\sigma_n^2}.
```

**累计误差可以控制，端点本身不能删除。** §3.10 已给 Y_(n−1)≥c_(d,T)>0、W_n≥c_(d,T)a_n^(−8/3)，以及 ℛ_n=w_n(T)+O(a_n^(5/3)K_n^(−1/2)+K_n^(−1))、指数小的 ε_n。末端 w(T)∈ℓ² 于是保证

```math
\sum_nr_n^2<\infty,\qquad
\sum_n\left|r_n-\frac{w_n(T)}{Y_{n-1}}\right|<\infty,
\qquad\sum_n|s_n|<\infty.
```

选固定 L 充分大，使 |r_n|,|s_n|≤1/2。只对 L≤n<N 作有限对数求和，并用 −log(1−x)=x+O(x²)，得到对所有 N>L 一致的

```math
\sum_{n=L}^{N-1}\frac{w_n(T)}{Y_{n-1}}
=\frac12\log\frac{b_L}{b_N}
+\sum_{n=L}^{N-1}\ell_n+O_{T,d,L}(1).
```

这不是把逐层 o(1) 当成可求和误差：平方余项及指数项可求和，不能求和的端点作为左侧实际量保留。∑W_n≤TR²<∞ 保证存在 N_j→∞、N_jW_(N_j)→0。Y_(N_j−1)²≤C N_j^(8/9) 给

```math
\sum_{n=L}^{N_j-1}\frac{w_n(T)}{Y_{n-1}}
\ge\frac1{18}\log N_j
+\frac12\log\frac1{N_jW_{N_j}}
+\sum_{n=L}^{N_j-1}\ell_n-C_{T,d,L}.
```

第二个对数项亦趋于无穷。任何正缺陷因此必须承担至少对数增长的端点累计量，并补偿实际相关性损失。

**条件守恒及真实黏性推论。** 若该极限终点 w(T)∈ℓ¹，则 d(T)=0。否则上述下界使 ∑w_n(T)/Y_(n−1)=∞，却由 Y_(n−1)≥c>0 得该和≤c^(−1)∑w_n(T)<∞，矛盾。因此正缺陷强迫 ∑w_n(T)=∞。

进一步，若正黏性整族在同一个固定 T 满足

```math
\sup_{0<\nu\le\nu_0}\sum_{n\ge0}w_n^\nu(T)<\infty,
```

则 Q_ν(T)→0。任取 ν_j↓0，沿既有坐标紧性取子列，非负 Fatou 给极限终点 ℓ¹，故 d=0；根输入收敛及末端能量 Fatou、正黏性精确预算给 limsup Q_(ν_j)≤d=0。子列反证得到整族结论。同理，若 ν_j→0 且 liminf Q_(ν_j)(T)>0，则 ∑w_n^(ν_j)(T)→∞；否则有终点和有界的子列，沿它得到同一矛盾。和可理解为扩展非负数，不预设每个正 ν 的端点属于 ℓ¹。

本节没有证明实际终点 ℓ¹ 上界，也没有分类 α=2/3。末端 ℓ² 与对数累计量相容，例如 1/n 型非负数列仍平方可和；这只解释尚未形成矛盾，不是满足原方程的例子。有限块新估计和端点判据均有独立限定核查，见验证篇 §8.22。本批停止一般相关性估计的继续加工，后续须取得新的实际端点或时间迁移控制。

### 3.17 接收端占有量与发送端的真实衰减下界

本节执行 §3.16 后的一项有限轨道估计，不假设终点 ℓ¹ 界或时间相关系数近饱和。仍固定 α=2/3、η=β=1、共同零初值和双根单位力；对 ν>0 的既有无限层解，或 ν=0 的既有分量极限，均使用完整坐标方程。固定 0≤s<t≤T、n≥1，R=√2T，记 w=w_n、z=z_n、x=w_(n+1)、K=K_n、h=h_n、a=a_n，所有坐标≤R。给定接收水平 A>0，置

```math
\Delta=t-s,\qquad c=\frac{h}{KA+\nu K^2},\qquad
B=e_nR+\nu K^2+c e_{n-1}R^2,\qquad
\kappa=c h e^{2cR},\qquad
\mathcal P(s,t)=cK\int_s^tz(r)(A-x(r))_+dr.
```

**命题：保留接收端低于 A 的时间积分。** 若 w(s)>0，则

```math
w(t)\ge
\frac{w(s)\exp[-cR-B\Delta-\mathcal P(s,t)]}
{\sqrt{1+2\kappa w(s)^2\Delta}}.
```

𝒫 非负，是接收端低于水平 A 时实际 z 振幅加权的积分；不能只用接收端的瞬时值代替它。该式也不允许删去发送端 νK² 阻尼。特别地，若

```math
w(t)\le\tfrac12w(s),\qquad
cR+B\Delta+\mathcal P(s,t)\le\tfrac12\log2,
```

则 Δ≥1/(2κw(s)²)。κ>0 在当前 h>0、A>0 的模型中自动成立。

**证明。** 舍去实际发送源及 z 方程的负交换，完整图给

```math
\frac{w'}w\ge-hz-e_nR-\nu K^2,\qquad
z'\le hw^2+e_{n-1}R^2-(Kx+\nu K^2)z.
```

正发送源保证 w(s)>0 后在有限区间始终为正，故对数合法。对 U=w exp(−cz) 精确相减，得到

```math
\frac{U'}U\ge-chw^2-B+cKz(x-A)
\ge-\kappa U^2-B-cKz(A-x)_+.
```

第二步用了 w²=U²exp(2cz)≤U²exp(2cR)。令 p(r)=cKz(r)(A−x(r))_+、Λ(r)=∫_s^r(B+p)。U^(−2) 的微分不等式及积分因子给

```math
U(t)\ge\frac{U(s)e^{-\Lambda(t)}}
{\sqrt{1+2\kappa U(s)^2\int_s^te^{-2\Lambda(r)}dr}}.
```

Λ≥0，故其中积分≤Δ；使用 U(s)≥w(s)e^(−cR)、U(s)≤w(s)、w(t)≥U(t)，得到所示下界。半衰条件令右侧≤w(s)/2，从而 1+2κw(s)²Δ≥4exp[−2(cR+BΔ+𝒫)]≥2，证明半衰期下界。

**占有项的有限接收预算。** 记 L_(n+1)(s,t)=∫_s^t h_(n+1)z_(n+1)，则

```math
\mathcal P(s,t)\le
\frac{aA}{A+\nu K}
\sqrt{A\Delta\left[1+L_{n+1}(s,t)
+e_{n+1}R\Delta+4\nu K^2\Delta\right]}.
```

证明不假设 x(s)=0。真实接收方程给 x′≥Kz²−D(r)x，其中 D=h_(n+1)z_(n+1)+e_(n+1)z_(n+2)+4νK²。对 min(x,A) 使用 AC 链式法则，得 K∫_{x<A}z²≤A(1+∫D)；水平集 {x=A} 上导数几乎处处为零。再用 (A−x)_+≤A1_(x<A) 及 Cauchy–Schwarz，得 𝒫≤cA√K√[AΔ(1+∫D)]。cA√K=aA/(A+νK)，控制 D 的弱项即得结果。保留的是实际接收阻尼积分 L_(n+1)，没有粗替成 h_(n+1)RΔ。

**条件下的非可求和尺度及实际缺口。** 在无黏极限 ν=0，若整个区间 x≥A，则 𝒫=0。取 A=A_n=c_0 a_n^(−2/3)，并假设 0<w_n(s)≤C_0 a_n^(−2/3)。由于 cR=(R/c_0)a_n^(5/3)K_n^(−1/2)→0、B T→0，全部充分高层在 Δ≤T 下满足上述半衰小量条件，且 κ≤2a_n²/A_n。因此任何这样的半衰事件满足

```math
\Delta\ge\frac{A_n}{4a_n^2w_n(s)^2}
\ge\frac{c_0}{4C_0^2}a_n^{-4/3}
=\frac{c_0}{4C_0^2}(n+1)^{-8/9}.
```

这些下界的层号级数发散，但原轨道尚未统一保证接收端持续高于 A_n 或起始振幅上界，各层半衰区间亦可能重叠；不能据发散级数宣布整链传递时间发散、终点 ℓ¹ 界或 Q→0。一般区间中 𝒫 及实际接收阻尼积分仍未控。该引理明确了尾估计所缺的联合时间信息，超出只估总积分或形式消去 z 的路线；到此停止本批，后续须控制实际占有项或区间衔接。限定局部核查见验证篇 §8.23。

## 4. 稳态障碍可到四分之三，但不代替动态证明

假设 $`\alpha\le3/4`$ 时有正的有限能量无黏稳态，令 $`I=w_0+z_0>0`$。弱边通量随层号趋零，有限预算使充分大层号满足

```math
h_nw_n^2z_n\ge I/2,\qquad
w_{n+1}\le\frac{4\eta^2}{I}(n+1)^{2\alpha}w_n^4.
```

令 $`\rho=2\alpha/3`$、$`v_n=(n+1)^\rho w_n`$，则

```math
v_{n+1}\le C_*v_n^4,\qquad
C_*=\frac{4\eta^2}{I}2^{\max(\rho,0)}.
```

因 $`\sum(n+1)^{-2\rho}=\infty`$，有限能量要求 $`v_n`$ 在任意远处都能任意小。选充分大的 $`N`$ 使 $`q=C_*^{1/3}v_N<1`$，则 $`v_{N+j}\le C_*^{-1/3}q^{4^j}`$。然而

```math
z_n\ge\frac{I}{2\eta}\,2^{-n/2}(n+1)^{\alpha/3}v_n^{-2},
```

随该迭代超指数增长，与有限能量矛盾。因此此范围不存在有限能量无黏非负稳态；黏性稳态范数也必随黏性趋零而发散，否则有界子列会给出这样的稳态。正根外力和正纵向边排除了非负稳态中的零坐标。

本节本身不能推出动态无耗散。§3 已独立处理到 $`\alpha=1/2`$，而 $`1/2<\alpha\le3/4`$ 仍未知。有限时间与长期稳态的区别仍然保留。

## 5. 比较的是具体判据，不是整个文献的最优结果

同时令 $`\beta=0,e_n=0`$ 的删边链仍适用 §2 的证明：下一层平衡及弱出口增长下界只会变为附录 A4 §A4.4.2 已逐项验证的式子。不是使用加边／删边的耗散单调性。重编号后

```math
p_{2n}=\eta2^{n/2}(n+1)^\alpha,\qquad p_{2n+1}=2^n.
```

附录 A4 §A4.7.2 从旧方法推导的级数 $`\sum(p_{j+1}/p_j^2)^{1/3}`$，偶数支为

```math
\eta^{-2/3}\sum_{n\ge0}(n+1)^{-2\alpha/3}.
```

它仅在 $`\alpha>3/2`$ 收敛；奇数支有指数衰减，$`\sum1/p_{j+1}`$ 也收敛。因此 $`3/4<\alpha\le3/2`$ 内，稳态比较已给共同初值固定窗口异常耗散，而这条具体级数充分条件不满足。尤其 $`\alpha=1`$ 提供明确实例。

### 5.1 归一化稳态递推是旧形式，交错阻尼不满足最近证明的条件

本节仅比较 β=e=0 的链，不改完整模型。取[验证篇 §8.1](04-evidence-zh.md#81-删边后四分之三从哪里来)构造的正无黏常通量尾部 q_j，满足 p_j q_j² q_(j+1)=J。它只是尾部归一化参照，不预设已匹配受迫根。对任一正黏稳态 b_j^ν，置 r_j=b_j^ν/q_j。在相邻通量关系均成立的尾部（可取 j≥3），坐标方程恰给

```math
r_{j-1}^2=r_jr_{j+1}+\mu_jr_j,\qquad
r_{j+1}=\frac{r_{j-1}^2}{r_j}-\mu_j,\qquad
\mu_j=\frac{\nu m_jq_j^2}{J}.
```

这与 [Cheskidov–Friedlander (2009)](https://arxiv.org/html/0810.3718) Eqs. (2.1)、(2.4) 的归一化递推形式相同，差别在阻尼序列。原文 μ_j=μ2^(κj)，κ=2(1−c/3)，Theorem 2.2 用 c>3/2 即 κ<1。其证明 Eq. (2.3) 对增量 a_j=r_j−r_(j−1) 给

```math
a_{j+1}=-a_j\left(1+\frac{r_{j-1}}{r_j}\right)-\mu_j.
```

若 a_j≥0，则 a_(j+1)≤−μ_j<0，下一步给 a_(j+2)>2μ_j−μ_(j+1)。原文的几何系数保证右端为正，从而反复迭代反证；这里比较的正是这一充分条件，不宣称所有单调性证明必须如此。

本链的 m_(2n)=m_(2n+1)=4^n；用已推得的无黏尾部渐近式，任何固定 α、η、ν>0 均有

```math
\frac{\mu_{2n+1}}{\mu_{2n}}
\sim\eta^2 2^{-n}(n+1)^{2\alpha}\longrightarrow0,
\qquad
\frac{\mu_{2n+2}}{\mu_{2n+1}}
\sim4\eta^{-2}2^n(n+1)^{-2\alpha}
\left(\frac{n+2}{n+1}\right)^{-4\alpha/3}\longrightarrow\infty.
```

ν 与 J 在比值中消去。因此 2μ_j−μ_(j+1)>0 的条件在奇数 j 上最终失败，不能把原文的几何系数直接换成本序列来完成那套单调性反证。这不证明本链稳态必定不单调，也不证明所有已知一致界方法失效或我们的界首创。§2 的增长包络证明没有使用该相邻阻尼条件，仍按原证明保留；待排重的实质候选收缩为退化系数下的一致界及其动态应用，而非递推形式或平方差方法。

## 6. 第一项稳健性筛选：任意逐层有界交换扰动

本节响应机制探索计划，但不另造一个名称不同的模型。只扩大式 (L) 的静态系数类：固定 $`\alpha>3/4`$，将 $`\eta`$ 和 $`\beta`$ 换为序列，满足

```math
h_n=\eta_n2^{n/2}(n+1)^\alpha,\qquad
0<\eta_-\le\eta_n\le\eta_+<\infty,\qquad
0\le\beta_n\le b_+<\infty.
```

它们独立于时间和黏性，不要求随层号单调、收敛或周期；其余强边、弱边、外力、黏性及共同零初值保持不变。在式 (L) 中，同一层出现的两个 $`\beta`$ 都替为同一个 $`\beta_n`$，因此仍是逐边守恒，而非独立扰动两个方程造成能量缺陷。

**内部命题。** 这一整类模型仍有足够长固定窗口的黏性异常耗散，下界与起始窗口可只依赖 $`\alpha,\eta_-,\eta_+,b_+`$，不依赖具体序列或黏性。证明如下，不使用“增加回流会减少耗散”等未经证明的单调性。

### 6.1 正黏性构造与两条稳态包络

令 $`b=\max(1,b_+)`$、$`H=\eta_+\sqrt{D_\alpha}`$。两条同层边的系数分别不超过 $`HK_n`$ 和 $`bHK_n`$；正文基础 §3–4 的双线性估计可取常数 $`1+(1+b)H`$，节点流出估计可取 $`1+bH`$。有限截断、强加权尾界、稳态构造及相对能量重排均仍适用，因为每类边的邻接关系没有改变。只使用正系数及这些上界，不使用层间系数相等。由此先取得每个固定正黏性的正有限能量稳态。

记其输入为 $`I=w_0+z_0`$。强出口包络仍可取

```math
A_z^3=8(1+H),\qquad z_n\le A_z I^{1/3}2^{-n/3}.
```

理由是下一层弱出口平衡中，反向交换 $`\beta_{n+1}h_{n+1}z_{n+1}^2`$ 是可舍弃的非负输入。该平衡给

```math
\max(z_{n+1},z_{n+2})\ge
\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}+e_{n+1}},
```

正是 §2.1 所需式子，分母仍不超过 $`2(1+H)K_n`$，与 $`\beta_n`$ 无关。

弱出口选择更大的常数

```math
A_w^3=1+8b^3A_z^3D_\alpha+
\frac{8(bH+D_\alpha+1)}{\eta_-^2}.
```

若 $`w_n>A_wI^{1/3}(n+1)^{-2\alpha/3}`$，强包络保证 $`w_n>2b z_n`$。包含所有前层和本层 $`w_n`$ 的稳态切面预算给净交换通量不超过 $`I`$；其他出边及黏性损失非负，因此

```math
\tfrac12h_nw_n^2z_n\le
h_nw_nz_n(w_n-\beta_n z_n)\le I.
```

由强出口方程、上式的 $`z_n`$ 上界和 $`\nu M_n w_n^2\le I`$ 得

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{\beta_n h_n}{K_n}w_n-\frac{I}{K_nw_n^2},
\qquad
\frac{w_{n+1}}{w_n}>
\frac{\eta_-^2A_w^3}{2}-bH-\frac{D_\alpha}{A_w^3}>2.
```

阈值随层号递减，增长迭代与该稳态有限能量矛盾，故

```math
w_n\le A_wI^{1/3}(n+1)^{-2\alpha/3}.
```

至此没有使用 $`h_{n+1}/h_n`$ 或 $`\beta_{n+1}/\beta_n`$ 的规则性，也不需除以可能为零的 $`\beta_n`$。

### 6.2 返回同一零初值轨道

使用 §2.3 相同的 $`C`$、$`B=2^{1/4}C^{3/4}`$ 和 $`C_0=2B`$，但代入本节的包络常数。正黏性稳态范数不超过 $`B`$；相对能量恒等式给全时轨道范数不超过 $`C_0`$。根和 $`s=w_0+z_0`$ 的负交换项是 $`-(1+\beta_0)h_0w_0z_0`$，故可统一取

```math
L=1+[1+(1+b)\eta_+]C_0,\qquad s'\ge2-Ls.
```

精确能量预算再次给

```math
\frac{Q_\nu(T)}T\ge\frac1L>0
\quad\text{对所有 }0<\nu\le1,\quad
T\ge\frac2L+\frac{LC_0^2}{2}.
```

例如 $`\alpha=1`$、任意 $`\eta_n\in[1/2,2]`$ 和 $`\beta_n\in[0,10]`$ 都在这一充分类内。数字 10 不是临界回流强度；任何固定有限上界都可处理，代价是本组保证常数变差。这里反向边是同尺度回流，不是所有跨尺度逆向级联的统一结论。

## 7. 一般非单调交换：可求和条件与稀疏瓶颈

本节研究瓶颈的强度、次数与排列，而非只调对数指数。2026-09-30 先证明逐层可求和条件 (GS)，随后改用常通量递推决定的未来几何平均，得到更强的 (GP)。旧 (GS) 保留为推论，完整旧包络证明可由过程篇所记 Git 版本恢复。没有引入新基本作用律；实质原创性仍待排重，见[验证篇](04-evidence-zh.md)。

### 7.1 命题及固定黏性基础

保留式 (L) 的两条纵向边、黏性、两个单位根外力及共同零初值，只在两个方程中同时将 $`h_n`$ 换为 $`2^{n/2}a_n`$、$`\beta`$ 换为 $`\beta_n`$。假定系数固定且独立于时间和黏性，并满足

```math
a_n\ge a_->0,\quad 0\le\beta_n\le b_+<\infty,\quad
H=\sup_n a_n2^{-n/2}<\infty,\qquad
r_n=\exp\!\left[-2\sum_{k\ge0}4^{-k-1}\log a_{n+k}\right],
\quad P=\sum_nr_n^2<\infty.\tag{GP}
```

**充分条件定理。** (GP) 蕴含存在 $`T_*,\varepsilon>0`$，使全部 $`0<\nu\le1`$、全部固定 $`T\ge T_*`$ 满足 $`Q_\nu(T)/T\ge\varepsilon`$。不要求单调、相邻比值受控或与固定幂序列上下可比。§7.7 进一步证明：在本系数上、下界类内，$`P<\infty`$ 对有限能量无黏稳态存在及黏性稳态一致有界恰是充要条件；不是动态耗散的充要分类。

原逐层条件 $`S=\sum a_n^{-4/3}<\infty`$ 称为 (GS)。它蕴含 (GP)，但并非必要，详见 §7.5–7.6。原对数族负侧分类不能自动套用到一般序列。

记 $`b=\max(1,b_+)`$。因 $`h_n\le HK_n`$、$`\beta_nh_n\le bHK_n`$，基础篇 §3–4 的构造、唯一性、预算及 (R) 适用：节点流出常数用 $`1+bH`$，双线性常数用 $`1+(1+b)H`$；(R) 流出、流入平方和中的 $`1+H`$ 同样换为 $`1+bH`$。其余加权尾界、逐类映射和可积性论证不变。先在每个固定正黏性取得严格正的无限维稳态 $`b^\nu`$，再作以下增长反证；不能在有限截断末层向不存在的坐标迭代。

记 $`I=b^\nu_{w,0}+b^\nu_{z,0}>0`$，本节暂将稳态坐标简写为 $`w_n,z_n`$。全局预算及整层切面给

```math
\nu M_n(w_n^2+z_n^2)\le I,\qquad K_nz_n^2w_{n+1}\le I.
```

有限封闭无黏无迫时仍逐边守恒；极限顺序仍为固定正黏性先取封闭截断层数趋无穷，再在同一个固定窗口取黏性趋零。

### 7.2 常通量归一化与两个关键界

由 $`\log a_-\le\log a_n\le\log H+(n/2)\log2`$，定义 $`r_n`$ 的级数绝对收敛。移位直接给

```math
r_{n+1}=a_n^2r_n^4,\qquad
cK_n^{-1/3}\le r_n\le a_-^{-2/3},\quad
c=H^{-2/3}2^{-1/9}.
```

下界使用 $`\sum4^{-k-1}=1/3`$、$`\sum k4^{-k-1}=1/9`$。再由 $`r_{n+1}\ge c2^{-1/3}K_n^{-1/3}`$、$`a_n\le H\sqrt{K_n}`$ 得

```math
\sqrt{K_n}a_nr_n^3
=\sqrt{K_n}a_n^{-1/2}r_{n+1}^{3/4}
\ge c^{3/4}2^{-1/4}H^{-1/2},\qquad
d_n:=\frac1{\sqrt{K_n}a_nr_n^3}\le D_g:=2^{1/3}H.
```

这些界尚未使用 $`P<\infty`$，不预设稳态一致有界。$`r_{n+1}=a_n^2r_n^4`$ 是删边链已知常通量形式的归一化，不认领新递推；新命题需要在完整图上控制黏性稳态及同一初值轨道。

### 7.3 两个稳态包络

强出口的下一层平衡与 §2.1 相同，只用 $`h_{n+1}\le HK_{n+1}`$。取 $`A_z^3=8(1+H)`$，则

```math
z_n\le A_z I^{1/3}K_n^{-1/3}.
```

详细地，若超阈值，由 §2.1 的递推得到某个较高层振幅与 $`z_n`$ 的比大于 $`4-1/[4(1+H)^2]>2`$；递减的强阈值保留超阈值性质，无限增长与固定黏性稳态的有限能量矛盾。

设

```math
x=A_w^3=1+\frac{8b^3A_z^3}{c^3}+8(bD_g+D_g^2+1).
```

令 $`\rho_n=w_n/(I^{1/3}r_n)`$。若 $`\rho_n>A_w`$，由 $`r_n\ge cK_n^{-1/3}`$、$`x>8b^3A_z^3/c^3`$ 保证 $`w_n>2bz_n`$。包含全部前层及本层 $`w_n`$ 的切面预算给

```math
\tfrac12h_nw_n^2z_n\le
h_nw_nz_n(w_n-\beta_nz_n)\le I,
\qquad z_n\le\frac{2I}{h_nw_n^2}.
```

由 $`z_n`$ 的稳态方程舍弃非负纵向输入，再用上式和单坐标黏性预算，得

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{\beta_nh_n}{K_n}w_n-\frac{I}{K_nw_n^2},
\qquad
\rho_{n+1}\ge\tfrac12\rho_n^4-\beta_nd_n\rho_n-d_n^2\rho_n^{-2}.
```

归一化用 $`r_{n+1}=a_n^2r_n^4`$，必须保留实际的 $`h_n/K_n`$ 而不能先粗换成 $`H`$。因此超阈值时

```math
\frac{\rho_{n+1}}{\rho_n}
>\frac x2-bD_g-\frac{D_g^2}{x}>4.
```

常数的最后一项保证严格不等式。下一层仍超阈值，迭代给 $`\rho_{n+j}>4^j\rho_n`$。虽然 $`r_n`$ 未必单调，它不小于 $`c2^{-n/3}`$，所以真实振幅也指数增长，与固定黏性有限能量矛盾。故

```math
w_n\le A_w I^{1/3}r_n.
```

没有假设无黏常通量尾部能匹配受迫根；$`r_n`$ 只是比较阈值，所比较稳态始终是先行构造的真实正黏性稳态。

### 7.4 闭合能量并回到固定时间窗

定义

```math
C=\frac{A_z^2}{1-2^{-2/3}}+A_w^2P,\quad
B=2^{1/4}C^{3/4},\quad C_0=2B,\quad
L=1+[1+(1+b)a_0]C_0.
```

两个包络给 $`\|b^\nu\|_2^2\le CI^{2/3}`$；$`I\le\sqrt2\|b^\nu\|_2`$ 闭合为 $`\|b^\nu\|_2\le B`$。由 (R)，共同零初值轨道全时满足 $`\|u^\nu(t)\|_2\le C_0`$。根方程中的负项是 $`-w_0z_1-z_0w_1-(1+\beta_0)a_0w_0z_0-\nu(w_0+z_0)`$；两条纵向项之和不低于 $`-C_0s`$，所以 $`s=w_0+z_0`$ 满足 $`s'\ge2-Ls`$。从 $`s(0)=0`$ 比较并积分，使用精确预算及末端能量上界得

```math
\frac{Q_\nu(T)}T\ge\frac2L-
\frac{2/L^2+C_0^2/2}{T}\ge\frac1L
\quad\text{若 }T\ge T_*:=\frac2L+\frac{LC_0^2}{2}.
```

至此定理成立，$`\varepsilon=1/L`$。各常数不依赖黏性；若要求整个系数类共用常数，只需统一控制 $`H,P,b_+`$（$`a_0\le H`$），而正下界用于定义级数和 §7.7。没有先取长期极限，也没有把无黏能量损失替代真实黏性损失。两包络还给一致小尾，故稳态的逐坐标零黏子列强收敛于有限能量正无黏稳态。

### 7.5 旧逐层条件作为推论及稀疏实例

若 $`S=\sum a_n^{-4/3}<\infty`$，则 $`a_n\to\infty`$，从而有某个 $`a_->0`$。令 $`\lambda_k=3\cdot4^{-k-1}`$，有 $`\sum\lambda_k=1`$。加权几何平均及非负换序给

```math
r_n^2=\prod_{k\ge0}(a_{n+k}^{-4/3})^{\lambda_k}
\le\sum_{k\ge0}\lambda_ka_{n+k}^{-4/3},\qquad P\le S.
```

故 (GS) 是 (GP) 的充分子类；对数正侧及上一轮稀疏实例均保留。原 (GS) 常数及未来上包络是另一条有效证明，不与本节新常数混用。

取 $`\beta_n=1`$，定义固定系数

```math
a_n=\begin{cases}
m+1,&n=2^m,\quad m\in\mathbb N,\ m\ge1,\\
2^{n/2},&\text{其他 }n.
\end{cases}
```

大部分壳层有 $`h_n=K_n`$，但在 $`n=2^m`$ 有 $`h_n=2^{n/2}(m+1)`$ 的相对瓶颈。$`m+1\le2^{2^m/2}`$（从 $`m=1`$ 归纳），故 $`H=1`$、$`a_0=1`$，且

```math
S\le\frac1{1-2^{-2/3}}+\sum_{m\ge1}(m+1)^{-4/3}
\le\frac1{1-2^{-2/3}}+3<\infty.
```

旧 (GS) 证明可取 $`A_z^3=16,A_w^3=153`$；当前 (GP) 证明须取 §7.3 的较大常数，不能把 153 直接代入新证明。瓶颈是相对于邻层变弱，绝对交换系数仍增长；此模型是尺度非均匀正性网络，不宣称具有真实湍流标定或 NS 来源。

它不在 §6 的任何固定 $`\alpha`$ 有界倍率类内：非瓶颈上的 $`a_n`$ 指数增长，超过所有层号幂；瓶颈上的 $`a_n=m+1`$ 对任意正幂又过慢。相邻下降比 $`(m+1)2^{-(2^m-1)/2}\to0`$（$`m\ge2`$），旧局部幂阈值不能直接延续。此例证明 (GS) 覆盖的新系数不是旧有界倍率参数重写；仍不证明其为文献首次。

### 7.6 密集弱交换：逐层级数发散却仍有异常耗散

取 $`\beta_n=1`$，并令

```math
a_n=\begin{cases}1,&n\text{ 为偶数},\\2^{n/2},&n\text{ 为奇数}.\end{cases}
```

这里一半壳层始终只有 $`h_n=\sqrt{K_n}`$，另一半为 $`h_n=K_n`$；$`a_-=H=1`$。旧条件的 $`S`$ 因每个偶数项等于 1 而发散。直接求未来几何平均却得

```math
\log_2r_n=\begin{cases}
-n/15-17/225,&n\text{ 为偶数},\\
-4n/15-8/225,&n\text{ 为奇数}.
\end{cases}
```

两个几何级数都平方可求和，所以 (GP) 证明这个完整图模型具有共同零初值、固定窗口黏性异常耗散。由此**(GS) 不仅未证必要，而且确实不是必要条件**。并非所有弱交换都无害：全部取 $`a_n=1`$ 时 $`r_n=1,P=\infty`$，且原对数族 $`\alpha=0`$ 已有独立无耗散证明。

本周期实例的平方和可显式写为

```math
P=\frac{2^{-34/225}}{1-2^{-4/15}}
+\frac{2^{-136/225}}{1-2^{-16/15}}<\infty.
```

因此其全部窗口常数均由 §7.3–7.4 的明确公式确定，不需以数值轨道估计 P 或耗散起始时间；这些解析常数仍很粗。

周期性也非必要。任取不含相邻整数的固定集合 $`\mathcal B`$，在 $`n\in\mathcal B`$ 取 $`a_n=1`$，其余取 $`2^{n/2}`$。对 $`n\ge1`$，

```math
\log_2r_n=-n/3-1/9+
\sum_{N\in\mathcal B,\,N\ge n}\frac{N}{4^{N-n+1}}
\le-n/3-1/9+\frac{4n}{15}+\frac8{225}
\le-n/15.
```

理由是距离分组 $`\{2\ell,2\ell+1\}`$ 内至多一个瓶颈，而权重 $`(n+k)4^{-k-1}`$ 在 $`n\ge1`$ 时递减；每组用前一项上界，再求几何和。$`r_0\le1`$，故统一有 $`P\le(1-2^{-2/15})^{-1}`$。即使集合不周期、不稀疏，仍可用同一组窗口常数。禁止相邻只是这一推论的充分限制，不是瓶颈密度的最优边界，也不是对动态随机切换的结论。

### 7.7 精确的稳态判据，尚非动态充要条件

仅假定 §7.1 的 $`a_->0,H<\infty,b_+<\infty`$，暂不假设 $`P<\infty`$。在共同单位双根强迫下，下列三条等价：

1. $`P<\infty`$。
2. 存在非负有限能量的分量无黏稳态（自动严格正）。
3. 正黏性稳态满足 $`\sup_{0<\nu\le1}\|b^\nu\|_2<\infty`$。

**必要性证明。** 设有无黏稳态，记 $`I=w_0+z_0>0`$。整层有限切面恒等式给 $`K_nz_n^2w_{n+1}\le I`$。对 $`n\ge1`$，包含全部前层及本层 $`w_n`$ 的切面给

```math
h_nw_nz_n(w_n-\beta_nz_n)
=I-e_nw_n^2z_{n+1}-e_{n-1}w_{n-1}^2z_n.
```

有限能量使两个弱边项趋零。因此充分大层号有 $`h_nw_n^2z_n\ge I/2`$，从而

```math
z_n\ge\frac{I}{2h_nw_n^2},\qquad
w_{n+1}\le\frac{I}{K_nz_n^2}
\le\frac{4a_n^2w_n^4}{I},\qquad
\rho_{n+1}\le4\rho_n^4.
```

若某个充分大的 $`N`$ 有 $`\rho_N<4^{-1/3}`$，置 $`q=4^{1/3}\rho_N<1`$，则 $`\rho_{N+j}\le4^{-1/3}q^{4^j}`$。因 $`r_n\le a_-^{-2/3}`$，$`w_n`$ 超指数小；但 $`h_n\le H2^n`$ 和上述 $`z_n`$ 下界令 $`z_n`$ 超指数大，与有限能量矛盾。故全部充分大 $`n`$ 均有 $`w_n\ge4^{-1/3}I^{1/3}r_n`$，平方求和强制 $`P<\infty`$。

**充分性及黏性等价。** (GP) 已给出一致正黏性稳态界和平方可求和包络；逐坐标紧性及一致小尾产生强 $`\ell^2`$ 的无黏稳态极限。反之，若仅有一致黏性稳态范数界，取 $`\nu_j\to0`$ 的逐坐标子列，Fatou 给有限能量，坐标方程给无黏平衡；根单位外力及正纵向边保证所有坐标严格正。必要性证明再给 $`P<\infty`$，没有在这一步预设强收敛。

所以 $`P=\infty`$ 时 $`\|b^\nu\|_2\to\infty`$：否则有趋零黏性的有界子列，造成矛盾。**这不推出固定窗口无耗散，也不证明动态异常耗散必要求 P 有限。** 区分稳态分类与动态命题后，新的研究价值是给出依赖瓶颈排列的精确稳态判据，以及它的固定窗耗散充分应用；优先权仍须对照一般系数文献。

### 7.8 稀少但成块的弱交换：一个动态无耗散对照

仅有弱层数量或渐近密度不足以决定耗散。§7.6 有一半弱层却仍耗散；这里给出弱层密度为零、几乎所有层都强，却在任意固定窗无耗散的同图模型。此为内部解析结果，切面—通量—守恒方法已有先例，不直接认领强原创性。

固定 $`0\le\beta_n\le b_+<\infty`$，其余设定保持 §7.1。令

```math
N_j=2^{2^j},\quad L_j=2^{j+1},\quad j\ge2,\qquad
\mathcal B=\bigcup_{j\ge2}\{N_j,\ldots,N_j+L_j\},\qquad
a_n=\begin{cases}1,&n\in\mathcal B,\\2^{n/2},&n\notin\mathcal B.\end{cases}
```

弱块两端均包含，互不相交。仍有 $`a_-=H=1`$；块内 $`h_n=\sqrt{K_n}`$，块外 $`h_n=K_n`$。**命题：** 对每个固定 $`T>0`$，共同零初值的真实黏性耗散满足 $`Q_\nu(T)\to0`$。更一般地，块外任取固定的 $`1\le a_n\le2^{n/2}`$，结论仍成立：下文只在弱块内使用交换系数的具体值，其他层仅需基础分析的统一上界。证明不以稳态发散代替动态分析。

**第一步：块内时间积分界。** 任取趋零黏性子列，由固定窗能量界与坐标紧性再取无黏分量极限 $`u`$；其范数不超过 $`R=\sqrt2T`$。令 $`Y_n=K_n\int_0^Tz_n^2dt`$。总有 $`Y_n\le2^nTR^2`$。若 $`n+1\in\mathcal B`$，积分 $`w_{n+1}`$ 的无黏方程，舍弃非负反向输入，并用零初值，得到

```math
Y_n\le R+TR^2+h_{n+1}\int_0^Tw_{n+1}z_{n+1}dt
\le A+B\sqrt{Y_{n+1}},\qquad A=R+TR^2,\quad B=R\sqrt T.
```

最后一步使用 $`h_{n+1}=\sqrt{K_{n+1}}`$。黏性项是在固定坐标的子列极限中消失；不能把这一无黏递推不加修改地写成正黏性估计。

取 $`C=\max(1,2A,4B^2)`$、$`Z_n=Y_n/C`$，则

```math
Z_n\le\tfrac12+\tfrac12\sqrt{Z_{n+1}}
\le\max(1,\sqrt{Z_{n+1}}),\qquad
Z_n\le\max(1,Z_J^{2^{-(J-n)}}).
```

第二式仅在 $`n+1,\ldots,J`$ 都属于同一弱块时迭代。令 $`J=N_j+L_j`$、$`m_j=2^j`$。块的前 $`m_j`$ 层 $`N_j\le n<N_j+m_j`$ 满足 $`q=J-n\ge2^j+1`$ 和 $`J\le2N_j`$，故 $`J/2^q\le2`$。代入末层粗界得

```math
Y_n\le D_T:=4\max(C,TR^2),\qquad N_j\le n<N_j+m_j.
```

常数不依赖块号、黏性子列或极限解。这里没有控制所有壳层，只控制长弱块的一段。

**第二步：选择实际通量趋零的切面。** 记 $`J_n^{(4)}=\int_0^Tw_n^4dt`$，避免与末层号 $`J`$ 混用。在上述前缀内，

```math
F_n:=h_n\int_0^Tw_n^2z_n dt,\qquad
F_n^2\le Y_nJ_n^{(4)},\qquad
\sum_nJ_n^{(4)}\le TR^4.
```

所以每块可选 $`n_j`$ 使 $`F_{n_j}^2\le D_TTR^4/m_j\to0`$。回流积分满足

```math
G_{n_j}:=\beta_{n_j}h_{n_j}\int_0^Tw_{n_j}z_{n_j}^2dt
\le b_+R D_T2^{-n_j/2}\to0.
```

包含所有前层及本层 $`w_{n_j}`$ 的切面还有两个弱出口；其积分分别不超过 $`e_{n_j}TR^3`$、$`e_{n_j-1}TR^3`$，合计不超过 $`3\cdot2^{-n_j}TR^3\to0`$。部分切面恒等式的净通量是 $`F-G`$ 加这两个弱出口，不能遗漏回流。切面沿 $`n_j\to\infty`$ 穷尽全部坐标，故

```math
E(T)=\int_0^T(w_0+z_0)dt.
```

**第三步：回到真实黏性耗散。** 正黏性精确预算、根输入的时间一致收敛及末端能量 Fatou 给

```math
0\le\limsup Q_\nu(T)
\le\int_0^T(w_0+z_0)dt-E(T)=0
```

于该再取子列。任意趋零黏性子列都可这样再取，故整族 $`Q_\nu(T)\to0`$；不要求无黏解唯一或强 $`\ell^2`$ 收敛。

**可复用的弱块条件。** 更一般地，固定 $`1\le a_n\le2^{n/2}`$，若有弱块 $`[N_j,J_j]`$ 且 $`N_j\to\infty`$，块内全取 $`a_n=1`$，且存在整数 $`1\le m_j\le J_j-N_j+1`$ 满足

```math
m_j\to\infty,\qquad
\sup_j\frac{J_j}{2^{J_j-N_j-m_j+1}}=:A_0<\infty,
```

则仍有每个固定窗 $`Q_\nu(T)\to0`$。块不必有先前明确例子的长度，也不必是全部弱层。前 $`m_j`$ 层的后向距离至少 $`J_j-N_j-m_j+1`$，上面的同一递推给 $`Y_n\le2^{A_0}\max(C,TR^2)`$；四阶预算选层、回流与两个弱出口趋零及黏性极限完全同前。选择的切面随无黏子列极限而变是允许的。条件不含 T，因此一条满足条件的固定序列同时适用每个有限 T；不声称最优长度门槛。

**密度与判据核对。** 至第 $`j`$ 块累计弱层数为 $`O(2^j+j)`$；即使计入当前块，除以 $`N_j`$ 仍趋零。因此 $`\mathcal B`$ 的自然密度为零。令 $`s=L_j+1`$，从剖面定义与后续 $`0\le\log_2a_{N_j+k}\le(N_j+k)/2`$ 得

```math
0\ge\log_2r_{N_j}
\ge-4^{-s}\left(\frac{N_j+s}{3}+\frac19\right)\longrightarrow0.
```

所以 $`r_{N_j}\to1`$、$`P=\infty`$，与稳态必要性相容；它不是由 $`P=\infty`$ 推出无耗散。与 §7.6 的正侧合起来，两例反驳“弱层越稀少越容易耗散”的**仅按密度分类**，不证明一般重排单调性、最优弱块长度或全部 $`P=\infty`$ 情形无耗散。

**同密度、零密度改动的推论。** 另取 $`\widetilde a_n=1`$ 若 $`n`$ 为偶数或 $`n\in\mathcal B`$，否则取 $`2^{n/2}`$，并固定 $`\beta_n=1`$。弱块外仍在上述允许区间，故对该模型每个固定窗均有 $`Q_\nu(T)\to0`$。它与 §7.6 的耗散模型仅在 $`\mathcal B`$ 内的奇数层不同，差异集合密度为零；两个模型的弱层密度都为 $`1/2`$。方程、强边、弱边、力、黏性、初值及解类均相同，只改变同层交换的固定序列。

因此异常耗散并不在“系数仅改变于零密度集合”这个粗意义下稳定。这不是小幅扰动反例：被改的奇数层有 $`\widetilde a_n/a_n=2^{-n/2}\to0`$，不满足 §6 的上下有界倍率假设。不称它为任意零密度扰动结论，也不据此认领新基本级联机制。

**选定主命题及证明入口。** 记 §7.6 周期模型的耗散为 Q_ν^+，上面同密度弱块模型的耗散为 Q_ν^−。两者均采用基础篇的非负能量类解、双根单位力、共同零初值、封闭截断极限，系数与 ν 及时间无关。则

```math
\exists\,T_*,\varepsilon>0\quad
\forall\,0<\nu\le1\quad\forall\,T\ge T_*:
\qquad Q_\nu^+(T)/T\ge\varepsilon,
\qquad
\forall\,T>0:\quad\lim_{\nu\downarrow0}Q_\nu^-(T)=0.
```

两固定序列仅在零密度集合不同，弱层密度同为 1/2，边图没有断边；它们不是保持系数多重集合的纯重排。证明依赖是：基础篇 §3–4 给两侧共同的固定黏性解与精确预算；§7.2–7.4、§7.6 给正侧；本节块内积分—选层—极限预算给负侧。无需 §7.7 的稳态必要性、§7.9 的随机分类或 §7.10 的形式消元。内部审查的实际覆盖和原创性限制见[验证篇 §8.11](04-evidence-zh.md#811-选定动态对照的证明审查与依赖闭合)。

### 7.9 一次抽样后冻结的二值排列

引入概率仅为描述尺度排列，不改变动力学的力或初值。令 $`\xi_n`$ 独立，$`\mathbb P(\xi_n=1)=p`$，抽样一次后固定

```math
a_n(\omega)=\begin{cases}1,&\xi_n(\omega)=1\quad\text{弱层},\\
2^{n/2},&\xi_n(\omega)=0\quad\text{强层},\end{cases}
\qquad \beta_n=1,\qquad 0\le p\le1.
```

每个实现均有 $`a_-=H=1`$，采用共同零初值、单位双根力、同一封闭截断及能量类解。对一个实现，改变黏性时**不重新抽样**。概率结论不等于新的随机微分方程，也不证明这个人为网络的 NS 来源。

**内部概率命题。** 对每个固定 p，以下结论在一个概率为 1 的实现集合上成立：

| 弱层概率 | 剖面与稳态 | 共同初值、真实黏性耗散 |
|---|---|---|
| $`0\le p<1/4`$ | $`P<\infty`$，无黏有限能量稳态存在，黏性稳态一致有界 | 存在依赖实现但不依赖 ν 的 $`T_*,\varepsilon>0`$，全部固定 $`T\ge T_*`$ 有 $`Q_\nu(T)/T\ge\varepsilon`$ |
| $`1/4\le p\le1`$ | $`P=\infty`$，无上述稳态，黏性稳态范数趋于无穷 | 每个固定 $`T>0`$ 有 $`Q_\nu(T)\to0`$；2026-10-03 新增 §7.11 给动态证明 |

特别地，p=1/2 的独立排列几乎必然无耗散，但 §7.6 的周期排列有耗散；强大数律给两者弱层密度都为 1/2。这是排列统计的对照，不是随机耦合概念首创。新增 §7.11 后，本冻结独立二值族的动态门槛为 p=1/4，边界归无耗散侧；不是对任意有同样密度的确定性排列的分类。

**第一步：p<1/4 时平方可求和。** 若 p<1，对每个 n，首个强层距离 $`\ell_n`$ 几乎必然有限，分布为 $`\mathbb P(\ell_n=\ell)=(1-p)p^\ell`$。设 $`c=\log2/2`$。剖面定义中的首个强层就给

```math
r_n^2\le\exp[-c(n+\ell_n)4^{-\ell_n}].
```

其他项非负，故可舍弃；不同 n 的首距并不独立，也不需要独立。非负换序及 $`(1-e^{-x})^{-1}\le1+x^{-1}`$ 给

```math
\mathbb E P
\le(1-p)\sum_{\ell\ge0}p^\ell\sum_{n\ge0}e^{-c(n+\ell)4^{-\ell}}
\le1+\frac{2(1-p)}{(\log2)(1-4p)}=:M_p<\infty.
```

所以 P 几乎必然有限，§7.1–7.4 的确定性定理逐个实现给固定窗耗散。窗口及下界通常通过该实现的 P 选取；不能把逐实现量词误写成整个概率空间共用常数。若给定 $`0<\delta<1`$，Markov 给 $`\mathbb P(P\le M_p/\delta)\ge1-\delta`$，在此事件上可用同一组 §7.4 常数。此高概率界不声称概率空间上黏性极限与期望可以随意交换。

**第二步：p≥1/4 时 P 发散，包括临界点。** 在互不相交的区间 $`\{4^k,\ldots,2\cdot4^k-1\}`$ 内布置 $`q_k=\lfloor4^k/k\rfloor`$ 个互不相交、长 k 的候选全弱块。它们的全弱事件相互独立，成功概率为 $`p^k`$；第 k 区间至少一块成功的概率满足

```math
1-(1-p^k)^{q_k}\ge1-e^{-q_kp^k}
\ge1-e^{-1/(2k)}\ge\frac1{4k}.
```

这里 $`q_k\ge4^k/(2k)`$。跨 k 区间独立，第二 Borel–Cantelli 引理给无限多成功区间。若长 k 的弱块从 n 开始，则 $`n+k\le2\cdot4^k`$，而剖面中未来系数不超过强层值，故

```math
\log_2r_n\ge-4^{-k}\left(\frac{n+k}{3}+\frac19\right)>-1.
```

无限多互异 n 有 $`r_n>1/2`$，所以 P 发散。r_n 自身依赖无限未来，不独立；独立的是上面各有限区间的全弱事件。本步及 §7.7 本身只决定稳态。新增 §7.11 将这些同一弱块接入独立的动态阻断证明，才得到表中的无耗散结论。

**第三步：p≥1/2 时产生动态阻断块，包括临界点。** 先取 $`1/2\le p<1`$。对整数 $`k\ge4`$，在 $`I_k=\{2^k,\ldots,2^{k+1}-1\}`$ 内设

```math
m_k=\lceil\log_2k\rceil,\qquad \ell_k=k+m_k+2.
```

对 $`2^k\le i\le2^{k+1}-\ell_k-1`$，令 A_i 表示 i 层强、随后 $`\ell_k`$ 层全弱。用强层作起始标记，距离 $`1,\ldots,\ell_k`$ 的两起点事件不能同时发生；距离大于 $`\ell_k`$ 时它们依赖不相交变量，因而独立。令 $`W_k=\sum_i\mathbf1_{A_i}`$，则

```math
\lambda_k:=\mathbb EW_k=(2^k-\ell_k)(1-p)p^{\ell_k},\qquad
\mathbb EW_k^2\le\lambda_k+\lambda_k^2,
\qquad \mathbb P(W_k>0)\ge\frac{\lambda_k}{1+\lambda_k}.
```

最后一式是 $`\mathbb EW_k\le(\mathbb EW_k^2)^{1/2}\mathbb P(W_k>0)^{1/2}`$。由于 $`2^k-\ell_k\ge2^{k-1}`$、$`2^{m_k}<2k`$，

```math
\lambda_k\ge\frac{1-p}{16k},\qquad
\mathbb P(W_k>0)\ge\frac{1-p}{32k}.
```

成功事件跨 k 独立，因为所用变量全部在 I_k 内；它们的概率和发散。第二 Borel–Cantelli 再给无限多成功块，尤其覆盖 p=1/2，而非只证明严格大于 1/2。

一个成功块为 $`[N,J]=[i+1,i+\ell_k]`$。前 $`m_k`$ 层的最小后向距离为 $`J-N-m_k+1=\ell_k-m_k=k+2`$；$`J<2^{k+1}`$，故 $`J/2^{J-N-m_k+1}<1/2`$，且 $`m_k\to\infty`$。它们满足 §7.8 的一般弱块条件，逐个实现得到每个固定窗无耗散。这个概率 1 的块事件不含 T，故同一个实现集合覆盖所有有限 T，不是先逐 T 取不可数交集。p=1 的全弱序列直接满足该块条件，也可用原对数族 α=0 的无耗散证明。

上述第三步保留原有 p≥1/2 的证明作为有效子范围；早期的动态空档现由 §7.11 闭合，新增的是确定性回流控制与四次根递推。首强层、几何级数、二阶矩及 Borel–Cantelli 都是标准工具；随机推论不单独计为另一项原创突破，不凭概率门槛的数字认领首创。早期证据范围见验证篇 §8.7–8.8，新结果及限定核查见 §8.12。

### 7.10 非稳态输运的低成本筛选：形式消元不是证明

一般 P 发散时能否仍有真实固定窗异常耗散，尚无答案；§7.11 新增了较短弱块的动态排除条件，但不决定全部 P 发散序列。本节仅排除一种无条件的快捷论证，不改模型。

令 $`v_n=\sqrt{K_n}z_n/a_n`$，这是逐坐标可逆变换，**不是原能量空间内的有界共轭**。由实际方程精确得到

```math
\dot w_n=a_{n-1}^2v_{n-1}^2-a_n^2w_nv_n
+\frac{\beta_na_n^3}{\sqrt{K_n}}v_n^2
-\frac{w_na_{n+1}v_{n+1}}{K_n\sqrt{K_{n+1}}}
-\nu K_n^2w_n+\delta_{n0},
```

```math
K_n^{-1}\dot v_n=w_n^2-v_nw_{n+1}
-\frac{\beta_na_n}{\sqrt{K_n}}w_nv_n-\nu K_nv_n
+\frac{2w_{n-1}^2}{a_nK_n^{3/2}}
+\frac{\delta_{n0}}{a_n\sqrt{K_n}}.
```

负下标项删除。小的导数系数不允许直接置 $`v_n=w_n^2/w_{n+1}`$：分母可随尺度趋零，v 也未被原能量界统一控制。取任意 n≥4 的有限支撑非负状态，a_n=β_n=1、ν=0，令 $`w_n=z_n=1,w_{n+1}=K_n^{-1/2}`$，其余坐标为零。总能量 $`1+1/(2K_n)\le9/8`$，且恰有 $`v_n=\sqrt{K_n}=w_n^2/w_{n+1}`$，但第二式右端仍为 −1，并不随层号消失。

这是状态反例：否定“仅靠能量有界即可统一丢弃快方程余项”，不声称共同零初值轨道会经过这些状态，也不否定附加动力学控制下的近似。真实黏性层中的 νK_n 同样不能无条件忽略。把形式消元后的输运速度或某个时间级数当作已证动态阈值的路线不采用；后续必须保留余项并证明轨道控制，否则换结构。有限检查仅核精确坐标变换和上述反例。

**新阻断条件未覆盖的下一候选。** 在 §7.11 完成后，固定 j≥2，令

```math
\ell_j=2j,\qquad
N_j=2\left\lceil\frac{16^j\log_2(j+1)}2\right\rceil,\qquad
J_j=N_j+\ell_j-1.
```

块内全弱，块外仍取原周期系数，全部其余设置沿用论文。块分离，差异集合为零密度；J_j4^(−ℓ_j)=log₂(j+1)+o(1)→∞，不满足新一致块条件。原剖面尾界给

```math
-\log_2r_{N_j}
\le4^{-\ell_j}\left(\frac{N_j+\ell_j}{3}+\frac19\right)
\le\tfrac13\log_2(j+1)+O(j16^{-j}),
```

故 r_(N_j)²≥C(j+1)^(−2/3)，P=∞。以上只是选题筛查，不能由此推出动态结论。后续 §7.12 已用独立的时间积分估计证明该明确序列每个固定窗耗散趋零；它不再是待研究的正耗散候选。

### 7.11 真实通量的四次根递推：较短弱块及两类完整动态分类

2026-10-03 新增。本节沿用论文的完整图、β_n=1、双根单位力、共同零初值、黏性权重及解类；所有系数固定，1≤a_n≤√K_n。固定黏性基础与坐标紧性作为既有前提，不重新审查已投稿主命题。新增的是不依靠稳态的块内估计；不使用形式快变量消元或未证时间集中度。

**新的弱块命题。** 若存在全弱块 [N_j,J_j]，N_j→∞，块内 a_n=1，记包含端点的层数 ℓ_j=J_j−N_j+1，且

```math
\sup_j J_j4^{-\ell_j}=:A_0<\infty,
```

则每个固定 T>0 都有 Q_ν(T)→0。块外系数可任取上述允许值；不要求发散长度的一致有界前缀，也不要求 J_j≤2N_j。

**第一步：旧递推只负责控制回流。** 固定 T，从任意趋零黏性序列提取逐坐标时间一致的无黏极限 u，令 R=√2T，并设

```math
Y_n=K_n\int_0^Tz_n^2dt,\qquad
F_n=h_n\int_0^Tw_n^2z_n dt,\qquad
G_n=h_n\int_0^Tw_nz_n^2dt,\qquad
I_T=\int_0^T(w_0+z_0)dt\le2T^2.
```

对一个弱块 [N,J]，忽略有限早期块可设 N≥2、ℓ≥2。积分弱层 n≥1 的 w_n 方程，严格有

```math
Y_{n-1}=w_n(T)+e_n\int_0^Tw_nz_{n+1}dt
+h_n\int_0^Tw_nz_ndt-h_n\int_0^Tz_n^2dt.
```

舍去最后非正项并用能量界，得到旧平方根递推 Y_(n−1)≤A+B√Y_n，其中 A=R+TR²、B=R√T。取

```math
C_0=\max(1,2A,4B^2),\qquad D_0=\max(C_0,TR^2).
```

从 Y_J≤2^JTR² 后向迭代，给 q=J−n≥1 时

```math
Y_n\le D_0\,2^{J/2^q}.
```

q=1 时 J/2=n/2+1/2；q≥2、n≥2 时，由 q≤n(2^(q−1)−1) 得 J/2^q≤n/2。因此整个 [N,J−1] 都满足

```math
Y_n\le\sqrt2D_0\sqrt{K_n},\qquad
G_n\le R K_n^{-1/2}Y_n\le\sqrt2RD_0.
```

这只是回流有界，不是回流已经趋零；后者在块起点取得更强 Y 界后证明。

**第二步：有限切面给真实 F 上界，递推升级为四次根。** 包含所有 m<n 整层和本层 w_n 的有限切面，记末端部分能量为 E_n^half(T)，两条弱旁路的累计通量之和为 B_n≥0。无黏分量方程的有限求和给精确恒等式

```math
E_n^{\mathrm{half}}(T)=I_T-F_n+G_n-B_n,
\qquad F_n\le I_T+G_n\le D_1:=2T^2+\sqrt2RD_0.
```

没有预设无限空间能量守恒。所有有限切面的根输入均完整保留。弱层上的 Cauchy–Schwarz 给

```math
\left(h_n\int_0^Tw_nz_ndt\right)^2
\le F_n\left(h_n\int_0^Tz_ndt\right),\qquad
h_n\int_0^Tz_ndt\le\sqrt{TY_n}.
```

保留这项三次真实通量，而非将 w 直接替成 R，于是

```math
Y_{n-1}\le A+B_4Y_n^{1/4},\qquad
B_4=D_1^{1/2}T^{1/4},\qquad N+1\le n\le J-1.
```

置 C_4=max(1,2A,(2B_4)^(4/3))、D_2=max(C_4,D_0)，X_n=Y_n/C_4，则 X_(n−1)≤1/2+X_n^(1/4)/2≤max(1,X_n^(1/4))。用旧界 Y_(J−1)≤D_0 2^(J/2) 作为种子，从 J−1 到 n 共 J−1−n 步，严格得到

```math
Y_n\le D_2\,2^{\,2J/4^{J-n}},\qquad N\le n\le J-1,
\qquad Y_{N_j}\le D_2\,2^{8J_j4^{-\ell_j}}
\le D_2\,2^{8A_0}=:D_T.
```

ℓ=2 时没有四次根迭代，该式仍与种子一致。新块条件及 N_j→∞ 本身保证 ℓ_j→∞，不需另添此假设。全部常数只依赖 T 与 A_0，不依赖黏性子列或其极限。

**第三步：固定块起点已足够，返回整族耗散。** 对同一个极限轨道，∑_n∫₀ᵀw_n⁴dt≤TR⁴，故其第 N_j 项趋零。由上界，

```math
F_{N_j}^2\le Y_{N_j}\int_0^Tw_{N_j}^4dt\longrightarrow0,
\qquad G_{N_j}\le RD_T2^{-N_j/2}\longrightarrow0,
\qquad B_{N_j}\le3TR^3\,2^{-N_j}\longrightarrow0.
```

沿这些有限切面穷尽坐标，得到该极限 E(T)=I_T；正黏性精确预算、根收敛和末端 Fatou 给再取子列的 limsup Q_ν(T)≤I_T−E(T)=0。任意趋零黏性序列都能这样再取，故整族 Q_ν(T)→0。不要求无黏唯一或强 ℓ² 收敛，不在正黏性方程中直接套无黏 Y 递推。

**确定性推论：一个块长族的锐利动态门槛。** 对固定 c>0，令 N_j=2^(2^j)、ℓ_j=⌈c log₂N_j⌉，在所有 [N_j,N_j+ℓ_j−1] 内全取 a_n=1，块外保持 §7.6 的偶弱奇强序列。记对应耗散为 Q_ν^(c)。则

```math
0<c<\tfrac12:\quad
\exists T_*,\varepsilon>0\quad
\forall 0<\nu\le1\quad\forall T\ge T_*:
\quad Q_\nu^{(c)}(T)/T\ge\varepsilon;
\qquad
c\ge\tfrac12:\quad
\forall T>0:\quad Q_\nu^{(c)}(T)\longrightarrow0.
```

负侧因 J_j4^(−ℓ_j)≤(N_j+ℓ_j)/N_j^(2c) 有界，直接由新命题。正侧仅使用已有 GP，下面核其 P 假设，不重证 GP。

记 b_n=−log₂r_n。块外奇数 n 自身强，b_n≥n/4；块外偶数 n 的 n+1 仍是块外强奇数，因每个块起点为偶数，故 b_n≥(n+1)/16。于是块外 r_n²≤2^(−n/8)。充分晚的块彼此分离，首个块外强奇数 q≤N+ℓ+1；块内 n 有

```math
b_n\ge N4^{-\ell}/16\ge N^{1-2c}/64,
\qquad \sum_{n=N}^{J}r_n^2
\le\ell\,2^{-N^{1-2c}/32}.
```

c<1/2 时各块贡献可求和，P<∞。对 c≥1/2，已有剖面尾上界 b_(N_j)≤4^(−ℓ_j)((N_j+ℓ_j)/3+1/9)≤1/3+o(1)，所以 r_(N_j) 不趋零、P=∞。有限早期块的重叠只影响有限项。每个 c 的差异集合仍为零密度，弱层密度仍为 1/2；这是一族的分类，不是全部确定性序列的动态充要定理。

特别是先选定的 c=3/4 候选已被判定每个固定窗无耗散，不能作为 P 非必要性的正例。边界 c=1/2 也已归入负侧，较短块效应不只是更换原稿中一个巨大序列。

**冻结独立二值推论：闭合原先的概率空档。** §7.9 第二步已证明：对每个 p≥1/4，几乎必然在无限多个区间 [4^k,2·4^k−1] 内存在长 k 的全弱块。对这些块，J4^(−ℓ)<2，正好满足新命题。因此在同一概率为 1 的实现集合上，每个固定窗均无耗散。与已有 p<1/4 的 GP 正侧合并，得到本冻结独立族的完整动态分类：p<1/4 耗散，p≥1/4 无耗散，包括临界点。没有由 P 发散推动态，也没有在改变 ν 时重抽系数；块事件不依赖 T，因此无需不可数次概率事件交集。

新增定理、有限核验和限定文献比较的实际范围见[验证篇 §8.12](04-evidence-zh.md#812-四次根弱块估计及新动态分类)。一般 P=∞ 的动态必要性、对数区间 1/2<α≤3/4 仍未解决，当前投稿稿件未自动加入本节结果。

### 7.12 单层振幅和与加权弱块阻断

本节继续沿用 §7.11 的完整图、β_n=1、共同零初值和双根单位力；不改变系数类、黏性权重、解类或极限顺序。新增估计首先只用于无黏分量极限，再由既有精确黏性预算返回真实耗散。基本存在性、紧性及原主定理均作为前提。

**命题。** 设存在全弱区间 [N_j,J_j]，起点各异且 N_j→∞，记 ℓ_j=J_j−N_j+1≥1。如果

```math
\gamma_j=\frac{J_j}{2\,4^{J_j-N_j}}=2J_j4^{-\ell_j},
\qquad \sum_j2^{-\gamma_j}=\infty,
```

则对每个固定 T>0，Q_ν(T)→0。不要求这些区间互不重叠，也不另要求块长趋无穷或回流趋零。§7.11 的一致块条件使 γ_j 有界，故是本命题的特例；本节随后给出 γ_j→∞ 而仍满足级数条件的具体序列。

**第一步：单层振幅和给全局时间积分界。** 固定 T>0，从任意趋零黏性序列提取一个逐坐标时间一致的无黏极限，沿用 R=√2T、Y_n、F_n、G_n 和 I_T≤2T²。对 n≥1，只将本层的两条振幅方程相加并积分，得到精确恒等式

```math
\begin{aligned}
Y_{n-1}={}&w_n(T)+z_n(T)
+e_n\int_0^Tw_nz_{n+1}dt
+K_n\int_0^Tz_nw_{n+1}dt\\
&-e_{n-1}\int_0^Tw_{n-1}^2dt
-h_n\int_0^T(w_n-z_n)^2dt.
\end{aligned}
```

β_n=1 使同层振幅源恰为正平方；解出 Y_(n−1) 后该项非正，可以舍去。这里没有对无限多个振幅求和，也没有把振幅增加当作能量损失。n≥1 没有直接根力，根输入由下面的有限整层预算保留。于是

```math
Y_{n-1}\le2R+TR^2+K_n\int_0^Tz_nw_{n+1}dt.
```

包含 0,…,n 整层的有限能量预算给

```math
E_n^{\mathrm{full}}(T)=I_T-H_n
-e_n\int_0^Tw_n^2z_{n+1}dt,
\qquad H_n:=K_n\int_0^Tz_n^2w_{n+1}dt\le I_T.
```

这是有限求和恒等式，不需要预先假定全空间守恒。对真实时间乘积应用 Cauchy–Schwarz，

```math
K_n\int_0^Tz_nw_{n+1}dt
\le\left(H_nK_n\int_0^Tw_{n+1}dt\right)^{1/2}
\le\sqrt{2RT^3K_n}.
```

置 m=n−1 并用 K_(m+1)=2K_m，得到对每个 m≥0 的统一界

```math
Y_m\le S_T\sqrt{K_m},
\qquad S_T=2R+TR^2+2\sqrt{RT^3}.
```

S_T 不依赖交换排列或所选黏性子列。若直接使用正黏性方程，解出 Y_(n−1) 时还会出现正项 νM_n∫(w_n+z_n)，不能将它舍去；本节没有这样做。

**第二步：四次根递推现在可以从末弱层开始。** 每个弱层 n≥1 都有

```math
G_n\le RK_n^{-1/2}Y_n\le RS_T,
\qquad F_n\le I_T+G_n\le L_T:=2T^2+RS_T.
```

第二个不等式来自 §7.11 的有限半切面预算。积分 w_n 方程并使用真实通量，仍有

```math
\left(h_n\int_0^Tw_nz_ndt\right)^2
\le F_n\left(h_n\int_0^Tz_ndt\right)
\le L_T\sqrt{TY_n},
\qquad Y_{n-1}\le A+B_4Y_n^{1/4},
```

其中 A=R+TR²，B_4=√L_T T^(1/4)。取

```math
C_4=\max(1,2A,(2B_4)^{4/3}),\qquad
D_T=\max(C_4,S_T).
```

归一化后 X_(n−1)≤max(1,X_n^(1/4))。对任意全弱块 [N,J]，从第一步的末层种子 Y_J≤S_T2^(J/2) 回推 J−N 次，严格得到

```math
Y_N\le D_T\,2^{J/(2\,4^{J-N})}=D_T2^\gamma.
```

长度为 1 时没有回推，该式就是种子界。与 §7.11 先留一层的估计相比，完整块的指数由 8J4^(−ℓ) 降至 2J4^(−ℓ)；更重要的是，以下论证允许这些指数不一致有界。

**第三步：正能量缺陷会耗尽四阶预算。** 有限整层预算已经给 E(T)≤I_T。若 d:=I_T−E(T)>0，半切面恒等式和 E_n^half(T)≤E(T)、G_n≥0 给

```math
F_n=I_T-E_n^{\mathrm{half}}(T)+G_n-B_n\ge d-B_n,
\qquad 0\le B_n\le3TR^3\,2^{-n}.
```

因此充分大的 j 都有 F_(N_j)≥d/2。弱层上的 Cauchy–Schwarz 与第二步给

```math
J_{N_j}^{(4)}:=\int_0^Tw_{N_j}^4dt
\ge\frac{F_{N_j}^2}{Y_{N_j}}
\ge\frac{d^2}{4D_T}\,2^{-\gamma_j}.
```

正通量保证这里的 Y_(N_j)>0。起点各异，而同一个轨道满足 ∑_nJ_n^(4)≤TR⁴，所以级数条件与 d>0 矛盾。可见 E(T)=I_T；这个步骤利用回流的正确符号，无须另外证明 G_(N_j)→0。

最后，正黏性精确预算、根输入收敛和末端 Fatou 给所取子列的 limsup Q_ν(T)≤I_T−E(T)=0。起始黏性序列任意，故整族 Q_ν(T)→0。T 任意固定，系数及块条件均不随 T 或 ν 改变；不要求无黏唯一性或强 ℓ² 收敛。

**应用：§7.10 的候选也无固定窗耗散。** 该序列 ℓ_j=2j，N_j 为偶数，原块末 J_j=N_j+2j−1 为奇数。块后的 E_j=J_j+1=N_j+2j 仍是周期偶数弱层，因此 [N_j,E_j] 也是全弱块。写

```math
N_j=16^j\log_2(j+1)+\delta_j,\qquad 0\le\delta_j<2.
```

对延长一层的块，第二步给

```math
\gamma_j=\frac{E_j}{2\,16^j}
=\tfrac12\log_2(j+1)+\frac{\delta_j+2j}{2\,16^j},
\qquad Y_{N_j}\le2D_T\sqrt{j+1}.
```

j≥2 时余项小于 1，故 2^(−γ_j)≥1/(2√(j+1))，其和发散。命题适用：每个固定 T>0 都有 Q_ν(T)→0。该序列虽有 P=∞ 且原一致块条件失效，仍不是 P 非必要性的正耗散例子。

本节新增的是单层振幅和给出的时间积分控制，以及将各块所需四阶积分累加的阻断条件；不从稳态障碍推动态。内部审查和有限验证范围见[验证篇 §8.13](04-evidence-zh.md#813-单层振幅和与加权阻断的新增验证)。一般 P=∞ 的动态及对数中间区间仍开放，未新增全球优先权结论，未修改已投稿论文。

### 7.13 实际交换系数的纯置换：对数位移的锐利门槛

本节保持论文的完整图、β_n=1、K_n=2^n、M_n=4^n、e_n=2^(−n)、双根单位力、共同零初值、解类和极限顺序。只重新安排 §7.6 周期正例的实际同层交换系数

```math
h_n^+=\begin{cases}2^{n/2},&n\text{ 偶},\\2^n,&n\text{ 奇}.\end{cases}
```

设 σ 是非负整数的双射，令 h_n^σ=h^+_(σ(n))。称其可容许，是指每个 n 都满足 √K_n≤h_n^σ≤K_n。本节置换的是 h 的数值；K、黏性权重和外力位置全部固定，并非将整套变量及系数一起重新编号。

**定理。**

1. 若可容许 σ 满足 |σ(n)−n|≤c log₂(n+2)+C，其中 0≤c<1/2、C≥0 有限，则其几何剖面 P<∞，因而存在 T_σ,ε_σ>0，使所有 0<ν≤1、T≥T_σ 都有 Q_ν^σ(T)/T≥ε_σ。
2. 存在可容许 σ，使 |σ(n)−n|≤(1/2)log₂(n+2)，非固定点集合密度为零，并且在每个置换段内精确保留实际 h 的有限多重集合，却有每个固定 T>0 的 Q_ν^σ(T)→0。

因此 c=1/2 是这一位移约束下“所有可容许置换均保留异常耗散”的锐利最坏情形门槛。并非所有临界置换都无耗散；恒等置换也满足临界上界，却仍是正例。此处的 log 是层号的对数，不能混为波数或模型指数 α。

**正侧：小位移使强系数足够靠近每个未来窗口。** 记 a_n=h_n^σ/√K_n≥1、b_n=−log₂r_n。对充分大的 n，取原序列中不小于 n 的首个奇数 m∈{n,n+1}，令 t=σ^(−1)(m)。因 h_t^σ=2^m≤K_t=2^t，必有 t≥m≥n；位移假设给

```math
t-m\le c\log_2(t+2)+C.
```

右端为 o(t)，故充分大 t 时不超过 t/2，于是 t≤2m≤2n+2。置 d=t−n，可得

```math
0\le d\le c\log_2(n+2)+B,\qquad B=C+c+1.
```

充分大 n 上 d≤n/2，故 log₂a_t=m−t/2≥n/4。可容许性使其余 log₂a 非负，只保留几何剖面中的这一项便有

```math
b_n=2\sum_{k\ge0}4^{-k-1}\log_2a_{n+k}
\ge\frac n8\,4^{-d}
\ge\frac{4^{-B}}8\frac{n}{(n+2)^{2c}}.
```

c<1/2 时，r_n²≤2^(−κ n^(1−2c)) 对某 κ>0 及充分大 n 成立，因而 P<∞。异常耗散随后直接由已有 GP 给出；此处只核新置换的 GP 假设，不重证正侧基础。可容许上界在 t≥m 处、下界在舍去其余对数项处都有实际作用，不能删去。

**临界构造：把每个短段的弱系数排在前半、强系数排在后半。** 对 j≥2，设

```math
N_j=2^{2^j},\qquad L_j=2^{j-1},\qquad
\mathcal D_j=[N_j,N_j+2L_j-1]\cap\mathbb N.
```

这些段互不相交。段外 σ(n)=n；段内写 N=N_j、L=L_j，对 0≤k<L 定义

```math
\sigma(N+k)=N+2k,\qquad
\sigma(N+L+k)=N+2k+1.
```

两支恰好各取原段的偶、奇索引，故是段内双射。新的实际系数及归一化系数为

```math
\begin{aligned}
h_{N+k}^\sigma&=2^{N/2+k},
&a_{N+k}&=2^{k/2},\\
h_{N+L+k}^\sigma&=2^{N+2k+1},
&a_{N+L+k}&=2^{(N+3k+2-L)/2}.
\end{aligned}
```

第一支显然在 [√K,K] 中；第二支的下界由 L≤N+2、上界由 k≤L−1 给出。因此 σ 可容许。两支位移分别为 k、L−k−1，最大 L−1，且

```math
L-1<\tfrac12\log_2N\le\tfrac12\log_2(n+2)
\quad(n\in\mathcal D_j).
```

每个段内 h 的数值及其重数完全保留，没有删去大系数或增加小系数。段长 2L=log₂N，而起点双指数增长，故所有改动位置的自然密度为零；归一化弱层 a_n=1 的密度也仍为 1/2。前半段除起点外 a_(N+k)>1，不能把它称为全弱块，也不能直接代入 §7.11–7.12 的全弱条件。

**临界负侧：允许块内系数增长的四次根估计。** 固定 T，任取趋零黏性序列并提取一个无黏分量极限。§7.12 的单层振幅和给 Y_n≤S_T√K_n，不依赖 a 的排列。于是每个 n≥1 都有

```math
G_n\le RS_Ta_n,\qquad
F_n\le I_T+G_n\le L_Ta_n,
\qquad L_T=2T^2+RS_T.
```

积分 w_n 方程，保留真实通量的 Cauchy–Schwarz 给

```math
Y_{n-1}\le A+B_Ta_nY_n^{1/4},
\qquad A=R+TR^2,\quad B_T=L_T^{1/2}T^{1/4}.
```

取 C_T=max(1,2A,(2B_T)^(4/3))，Z_n=max(1,Y_n/C_T)。因 a_n≥1，归一化后 Z_(n−1)≤a_n Z_n^(1/4)。对前半段 [N,J]、J=N+L−1，从 Y_J≤S_T2^(J/2) 回推 L−1 次，得到

```math
Y_N\le D_T\,2^{\sum_{r=1}^{L-1}r/(2\,4^{r-1})+J/(2\,4^{L-1})},
\qquad D_T=\max(C_T,S_T).
```

几何加权和不超过 8/9，且 4^L=N，所以最后的种子指数为 2J/N≤4。故所有块起点统一满足 Y_(N_j)≤32D_T。全部常数仅依赖 T，不依赖 j 或所取黏性子列。

起点 a_(N_j)=1，而同一轨道上 ∑_n∫₀ᵀw_n⁴dt≤TR⁴，故

```math
F_{N_j}^2\le Y_{N_j}\int_0^Tw_{N_j}^4dt\longrightarrow0,
\qquad G_{N_j}\le RY_{N_j}2^{-N_j/2}\longrightarrow0.
```

两条弱旁路仍至多 3TR³2^(−N_j)。有限半切面穷尽后得 E(T)=I_T，再用正黏性精确预算、根收敛及末端 Fatou，得到该子列 Q_ν(T)→0；起始黏性序列任意，所以结论适用于整族。没有假定无黏唯一或强 ℓ² 收敛。

本定理新增的是**实际系数多重集合保持下的纯排列效应，以及位移量级的双侧门槛**。它严格补上原改值对照没有提供的属性，仍不认领新基本 pump、全新递推方法或全部 P=∞ 分类。证明依赖 GP 及已有振幅和估计；新增范围、有限独立检查及先例边界见[验证篇 §8.15](04-evidence-zh.md#815-首次到达筛选与纯置换位移定理)。已投稿源稿没有自动更换为本定理。

### 7.14 无迫自由衰减中的纯置换耗散对照

本节固定 §7.13 的周期实际系数 h^+ 与该节明确构造的临界纯置换 h^σ。完整图、β_n=1、K_n=2^n、M_n=4^n、e_n=2^(−n)、封闭截断及极限顺序不变。**本节明确改变外力和初值：** 外力全部为零，两个模型共同取 w_0(0)=z_0(0)=1，其余坐标为零。因此 E(0)=1，先固定 ν>0 构造无限层能量类解，再令 ν→0。本文使用 N(u) 表示实际方程右侧的无黏非线性，避免与累计损失 Q_ν 混淆。

**定理。** 存在 T_0>0、ν_0>0，独立于 ν，使

```math
Q_\nu^+(T_0)>\frac12\quad(0<\nu\le\nu_0),
\qquad
\forall T>0\text{ 固定}:\quad Q_\nu^\sigma(T)\longrightarrow0.
```

正侧只证明这份共同初值的有限比例损失，不声称有限时完全灭绝。两组实际 h 多重集合、图和初值相同，仅系数在层间的排列不同。该无迫对照尚未加入已投稿论文。

**固定黏性基础及预算适配。** 封闭截断的边相消与正性不变，此初值的能量界改为 ||u^ν(t)||₂≤R=√2。固定 ν 的 V 界、分量紧性、可求和尾通量、能量类唯一性沿共同基础同样成立：原构造所需的局部范数界已由 R 给出，初值是有限支撑的 ℓ² 元素，删除外力也满足其 V′ 条件。固定 ν 的真实预算为

```math
E^\nu(T)+Q_\nu(T)=1,
\qquad E^\nu(t)\text{ 非增}.
```

不能把原零初值受迫预算的输入积分直接置零而遗漏初始能量。

**正侧第一步：辅助受迫稳态和路径上的权重。** 只在证明中取周期 h^+ 的单位双根受迫稳态 b^ν，实际自由衰减轨道仍无外力。已有 GP 和周期 r_n 的指数尾给与 0<ν≤1 无关的有限 B≥1、W，使

```math
\|b^\nu\|_2\le B,
\qquad
\sum_{n\ge0}(2n+2)\bigl[(b_{w,n}^\nu)^2+(b_{z,n}^\nu)^2\bigr]\le W.
```

详细地，GP 包络 w_n≤A_w I_ν^(1/3)r_n、z_n≤A_z I_ν^(1/3)2^(−n/3)，I_ν=b_(w,0)^ν+b_(z,0)^ν≤√2B；周期剖面的平方不超过常数乘 2^(−2n/15)，故上述带层号的一阶矩一致有限。每个 b^ν 严格正且属于 V；这里不以无黏稳态作黏性测试函数。

因 h_0=K_0=e_0=1，根稳态方程分别给

```math
b_{w,0}^\nu\ge\frac1{1+2B},\qquad
b_{z,0}^\nu\ge\frac1{1+2B}.
```

记 c=(1+2B)^(−1)，则 2c≤I_ν≤I_max=√2B。固定 N_0≥1，使 3B³2^(−N_0)≤c/2；置

```math
\kappa=\frac{c}{2B^2},\qquad
\nu_0=\min(1,\kappa4^{-N_0}),\qquad
N_\nu=\left\lfloor\log_4(\kappa/\nu)\right\rfloor.
```

对 0<ν≤ν_0，N_ν≥N_0，且任意不越过 N_ν 的稳态切面上黏性损失至多为

```math
\nu\sum_{n\le N_\nu}M_n
\bigl[(b_{w,n}^\nu)^2+(b_{z,n}^\nu)^2\bigr]
\le\nu4^{N_\nu}B^2\le c/2.
```

整层稳态预算因此在 N_0≤n≤N_ν 给强纵向边权

```math
K_n(b_{z,n}^\nu)^2b_{w,n+1}^\nu
\ge I_\nu-c/2-B^3 2^{-n}\ge c.
```

包含所有前层及本层 w_n 的稳态半切面给同层正向边权

```math
h_n(b_{w,n}^\nu)^2b_{z,n}^\nu
\ge I_\nu-c/2-3B^3 2^{-n}\ge c.
```

半切面中的同层反向边是非负回流，保留后只加强这条下界；两条弱旁路都已计入 3B³2^(−n)。

有限低层也有 ν 一致的严格正下界。可从两个根的 c 开始，由稳态方程逐层递推

```math
b_{w,n+1}^\nu\ge
\frac{K_n(b_{z,n}^\nu)^2}{(e_{n+1}+h_{n+1})B+M_{n+1}},
\qquad
b_{z,n+1}^\nu\ge
\frac{e_n(b_{w,n}^\nu)^2}{(K_{n+1}+h_{n+1})B+M_{n+1}}.
```

只需递推到 N_0 即可。于是存在 q>0，与 ν 无关，使前向路径

```math
w_0\to z_0\to w_1\to z_1\to\cdots\to w_{N_\nu}\to z_{N_\nu}
```

的每条边均满足 f_ij^ν=c_ij(b_i^ν)²b_j^ν≥q。q 取上述有限低层边权下界及 c 的最小值。这里并未宣称整个黏性尾部边权一致非退化；越过 N_ν 后改用实际黏性。

**正侧第二步：根钉住及尾部黏性共同控制能量。** 对 v∈V，令 ρ_i=v_i/b_i^ν，并定义

```math
S_\nu(v)=\frac12\sum_{i\text{ 为根}}\frac{v_i^2}{b_i^\nu}
+\frac12\sum_{i\to j}f_{ij}^\nu(\rho_i-\rho_j)^2.
```

按路径令 w_n 的位置为 2n、z_n 的位置为 2n+1。长度为 ℓ 的路径上，Cauchy–Schwarz 给 ρ_ℓ²≤2ρ_0²+2ℓ∑路径(Δρ)²。根项给 ρ_0²≤2S_ν(v)/c，路径边权下界给 ∑路径(Δρ)²≤2S_ν(v)/q。因此头部范数满足

```math
\sum_{n\le N_\nu}(v_{w,n}^2+v_{z,n}^2)
\le\left(\frac{4B^2}{c}+\frac{4W}{q}\right)S_\nu(v).
```

对尾部 n>N_ν，有 ν4^n>κ，从而其范数平方不超过 ν||v||_V²/κ。置

```math
C=\max\left(1,\frac{2B^2}{c}+\frac{2W}{q},\kappa^{-1}\right),
```

便得到所需的黏性一致估计

```math
\boxed{\ \|v\|_2^2\le C\bigl[2S_\nu(v)+\nu\|v\|_V^2\bigr].\ }
```

头部两项常数相加，不能只取它们各自的最大值；该因子也保留在后面的 T_0 中。

**正侧第三步：正号测试和小损失反证。** 对实际自由衰减解记 L_ν(t)=⟨u^ν(t),b^ν⟩。逐边配对及辅助稳态平衡恰给

```math
\langle N(v),b^\nu\rangle
=S_\nu(v)-\frac\nu2\|v\|_V^2,
\qquad
L_\nu'=S_\nu(u^\nu)-\frac\nu2\|u^\nu\|_V^2
-\nu\sum_iM_i u_i^\nu b_i^\nu.
```

首项是正号。在 ν=0 的符号检验中，取无黏受迫稳态 b，此初值给 L′(0)=b_(w,1)+b_(z,1)>0，直接反驳误写的 −S_b。正黏性轨道的初始导数还包含 −ν[b_(w,0)^ν+b_(z,0)^ν]，不能把无黏检验式当作正黏性精确等式，也不能由错误符号声称 L_ν 下降。

上述恒等式对固定 ν 合法：u∈L²(0,T;V)、b^ν∈V，双线性配对和链式法则可用。具体地，流出平方和 ∑_(i→j)f_ijρ_i² 不超过 2B∑_iK_i v_i²；节点稳态收支使流入平方和 ∑_(i→j)f_ijρ_j² 不超过前项加 ν||v||_V²，根项非负。由 2|ρ_iρ_j|≤ρ_i²+ρ_j²，所有交叉项和边权平方差绝对可积，因此无限重排有据。对黏性交叉项使用实际稳态预算 ν||b^ν||_V²=I_ν，以及 Cauchy–Schwarz，得

```math
\nu\int_0^T\sum_iM_i u_i^\nu b_i^\nu\,dt
\le\sqrt{T I_\nu Q_\nu(T)}.
```

因 0≤L_ν≤RB、L_ν(0)≥0，积分正号恒等式给

```math
\int_0^T S_\nu(u^\nu)\,dt
\le RB+\frac12Q_\nu(T)+\sqrt{T I_{\max}Q_\nu(T)}.
```

能量单调使 ∫₀ᵀ||u^ν||₂²dt≥2T[1−Q_ν(T)]。将上式代入第二步的估计，整理得

```math
\frac{T[1-Q_\nu(T)]}{C}
\le RB+Q_\nu(T)+\sqrt{T I_{\max}Q_\nu(T)}.
```

取

```math
T_0=\max\{1,\ 8C(RB+1/2),\ 32C^2 I_{\max}\}.
```

若 Q_ν(T_0)≤1/2，左端至少 T_0/(2C)，右端不超过 RB+1/2+√(T_0 I_max/2)≤T_0/(4C)，矛盾。因此所有 0<ν≤ν_0 均有 Q_ν(T_0)>1/2。这里直接控制正黏性轨道，没有用无黏子列的失能推断真实损失。

**负侧：在置换阻断中保留初始能量。** 固定 T，任取趋零黏性序列并抽取无黏分量极限，||u(t)||₂≤R=√2。每个 n≥1 的本层初值仍零，因此 §7.12 的振幅和恒等式不变。整层切面初始含两个根，改为

```math
E_n^{\rm full}(T)
=1-K_n\int_0^Tz_n^2w_{n+1}dt-e_n\int_0^Tw_n^2z_{n+1}dt.
```

故 H_n=K_n∫z_n²w_(n+1)≤1。振幅和的强混合项不超过 √(K_nRT)，得到所有 m≥0 的

```math
Y_m\le S_T\sqrt{K_m},\qquad
S_T=2R+TR^2+\sqrt{2RT}.
```

半切面也明确保留初始能量：E_n^half(T)=1−F_n+G_n−B_n，n≥1。于是 G_n≤RS_Ta_n、F_n≤(1+RS_T)a_n。置 A=R+TR²、B_T=(1+RS_T)^(1/2)T^(1/4)，得到 Y_(n−1)≤A+B_Ta_nY_n^(1/4)。按 §7.13 的同一段内有限迭代，取 C_T=max(1,2A,(2B_T)^(4/3))、D_T=max(C_T,S_T)，有 Y_(N_j)≤32D_T。

总四阶预算 ∑∫w_n⁴≤TR⁴ 和起点 a_(N_j)=1 随即给 F_(N_j)→0；G_(N_j)及两条弱旁路同样趋零。沿这些半切面穷尽得到 E(T)=1。再由正黏性精确预算与末端 Fatou，所取子列 limsup Q_ν(T)≤1−E(T)=0。起始黏性序列任意，故全族各固定窗 Q_ν^σ(T)→0，不要求无黏解唯一或强 ℓ² 收敛。

新增内容是完整图的黏性一致头尾估计及有限初始能量下的纯排列对照。根钉住的加权 Poincaré、图基态平方差和自由衰减现象均已有先例；不据这份内部证明认领这些方法首创或全球优先权。实际独立检查、符号纠正与原文比较见[验证篇 §8.16](04-evidence-zh.md#816-自由衰减纯置换对照的新增验证)。

### 7.15 层能量与角度的精确分解：广义框架的包含范围

本节只说明 §7.13–7.14 与既有广义壳框架的关系，不新增异常耗散定理，不复核这些定理的原证明。固定 β_n=1、K_n=2^n、e_n=2^(−n)、M_n=4^n；用 f=0 表示 §7.14 的无迫设置，用 f=1 表示 §7.13 的单位双根力。初值分别沿用各节。

**径向与角度。** 令

```math
X_n=(w_n^2+z_n^2)^{1/2},\qquad
w_n=X_n\cos\theta_n,\quad z_n=X_n\sin\theta_n.
```

当前两种设置中，各有限坐标在 t>0 严格正：将方程写成非负源减去有限连续系数乘当前坐标，根层由正初值或正外力起动，再按层用变常数公式递推。因此 θ_n∈(0,π/2)，以下除法在 t>0 合法。定义

```math
\Phi_n=K_nz_n^2w_{n+1}+e_nw_n^2z_{n+1},\qquad
\phi_n=\frac{\Phi_n}{K_nX_n^2X_{n+1}}
=\sin^2\theta_n\cos\theta_{n+1}
+4^{-n}\cos^2\theta_n\sin\theta_{n+1}.
```

记 p=sin²θ_n、ρ=4^(−n)。Cauchy–Schwarz 给 φ_n²≤p²+ρ²(1−p)²≤1，最后一步来自恒等式

```math
1-p^2-\rho^2(1-p)^2
=2p(1-p)+(1-\rho^2)(1-p)^2\ge0.
```

于是 0≤φ_n≤1。逐层相消同层交换，得到精确的径向方程

```math
X_n'=K_{n-1}\phi_{n-1}X_{n-1}^2
-K_n\phi_nX_nX_{n+1}-\nu M_nX_n
+f\delta_{n0}\frac{w_0+z_0}{X_0}.
```

n=0 删除入流项。高层在 t=0 为零，不能声称该除法公式在那里逐点成立；可将未定义的 φ_n(0) 任意设为 0，径向方程在 t>0 成立，积分式由 t=ε 向 0 延拓。各 X_n 是有限坐标范数，连续并局部绝对连续；右侧各项在有限时间及固定层号下有界，根力比值亦不超过 √2。层能量形式 X_nX_n'=Φ_(n−1)−Φ_n−νM_nX_n²+fδ_n0(w_0+z_0) 无须在初始零点作除法。

同层系数没有从动力学中消失。由 θ_n'=(w_nz_n'−z_nw_n')/X_n² 得

```math
\begin{aligned}
\theta_n'={}&h_n(w_n-z_n)
+\frac{e_{n-1}w_nw_{n-1}^2-K_{n-1}z_nz_{n-1}^2}{X_n^2}\\
&+\frac{w_nz_n}{X_n^2}(e_nz_{n+1}-K_nw_{n+1})
+f\delta_{n0}\frac{w_n-z_n}{X_n^2}.
\end{aligned}
```

n=0 删除入流。交换分子恰为 h_n(w_n−z_n)(w_n²+z_n²)，直接黏性项在角度分子中相消；角度轨道仍可通过 w,z 依赖 ν，不能据此称角度与黏性无关。排列 h 改变角度轨道，再改变径向方程中的 φ。

**不是闭合的径向坐标等价。** 任取一层 n，使上一层全零、下一层为 (w_(n+1),z_(n+1))=(1,0)。本层分别取 (1,0) 与 (0,1)，其余层相同。两个非负有限能量状态有相同的全部 X，却分别给 Φ_n=0 与 Φ_n=K_n，因此 X_n' 分别为 −νM_n 与 −K_n−νM_n。该反例排除对所有非负状态仅由径向变量决定的自治闭合方程，也排除仅凭非负性和能量得到的瞬时一致正通量下界。它不是指定共同初值轨道的反例，不排除沿轨道的时变系数表示、受限轨道归约或一般非线性变换。

**与 BMR 框架的准确映射。** 对 f=0，令 j≥1，并取

```math
Y_j=X_{j-1},\quad Y_0=0,\quad\psi_0=0,\quad k_j=4^j,\quad g_j=4/\nu,
\quad\psi_j=\frac{\Phi_{j-1}}{4^jX_{j-1}^2X_j}
=2^{-j-1}\phi_{j-1}.
```

则 0≤ψ_j≤2^(−j−1)，且

```math
Y_j'=\psi_{j-1}k_{j-1}Y_{j-1}^2
-\psi_jk_jY_jY_{j+1}-\frac{k_j}{g_j}Y_j.
```

j=1 的入流为零。g 是正的常数序列，固定 ν 下满足原文的单调性及 ∑g_j^(−1)=∞；当前有限支撑初值属于所有 H^s。原文 §3.3.1 明确允许有界时变系数和多分量能量归约；命题 3、引理 7 的能量部分只用有界性。因此当前完整图沿已知轨道的径向能量估计属于这个既有框架，不能只以原文四通道或静态系数的外观排除。这里的 ψ 来自已知向量轨道，不提供由 Y 自行确定的闭合系数；也不以此映射替代原向量系统的存在唯一性构造或自动核准零点处的统一 Lipschitz 假设。

**实际包络常数的零黏退化。** 对 §7.14 的共同根初值，w_1'(0)=z_1'(0)=1，因此 Φ_0(t)=2t+o(t)，X_0²(t)=2+o(1)、X_1(t)=√2t+o(t)。任意 T>0 上，记 A_ν=ess sup_(j≥1,0<t<T) ψ_j(t)，便有

```math
\lim_{t\downarrow0}\psi_1(t)=\frac{\sqrt2}{8},\qquad
\frac{\sqrt2}{8}\le A_\nu\le\frac14.
```

BMR 引理 7 所用包络因子在当前映射中为

```math
C_j(v)=\left(1+\frac{1}{\tfrac12g_jA_\nu v}\right)^{-1}
=\left(1+\frac{\nu}{2A_\nu v}\right)^{-1},\qquad v>0.
```

所以对任意固定 v>0，

```math
\left(1+\frac{2\sqrt2\nu}{v}\right)^{-1}
\le C_j(v)\le
\left(1+\frac{2\nu}{v}\right)^{-1}\longrightarrow1.
```

这份现有包络的收缩不是黏性一致的，退化并非仅因选取粗上界。它没有给 §7.14 的真实 Q 双侧分类，也没有追踪实际 h 多重集合及位移；但此计算不证明所有可能改良都失败。f=1 的径向方程另有根力项，不直接等同于该来源的无迫方程。来源读取、独立核查与贡献判断见[验证篇 §8.17](04-evidence-zh.md#817-完整图的多分量覆盖与纯置换结果的增量边界)。本节的极坐标代数和能量归约均不认领首创。
