# 02 模型与共同分析基础

## 1. 方程与解类

固定 `n≥0`、`η>0`、`α∈ℝ`、`0≤β≤1`，负下标项删除。置

```math
K_n=2^n,\quad M_n=4^n,\quad e_n=2^{-n},\quad
h_n=\eta2^{n/2}(n+1)^\alpha.
```

```math
\begin{aligned}
\dot w_n={}&K_{n-1}z_{n-1}^2-e_nw_nz_{n+1}
+h_n(\beta z_n^2-w_nz_n)-\nu M_nw_n+\delta_{n0},\\
\dot z_n={}&e_{n-1}w_{n-1}^2-K_nz_nw_{n+1}
+h_n(w_n^2-\beta w_nz_n)-\nu M_nz_n+\delta_{n0}.
\end{aligned}\tag{L}
```

全部系数独立于黏性，初值共同全零，两个根各受单位外力。设 `u=(w,z)`，使用非负能量类解

```math
u^\nu\in C([0,\infty);\ell^2)\cap L^2_{\mathrm{loc}}([0,\infty);V),\qquad
\|u\|_V^2=\sum_nM_n(w_n^2+z_n^2).
```

能量 `E=||u||₂²/2`，累计真实黏性耗散 `Q_ν(T)=ν∫₀ᵀ||u||_V²dt`，平均耗散是 `Q_ν(T)/T`。本项目的异常耗散命题要求存在与黏性无关的 `T_*,ε>0`，使每个固定 `T≥T_*` 满足 `liminf_(ν→0) Q_ν(T)/T≥ε`；不混同于先取长时间的稳态命题。

一般交换族保持式 (L) 的边图，在两个方程中同时替换 `h_n=2^(n/2)a_n`、`β=β_n`，所有系数固定且独立于时间、黏性。其共同解类、初值、强迫和截断不变；固定黏性分析所需上界及新的耗散充分条件见[结果篇 §7](03-results-zh.md#7-一般非单调交换可求和条件与稀疏瓶颈)。原对数族的负侧定理不因此自动推广到任意序列。

## 2. 逐边守恒、正性与封闭截断

有向边 `i→j` 系数 `c≥0` 对两个坐标贡献 `(-c u_i u_j,+c u_i²)`，故对能量贡献为零。四类边是 `w_n→z_n`、`z_n→w_n`、`z_n→w_(n+1)`、`w_n→z_(n+1)`，系数依次为 `h_n,βh_n,K_n,e_n`。

零坐标面的输入非负，因此保持非负性。截断到 `0≤n≤N` 时删除两个跨末层纵向出口的整条边，保留末层同层交换。无黏无迫封闭系统严格守恒；没有附加吸收末端。

## 3. 固定正黏性的构造及精确预算

这部分统一承接旧双通道的构造，并将有限交换上界替换为当前系数的上界。对每个固定 α，

```math
H=\sup_nh_n/K_n<\infty,
```

因为指数衰减压过任意固定层号幂。此时每个节点流出系数和不超过 `(1+H)K_n≤(1+H)M_n`；每类边的源、目标映射不重复。没有要求 H 随 α 或 η 一致。本节后续构造和比较只使用此边图、非负系数与 H 的有限性，因此附录 A3、A4 的同边图系数满足相应上界时也引用本节；不能把当前对数 h 的公式误当成唯一适用系数。

有限封闭系统给 `||u(t)||₂≤||u(0)||₂+√2t` 及固定黏性下的 V 平方积分界；有界范数排除有限维常微分方程的有限时爆破。固定坐标的导数在每个有限窗口上一致有界。对坐标和整数窗口作对角抽取，得到各坐标在紧时间区间上一致收敛；每条方程仅含有限个相邻坐标，故通过积分形式得到全局非负分量解。Fatou 给逐时 ℓ² 界和固定黏性下的 L²V 界，截断序列的全局能量等式在这一步只先给能量不等式，不能直接声称强收敛。整层切面的通量只有

```math
\Phi_N=K_Nz_N^2w_{N+1}+e_Nw_N^2z_{N+1}\ge0.
```

若窗口范数上界为 R，则 `∫Φ_N≤R∫M_N(w_N²+z_N²)→0`，原因是这些加权平方积分组成可求和数列。固定正黏性下积分有限切面再令 N 趋无穷，得到

```math
E(T)+Q_\nu(T)=E(0)+\int_0^T(w_0+z_0)\,dt.
```

切面恒等式可先在任何固定 N 的分量极限中成立，再用上述可求和尾界取 N→∞；没有把截断边界的零通量当作无限模型的零通量。预算右端和 Q_ν(T) 连续，因而 E(T) 连续。坐标连续及局部范数有界给弱 ℓ² 连续，再与范数连续合起来给强 ℓ² 连续。对共同零初值可取 `R=√2T`。根平方积分在预算中的系数是 **ν**，不是 1。

有限稳态用 Brouwer 投影构造：令 C_N 为有限维非负闭球，半径 `R>√2/ν`。连续自映射 u↦P_(C_N)(u+δf(u))（δ>0）的不动点满足 ⟨f(u),v−u⟩≤0，对每个 v∈C_N 成立。若在球面，取 v=0 给 u·f(u)≥0，与逐边守恒所得 `u·f(u)≤√2R−νR²<0` 矛盾。在球内，正坐标可以双向变化，故 f_i=0；零坐标可以向正侧变化，给 f_i≤0，而向量场零面向内给 f_i≥0。因此确有平衡点，不把“向内”直接当成已经存在稳态。

其预算给 `||b||₂≤√2/ν`、`||b||_V²≤2/ν²`，且截断层数无关。零延拓后，任意 J 的平方尾不超过 `2ν⁻²4⁻(J+1)`；固定 ν 时先令 J→∞，便得到强 ℓ² 稳态子列。坐标方程通过极限，Fatou 保留 V 界，整层通量至多为 ||b||₂ M_N(w_N²+z_N²)→0，因此 `ν||b||_V²=b_w0+b_z0`。两个根若为零，其平衡方程仍含单位正输入，矛盾；已有正 z_n 通过 K_n 排除 w_(n+1)=0，已有正 w_n 通过 e_n 排除 z_(n+1)=0，逐层得到严格正性。**这一步的界允许随黏性发散，没有预设异常耗散。**

## 4. 唯一性与相对稳态非扩张性

逐边定义 `B_i(a,v)=-c a_i v_j`、`B_j(a,v)=c a_i v_i`。有限边和有 `⟨v,B(a,v)⟩=0`。由归一化边权及逐类 Cauchy–Schwarz，

```math
|\langle q,B(a,v)\rangle|\le(1+2H)\|a\|_2\|v\|_V\|q\|_V.
```

两解差 `d=a-b` 的非线性为 `B(a,d)+B(d,b)`；第一项与 d 配对相消，第二项由 Young 吸收一半黏性项，余项为 `C_H||b||_V²||d||₂²/ν`。固定黏性下 Gronwall 给能量类唯一性。上述配对可积，并由 `u'∈L²(0,T;V')` 与 `u∈L²(0,T;V)` 合法使用能量链式法则。

双线性界不依赖解或稳态存在：将 V 的坐标权重开方后，每类纵向边是互不重叠的二阶反对称块，块权分别为 K_na_z,n/(K_nK_(n+1))、e_na_w,n/(K_nK_(n+1))，绝对值各不超过 ||a||₂/2。同层正反边合并的块权为 h_n(a_w,n−βa_z,n)/M_n，绝对值不超过 2H||a||₂。因此三类算子范数相加给上式的 1+2H；一般 β_n≤b_+ 时改为 1+(1+b)H，b=max(1,b_+)。有限支撑稠密性将 B 延拓为 ℓ²×V→V'，反对称性保证配对相消；局部 ℓ² 上界与 L²V 界，以及黏性和两根输入的 V' 界，随即给 u'∈L²V'。这说明链式法则并未预设待证的强连续或无限重排结论。

若 b 是正稳态，记 `ρ_i=d_i/b_i`、`f_ij=c_ij b_i²b_j`。节点稳态平衡配平方得到

```math
\frac12\frac d{dt}\|d\|_2^2+\frac\nu2\|d\|_V^2
+\frac12\sum_i\frac{F_i}{b_i}d_i^2
+\frac12\sum_{i\to j}f_{ij}(\rho_i-\rho_j)^2=0.\tag{R}
```

`F_i=1` 仅在两个根，其余为零；该推导允许有向环，无需拓扑排序。无穷重排必须说明：流出加权平方和不超过 `(1+H)||b||₂||d||_V²`；由节点平衡，流入平方和不超过 `[(1+H)||b||₂+ν]||d||_V²`。具体地，记这些非负和为 O=∑_(i→j)f_ijρ_i²、A=∑_(i→j)f_ijρ_j²，则逐节点平衡给

```math
\sum_{k\to i}f_{ki}-\sum_{i\to j}f_{ij}
=\nu M_i b_i^2-F_i b_i,\qquad
A=O+\nu\|d\|_V^2-\sum_i(F_i/b_i)d_i^2.
```

每节点只有有限条边，先求 O 的有限上界，再用 F_i≥0 控制 A；根项仅两项且 b_i>0，不要求 1/b 在整个图上有界。由 2|ρ_iρ_j|≤ρ_i²+ρ_j²，混合项绝对可求和，平方差亦可积。于是将逐边线性项 −f_ijρ_i²+f_ijρ_iρ_j 配平方合法，恰得 (R) 中三项的二分之一系数。无需额外假设 ρ 有界，也没有从形式恒等式直接跳到无限维非扩张性。一般 β_n 的流出常数按结果篇 §7.1 替换。

式 (R) 给相对稳态非扩张性与正黏性稳态唯一性；没有给黏性一致的趋稳速度。正侧证明只用 `||u(t)||₂≤2||b||₂`，不等待趋稳。逐层有界倍率推广使用相同边图，将 H 换成相应正反向上界；详见[结果 §6](03-results-zh.md)。

### 4.1 公式来源：已知图基态表示的直接应用

2026-09-30 核查发现，(R) 的平方差代数不是可单独认领的新方法。[Keller–Pinchover–Pogorzelski，Criticality theory for Schrödinger operators on graphs](https://arxiv.org/abs/1708.09664)（2017 预印本，2020 期刊版）§4.2 Proposition 4.8 给出了图上的基态变换；以下是我们对该表示与本模型的逐项对应，不是原作者研究过本模型的主张。

先在无自环有限图上定义二次向量场 Q，缺失边的 c_ij 取零：

```math
Q_i(u)=\sum_{k\to i}c_{ki}u_k^2-\sum_{i\to j}c_{ij}u_iu_j,
\quad J_b=DQ(b)-\nu\,\mathrm{diag}(M_i),
\quad \mathcal H=-\tfrac12(J_b+J_b^{\mathsf T}).
```

其对称图权重与对角项为

```math
A_{ij}=\tfrac12(c_{ij}b_i+c_{ji}b_j)\quad(i\ne j),\qquad
\mathcal H_{ij}=-A_{ij},\qquad
\mathcal H_{ii}=\nu M_i+\sum_{i\to j}c_{ij}b_j.
```

因此 𝓗 是图 Laplace 算子加实势 V_i=𝓗_ii−∑_j A_ij；此实势不必非负。这里 𝓗 是算子，与 §3 的系数上界 H 不同。正稳态 Q(b)−νMb+F=0 恰给

```math
\frac{(\mathcal H b)_i}{b_i}
=\tfrac12\frac{F_i}{b_i}+\tfrac\nu2M_i.
```

图基态表示（每条无向边只计一次）于是成为

```math
\langle d,\mathcal H d\rangle
=\sum_{i<j}A_{ij}b_ib_j
\left(\frac{d_i}{b_i}-\frac{d_j}{b_j}\right)^2
+\sum_i\frac{(\mathcal H b)_i}{b_i}d_i^2.
```

另一方面，Q(b+d)−Q(b)=DQ(b)d+Q(d)，逐边守恒使 ⟨d,Q(d)⟩=0，故相对能量导数等于 −⟨d,𝓗d⟩。代入 A_ij b_i b_j=(c_ij b_i² b_j+c_ji b_j² b_i)/2，恰好得到 (R)，包括所有二分之一系数。有向环、双向边及合流不妨碍这个对应。

原文表示对紧支撑测试函数成立；把它用于本项目非紧支撑无限维轨道，仍须本节已有的可积性与能量链式法则。静态表示的先例不替代这些分析步骤，也没有证明本项目的黏性一致稳态界或异常耗散。保留 (R) 作为有效工具，但撤下“平方差代数本身是新方法”的贡献候选；实际读取方式见[文献入口](../references/README.md)。

## 5. 符号与估计的使用边界

`W_n=∫w_n²`、`Z_n=∫z_n²`、`J_n=∫w_n⁴`；时间均值记 `m_w=T⁻¹∫w`，均方根记 `r_w=√(W/T)`，不再复用同一横杠符号。集中度 `𝓘_n=TJ_n/W_n²` 仅在 W 正时如此定义；W 为零时约定 1，此时相应通量为零。

真实强边通量是 `K_n z_n²w_(n+1)`，真实正向同层能量通量是 `h_n w_n²z_n`。振幅源 `K_n z_n²` 与均方根乘积 `h_n r_w²r_z` 都不是实际能量通量。

单独乘 z 方程求和时必须保留根外力 `∫z_0`。舍弃非负阻尼得到可用的预算上界

```math
\nu M_nZ_n\le\int_0^Tz_0\,dt+
R\sum_{k=0}^n(e_{k-1}W_{k-1}+h_kW_k),
```

负下标删除。此粗界不是 MB，也不填补中间区间。漏迫项的旧估计和总变差命题已撤回，反例见[纠错记录](04-evidence-zh.md)。
