# 附录 B 切面筛选与顺序时间闸门

这是不同于自治对数模型的机制对照；特别是时间闸门依赖外部固定时序与有限时间内无限次切换。局部 pump 与顺序开启已有 Tao 的结构先例，不认领为新机制。以下保留完整预算、反例和输运证明；来源见[迁移索引](../06-process-zh.md)。


### B.2. 模型、解类与耗散对象

本节只研究已有的正性、跨度至多二的模型族：

```math
\dot a_n=p_{n-1}a_{n-1}^2+q_{n-2}a_{n-2}^2
-a_n(p_na_{n+1}+q_na_{n+2})-\nu4^na_n+F\delta_{n0},
\quad 0<p_n\le4^n,\quad0\le q_n\le4^n.
```

负下标删除，$`F>0`$ 固定。取共同非负初值 $`a^{\rm in}\in\ell^2`$，与黏性无关。使用[附录 A1.4](legacy-models-zh.md#a14-证明链的共同基础)构造的能量类解及其精确能量等式；本地早期稿 `manuscript/model.tex` 中对应 `dynamics`。下面的排除证明只需要该等式（全局能量不等式亦足够）、有限切面等式和非负性；不预设黏性一致的稳态界。

固定任意有限 $`T>0`$，定义

```math
A_0=\|a^{\rm in}\|_2,\qquad R_T=A_0+FT,
\qquad Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}4^na_n^\nu(t)^2\,dt.
```

$`Q_\nu(T)`$ 是累计黏性耗散，不是瞬时耗散；平均耗散是 $`Q_\nu(T)/T`$。从能量预算及 Cauchy–Schwarz 得到 $`\|a^\nu(t)\|_2\le A_0+Ft\le R_T`$。在零范数处可用 $`(\|a\|_2^2+\epsilon)^{1/2}`$ 正则化后令 $`\epsilon\downarrow0`$，不除以零。

### B.3. 切面阻碍累计耗散的定量界

对 $`N\ge1`$ 定义

```math
\Pi_N=p_Na_N^2a_{N+1}+q_Na_N^2a_{N+2}
       +q_{N-1}a_{N-1}^2a_{N+1},\qquad
C_N=p_N+q_N+q_{N-1}>0.
```

$`C_N`$ 是跨切面系数之和，不是实际通量，也不是必要充分的“传输能力”。记 $`J_N^\nu(T)=\int_0^T\Pi_N(a^\nu(t))\,dt`$。

#### B.3.1 单个切面的界

将全局能量预算减去前 $`N+1`$ 个壳的预算，得到

```math
E_{>N}(T)+\nu\int_0^T\sum_{n>N}4^na_n^2\,dt
=E_{>N}(0)+J_N^\nu(T).
```

若只知道全局能量不等式，上式改为 $`\le`$，后续上界仍成立。根外力在相减时抵消，不在高壳偷偷增加输入。舍弃非负的末端尾能量，再估计低壳耗散，得

```math
0\le Q_\nu(T)
\le\nu4^NTR_T^2+E_{>N}(0)+J_N^\nu(T)
\le\nu4^NTR_T^2+E_{>N}(0)+TC_NR_T^3.\tag{1}
```

因此，若存在 $`N_j\to\infty`$ 使 $`C_{N_j}\to0`$，先固定 $`N_j`$ 令 $`\nu\downarrow0`$，再令 $`j\to\infty`$，便有 $`Q_\nu(T)\to0`$。这不要求逐坐标无黏极限已被识别。

#### B.3.2 多个切面的加权界

还可以处理切面系数不趋零的情形。由每个振幅不超过 $`R_T`$，

```math
\frac{\Pi_N}{C_N}
\le R_T(a_N^2+a_{N-1}^2).
```

对任意有限切面集合 $`\mathcal S\subseteq\{M,\ldots,L\}`$，每个源壳最多被右端计算两次，故

```math
\sum_{N\in\mathcal S}\frac{J_N^\nu(T)}{C_N}
\le2TR_T^3.
```

设 $`W_{\mathcal S}=\sum_{N\in\mathcal S}C_N^{-1}`$。用权重 $`C_N^{-1}/W_{\mathcal S}`$ 平均式 (1) 的第一项上界（尚未将 $`J_N`$ 替成 $`TC_NR_T^3`$），得到

```math
Q_\nu(T)\le\nu4^LTR_T^2+E_{>M}(0)
+\frac{2TR_T^3}{W_{\mathcal S}}.\tag{2}
```

**排除命题。** 如果 $`\sum_{N\ge1}C_N^{-1}=\infty`$，那么对每个固定有限 $`T>0`$，

```math
\lim_{\nu\downarrow0}Q_\nu(T)=0.
```

证明：固定 $`M,L`$ 并取 $`\mathcal S=\{M,\ldots,L\}`$，先令 $`\nu\downarrow0`$ 消去式 (2) 的低壳项，再令 $`L\to\infty`$ 消去逆系数和项，最后令 $`M\to\infty`$ 消去共同初值的尾能量。各项非负，所以零上极限给出零极限。整个证明只取有限切面和，未交换未受控的无限求和与黏性极限。

特别地，若 $`C_N`$ 沿无限子列有界，倒数和必发散。这将原主稿 `weakcutobstruction` 的稳态障碍补充为**共同初值、固定窗口的耗散消失结论**。不是说稳态耗散一定消失，也不是说所有能量类无黏极限都已证明强收敛或守恒。

反方向没有证明：倒数和收敛并不自动给出异常耗散。尤其当前 S 的切面系数很大，不能用本判据推断它的固定窗口行为。也不能将上述条件擅自强化为 $`\sum C_N^{-2/3}=\infty`$；时间积分不允许直接交换相应的凹幂与求和。

### B.4. 对原稀疏修复例的实质补充

仍取已有的 $`B=\{j^2:j\ge2\}`$、弱边 $`p_n=2^{-n}`$（$`n\in B`$），其余 $`p_n=4^n`$；只在 $`S\subseteq B`$ 设置 $`q_n=4^n`$，其他 $`q_n=0`$。取 $`F=1`$ 和共同全零初值。

若 $`B\setminus S`$ 无限，每个未修复切面 $`N\in B\setminus S`$ 满足 $`q_N=q_{N-1}=0`$，所以 $`C_N=2^{-N}\to0`$。由式 (1)，**每个固定有限窗口的累计及平均黏性耗散均趋零**。

若 $`B\setminus S`$ 有限，则已有 `coverage` 和 `finitewindow` 证明在足够长的固定窗口上有正平均耗散下界。因此，该特定修复族现在可获得固定窗口意义下的有／无对照：

| 修复情形 | 共同零初值的固定窗口结论 |
|---|---|
| 漏修无限处 | 对每个固定 $`T<\infty`$，$`Q_\nu(T)/T\to0`$ |
| 只漏修有限处 | 存在依赖模型但不依赖黏性的 $`T_*,\varepsilon>0`$，对固定 $`T\ge T_*`$ 有下极限至少 $`\varepsilon`$ |

全修复 $`S=B`$ 可使用主稿已有的粗界：$`T\ge2113537`$ 时平均耗散下界 $`1/258`$。有限遗漏时常数依赖遗漏位置，不能沿用全修复常数。这里比较的是稀疏修复族，**不是 W/S**；没有改变 W/S 的未知事项。

这是对已有构造结论强度的补充，证明属于直接能量预算估计；按用户要求的较强原创性标准，它是后续构造的基准，不因此把研究目标宣布完成。主稿旧定理本身只陈述稳态障碍；新推导尚只在本篇，未伪称已经写入英文主稿。

### B.5. 两通道协同：先排除同步障碍

考虑每层两个非负振幅 $`x_n,y_n`$，黏性均为 $`-\nu4^n`$ 乘各自振幅，纵向边分别为

```math
x_n\xrightarrow{c_n}x_{n+1},\qquad
y_n\xrightarrow{d_n}y_{n+1}.
```

每条边仍用守恒对 $`(-cuv,+cu^2)`$。允许同层任意强度的此类保守交换，外力只在零层，初值固定且总能量有限。以下陈述以存在非负能量类解并满足相应预算为前提，不用有限恒等式代替一般无限系统的存在性证明。

同层交换在整层切面预算中抵消。净向高层的通量仍为

```math
\Pi_N=c_Nx_N^2x_{N+1}+d_Ny_N^2y_{N+1},
\qquad C_N=c_N+d_N,
\qquad\Pi_N/C_N\le R_T(x_N^2+y_N^2).
```

与 §B.3 相同的证明成立，源层只出现一次，式 (2) 中因子 2 可改为 1。因此，如果 $`\sum_N(c_N+d_N)^{-1}=\infty`$，不论同层交换有多强，都不能产生固定窗口异常耗散。特别是两条通道在无限多个相同尺度同时保持有界的纵向系数时，协同目标不可能通过这种交换实现。

**下一构造的必要筛选：** 若尝试障碍错位，必须先使合并切面逃离上述排除条件；随后还要证明动力学确实把能量输送到可通行的通道。总系数大不是充分条件，已有 S 对照正提醒了这一点。若仅沿错位强边形成一条已知 dyadic 链，则只是路径拼接，不能直接认作新的协同机制。

依照这条筛选，具体的双向同层交换候选及开／关内部证明已单列在[下一篇](legacy-models-zh.md)。它的耦合侧估计不由本篇排除判据推出，需使用单独的增长反证。


### B.7. 时间闸门：一个可证的对照，不认领新机制

本节落实头脑风暴中的时间闸门方向。**明确更换问题设置：** 不沿用前文受迫零初值模型，而研究无外力、共同初值仅第一壳非零的非自治正性链。它是受外部时序控制的数学级联，不声称由流体方程导出。全部开关时序和非线性系数独立于黏性。

#### B.7.1 方程与固定时序

令 $`k_n=2^n`$，$`n\ge0`$，取

```math
\dot a_n=\kappa_{n-1}(t)a_{n-1}^2
-\kappa_n(t)a_na_{n+1}-\nu4^n a_n,
\qquad a(0)=(1,0,0,\ldots),\quad \kappa_{-1}=0.
```

每一时刻最多开放一条相邻边。具体规定

```math
\tau_n=8(n+1)2^{-n},\qquad
t_n=\sum_{j<n}\tau_j=32-16(n+2)2^{-n},\qquad T_*=32,
```

```math
\kappa_n(t)=
\begin{cases}
2^n\sin^2\!\left(\pi(t-t_n)/\tau_n\right),&t_n\le t\le t_{n+1},\\
0,&\text{其余时刻}.
\end{cases}
```

各坐标系数是时间的 $`C^1`$ 函数，且 $`0\le\kappa_n\le k_n`$、$`\int\kappa_n\,dt=4(n+1)`$。在 $`T_*`$ 之后全部关闭。时间是模型的无量纲时间，不把 32 解释为物理秒数。逐坐标光滑不代表无限维系数具有统一时间正则性：开关速度随尺度增长，无限多个窗口在 $`T_*`$ 聚集，这是构造的实质条件。

有限封闭截断删除跨末端边。每条边的能量贡献 $`a_n(-\kappa_n a_na_{n+1})+a_{n+1}\kappa_n a_n^2`$ 精确相消，即使系数随时间变化也不产生额外项，因为能量定义本身不依赖时间。非自治控制在这个方程中不直接注入能量，但它仍是人为控制，不能说系统自行选择了开关时刻。

**内部命题：** 对该固定模型的正黏性解，记

```math
Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}4^na_n(t)^2\,dt,
```

则 $`\liminf_{\nu\downarrow0}Q_\nu(33)\ge2/9>0`$。初始能量为 $`1/2`$。下面证明真实黏性耗散，不把无黏能量逃向无穷远当作该结论的替代。

#### B.7.2 正黏性系统不存在额外的能量漏失

任何 $`t<T_*`$ 之前只经过有限个窗口，非零坐标有限，可依次解二维系统，已离开的低壳只作线性黏性衰减。令 $`A_n=a_n(t_n)`$；进入第 $`n`$ 个窗口时，下一壳尚为零。窗口内记 $`x=a_n,y=a_{n+1},d=\nu4^n`$，则

```math
x'=-\kappa_n xy-dx,\qquad
y'=\kappa_n x^2-4dy,\qquad (x,y)(t_n)=(A_n,0).
```

正性保持。令 $`r=(x^2+y^2)^{1/2}`$，有

```math
-4dr\le r'=-d\frac{x^2+4y^2}{r}\le-dr.
```

因而 $`A_N\le\exp(-D_{\nu,N})`$，其中

```math
D_{\nu,N}=\sum_{n<N}\nu4^n\tau_n
=8\nu[(N-1)2^N+1].
```

对每个固定 $`\nu>0`$，$`D_{\nu,N}\to\infty`$。在 $`t_N`$ 之后没有再从低于 $`N`$ 的壳输入能量；故在 $`T_*`$ 之前，所有编号至少 $`N`$ 的壳总能量至多 $`A_N^2/2`$。这个随 $`N`$ 趋零的尾界加逐坐标极限，给 $`t\uparrow T_*`$ 时的强 $`\ell^2`$ 极限。之后按线性黏性方程延拓。依次唯一的二维演化及该连续延拓也给此解的唯一性。

对有限个窗口先写精确能量等式，再令窗口数趋无穷；强能量收敛和非负耗散积分的单调收敛给

```math
\frac12\sum_n a_n(T)^2+Q_\nu(T)=\frac12
\quad(\nu>0,\ T\ge0).
```

所以在正黏性下，$`T_*`$ 不存在未记入 $`Q_\nu`$ 的能量跳失。

#### B.7.3 到达高壳的能量不会在途中全部耗尽

在单个窗口内令 $`s=y/r`$，$`q=\operatorname{arctanh}s`$。因 $`x>0`$，$`0\le s<1`$，直接求导得

```math
s'=(1-s^2)(\kappa_n r-3ds),\qquad
q'=\kappa_n r-3ds.
```

因此在窗口终点

```math
q(t_{n+1})\ge4(n+1)A_n e^{-4d\tau_n}-3d\tau_n.
```

若 $`D_{\nu,N}\le1/32`$ 且 $`A_n\ge1/2`$，对 $`n<N`$ 用 $`e^{-1/8}\ge7/8`$ 得

```math
q(t_{n+1})\ge\tfrac74(n+1)-\tfrac3{32}\ge n+1,
\qquad
A_{n+1}\ge A_n e^{-4d\tau_n}\tanh(n+1).
```

记 $`P_N=\prod_{j=1}^N\tanh j`$。因为 $`1-\tanh j\le2e^{-2j}`$，有限乘积不等式给

```math
P_N\ge1-\sum_{j=1}^N(1-\tanh j)
\ge1-\frac2{e^2-1}>\frac23.
```

这里 $`e^2>7`$。从 $`A_0=1`$ 归纳，所有 $`n\le N`$ 均满足

```math
A_n\ge e^{-4D_{\nu,n}}P_n>\frac78\frac23=\frac7{12}>\frac12.
```

这同时验证了归纳使用的下界，没有预设每一步都能转移几乎全部能量。

#### B.7.4 从高壳能量得到黏性耗散下界

取 $`N=N_\nu=\lfloor\tfrac34\log_2(1/\nu)\rfloor`$，只考虑足够小的黏性。则

```math
D_{\nu,N}\le8N\nu^{1/4}\longrightarrow0,
\qquad \nu4^N\ge\tfrac14\nu^{-1/2}\longrightarrow\infty.
```

这个 $`N_\nu`$ 是证明中选取的观察切面，不是改变模型的截断或开关时刻。在 $`t_N`$，高壳尾部的能量恰为 $`A_N^2/2`$。此后跨入尾部的边已永久关闭。由 §B.7.2 的精确预算，尾部能量 $`E_{\ge N}`$ 满足

```math
E_{\ge N}'\le-2\nu4^N E_{\ge N},
\qquad
Q_\nu(33)\ge\frac{A_N^2}{2}
\left(1-e^{-2\nu4^N(33-t_N)}\right).
```

因 $`33-t_N\ge1`$，右侧指数项趋零。结合上一节的乘积下界与 $`D_{\nu,N}\to0`$，即得命题。证明分开控制了前段输运损失和后段真实黏性耗散，没有只凭无黏显式解推断零黏极限。

#### B.7.5 哪一部分是机制，哪一部分已有人做过

冻结任意一个时刻的系数，图上最多只剩一条边。对同一第一壳初值，冻结系统始终只涉及有限个非零坐标，固定窗口 $`Q_\nu\to0`$。上述非自治系统却有正下极限。这说明“每个冻结系统都不异常耗散”不能单独推出切换系统也不异常耗散。

但这个对照依赖有限时间内无限多次切换。若仍每次只开放下一条边，而任意有限窗口只发生有限次切换，那么紧支集初值在该窗口内只到达有限个壳。其能量有界，黏性权重在该有限集合上有界，故 $`Q_\nu(T)\le C_T\nu\to0`$。这是一条针对本类顺序闸门的排除结论，不是对任意时变无限网络的定理。

查新已发现强先例：[Tao，arXiv:1402.0290v3](https://arxiv.org/html/1402.0290v3) §5.1 的 pump 及 §5.2 Proposition 5.1、Eqs. (5.5)–(5.7)，已经使用相邻通道依次开启并在有限时间聚集的结构。既有核查实际读了该命题及证明；其目标是指定耗散参数下的强范数爆破，而不是本节的固定初值零黏耗散下界。另有 [Gürcan 的动态网络模型](https://arxiv.org/html/2004.01134v2) §II.1–III，通过定期重连研究级联统计；不能把动态网络本身认作首次。

本节独立补的是固定时序、标准 $`\nu k_n^2`$ 黏性下的输运估计及耗散下界，不能将 Tao 的爆破定理误称为已经证明了这一结论，也不能把其既有结构重新包装成我们的原创机制。评价：可保留为可检验的非自治对照，但按较强原创性目标，暂不升为主候选。仅把方形闸门平滑成正弦平方，或更换时间常数，也不构成显著创新。后续若继续时间方向，必须提出超出这种外部预编排接力的新结论，而不只继续加门、改时序。

### B.8. 保留的分量诊断与结构检查

这些是从旧日志／局部方程提取的有效有限关系，不是中间区间的新证明。

#### B.8.1 分量差不形成自治标量链

对式 (L) 取 β=1、d_n=w_n-z_n，直接相减给

```math
\begin{aligned}
\dot d_n={}&K_{n-1}z_{n-1}^2-e_{n-1}w_{n-1}^2
-e_nw_nz_{n+1}+K_nz_nw_{n+1}\\
&+h_n(z_n^2-w_n^2)-\nu M_nd_n.
\end{aligned}
```

负下标删除；相同根外力抵消。旧日志 LOG-20260929-37 的这个差方程可以保留，但它随后所列“根层精确恒等式”的符号和项不能保留，正确预算见正文验证 §4.5。差方程仍依赖 w,z 和邻层；不能由有限扫描宣布全轨道 w≥z，更不能据此补上 MB。

#### B.8.2 两个非守恒加权量，不是唯一性证明

有限封闭、无黏无迫时，检查

```math
J_{\rm alt}=\frac12\sum_n(-1)^n(w_n^2+z_n^2),\qquad
J_{\rm diff}=\frac12\sum_n(w_n^2-z_n^2).
```

逐边相消只适用于相同权重。只置 z_0=w_1=1、其余为零，则 J_alt'=-2K_0=-2；只置 w_0=2、z_0=1、其余为零，β=1，则 J_diff'=-4h_0。因此这两个候选均不守恒。
