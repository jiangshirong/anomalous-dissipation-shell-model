## 固定黏性构造、适应性与精确预算

<!-- source: docs/appendices/mechanisms-zh.md B.11.2 -->

使用 H=ℓ²、||u||_V²=∑K_n²u_n²。对任意给定环境路径定义

```math
B_c(p,v)_n=c_{n-1}p_{n-1}v_{n-1}-c_np_nv_{n+1}.
```

由 1≤c_n≤2K_n，

```math
\|B_c(p,v)\|_H\le3\|p\|_H\|v\|_V,\qquad
\|B_c(p,v)\|_{V'}\le3\|p\|_H\|v\|_H,\qquad
\langle v,B_c(p,v)\rangle=0.
```

常数对环境、时间及截断统一。每个有限坐标环境在紧时间窗只有有限次跳变，有限系统是具有分段连续系数的 ODE；u_n=0 时右侧非负，非负锥不变，能量等式阻止有限时爆破。

固定 $\nu,T$，有限系统满足 $\sup_t\|u\|_H\le1$、$\nu\int_0^T\|u\|_V^2\le1/2$，导数在 $L^2(0,T;V')$ 一致有界。$V$ 紧嵌入 $H$；也可直接用

```math
\int_0^T\sum_{n>M}u_n^2\,dt
\le\frac1{2\nu K_{M+1}^2}
```

和有限坐标的一致 Lipschitz 界，经对角抽取获得 $L^2(0,T;H)$ 强收敛。$H\times H\to V'$ 的双线性估计让非线性通过极限，极限导数属于 $L^2V'$。Hilbert 三元组链式法则给 $u\in C([0,T];H)$；与方程配对、绝对收敛的逐边相消恢复精确能量等式。最后将前 $j+1$ 个坐标方程相加，还得到每个有限前缀的精确预算。

若 $u,v$ 为两个能量类解、$d=u-v$，则

```math
d'=B_c(u,d)+B_c(d,v)-\nu A d,\qquad (Ad)_n=K_n^2d_n,
\qquad
\frac12\frac d{dt}\|d\|_H^2+\nu\|d\|_V^2
\le3\|v\|_V\|d\|_H^2.
```

第一项配对相消，第二项用 $H\times V\to H$ 界；$\|v\|_V$ 在有限区间可积，Gronwall 给路径唯一性和 Galerkin 全部极限一致。

有限 Galerkin 解适应于环境自然滤过；逐坐标收敛与唯一性给适应的极限。坐标连续且绝对连续，可用于后面的随机乘积公式。

这里只需每个有限坐标集合的跳率有限，不假设整个无限环境在有限时间只有有限总跳数。先固定 ν 构造无限解，之后才取 ν↓0；没有将随 ν 变化的有限截断当作原模型。

## 路径能量比较与非爆炸准则

<!-- source: docs/appendices/mechanisms-zh.md B.11.14 -->

固定一条环境路径，另引入辅助概率空间。在其上令 X 从 0 出发，仅作 n→n+1 跳跃，时变跳率为

```math
\lambda_n(t)=2c_n(t).
```

先构造到任意有限层的过程，再取最小过程，允许它暂时以 ∞ 表示有限时爆炸。令 P_ω 表示给定环境后的辅助概率。这个过程只用于估计，不加入壳模型，也不改变其能量预算。

**能量比较。** 在封闭截断 J 中，置 p_n=(u_n^(ν,J))²。实际振幅满足 0≤u_n≤1。把已经确定的轨道视为系数，定义

```math
b_n(t)=2c_n(t)u_{n+1}^{\nu,J}(t)\quad(n<J),
\qquad b_J=0,\qquad
\kappa_n=2\nu K_n^2.
```

逐坐标直接计算得

```math
p_n'=b_{n-1}p_{n-1}-(b_n+\kappa_n)p_n.
```

这是一个有限状态、时变纯生并带杀死的前向方程：活着时位于 n 的概率是 p_n，被杀死的概率是 2Q_(ν,J)。这里对固定轨道使用有限维前向方程的唯一性。

因 b_n≤λ_n，可以保持活粒子 Y 的位置始终不超过 X：两者同层时，共同跳跃率取 b_n，X 单独跳跃率取 λ_n−b_n；X 已在前方时分别按各自速率跳跃，Y 一步不会越过 X；Y 按 κ_n 被杀死。各边际率保持正确，封闭末层 b_J=0 不造成例外。

若 Y 在高于 L 的层被杀死，或在 T 时仍活着且位于高于 L 的层，则 X(T)>L。低层杀死的累计概率至多 2νK_L²T。因此对 J>L，

```math
\frac12\sum_{n>L}(u_n^{\nu,J}(T))^2+Q_{\nu,J}(T)
\le \nu K_L^2T+\frac12P_\omega(X(T)>L).
```

单独的活尾还满足 ∑_(n>L)(u_n^(ν,J)(T))²≤P_ω(X(T)>L)。对固定 ν 取 Galerkin 极限，按非负项 Fatou 或 [固定黏性构造](proofs-zh.md#固定黏性构造适应性与精确预算) 的能量收敛得到无限链的相同上界。

**由非爆炸返回实际耗散。** 若联合环境与辅助过程下 $X$ 不爆炸，Fubini 给出一个环境概率一事件，其上 $P_\omega(X\text{ 不爆炸})=1$。同一环境的任意有限 $T$ 均有 $P_\omega(X(T)>L)\to0$。在上式中先固定 $L$ 令 $\nu\downarrow0$，再令 $L\to\infty$，得到全部有限窗 $Q_\nu(T)\to0$。预算上界 $Q_\nu\le1/2$ 给固定窗期望收敛。

**独立边的特例。** 在各边独立的平稳环境下，记 $\mathcal S=\sum_{n\ge1}1/r_n$。

**辅助过程的无爆炸。** 在环境与辅助时钟的联合概率下，令 S_n 为 X 在 n 的驻留时间。进入 n 的时刻只依赖较低层环境和已经使用的辅助时钟，与第 n 坐标整条环境路径独立。该坐标平稳，所以其进入时状态仍公平；进入以后过程的分布也不依赖进入的具体时刻。逐层归纳可知 S_n（n≥1）相互独立，虽不同分布。根层 S_0 是均值 1/2 的指数时间。

进入 n 时有概率 1/2 处于弱状态；在长度 t 内既不翻转、也不发生辅助出生的概率为 exp[−(r_n/2+2)t]。因此

```math
P(S_n>t)\ge\frac12e^{-(r_n/2+2)t},
\qquad
1-\mathbb E e^{-S_n}
=\int_0^\infty e^{-t}P(S_n>t)\,dt
\ge\frac1{r_n+6}.
```

当 𝒮=∞ 时，∑1/(r_n+6) 也发散：若无限多个 r_n<1 则显然，否则最终与 ∑1/r_n 可比。独立性给

```math
\mathbb E\exp\!\left(-\sum_{n=1}^N S_n\right)
\le\exp\!\left(-\sum_{n=1}^N\frac1{r_n+6}\right)
\longrightarrow0.
```



由有界收敛，∑S_n=∞ 几乎必然，即 X 不爆炸。Fubini 给一个环境概率一事件，其上 P_ω(X 不爆炸)=1。对这样的同一环境，每个有限 T 都有 P_ω(X(T)>L)→0。

在能量比较中先固定 L 令 ν↓0，再令 L→∞，得到 Q_ν(T)→0。由于 X 是同一个只向上跳的无爆炸过程，其路径性质同时适用于所有有限 T；这里的环境事件不依 ν，也不需要不可数交集。预算 Q_ν≤1/2 再给期望收敛。上述单独活尾上界还提供小黏性轨道的统一空间尾控制。

正耗散方向由强状态占用传递和实际黏性清除给出。

## 平稳块入口费用的阻断

<!-- source: docs/appendices/mechanisms-zh.md B.11.27 -->

继续使用 [路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的辅助纯生过程 X，其跳率为 λ_n=2c_n；弱状态出生率恰为 2，强状态出生率为 4K_n−2。下面只对辅助过程建立阻断，再用既有路径能量比较。

**单块引理。** 对任意长度 L≥1、单边相关率 r>0、共同比例 θ∈[0,1] 的有限平稳块，设 D 为 X 首次进入该块到离开该块的时间；进入时间独立于该块环境。令

```math
w=\frac{\min\{L,\theta^{-1}\}}r,\qquad
\delta=\frac1{40}\min\{1,w\}.
```

不论块位于哪些壳层，都有统一界

```math
P(D>\delta)\ge\frac{e^{-2}}{15},\qquad
1-\mathbb E e^{-D}\ge\frac1{12000}\min\{1,w\}.
```

**证明。** 若 r<1，首边初始弱且长度 δ 内不变号、不出生的概率为 (1/2)exp[−(r/2+2)δ]，而 (r/2+2)δ<1。若 r≥1、θ>1/2，则 δ≤1/(20r)，同一指数仍小于 1。这两种情形均给大于所需常数的下界。首边有效翻转率是 r/2，不把重置事件率误算成翻转率。

剩下 r≥1、0<θ≤1/2。把进入块的时间平移成 0。由平稳性，最近共同重置的年龄 B 服从 Exp(θr)，重置符号 S 公平，未来重置时钟与 B、S 及私有时钟独立。在事件

```math
\mathcal A=\left\{B\ge\frac1{(1-\theta)r}\right\}
```

上，P(𝒜)=exp[−θ/(1−θ)]≥e^(−1)。给定 B、S 后，暂时抑制时刻 0 以后的全部共同重置，只保留私有翻转，得到一个辅助的“无未来重置”块环境。各条边的整条私有路径在此条件下独立；在任意确定 t≥0，每条边处于弱状态的概率至少

```math
\frac{1-e^{-(1-\theta)r(B+t)}}2
\ge\frac{1-e^{-1}}2>\frac14.
```

记该辅助环境中的各边驻留时间为 \widetilde S_i，穿块时间为 \widetilde D=∑_(i=1)^L \widetilde S_i，并令 b=(1−θ)r/2+2。进入第 i 条边的时间只依赖此前边的私有路径和辅助出生时钟。给定 B、S 及这些已用历史，第 i 条边的整条私有路径仍未使用；上述弱概率下界因而对随机到达时间也成立。一旦到达时为弱，私有翻转或弱出生的第一次发生时间为 Exp(b)。故

```math
P(\widetilde S_i>s\mid\text{已用历史},B,S)
\ge\frac14e^{-bs},\qquad
\mathbb E(e^{-b\widetilde S_i}\mid\text{已用历史},B,S)
\le\frac78.
```

这里没有断言块内各驻留时间独立。对条件拉普拉斯界逐次取期望即可得到

```math
\mathbb E(e^{-b\widetilde D}\mid B,S)\le(7/8)^L.
```

在 𝒜 上，Markov 不等式及 e^(1/16)≤16/15 给

```math
P\left(\widetilde D\le\frac{L}{16b}\mid B,S\right)
\le\left(e^{1/16}\frac78\right)^L
\le(14/15)^L,
\qquad
P\left(\widetilde D>\frac{L}{16b}\mid B,S\right)\ge\frac1{15}.
```

因 r≥1，有 b≤(5/2)r，故 δ≤L/(40r)≤L/(16b)；又 θrδ≤1/40。未来 δ 内无共同重置的概率至少 e^(−1)，且该事件与已条件化的私有过程独立。在此事件上，实际辅助过程和无未来重置版本在 [0,δ] 一致。乘上年龄事件的概率，得到 P(D>δ)≥e^(−2)/15。

θ=0 时直接从独立公平私有路径启动，任意到达时刻的未用边弱概率为 1/2；上述条件拉普拉斯论证适用，且无需年龄事件或无共同重置事件，故同一较保守界仍成立。全部参数情形现已覆盖。

最后由尾积分、δ≤1/40 和 1−e^(−δ)≥δ/2，

```math
1-\mathbb E e^{-D}
=\int_0^\infty e^{-t}P(D>t)\,dt
\ge\frac{e^{-2}}{15}(1-e^{-\delta})
\ge\frac{e^{-2}}{1200}\min\{1,w\}
\ge\frac1{12000}\min\{1,w\}.
```

末步可用 e<3。引理证毕。

**串接成零耗散。** 对原块序列记穿块时间 D_j。各有限块必能被辅助过程到达并离开，因为 λ_n≥2；在进入新块之前，该块环境尚未被使用。块间独立和平稳性使 D_j 相互独立，虽分布不同。此处不要求块内驻留独立，也没有对非线性轨道的进入时刻作独立性假设。

记 𝒲=∑_j w_j。若 𝒲=∞，则 ∑min{1,w_j}=∞。单块引理给

```math
\mathbb E\exp\!\left(-\sum_{j=1}^N D_j\right)
\le\exp\!\left(-\frac1{12000}
\sum_{j=1}^N\min\{1,w_j\}\right)\longrightarrow0.
```

因此 ∑D_j=∞ 几乎必然。按 [路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的 Fubini 与路径能量比较，得到一个环境概率一事件，其上辅助过程不爆炸，且全部有限 T 有 Q_ν(T)→0；预算 Q_ν≤1/2 再给期望收敛。入口引理适用于任意有限块和正有限速率。

## 任意当前配置的块内阻断与必要性

<!-- source: docs/appendices/mechanisms-zh.md B.11.41 -->

记入口费用 w_j=min{ℓ_j,1/θ_j}/r_j，约定 θ_j=0 时 w_j=ℓ_j/r_j。[入口阻断](proofs-zh.md#平稳块入口费用的阻断) 的单块引理不限制块长或速率，故 ∑w_j=∞ 已给真实耗散的零侧。以下只需处理 ∑w_j<∞ 而 𝒞=∞ 的情形。

此时 ∑1/r_j<∞，因为 w_j≥1/r_j。端点块的全部费用已经包含在 w_j 中；对内部参数，必须有

```math
\sum_{j:\,0<\theta_j<1}\frac{\mathcal N_j-1}{\theta_jr_j}=\infty.
```

只在 𝒩_j>1 的块上选择完整的 Φ 段。这类块满足 ℓ_j>1/θ_j，故 w_j=1/(θ_jr_j)。入口费用可求和意味着，除有限个所选块外，r_j≥1 且 θ_jr_j≥1。

**任意当前配置的条件阻断。** 固定 0<θ<1、r≥1、整数 k≥11；在原块内部取完整段 [k,Φ_θ(k))，长度 L=⌈4^k/[θ(1−θ)]⌉。从辅助纯生过程首次到达 k 的停止时刻 S 出发，给定此前完整历史，有

```math
P\!\left(D>\frac1{\theta r}\mid\mathcal F_S\right)\ge\frac1{16}.
```

若再有 θr≥1，则

```math
\mathbb E(e^{-D}\mid\mathcal F_S)
\le \exp\!\left(-\frac1{32\theta r}\right).
```

与 [必要性：任意初始状态下每个指数长段都有等待代价](proofs-zh.md#任意当前配置的块内阻断与必要性) 相比，这里不要求 r≤2^k，也不要求失步份额有正下界。证明仍只使用有限段所属块的强 Markov 性。

将 S 平移为 0、固定任意当前符号配置，暂时抑制未来共同重置。令

```math
K=2^k,\quad \varepsilon=1-\theta,\quad
a_{\rm pr}=\frac{\varepsilon r}{2},\quad b=a_{\rm pr}+2,\quad
t_0=\frac1{16K},\quad T=\frac1{\theta r}.
```

首边出生率至多 4K，其驻留 σ≥t_0 的概率至少 e^(−1/4)。条件于首边私有路径及其出生信息；其余未用边的私有驱动仍独立。从任意初始符号出发，在任何到达时刻 t≥t_0，未用边的弱概率至少

```math
q_0=\frac{1-e^{-\varepsilon r/(16K)}}2
\ge\frac1{64}\min\left\{\frac{\varepsilon r}{K},1\right\}.
```

当指数不超过 1，使用 1−e^(−x)≥x/2；当它超过 1，使用 (1−e^(−1))/2>1/4。这样避免把大速率代入仅对小指数成立的线性下界。

到达弱状态后，私有翻转或弱出生的首次发生时间为 Exp(b)，因此各剩余驻留的逐次条件因子满足 E(e^(−bS_i)｜已用信息)≤1−q_0/2。由于

```math
L-1\ge\frac{K^2}{2\varepsilon\theta},\qquad
\frac{q_0(L-1)}2
\ge\frac{\min\{rK,K^2/\varepsilon\}}{256\theta}
\ge\frac8\theta,\qquad
bT=\frac{\varepsilon/2+2/r}{\theta}\le\frac{5}{2\theta},
```

在 σ≥t_0 的首边条件信息下，无未来重置版本在 T 内穿完整段的概率至多

```math
e^{bT}(1-q_0/2)^{L-1}
\le e^{-11/(2\theta)}<\frac14.
```

若 σ>T，这个快速穿越概率本来就是零。未来长度 T 内无共同重置的概率恰为 e^(−1)，与私有和出生驱动独立；在该事件上实际版本与无重置版本一致。因此

```math
P(D>T\mid\mathcal F_S)\ge\frac34e^{-5/4}>\frac1{16}.
```

θr≥1 时，再用 1−e^(−1/(θr))≥1/(2θr) 得到所述拉普拉斯因子。

**串接。** 在第 j 块选 h=0,…,𝒩_j−2 的完整段

```math
[\Phi_{\theta_j}^{\circ h}(m_j),
 \Phi_{\theta_j}^{\circ(h+1)}(m_j)).
```

丢弃上述有限个低速块、以及起点 k<11 的有限个段；每项费用有限，剩余费用仍发散。按辅助到达停止时刻依次条件化，夹在所选段之间的耗时非负，故到达前 J 块末端的时刻 T_J 满足

```math
\mathbb E e^{-T_J}
\le \exp\!\left[-\frac1{32}
\sum_{\substack{\text{前 }J\text{ 块中的}\\\text{保留完整段}}}
\frac1{\theta_jr_j}\right]\longrightarrow0.
```

不需要段间独立性。所有有限目标因出生率至少 2 而可到达，T_J 的极限由上式必为无穷，故辅助过程不爆炸。[路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的 Fubini 与路径能量比较给几乎处处全部有限窗 Q_ν→0，预算上界再给期望收敛。

## 强状态占用的确定性传递

<!-- source: docs/appendices/mechanisms-zh.md B.11.15 -->

本节是确定性引理，不要求 Markov 性、独立性或系数快速平均。设任意给定系数满足 1≤c_j(t)≤2K_j，仍使用同一单位初能、无迫非负能量解。记

```math
H_n(t)=\sum_{j=0}^n u_j^\nu(t)^2,\qquad H_{-1}=0,
\qquad
H_n'=-2c_nu_n^2u_{n+1}
-2\nu\sum_{j=0}^nK_j^2u_j^2\le0.
```

给定 0<d≤1、a≥0，假设 H_(n−1)(t_0)≤a、νK_n≤1。若在长度

```math
h=\frac{512}{K_nd^2}
```

的区间 [t_0,t_0+h] 内，强状态集合 {t:c_n(t)≥K_n} 的测度至少 h/4，则 H_n(t_0+h)≤a+d。

**证明。** 若某时 H_n≤a+d，由单调性即完成。否则全区间 H_n>a+d，而 H_(n−1)≤a，所以 u_n²>d。记 ξ(t)=1_{c_n(t)≥K_n}。因 c_(n+1)≤4K_n、u_(n+2)≤1 及 νK_n≤1，

```math
u_{n+1}'\ge K_nd\,\xi(t)-8K_nu_{n+1},
\qquad
u_{n+1}(t)\ge K_nd
\int_{t_0}^t e^{-8K_n(t-s)}\xi(s)\,ds.
```

将整个区间等分为 m=⌈8K_nh⌉ 段，每段长度不超过 1/(8K_n)。因 K_nh≥1，有 m≤9K_nh。记各段的强状态占用时长为 O_j，总和 O≥h/4。同一小段内的指数核至少 e^(−1)，三角区域积分是 O_j²/2。于是

```math
\begin{aligned}
H_n(t_0)-H_n(t_0+h)
&\ge2K_n^2d^2
\int_{t_0}^{t_0+h}\int_{t_0}^t
e^{-8K_n(t-s)}\xi(s)\xi(t)\,ds\,dt\\
&\ge e^{-1}K_n^2d^2\sum_{j=1}^mO_j^2
\ge \frac{e^{-1}K_n^2d^2O^2}{m}\\
&\ge \frac{K_nd^2h}{144e}
=\frac{512}{144e}>1,
\end{aligned}
```

最后一步可用 e<3。它与 0≤H_n≤1 矛盾，证毕。该引理允许强状态被任意多次短弱间隔打断；要求的是占用量，不是一个连续长强区间。这一点避免了高速翻转时“完整强区间过短”的障碍。

## 联合环境中的单边传递调度

<!-- source: docs/appendices/mechanisms-zh.md B.11.16 -->

在有限块的联合 Markov 过程中，任意一条边的投影生成元恒为 $r[g(-z)-g(z)]/2$。从任意停止时刻开始，等待这条边进入强状态，再完整观察长度 $h$ 的区间；强状态占用不少于 $h/4$ 时完成，否则从区间末尾继续试验。从强状态启动，

```math
P(\zeta(s)=+1\mid\zeta(0)=+1)=\frac{1+e^{-rs}}2,
\qquad \mathbb EO\ge h/2,\qquad P(O\ge h/4)\ge1/3.
```

最后一个界由 $0\le O\le h$、$\mathbb EO\le h(1-p)/4+hp$ 得到。每次等待强状态的条件期望至多 $2/r$，强 Markov 性在每次完整试验结束后适用。因此完成一个占用区间的条件平均时间至多

```math
3h+\frac6r.
```

此计算条件于完整有限块历史，允许同块不同边相关。试验与完成时刻都是停止时刻。

## 两种传递步长的统一比较

<!-- source: docs/appendices/mechanisms-zh.md B.11.40 -->

沿用 q=8/9，取 v=17/16。对 0<θ<1，定义较小步长

```math
\Psi_\theta(k)=k+
\max\left\{\left\lfloor\theta^{-1}\right\rfloor,
            \left\lfloor\frac{v^k}{1-\theta}\right\rfloor\right\}.
```

第一种段长允许逐边传递，总代价量级不超过 1/(θr)；第二种段长允许等待共同开启，代价也为同一量级。这两种方式都在原来的相关块中执行，逐边传递不要求边独立。

**统一几何引理。** 对全部 θ∈(0,1) 和整数 k≥256，

```math
\Psi_\theta(\Psi_\theta(k))\ge\Phi_\theta(k).
```

证明如下。由 v^16>2，记 n=⌊k/16⌋≥16，整数归纳给

```math
\lfloor v^k\rfloor\ge2^n\ge1024(n+1)\ge64k+64.
```

令 x=Ψ_θ(k)，A=1/θ，则 x≥64k+64，且 x≥k+⌊A⌋≥A。对 x≥256 有 log₂x≤x/32（在 256 取等号，此后差值单调增加）。所以

```math
v^x>2^{x/16}\ge 2^{\,2k+2+\log_2x}
=4x\,4^k\ge4A\,4^k.
```

因 A4^k/(1−θ)≥1，取整后仍有

```math
\left\lfloor\frac{v^x}{1-\theta}\right\rfloor
\ge\left\lceil\frac{A4^k}{1-\theta}\right\rceil.
```

加上 x≥k 即得引理。两个映射单调，由此从任意 k≥max{256,m_j} 开始覆盖该块剩余部分，Ψ 段数至多 2𝒩_j；最后一段可截短到块尾。

## 可求和混合调度与实际黏性清除

<!-- source: docs/appendices/mechanisms-zh.md B.11.42 -->

固定 a∈(0,1)，沿用确定性占用传递引理，令

```math
d_n=\frac a4(3/4)^n,\qquad
h_n=8192a^{-2}q^n,\quad q=8/9,\qquad
C_a=\sum_{n\ge0}h_n=73728a^{-2},\qquad c=\frac{17}{18}.
```

根边先用 h_0。每条边从任意停止时刻开始，已有联合 Markov 过程的单边投影保证条件平均传递费用≤3h_n+6/r_j；这个估计允许它与同块其他边相关。

**短块或无共同重置。** θ_j=0，或 0<θ_j<1 且 ℓ_j≤1/θ_j 时，整块逐边执行上述占用调度，条件平均费用≤3∑_(n∈I_j)h_n+6𝒞_j。

**其余块的前段。** 对 θ_j=1 的块，以及 0<θ_j<1、ℓ_j>1/θ_j 的块，先逐边处理所有满足下列任一条件的前段坐标：

```math
n<256,\qquad \frac32 r_j C_a c^n>1.
```

第二个表达式随 n 下降，所以这确实是一个连续前段，可能为空或占满整块。记所有这类前段坐标的额外费用为

```math
P_a=\sum_{\text{上述前段坐标 }n}\frac1{r_{j(n)}}.
```

虽然 r_j 可增长任意快或不单调，这个总和仍有限：

```math
P_a\le
\sum_{1\le n<256}\frac1{r_{j(n)}}+
\frac32 C_a\sum_{n\ge256}c^n<\infty.
```

理由是高层前段恰好满足 1/r_j<(3/2)C_a c^n，而不同块和段使用的实际坐标不重叠。这一可求和的逐坐标计费取代了旧证明的多项式速率假设。

**其余块的尾段。** 从前段之后的 k≥256 开始，0<θ_j<1 时按 Ψ_(θ_j) 细分，最后一段截短。若最大项为 ⌊1/θ_j⌋，在该段逐边传递，额外等待费用≤6/(θ_jr_j)。若最大项为 ⌊v^k/(1−θ_j)⌋，在这一段使用共同开启：段长 L、总传递时长 W 及相关事件率 Γ 满足

```math
L\le\frac{v^k}{1-\theta_j},\quad W\le C_aq^k,\quad
\Gamma=r_j\left[\theta_j+\frac{(1-\theta_j)L}{2}\right],
```

```math
\Gamma W\le r_j C_a\left(q^k+\frac12c^k\right)
\le\frac32 r_jC_a c^k\le1.
```

等待当前段全强的条件平均时间≤2/(θ_jr_j)，因为下一次正共同重置必使它全强。观察完整 W 时间；无任何相关事件足以保证成功，条件成功概率至少 e^(−1)。在观察结束后再判断并重试，强 Markov 性给条件平均费用

```math
e\left(W+\frac2{\theta_jr_j}\right)
\le3W+\frac6{\theta_jr_j}.
```

前一种逐边方式也满足同一上界。不同段共享实际原块时钟，等待或失败后不重抽环境。[统一步长比较](proofs-zh.md#两种传递步长的统一比较) 给每块尾段数≤2𝒩_j，而这些长块有 𝒞_j=𝒩_j/(θ_jr_j)，故尾段额外等待费用≤12𝒞_j。

θ_j=1 时，整个剩余尾段共用一个全强区间即可。此时 Γ=r_j，W≤C_aq^k，仍有 ΓW≤1，同样的重试给费用≤3W+6/r_j≤3W+12𝒞_j。不需要为该端点定义 Φ 或 Ψ。

将根边、前段、短块及所有尾段按顺序拼接，条件期望与单调收敛给

```math
\mathbb E\tau_a\le M_a:=
3C_a+6P_a+12\mathcal C<\infty.
```

整个环境调度和其极限 τ_a 不依赖 ν。成功长段中的各 h_n 区间可在观察结束后回溯标记；只把它们用于确定性传递，不以依赖未来成功的内部时刻作概率条件化。每次重试及每块完成时刻都是停止时刻。

**真实黏性清除。** 固定成功路径及任意 0<ν≤1，只对 n≤L_ν=⌊log₂(1/ν)⌋ 的有限个成功区间应用 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)。等待和失败期间前缀能量不增加，故 H_(L_ν)(τ_a)≤a。由真实预算 y_ν=∑u_n²=1−2Q_ν，

```math
y_\nu'\le-2\nu K_{L_\nu+1}^2(y_\nu-a),\qquad
y_\nu(\tau_a+s)\le a+e^{-2s/\nu}.
```

这证明 [统一分类](model-zh.md#统一费用判据与完整分类) 的实际损失下界。a=1/4 时，事件 {τ_a≤2M_a} 的概率≥1/2；在确定 T=2M_a+1 上，此共同事件使全部 0<ν≤1 的 Q_ν(T)≥1/4，期望≥1/8。对可数有理 a↓0 取共同概率一事件，再按先零黏、后长时的顺序，得到全部初能 1/2。正负两侧现已闭合。
