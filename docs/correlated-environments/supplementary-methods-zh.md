## 标量有限矩的离散强制估计

<!-- source: docs/appendices/mechanisms-zh.md B.10.3, scalar specialization -->

补充证明中的有限矩记号取 $\chi=2^{-1/3}$、$z_n=\sqrt\chi K_n^{1/3}u_n$。逐项恒等式给

```math
\sum_{n<N}(z_n^2-z_nz_{n+1})
=\frac12\left[z_0^2+\sum_{n<N}(z_{n+1}-z_n)^2-z_N^2\right],
\qquad
M_N=\chi^{-1/2}\sum_{n=0}^N\chi^{2n}z_n.
```

置 $d_0=z_0$、$d_j=z_j-z_{j-1}$。交换有限求和并用 Cauchy–Schwarz，

```math
\left(\sum_{n=0}^N\chi^{2n}z_n\right)^2
=\left(\sum_{j=0}^Nd_j\sum_{n=j}^N\chi^{2n}\right)^2
\le\frac{\sum_{j=0}^Nd_j^2}{(1-\chi^2)^2(1-\chi^4)}.
```

所以

```math
D_N\ge c_D M_N^2-\frac\chi2K_N^{2/3}u_N^2,
\qquad c_D=\frac{\chi(1-\chi^2)^2(1-\chi^4)}2>0.
```

这给出后文矩证明所需的标量离散估计。

## 刷新环境：保留轨道相关性的精确校正

<!-- source: docs/appendices/mechanisms-zh.md B.11.4 -->

置 χ=2^(−1/3)、b_n=χ^n，对有限 N 定义 M_N=∑_(n≤N)b_nu_n。其非线性矩中，完整内边和跨切面边对应

```math
G_n=b_n(\chi u_n^2-u_nu_{n+1})\quad(n<N),\qquad
G_N=-b_Nu_Nu_{N+1}.
```

坐标方程及能量界给，几乎处处

```math
|u_n'|\le K_n(u_{n-1}^2+u_n^2+u_{n+1}^2)
 +\nu K_n^2\le K_n+\nu K_n^2.
```

因此统一有

```math
|G_n|\le2b_n,\qquad
|G_n'|\le b_n(5K_n+7\nu K_n^2).
```

对内边，后一式的直接系数为 2χ+3 与 2χ+5；跨切面系数为 3 与 5，均在上述界内。这里保留环境与轨道的相关性。

二态生成元给 dζ_n=−r_nζ_n dt+dℳ_n。G_n 连续、适应且有限变差，没有跳跃二次协变项。对每个有限 N 逐项取期望，得到

```math
\mathbb E\int_0^t\zeta_nG_n\,ds
=\frac1{r_n}\mathbb E\left[
\zeta_n(0)G_n(0)-\zeta_n(t)G_n(t)
+\int_0^t\zeta_nG_n'\,ds\right].
```

鞅积分期望为零，因为每个 n 的跳率有限且 G_n 有界。绝不使用 E(ζ_nG_n)=Eζ_n EG_n。

设 σ_p=∑_(n≥1)K_n^(−p)=1/(2^p−1)。从 n=1 起求和，因为 K_0−1=0。在 0<ν≤1、t≤T 时，所有随机系数误差（包括跨切面边）满足

```math
\left|\sum_{n=0}^N(K_n-1)
\mathbb E\int_0^t\zeta_nG_n\,ds\right|
\le\eta(T):=
\frac{4\sigma_{10/3}+T(5\sigma_{7/3}+7\sigma_{4/3})}{A}.
```

三个幂次来自 (K_n−1)b_n/r_n 分别乘端点项、K_n 导数项和 νK_n² 导数项。该界对 N、ν 统一，是接入正耗散证明的关键。

## 从相关性校正到实际正黏性损失

<!-- source: docs/appendices/mechanisms-zh.md B.11.5 -->

分解 c_n=K_n+(K_n−1)ζ_n 后，确定系数部分的内边矩为

```math
D_N=\sum_{n<N}(z_n^2-z_nz_{n+1}),\qquad
z_n=\sqrt{\chi}K_n^{1/3}u_n.
```

本文件开头的标量离散强制估计，给

```math
D_N\ge c_D M_N^2-\frac{\chi}{2}K_N^{2/3}u_N^2,\qquad
c_D=\frac{\chi(1-\chi^2)^2(1-\chi^4)}2>0.
```

取 N=N_ν=⌊(3/4)log₂(1/ν)⌋。确定系数的跨边项为 −K_N^(2/3)u_Nu_(N+1)，与上式负末端合并后，时间积分至多 A_0Q_ν(t)，A_0=χ^(−4)。随机跨边已包含在 [刷新环境：保留轨道相关性的精确校正](supplementary-methods-zh.md#刷新环境保留轨道相关性的精确校正) 的 G_N 中，不能重复遗漏或当成零。

黏性矩项用 Cauchy–Schwarz，至多 B_0√(tQ_ν(t))，B_0²=(1−χ⁴)^(−1)。记 m_N(t)=E M_N(t)、q_ν(T)=E Q_ν(T)，取期望并用 E M_N²≥m_N² 及 E√Q≤√EQ，得到对所有 t≤T：

```math
m_N(t)\ge1+c_D\int_0^tm_N(s)^2\,ds
-\eta(T)-A_0q_\nu(T)-B_0\sqrt{Tq_\nu(T)}.
```

同时 0≤m_N≤(1−χ²)^(−1/2)。定义

```math
T_D=\frac4{c_D},\qquad
\varepsilon_D=
\min\left\{\frac1{8A_0},
\frac1{64B_0^2T_D}\right\}.
```

用 3/4<χ<4/5，得到

```math
c_D>\frac{(3/4)(9/25)^2(369/625)}2>\frac1{50},
\quad T_D<200,\quad
\eta(T_D)<\frac{4/7+5200/3}{8192}<\frac14.
```

若 q_ν(T_D)≤ε_D，其余两个误差各≤1/8，故 m_N(t)≥1/2+c_D∫_0^tm_N²。对应 Riccati 下解在时间 2/c_D 前爆破，与 m_N 有界矛盾。因此 q_ν(T_D)>ε_D，对所有 0<ν≤1 成立，证明完成。固定 A=8192 不随 ν 增大；没有交换平均场极限与零黏极限。

## 同一正概率事件上的全黏性下界

<!-- source: docs/appendices/mechanisms-zh.md B.11.7 -->

还可以避免交换期望与极限，得到更强的路径结论。以下固定 T=T_D，使用 [固定黏性构造](proofs-zh.md#固定黏性构造适应性与精确预算) 对任意给定坐标环境路径的确定性构造，所有 ν 共享这条路径；不是将每个 ν 各自的概率一事件作不可数交集。

定义 I_n(t)=∫_0^tζ_n(s)ds。由 dζ_n=−r_nζ_n dt+dℳ_n，

```math
I_n(t)=\frac{\zeta_n(0)-\zeta_n(t)+\mathcal M_n(t)}{r_n}.
```

每次 ζ_n 跳变的平方为 4、跳率 r_n/2，所以 E|ℳ_n(T)|²=2r_nT。Doob 不等式和 |ζ_n(0)−ζ_n(t)|≤2 给

```math
\mathbb E\sup_{t\le T}|I_n(t)|^2
\le\frac8{r_n^2}+\frac{16T}{r_n}.
```

取 β=11/6，置

```math
h=\left[
4\left(2\sigma_{7/6}+5T\sigma_{1/6}
 +\frac{7T}{1-2^{-5/6}}\right)
\right]^{-1}>0,\qquad
E_n=\left\{\sup_{t\le T}|I_n(t)|\le hK_n^{-\beta}\right\}.
```

Markov 不等式给

```math
\mathbb P(E_n^c)\le h^{-2}
\left(\frac8{A^2}K_n^{-13/3}
 +\frac{16T}{A}K_n^{-1/3}\right),
\qquad \sum_{n\ge1}\mathbb P(E_n^c)<\infty.
```

每个 E_n 的概率也严格正：选择足够密的有限个等距交替跳点，使理想积分一直位于宽度 hK_n^(−β) 的窄条内部；再将跳点各限制在足够小、互不相交的邻域，使全部跳时偏差造成的累计积分偏差仍留在窄条内。每个邻域恰好一次跳、其余时间无跳，是正概率 Poisson 事件。此论证对两个初始符号都成立。

各坐标独立。记 p_n=P(E_n^c)<1，有限前缀乘积为正，尾部 p_n≤1/2 时 log(1−p_n)≥−2p_n，故

```math
E=\bigcap_{n\ge1}E_n,\qquad
\mathbb P(E)=\prod_{n\ge1}(1-p_n)>0.
```

不从可求和失败概率单独跳到全部事件同时成功；这里用到了每个成功概率为正及独立性。

在 E 上，沿任意 ν 的实际轨道作普通分部积分，

```math
\int_0^t\zeta_nG_n\,ds
=I_n(t)G_n(t)-\int_0^tI_nG_n'\,ds.
```

I_n(0)=0，所以端点常数为 2，不是期望校正中的 4。对 N=N_ν、t≤T，路径误差满足

```math
\begin{aligned}
\left|\sum_{n=0}^N(K_n-1)\int_0^t\zeta_nG_n\,ds\right|
&\le h\left[
2\sigma_{7/6}+5T\sigma_{1/6}
 +7\nu T\sum_{n=1}^N K_n^{5/6}\right]\\
&\le h\left[
2\sigma_{7/6}+5T\sigma_{1/6}
 +\frac{7T\nu^{3/8}}{1-2^{-5/6}}\right]
\le\frac14.
\end{aligned}
```

第二步用 K_N≤ν^(−3/4)，并非对无穷正幂级数求和。该界对全部 0<ν≤1 统一。现在 [从相关性校正到实际正黏性损失](supplementary-methods-zh.md#从相关性校正到实际正黏性损失) 的矩估计直接用于 M_N、Q_ν，而不取期望；若 Q_ν(T_D)≤ε_D，同一 Riccati 矛盾仍成立。因此

```math
\forall\omega\in E,\ \forall\,0<\nu\le1:\quad
Q_\nu(T_D,\omega)>\varepsilon_D,
\qquad
\liminf_{\nu\downarrow0}Q_\nu(T_D,\omega)\ge\varepsilon_D.
```

E 完全由环境决定，不随 ν 或轨道重新选取。本证明只给 P(E)>0，没有给有用的数值概率下界，也没有证明 E 的概率为 1。冻结无耗散的初始符号事件具有概率一，可与 E 相交而不改变其正概率；因而在正概率的共同初始环境样本上，冻结侧损失趋零而刷新侧的全黏性下界成立。

## 概率一的样本依赖窗口与全部初能的顺序极限

<!-- source: docs/appendices/mechanisms-zh.md B.11.9 -->

保持 [方程与实际损失](model-zh.md#方程与实际黏性损失) 的模型、A=8192、刷新率、初值及解类不变。本节解决此前开放的随机窗口问题，且得到更强结论。存在一个与 ν 无关的概率一环境事件 Ω_*，使每个 ω∈Ω_* 都满足

```math
\lim_{T\to\infty}\liminf_{\nu\downarrow0}Q_\nu(T,\omega)
=\lim_{T\to\infty}\limsup_{\nu\downarrow0}Q_\nu(T,\omega)
=\frac12.
```

等价地，对每个 δ∈(0,1/2)，可选有限的 T_δ(ω) 和 ν_δ(ω)>0，使所有 0<ν≤ν_δ(ω) 都有 Q_ν(T_δ(ω),ω)>1/2−δ。窗口可依环境和目标损失而定，但不随随后趋零的 ν 改变。没有证明某个有限窗恰好耗尽全部能量，也没有证明每个固定窗的 ν 极限存在。先零黏、后长时间的顺序不可颠倒；冻结环境同一顺序的结果为 0。

**有限前缀的统一清空。** 先对任意确定的系数路径 1≤c_n≤2K_n 证明一个估计。令 L_j=K_j+K_j²。由 [刷新环境：保留轨道相关性的精确校正](supplementary-methods-zh.md#刷新环境保留轨道相关性的精确校正) 的导数界，0<ν≤1 时 |u_j′|≤L_j；接收坐标满足

```math
u_{j+1}'\ge u_j^2-4L_j u_{j+1}.
```

这里 2K_(j+1)+K_(j+1)²=4L_j。固定 t≥1，令 a=u_j(t)∈[0,1]、d=a/L_j≤1/2。若 a>0，则对 0≤s≤d，有 u_j(t−s)≥a−L_js。变参数下界给

```math
\begin{aligned}
u_{j+1}(t)
&\ge\int_0^d e^{-4L_js}(a-L_js)^2\,ds\\
&=\frac{a^3}{L_j}\int_0^1e^{-4av}(1-v)^2\,dv
\ge\frac{5-e^{-4}}{32L_j}a^3
\ge\frac{a^3}{8L_j}.
\end{aligned}
```

a=0 时结论也成立。真实前缀能量预算给 ∫_0^∞c_j u_j²u_(j+1)dt≤1/2，而 c_j≥1，所以

```math
\int_1^\infty u_j^5\,dt\le4L_j,\qquad
\int_0^T u_j^2\,dt\le
F_j(T):=1+(4L_j)^{2/5}T^{3/5}\quad(T\ge1).
```

这两个界同时对所有环境及 0<ν≤1 成立。令 H_M(t)=∑_(j≤M)u_j(t)²；它由前缀预算单调不增，故

```math
H_M(T)\le\frac1T\int_0^T H_M(t)\,dt
\le\frac{M+1}{T}
 +T^{-2/5}\sum_{j=0}^M(4L_j)^{2/5}
\longrightarrow0.
```

每个固定前缀都统一清空。这不单独证明能量已经耗散：冻结环境也满足它，能量可以仅向更高有限壳迁移。下面利用刷新过程控制这些高壳。

**有限矩控制实际能量。** 沿用 χ、M_N、D_N、z_n 及 N_ν。差分恒等式与有限 Cauchy–Schwarz 给

```math
\begin{aligned}
2D_N+z_N^2
 &=z_0^2+\sum_{n=0}^{N-1}(z_{n+1}-z_n)^2=:W_N,\\
z_n^2&\le(n+1)W_N,\qquad
\sum_{n=0}^Nu_n^2
\le\frac{W_N}{\chi(1-\chi^2)^2}.
\end{aligned}
```

因此，取 c_E=χ(1−χ²)²/2>0，

```math
D_N\ge c_E\sum_{n=0}^Nu_n^2-\frac{\chi}{2}K_N^{2/3}u_N^2.
```

这次控制的是实际头部能量，不只控制 M_N²。既有切面及黏性估计的 A_0、B_0 仍可原样使用。又因 K_(N_ν+1)>ν^(−3/4)，

```math
\int_0^T\sum_{n>N_\nu}u_n^2\,dt
\le\frac{Q_\nu(T)}{\nu K_{N_\nu+1}^2}
\le\nu^{1/2}Q_\nu(T),
```

而精确预算与 Q_ν 单调性给 ∫_0^T∑_n u_n²dt≥T[1−2Q_ν(T)]。于是

```math
M_{N_\nu}(T)\ge
1+c_ET-(2c_ET+A_0+c_E\nu^{1/2})Q_\nu(T)
-B_0\sqrt{TQ_\nu(T)}+\mathcal R_\nu(T),
```

其中 ℛ_ν 是完整的随机系数矩项，包含跨切面边；始终有 0≤M_N≤C_M:=(1−χ²)^(−1/2)。

**低层误差是次线性的。** 固定整数 m≥1，最后才令 m→∞。对足够小 ν 有 N_ν≥m。n<m 的边均为内边，利用 2u_nu_(n+1)≤u_n²+u_(n+1)²，得到

```math
\left|\sum_{n=1}^{m-1}(K_n-1)\int_0^T\zeta_nG_n\,dt\right|
\le\mathcal L_m(T):=
\sum_{n=1}^{m-1}K_n^{2/3}
\left[(\chi+\tfrac12)F_n(T)+\tfrac12F_{n+1}(T)\right].
```

对每个固定 m，ℒ_m(T)/T→0，统一于 ν 和环境。这里没有要求低层环境在某个幸运区间内快速交替。

**高层误差的时间平均。** 将时间分为单位块 k=0,1,…，定义

```math
I_{n,k}(s)=\int_0^s\zeta_n(k+r)\,dr,\qquad
J_{n,k}=\sup_{0\le s\le1}|I_{n,k}(s)|.
```

每个坐标可写为初始符号乘以 (−1) 的 Poisson 跳数次幂。绝对值消去块初符号，因此 J_(n,k) 只依赖该坐标在该块内的 Poisson 增量。不同坐标和不交时间块的这些增量独立；固定 n 时各 k 同分布。这个事实不要求轨道与环境独立。

[同一正概率事件上的全黏性下界](supplementary-methods-zh.md#同一正概率事件上的全黏性下界) 的二态鞅估计在单位窗给

```math
\mathbb EJ_{n,k}^2\le\frac8{A^2}K_n^{-8}
 +\frac{16}{A}K_n^{-4},\qquad
\mathbb EJ_{n,k}\le\frac{\sqrt8}{A}K_n^{-4}
 +\frac4{\sqrt A}K_n^{-2}
\le C_AK_n^{-2},
\quad C_A=\frac{\sqrt8}{A}+\frac4{\sqrt A}.
```

定义可积随机变量

```math
Y_k^{(m)}=\sum_{n=m}^\infty
(2K_n^{2/3}+5K_n^{5/3})J_{n,k},\qquad
\mu_m=\mathbb EY_k^{(m)}
\le C_A\sum_{n=m}^\infty
(2K_n^{-4/3}+5K_n^{-1/3})
\longrightarrow0.
```

固定 m 时，Y_k^(m) 为独立同分布的非负可积序列。因此强大数定律对所有整数 m 同时给出概率一事件，在其上

```math
\frac1T\sum_{k=0}^{T-1}Y_k^{(m)}
\longrightarrow\mu_m
\quad(T\to\infty,\ T\in\mathbb N).
```

另取 β=11/6。对每个 k，Markov 不等式给

```math
\sum_{n\ge1}\mathbb P(K_n^\beta J_{n,k}>1)
\le\sum_{n\ge1}
\left(\frac8{A^2}K_n^{-13/3}
 +\frac{16}{A}K_n^{-1/3}\right)<\infty.
```

Borel–Cantelli 及可数交集给另一个概率一事件：对每个有限整数 T，

```math
C_T(\omega):=\max_{0\le k<T}\sup_{n\ge1}K_n^\beta J_{n,k}<\infty.
```

令 Ω_* 为以上两个事件的交集；它只依环境，不依 ν。每个单位块都从 I_(n,k)(0)=0 作分部积分，利用 [刷新环境：保留轨道相关性的精确校正](supplementary-methods-zh.md#刷新环境保留轨道相关性的精确校正) 对内边和跨边统一的 G、G′ 界，得到

```math
\begin{aligned}
\left|\sum_{n=m}^{N_\nu}(K_n-1)
\int_0^T\zeta_nG_n\,dt\right|
&\le\sum_{k=0}^{T-1}Y_k^{(m)}
 +7\nu\sum_{k=0}^{T-1}
\sum_{n=m}^{N_\nu}K_n^{8/3}J_{n,k}\\
&\le\sum_{k=0}^{T-1}Y_k^{(m)}
 +\frac{7TC_T(\omega)}{1-2^{-5/6}}\nu^{3/8}.
\end{aligned}
```

黏性误差中先使用有限和及 K_(N_ν)≤ν^(−3/4)，绝不把正幂级数延伸到无穷。对每个固定整数 T，最后一项随 ν↓0 消失，且在同一路径上对全部小 ν 有效。

**极限次序与结论。** 固定 ω∈Ω_*、整数 m,T，并令 q(T)=liminf_(ν↓0)Q_ν(T,ω)。选实现这个 liminf 的序列；上述全部路径界对它成立，不要求该序列适应于随机滤过。由 M_N≤C_M 得

```math
1+c_ET\le C_M+(2c_ET+A_0)q(T)
 +B_0\sqrt{Tq(T)}
 +\mathcal L_m(T)+\sum_{k=0}^{T-1}Y_k^{(m)}.
```

q(T) 单调不减且在 [0,1/2] 内，故 q_∞=lim_(T→∞)q(T) 存在。先除以 T，再令整数 T→∞，得到 c_E≤2c_Eq_∞+μ_m。最后令 m→∞，μ_m→0，便有 q_∞≥1/2；预算给反向界。limsup_ν 的长期极限由夹逼同样等于 1/2。对非整数 T 使用 Q_ν 的单调性。

T_δ 与 ν_δ 也可从路径证书直接选取，避免任何不可数概率交集：选 m 使 μ_m<c_Eδ，令 q_*=1/2−δ，取首个正整数 T 使

```math
1+c_ET-C_M-(2c_ET+A_0)q_*
-B_0\sqrt{Tq_*}
-\mathcal L_m(T)-\sum_{k=0}^{T-1}Y_k^{(m)}>1.
```

其左侧除以 T 趋于 2c_Eδ−μ_m>0，所以该 T 在 Ω_* 上有限。再选 ν_δ>0，使 N_ν≥m 且 c_Eν^(1/2)/2+7TC_Tν^(3/8)/(1−2^(−5/6))<1 对全部 0<ν≤ν_δ 成立。若其中某个 ν 有 Q_ν(T)≤q_*，便与矩不等式矛盾。这给出只依环境的可测选择，并同时控制所有足够小黏性。

冻结样本几乎处处有无限多弱边，可与 Ω_* 相交而仍为概率一；共享初始符号后，冻结侧的先零黏后长时损失为 0，刷新侧为全部初能 1/2。每个确定固定窗仍有 [预定窗零损失事件](consequences-zh.md#预定有限窗的正概率零损失事件) 的正概率零耗散事件，两者量词一致而不矛盾。该方法的等待窗口估计与当前完整速率分类分开列出。概率一长期失能本身有 BFM 先例，具体先例见[文献及证据](literature-zh.md)。

## 持续刷新也可能无耗散：慢刷新与快刷新的同边际对照

<!-- source: docs/appendices/mechanisms-zh.md B.11.10 -->

上一节说明原快速刷新模型几乎必然有足够长的耗散窗口，但“系数持续变化”本身并不足够。本节明确改变环境参数：保留相同方程、初值、黏性及独立公平初始符号，只把第 n 条边的对称跳率改为 r_n/2，其中每个 r_n>0 有限、确定且不依 ν。固定黏性构造仍由 [固定黏性构造](proofs-zh.md#固定黏性构造适应性与精确预算) 的统一系数界承担。

任给固定 T>0，若

```math
\sum_{n\ge1}\exp(-r_nT/2)=\infty,
```

则几乎处处 Q_ν(T)→0。证明只需整窗保持弱状态的边：事件 A_(n,T) 表示 ζ_n(0)=−1 且第 n 坐标在 [0,T] 无跳变，其概率为

```math
\mathbb P(A_{n,T})=\tfrac12e^{-r_nT/2}.
```

这些事件跨 n 独立，第二 Borel–Cantelli 引理给无限多条整窗满足 c_n(t)=1 的边。其他边可以任意刷新。沿选出的 m 条边重复 [冻结环境零侧](consequences-zh.md#严格冻结环境的零耗散) 的真实尾预算，只需要所选边在该窗为弱，不需要整个环境静态；因此

```math
Q_\nu(T)\le\nu T K_{L_m}^2+\frac Tm.
```

先固定 m 令 ν↓0，再令 m→∞，即得结论。若级数发散对每个正整数 T 都成立，可数交集与 Q_ν 的时间单调性给同一个概率一事件，其上所有有限固定窗都无异常耗散。

一个明确充分条件是 r_n=o(log(n+1))：固定 T 后，充分大的 n 满足 r_nT/2≤(1/2)log(n+1)，故级数逐项下界为 (n+1)^(−1/2)。特别地，任意常数正刷新率 r_n=r 均满足条件；即使这个常数很大，也不能在无限链的固定窗消除无限多条持续弱边。

因此现在可比较两种都持续演化的环境，而不只比较冻结与演化：

| 环境跳率 | 每个确定时刻的全系数场分布 | 实际黏性结论 |
|---|---|---|
| 任意固定 r/2>0，逐边独立刷新 | 独立公平的 1 或 2K_n−1 | 几乎处处所有固定窗 Q_ν→0；先零黏再长时间为 0 |
| 8192 K_n⁴/2，逐边独立刷新 | 同一分布 | 几乎处处在样本依赖窗耗掉任意接近全部初能；先零黏再长时间为 1/2 |

两过程可以共享全部初始符号；相应概率一事件的交集仍为概率一。因此同一初始环境样本下，二者在快侧选定的有限样本窗口内仍有零／正损失对照。这里慢侧“所有有限窗”已在同一个样本事件上证明，允许代入快侧选出的随机但有限窗口，不是在不可数个单独概率一事件间换量词。

没有证明发散条件必要，也没有分类介于次对数率与当前 K_n⁴ 充分率之间的刷新族。这个推论把贡献候选进一步定位到时间相关尺度，而不是把随机性或所有形式的刷新都等同于促进耗散。

## 可求和刷新等待与真实黏性损失

<!-- source: docs/appendices/mechanisms-zh.md B.11.16 -->

现在恢复 D1 独立二态环境，假设 𝒮<∞。固定 a∈(0,1)，取

```math
d_n=\frac{a}{(n+1)(n+2)},\qquad
A_n=\sum_{j=0}^n d_j<a,\qquad
h_n=\frac{512}{K_nd_n^2}.
```

有 ∑d_n=a，以及

```math
\sum_{n=0}^{\infty}h_n
=512a^{-2}\sum_{n=0}^{\infty}
\frac{(n+1)^2(n+2)^2}{2^n}
=212992a^{-2}.
```

构造只依环境的递增时间 τ_n。根边恒满足 c_0=K_0=1，取 τ_0=h_0。对 n≥1，从 τ_(n−1) 开始，等待第 n 环境进入强状态，再观察长度 h_n 的一段；若强状态占用量不少于 h_n/4，该段结束时定义 τ_n。否则，从该段末尾再等待进入强状态，重复观察，直到成功。所有观察段都是完整观察后再判定，不预知未来；这些时刻是相应环境滤过的停止时刻。

从强状态启动的对称二态过程满足

```math
P(\zeta_n(s)=+1\mid\zeta_n(0)=+1)
=\frac{1+e^{-r_ns}}2,
\qquad
\mathbb EO\ge\frac{h_n}2.
```

因 0≤O≤h_n，若 p=P(O≥h_n/4)，则 E O≤h_n(1-p)/4+h_np，故 p≥1/3。强 Markov 性保证每次尝试在给定历史后仍有这一成功概率。每次开始前的强状态等待，条件期望至多 2/r_n；尝试数被成功率 1/3 的几何分布控制，不要求各次成功事件独立。因此

```math
\mathbb E(\tau_n-\tau_{n-1})
\le3h_n+\frac6{r_n}.
```

从第 n−1 层构造的进入时刻只用到前 n 个坐标，不依赖第 n 环境；因此随机进入时刻不破坏上述条件估计。累加、单调收敛得到

```math
\tau_a:=\lim_{n\to\infty}\tau_n<\infty\quad\text{几乎必然},
\qquad
\mathbb E\tau_a
\le3\sum_{n\ge0}h_n+6\mathcal S
=M_a.
```

该构造对所有黏性共用。对固定 0<ν≤1，取

```math
L_\nu=\left\lfloor\log_2\frac1\nu\right\rfloor.
```

所有 n≤L_ν 满足 νK_n≤1。按 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递) 从根起归纳，H_n(τ_n)≤A_n；由于前缀能量不增，在有限时刻 τ_a 也有 H_(L_ν)(τ_a)≤a。这一切面是无限层固定黏性解中的切面，并非将原方程截断为 L_ν 层。

设 y_ν(t)=∑_n u_n^\nu(t)²=1−2Q_ν(t)。对几乎处处 t≥τ_a，由精确能量预算，

```math
y_\nu'(t)
\le-2\nu K_{L_\nu+1}^2
\bigl(y_\nu(t)-H_{L_\nu}(t)\bigr)
\le-2\nu K_{L_\nu+1}^2(y_\nu(t)-a).
```

积分得 y_ν(τ_a+s)≤a+exp(−2νK_(L_ν+1)²s)。又 K_(L_ν+1)>1/ν，故

```math
y_\nu(\tau_a+s)\le a+e^{-2s/\nu},
\qquad
Q_\nu(\tau_a+s)\ge\frac{1-a-e^{-2s/\nu}}2.
```

这直接控制真实黏性积分，不将逃向高壳的能量等同于已经耗散。固定样本及 a 先令 ν↓0，再增加 T，得到长期损失至少 (1−a)/2；对可数个有理 a↓0 取共同事件，预算给上界 1/2，完成 [独立边分类](consequences-zh.md#独立边的相关时间级数分类) 第二项与上下极限的夹逼。

**确定窗口与等待尾界。** 对任意固定 a∈(0,1/2)、T>1，

```math
P(\tau_a>T-1)\le\frac{M_a}{T-1}.
```

在其补事件上，所有

```math
0<\nu\le\nu_a:=
\min\!\left\{1,\frac2{\log(1/a)}\right\}
```

同时有 Q_ν(T)≥1/2−a。因此

```math
\mathbb E Q_\nu(T)\ge
\left(\frac12-a\right)
\left(1-\frac{M_a}{T-1}\right)_+
\qquad(0<\nu\le\nu_a).
```

对 a=1/4，可直接用 e^(−2)<1/4，得到 [独立边分类](consequences-zh.md#独立边的相关时间级数分类) 的 T_*、共同事件及全 0<ν≤1 下界。

## 分块相关二态环境的精确分类

<!-- source: docs/appendices/mechanisms-zh.md B.11.18 -->

将非根边编号集合 {1,2,…} 划分为顺次相邻的非空区块 I_j。允许可数无限个有限块，也允许有限个块且最后一块为无限尾块。记 m_j=min I_j。每个块使用一个公平平稳二态 Markov 过程 η_j，每方向翻转率为 ρ_j/2，其中 0<ρ_j<∞；不同块的整个过程独立。令

```math
\zeta_n(t)=\eta_j(t)\quad(n\in I_j),\qquad
c_n(t)=K_n+(K_n-1)\zeta_n(t),\qquad c_0=1,
\qquad
\mathcal S_{\mathrm{blk}}=\sum_j\frac1{\rho_j}.
```

块划分、速率及环境都不依赖 ν。[固定黏性构造](proofs-zh.md#固定黏性构造适应性与精确预算) 的系数界、固定黏性构造和精确预算是路径性结论，不要求各边独立，故在此直接适用。

**分块分类定理。**

1. 若 𝒮_blk=∞，则在同一个环境概率一事件上，对所有有限 T>0 都有 Q_ν(T)→0；每个固定 T 的期望也趋于零。
2. 若 𝒮_blk<∞，则在同一个环境概率一事件上，

```math
\lim_{T\to\infty}\liminf_{\nu\downarrow0}Q_\nu(T)
=\lim_{T\to\infty}\limsup_{\nu\downarrow0}Q_\nu(T)=\frac12.
```

更具体地，对每个固定 a∈(0,1)，存在不依赖 ν 的环境随机时间 τ_a，使

```math
\mathbb E\tau_a\le
M_a^{\mathrm{blk}}:=4202496\,a^{-2}+6\mathcal S_{\mathrm{blk}}<\infty,
\qquad
Q_\nu(\tau_a+s)\ge\frac{1-a-e^{-2s/\nu}}2
\quad(s\ge0,\ 0<\nu\le1)
```

在同一事件上同时成立。于是取 T_*=1+2M_(1/4)^blk，事件 {τ_(1/4)≤2M_(1/4)^blk} 的概率至少为 1/2，其上所有 0<ν≤1 均有 Q_ν(T_*)>1/4，因而 E Q_ν(T_*)≥1/8。该常数仅用于给出明确有限窗口，不优于独立情形已有的常数。

判据对独立块求和，不乘块长；块长可以无界。这是对指定“块内完全同步、块间独立”家族的分类，不是任意空间相关环境的一般定理。每个预定有限窗仍有正概率零耗散，见 [单边完整时间统计不变时的空间相关耗散对照](consequences-zh.md#相同单边完整路径律的空间对照)。

## 充分性：块内前段占用传递与共用尾段强区间

<!-- source: docs/appendices/mechanisms-zh.md B.11.20 -->

如果逐边照搬 [单边调度](proofs-zh.md#联合环境中的单边传递调度)，只能得到 ∑_j|I_j|/ρ_j 的等待费用，不能证明新定理。本节消除这个块长因子。

固定 a∈(0,1)，重新选择几何残留预算及 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递) 所需的传递时长：

```math
d_n=\frac a4\left(\frac34\right)^n,\qquad
A_n=\sum_{k=0}^n d_k<a,\qquad
h_n=\frac{512}{K_nd_n^2}
=8192a^{-2}\left(\frac89\right)^n.
```

记 q=8/9，则

```math
\sum_{n\ge0}d_n=a,\qquad
\sum_{n\ge0}h_n=73728a^{-2},\qquad
\sum_{k=n}^\infty h_k=9h_n.
```

先用恒强根边，经过 h_0 时间完成第 0 层传递，置 σ_0=h_0。以下在第 j 块的开始时刻 σ_(j−1) 之后构造完成时刻 σ_j；这些时刻只依环境。

**块内分界。** 按编号把 I_j 分成两个相邻部分：

- 前段 F_j={n∈I_j:9h_n>1/ρ_j}；
- 尾段 R_j={n∈I_j:9h_n≤1/ρ_j}。

h_n 严格递减，故前段总是有限；两部分之一可以为空。若尾段非空，记 k_j=min R_j 和 H_j=∑_(n∈R_j)h_n，则

```math
H_j\le9h_{k_j}\le\frac1{\rho_j}.
```

即使最后一块无限，H_j 仍有限。前段每个 n 满足 1/ρ_j<9h_n。

**前段的逐层尝试。** 在当前完成时刻等待 η_j 进入强状态，观察完整长度 h_n 的区间；若强状态占用不少于 h_n/4，就完成该层，否则从区间末尾再次等待并尝试。从强状态启动，

```math
\mathbb E O=\int_0^{h_n}\frac{1+e^{-\rho_js}}2\,ds\ge\frac{h_n}2,
\qquad P(O\ge h_n/4)\ge\frac13.
```

从任意状态等待到强的条件期望至多 2/ρ_j。强 Markov 性在每次尝试后适用，因而给定此前历史，完成第 n 层的条件期望费用不超过

```math
3h_n+\frac6{\rho_j}\le57h_n\qquad(n\in F_j).
```

这里不声称进入块内后续层时的门仍公平或独立；门的状态可以被过去选择。估计从任意当前状态出发，只有等待到强之后才使用强启动分布。涉及第 j 块的所有有限阶段都可放在前 j 个门的有限维联合 Markov 过程中，避免要求整个无限环境具有有限总跳率。

**尾段共用一次强区间。** 前段完成后，等待 η_j 到强，观察完整长度 H_j 的区间。若其间没有翻转，则所有尾段边共同强，顺次分配各自长度 h_n 的传递区间即可；若有翻转，在 H_j 区间末尾重新等待到强并重试。每次的条件成功概率为

```math
p_j=e^{-\rho_jH_j/2}\ge e^{-1/2}>\frac12.
```

因此尾段完成的条件期望费用不超过

```math
2H_j+\frac4{\rho_j}\le\frac6{\rho_j}.
```

若尾段为空，费用为零。关键是此处只为整个尾段支付一个等待费用；没有为每条同步边重新付费。

每次观察都在完整区间结束后判定，故块完成时刻 σ_j 是停止时刻。成功尾段内部各 h_n 小区间可以在确认整段成功后回溯标记；它们不必是停止时刻，且后续概率估计只在块完成时刻使用强 Markov 性。确定性 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递) 可以直接用于这些已选区间。若尾段无限，区间右端为有限和 H_j；证明任意有限前缀只需其中有限个小区间。

由条件期望估计，

```math
\mathbb E(\sigma_j-\sigma_{j-1}\mid\mathcal F_{\sigma_{j-1}})
\le57\sum_{n\in I_j}h_n+\frac6{\rho_j}.
```

令 τ_a 为所有块完成时刻的递增极限；有限多个块时取最后一个完成时刻。由单调收敛和根边的 h_0，

```math
\mathbb E\tau_a
\le57\sum_{n\ge0}h_n+6\mathcal S_{\mathrm{blk}}
=4202496a^{-2}+6\mathcal S_{\mathrm{blk}}<\infty.
```

故 τ_a<∞ 几乎必然，且所有构造都与 ν 无关。

**真实黏性清除及共同事件。** 固定一条上述成功的环境路径，考虑任意 0<ν≤1，令 L_ν=⌊log₂(1/ν)⌋。每个 n≤L_ν 都满足 νK_n≤1。按各块中成功区间的先后次序应用 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)，得到 H_n≤A_n；前缀单调性保证先前已得的界在等待和失败尝试期间不会失效。即使 L_ν 落在块内部、或无限尾块中，也只需到该层为止的有限次归纳。因此

```math
H_{L_\nu}(\tau_a)\le a.
```

同一 τ_a 对所有 ν 有效。对实际无限层解令 y_ν=∑u_n²=1−2Q_ν。对 t≥τ_a，预算与 H_(L_ν)(t)≤a 给

```math
y_\nu'(t)\le-2\nu K_{L_\nu+1}^2(y_\nu(t)-a),\qquad
y_\nu(\tau_a+s)\le a+e^{-2s/\nu},
```

因为 K_(L_ν+1)>1/ν。于是得到定理所列的 Q 下界。此步使用真实黏性积分，不把共同强区间内的传递本身当成已经耗散。

对可数个有理 a∈(0,1) 取共同概率一事件，先 ν↓0、后 T→∞、最后 a↓0，预算上界 1/2 给两种顺序极限。Markov 不等式及 e^(−2)<1/4 给确定窗的共同正概率下界。全程不对不可数个单独概率一事件取交，也不交换零黏与长时极限。证毕。

## 证明：块入口阻断与重置后的短传递窗口

<!-- source: docs/appendices/mechanisms-zh.md B.11.24 -->

本节采用多项式块长 ℓ_j=⌈j^β⌉、r_j=A j^p 及固定 θ>0，给出另一组显式窗口常数。

正侧取 $p>1$、$a\in(0,1)$、$q=8/9$、$d_n=(a/4)(3/4)^n$、$h_n=8192a^{-2}q^n$，并记

```math
C_a=73728Aa^{-2}\sup_{j\ge1}(j^{p+\beta}q^j),\qquad
M_a(\theta)=e^{C_a}\left(73728a^{-2}+\frac2{\theta A}\sum_{j\ge1}j^{-p}\right).
```



**零侧。** 对 θ>0、p≤1，采用 [路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的辅助纯生过程 X，跳率 λ_n=2c_n，以及不要求边独立的路径能量上界。设 D_j 为从块首 m_j 到下一块首 m_(j+1) 的穿块时间。每块有限、λ_n≥2，故到达每个有限块的时刻有限。

进入新块前尚未使用该块环境，故平稳性和块间独立性给 D_j 的相互独立性，正如 [必要性：每次进入新块仍遇到独立平稳门](proofs-zh.md#平稳块入口费用的阻断)；块内驻留时间不必独立。首边在进入时公平，且它自身是翻转率 r_j/2 的二态链，所以在首边初始弱、长度 t 内不变号且辅助出生时钟不触发的事件上，D_j>t。于是

```math
P(D_j>t)\ge\frac12e^{-(r_j/2+2)t},\qquad
1-\mathbb E e^{-D_j}\ge\frac1{r_j+6}.
```

p≤1 时 ∑1/(Aj^p+6)=∞。独立拉普拉斯乘积给 ∑D_j=∞ 几乎必然，Fubini 再给同一环境上的辅助无爆炸。路径能量比较先 ν↓0、后切面 L→∞，得到全部有限窗 Q_ν→0，预算上界给期望收敛。这里用的是单边“不变号”，没有误把共同重置事件率 θr_j 当成该边有效翻转率。

θ=0 时所有边独立，[独立边分类](consequences-zh.md#独立边的相关时间级数分类) 直接适用，其相关时间之和为

```math
\sum_{n\ge1}\frac1{r_{j(n)}}
=\frac1A\sum_{j\ge1}\ell_j j^{-p}.
```

由于 j^β≤ℓ_j≤2j^β，该级数恰在 p>β+1 时收敛，给第二项的完整分类。

**正侧的块尝试。** 以下固定 θ>0、p>1。根边恒强，先经过 h_0，置 σ_0=h_0。记第 j 块所需的总传递时长及总时钟率为

```math
W_j=\sum_{n\in I_j}h_n\le73728a^{-2}q^{m_j},\qquad
\Gamma_j=r_j\left[\theta+\frac{(1-\theta)\ell_j}{2}\right].
```

在第 j 块开始时刻 σ_(j−1) 后，等待本块首次全为 +1（若当前已经全强，则不等待）。下一次符号为 +1 的共同重置必使整块全强，所以这个等待的条件期望至多 2/(θr_j)。随后观察完整 W_j 区间，以“全区间内整块保持全强”为成功条件。无任何共同重置或私有翻转足以保证成功，所以每次条件成功概率至少为

```math
P_j=e^{-\Gamma_jW_j}>0.
```

实际成功允许不改变全强状态的重置，故上述概率界只会偏保守。若失败，从 W_j 区间末尾重新等待全强并重试。每次尝试开始及完整观察结束都是有限维联合门过程的停止时刻，强 Markov 性保证条件费用和成功概率仍有上述界。整个调度只需观察符号轨迹，不需要识别不可见的同符号重置。几何重试给

```math
\mathbb E(\sigma_j-\sigma_{j-1}\mid\mathcal F_{\sigma_{j-1}})
\le e^{\Gamma_jW_j}\left(W_j+\frac2{\theta r_j}\right).
```

整个成功区间内每条本块边均强，按 h_n 顺次分配传递区间即可。最后成功区间可以在完成后回溯标记；这些内部小区间只用于确定性 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)，不把依赖未来成功的时刻用于概率条件化。

**求和与真实黏性。** 因 ℓ_j≤2j^β、m_j≥j，

```math
\Gamma_j\le A j^{p+\beta},\qquad
\Gamma_jW_j\le73728Aa^{-2}j^{p+\beta}q^j\le C_a.
```

多项式乘几何序列趋零，故 C_a 有限；它不依 θ。又 ∑h_n=73728a^(-2)，p>1 给 ∑1/r_j<∞。令 τ_a=lim_jσ_j，由非负项求和及单调收敛，

```math
\mathbb E\tau_a
\le h_0+\sum_j e^{\Gamma_jW_j}
\left(W_j+\frac2{\theta r_j}\right)
\le M_a(\theta)<\infty.
```

故 τ_a 几乎必然有限，且构造不含 ν。固定这样的环境及任意 0<ν≤1，令 L_ν=⌊log₂(1/ν)⌋。只对 n≤L_ν 的有限个成功小区间应用 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)，得到 H_(L_ν)(τ_a)≤∑_(n≤L_ν)d_n<a。失败尝试与等待期间，前缀单调性保证已得界不被破坏；即使 L_ν 落在块内部，结论也成立。

最后对实际无限层解使用精确预算：y_ν=∑u_n²=1−2Q_ν 在 τ_a 后满足

```math
y_\nu'\le-2\nu K_{L_\nu+1}^2(y_\nu-a),\qquad
y_\nu(\tau_a+s)\le a+e^{-2s/\nu}.
```

这给出所列 Q 下界，控制的是实际黏性损失。对可数个有理 a↓0 取共同概率一事件，先取零黏上下极限，再增长 T，即得全部初能的顺序极限。固定窗共同正概率事件由 Markov 不等式得到，不交换期望与下极限。证毕。

**每个预定窗口的零损失事件。** 给定 T，取 [预定窗零损失事件](consequences-zh.md#预定有限窗的正概率零损失事件) 所需有限弱前缀，让与此前缀相交的有限多个整块初始全弱，且在 [0,T] 内所有这些块的共同及私有时钟均不触发。各块的全弱平稳概率严格为正，事件概率至少为这些有限个概率的乘积再乘 exp(−T∑Γ_j)>0。该事件上旧路径估计仍给 Q_ν(T)→0。这保留了固定窗／样本窗的区别。

## 充分性：逐块选择两种可观测传递调度

<!-- source: docs/appendices/mechanisms-zh.md B.11.28 -->

本节采用多项式块长与块率，给出逐边／整块两种调度及显式窗口估计。

取 $\ell_j=\lceil j^\beta\rceil$、$r_j=Aj^p$、$q=8/9$、$d_n=(a/4)(3/4)^n$、$h_n=8192a^{-2}q^n$、$w_j=\min\{\ell_j,1/\theta_j\}/r_j$，并记

```math
\mathcal W=\sum_jw_j,\qquad
C_a=73728Aa^{-2}\sup_{j\ge1}(j^{p+\beta}q^j),\qquad
\widehat M_a=e^{C_a}(221184a^{-2}+6\mathcal W).
```



固定 a∈(0,1)，使用 [渐弱共同作用判据](consequences-zh.md#逐块渐弱共同作用的判据) 的几何 d_n、h_n。根边恒强，先经过 h_0。记第 j 块的总传递时长和总时钟率为

```math
W_j=\sum_{n\in I_j}h_n\le73728a^{-2}q^{m_j},\qquad
\Gamma_j=r_j\left[\theta_j+\frac{(1-\theta_j)\ell_j}{2}\right].
```

在每块开始前，依据确定参数选择以下一种调度；不观察未来来选择。

**若 ℓ_j≤1/θ_j，采用逐边占用调度。** 对块内每条边，从前一条边完成时开始，等到当前边强，观察完整 h_n 区间；占用量不少于 h_n/4 才算成功，否则重试。虽然这些边存在共同重置，但对任意单边函数，联合块生成元仍闭合为翻转率 r_j/2 的二态生成元。因此给定块当前全部状态，当前边的未来转移律只依自己的当前符号；有限维块过程的强 Markov 性使这个结论在各实际停止时刻成立。

每次等强的条件期望至多 2/r_j，从强启动的一段占用成功概率至少 1/3，与 [单边调度](proofs-zh.md#联合环境中的单边传递调度) 相同。因此整个块的条件平均费用不超过

```math
3W_j+\frac{6\ell_j}{r_j}=3W_j+6w_j.
```

这一步不假设到达块内后续边时其状态仍公平，也不假设各边独立。θ_j=0 自动采用此调度。

**若 ℓ_j>1/θ_j，采用整块全强调度。** 此时 θ_j>0。等到本块全部为强，再观察完整 W_j 区间；全程保持全强才算成功，失败后重试。等待均值至多 2/(θ_jr_j)，每次成功概率至少 exp(−Γ_jW_j)，故条件平均费用不超过

```math
e^{\Gamma_jW_j}\left(W_j+\frac2{\theta_jr_j}\right)
=e^{\Gamma_jW_j}(W_j+2w_j).
```

这正是 [证明：块入口阻断与重置后的短传递窗口](supplementary-methods-zh.md#证明块入口阻断与重置后的短传递窗口) 的可观测全强调度，判断只用符号路径。完成前不宣布成功；成功区间内各条边的小区间仅在完成后回溯用于确定性 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)，不用作强 Markov 条件化的时刻。

**统一求和。** ℓ_j≤2j^β、j^β≥1、m_j≥j 给

```math
\Gamma_j
\le A j^p\bigl[\theta_j+(1-\theta_j)j^\beta\bigr]
\le A j^{p+\beta},\qquad
\Gamma_jW_j\le C_a.
```

所以无论选哪种调度，块完成时刻 σ_j 满足

```math
\mathbb E(\sigma_j-\sigma_{j-1}\mid\mathcal F_{\sigma_{j-1}})
\le e^{C_a}(3W_j+6w_j).
```

各次等待、观察结束与块完成均为已用有限多个块的联合环境停止时刻，不需要整个无限环境的总跳率有限。若 𝒲<∞，令 τ_a=lim_jσ_j；非负项求和给

```math
\mathbb E\tau_a
\le h_0+e^{C_a}\left(3\sum_jW_j+6\mathcal W\right)
\le\widehat M_a<\infty.
```

故 τ_a 几乎必然有限。每一成功小区间都满足 [确定性占用传递](proofs-zh.md#强状态占用的确定性传递)；等待或失败期间前缀能量不增。对同一环境及任意 0<ν≤1，只归纳到有限切面 L_ν=⌊log₂(1/ν)⌋，得到 H_(L_ν)(τ_a)≤∑_(n≤L_ν)d_n<a。若切面位于块内部，同一结论仍成立。

随后应用[实际黏性清除](proofs-zh.md#可求和混合调度与实际黏性清除)：

```math
y_\nu=\sum_n(u_n^\nu)^2=1-2Q_\nu,\qquad
y_\nu(\tau_a+s)\le a+e^{-2s/\nu}.
```

这证明 [渐弱共同作用判据](consequences-zh.md#逐块渐弱共同作用的判据) 的路径下界。对可数个有理 a↓0 取共同概率一事件，先零黏、后长时取上下极限，得到全部初能损失；确定窗的共同正概率事件由 Eτ_a 的 Markov 界得到。没有对不可数个单独概率一事件取交，也没有从辅助过程爆炸推出非线性耗散。

每个预定有限 T 仍有严格正概率的零损失环境事件：令所需有限弱前缀涉及的整块初始全弱，且该窗口内其全部时钟均不触发。每个有限块的全弱平稳概率正、总时钟率有限，[预定窗零损失事件](consequences-zh.md#预定有限窗的正概率零损失事件) 的原路径估计适用。因此正侧没有被加强成预定窗口概率一正耗散。证毕。

## 私有翻转使无限长区块的辅助传输不爆炸

<!-- source: docs/appendices/mechanisms-zh.md B.11.30 -->

以下无限块引理检验 [渐弱共同作用判据](consequences-zh.md#逐块渐弱共同作用的判据) 能否完全删除块长增长控制。下述反例保持 D1 方程、K_n=2^n、单位根脉冲、无迫、标准黏性、无限层能量解与精确预算；改变的是预先固定的有限区块长度。仍只重置环境系数，不重置振幅或辅助粒子的位置。

先证明一个不要求平稳初始符号的引理。固定有限起始坐标 m≥1，在所有 n≥m 上让 ζ_n 独立以同一速率 a>0 翻转，暂时没有共同重置。初始符号配置可以任意，也可以相关，但与未来私有时钟、辅助出生时钟独立。令辅助过程 X 从 m 出发，按 λ_n(t)=2c_n(t) 向上跳跃，其中 c_n=K_n+(K_n−1)ζ_n。

**引理。** 对任意上述初始配置，X 几乎必然不爆炸，即不能在有限时间穿越无限多条边。这个结论对任意小的固定 a>0 成立。

**证明。** 先给定全部初始符号。设 S_n 为在 n 的驻留时间，σ=S_m 是第一次跳跃时间。因 2≤λ_m(t)≤4K_m−2<∞，有 0<σ<∞ 几乎必然。

条件于初始配置及决定 σ 的首边路径、辅助时钟，其余边的未来私有路径仍相互独立。对于尚未使用的 n>m，任意 t≥σ 均有

```math
P(\zeta_n(t)=-1\mid\zeta_n(0))
=\frac{1-\zeta_n(0)e^{-2at}}2
\ge q_\sigma:=\frac{1-e^{-2a\sigma}}2>0.
```

到达第 n 条边的时间只依赖先前边的路径和已用辅助时钟，故这个下界同样适用于随机到达。到达时若为弱，私有翻转或弱出生的第一次发生时间为 Exp(a+2)。于是对已用历史有

```math
P(S_n>s\mid\text{已用历史})\ge q_\sigma e^{-(a+2)s},
\qquad
\mathbb E(e^{-S_n}\mid\text{已用历史})
\le1-\frac{q_\sigma}{a+3}=:\rho_\sigma<1.
```

给定上述首边信息，逐次条件期望得到

```math
\mathbb E\!\left[
\exp\!\left(-\sum_{n=m+1}^{N}S_n\right)
\ \middle|\ \text{首边信息、初始配置}
\right]\le\rho_\sigma^{\,N-m}\longrightarrow0.
```

由条件有界收敛，∑_(n>m)S_n=∞ 几乎必然。最后对初始配置取平均即可。证明没有把块内驻留时间当成独立；只在无共同重置时，使用尚未访问的私有路径独立性。即使所有符号最初为强，首个严格正的驻留时间也让后续无限多条边具有统一的正弱概率。证毕。

## 有限率共同重置不能消除无限块阻断

<!-- source: docs/appendices/mechanisms-zh.md B.11.31 -->

固定 r∈(0,∞)、θ∈[0,1)，在无限尾块 n≥m 使用共同公平重置率 θr、各边私有翻转率

```math
a=\frac{(1-\theta)r}{2}>0.
```

**无限块结论。** 对任意有限起始坐标，辅助过程仍几乎必然不爆炸。该结论允许平稳年龄混合初始律，也允许任意与未来时钟独立的初始符号律。

固定有限 T，条件于 [0,T] 内完整的共同重置时钟及其标记。其事件数服从有限均值的 Poisson 分布，几乎必然有限。条件化后，各重置时间可视为给定时刻，与私有时钟和辅助出生驱动独立。第一个重置前，[私有翻转使无限长区块的辅助传输不爆炸](supplementary-methods-zh.md#私有翻转使无限长区块的辅助传输不爆炸) 给非爆炸；每次重置只将符号置为共同 ±1，X 保持在当时的有限坐标。下一段的私有时钟和辅助出生驱动增量独立于此前历史，故可从该有限坐标再次应用 [私有翻转使无限长区块的辅助传输不爆炸](supplementary-methods-zh.md#私有翻转使无限长区块的辅助传输不爆炸)；等价地，指数出生阈值具有无记忆性。对有限段归纳，X 在 [0,T] 不爆炸。先对共同时钟取平均，再对正整数 T 取可数交，即得到全部有限窗口的非爆炸事件。

这里无需假设无限个私有时钟的总事件率有限；只要求每个坐标的时钟率有限，以及共同重置在有限窗口内次数有限。也没有将整个过程误写成把粒子位置重置到固定起点的更新过程。

若 D1 的所有非根边组成一个无限块，并从 [平稳重置环境](model-zh.md#平稳块环境与保持的统计量) 的平稳律启动，那么根层到块首的进入时间独立于尾块环境。由上述结论、平稳性和 [路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的 Fubini／路径能量比较，θ<1 时几乎处处所有有限 T 均有 Q_ν(T)→0；期望也趋于零。θ=1 则恢复 [同步块分类及无限尾块](supplementary-methods-zh.md#分块相关二态环境的精确分类) 的单个无限同步块，∑_j1/r_j=1/r<∞，有完整正侧结论。每条边单独的完整时间路径律在所有 θ 下仍相同，均为翻转率 r/2 的公平平稳二态链。

因此在这一个无限块家族中，完全同步 θ=1 是耗散分类的特殊端点。以下将该障碍转为**全部区块均有限**的反例，避免把无限块本身作为有限块问题的答案。

## 递归有限块反例：等待级数收敛但实际耗散为零

<!-- source: docs/appendices/mechanisms-zh.md B.11.32 -->

对固定 m≥1、L≥1、r>0、θ<1，令 D_(m,L;r,θ) 为辅助过程从 m 穿过 L 条边、首次到达 m+L 的时间，块环境按上述共同重置／私有翻转机制平稳启动。定义确定的有限块量

```math
\Psi_{m,L}(r,\theta)
=\mathbb E\exp[-D_{m,L;r,\theta}].
```

平稳块的分布在限制到前 L 条边时彼此一致：使用同一个过去末次重置年龄、公共符号和私有路径即可同时实现全部长度。出生过程到达 m+L 前也只读取此前 L 条边。因此这些 D 可耦合为 [有限率共同重置不能消除无限块阻断](supplementary-methods-zh.md#有限率共同重置不能消除无限块阻断) 无限块过程的逐层到达时间。该过程不爆炸给

```math
D_{m,L;r,\theta}\uparrow\infty\quad\text{几乎必然},\qquad
\Psi_{m,L}(r,\theta)\downarrow0
\quad(L\to\infty).
```

这里 r、θ、m 在 L 极限中固定；θ<1 虽可任意接近 1，仍是严格不等号。

**反例定理。** 任取预先规定的序列 ε_j∈(0,1/2]，置

```math
r_j=j^2,\qquad \theta_j=1-\varepsilon_j\in[1/2,1).
```

存在全部有限的相邻块划分，使

```math
\sum_j\frac{\min\{\ell_j,\theta_j^{-1}\}}{r_j}<\infty,
\qquad
Q_\nu(T)\longrightarrow0
\quad\text{几乎处处、同时对全部有限 }T.
```

在**同一个**块划分、相同 r_j 下，把 θ_j 全部换成 1，则有 [同步块分类及无限尾块](supplementary-methods-zh.md#分块相关二态环境的精确分类) 的完整正侧结论。两组每条边各自的完整时间路径分布严格相同。

**确定性递归构造。** 从 m_1=1 开始，依次定义

```math
\ell_j=
\min\left\{L\in\mathbb N:
L\ge\max\{2,j\},\
\Psi_{m_j,L}(j^2,1-\varepsilon_j)\le\frac12
\right\},
\qquad m_{j+1}=m_j+\ell_j.
```

由 Ψ↓0，每一步的集合非空，ℓ_j 是有限确定整数。所有区块在选定 ε 序列后即固定，不依赖 ν，不随实际环境样本调整，也不在取零黏极限时改变。每块保持独立和平稳，私有翻转率为 ε_j j²/2>0。

**零耗散证明。** 设全局辅助过程在第 j 块的实际穿块时间为 D_j。进入该块前尚未使用它的环境；平稳性、块间独立与新辅助时钟独立，保证 D_j 相互独立，其分布恰为递归定义所用的 D_(m_j,ℓ_j;j²,θ_j)。故

```math
\mathbb E\exp\!\left(-\sum_{j=1}^J D_j\right)
=\prod_{j=1}^J\Psi_{m_j,\ell_j}(j^2,\theta_j)
\le2^{-J}\longrightarrow0.
```

因此 ∑D_j=∞ 几乎必然。[路径能量比较](proofs-zh.md#路径能量比较与非爆炸准则) 的路径能量比较给

```math
Q_\nu(T)\le\nu K_N^2T+\frac12P_\omega(X(T)>N).
```

Fubini 提供同一环境概率一事件，其上辅助过程在全部有限窗口不爆炸。先固定 N 令 ν↓0，再令 N→∞，得到全部有限窗零实际黏性损失；由 Q_ν≤1/2，固定 T 的期望也趋于零。

**级数确实收敛。** 因 ℓ_j≥2、θ_j≥1/2，恰有 min{ℓ_j,1/θ_j}=1/θ_j，所以

```math
\sum_j\frac{\min\{\ell_j,\theta_j^{-1}\}}{r_j}
=\sum_j\frac1{(1-\varepsilon_j)j^2}
\le2\sum_j\frac1{j^2}<\infty.
```

因此 [渐弱共同作用判据](consequences-zh.md#逐块渐弱共同作用的判据) 的有效等待级数不能在任意有限块几何下单独作为充分条件。这是实际动力学反例，不是仅指出旧成功概率估计不再有界。

**完全同步的配对环境。** 保持以上 ℓ_j、m_j、r_j、初值和黏性，仅令 θ_j=1。块内有效翻转率为 r_j/2，∑1/r_j=∑1/j²<∞，[同步块分类及无限尾块](supplementary-methods-zh.md#分块相关二态环境的精确分类) 直接给确定窗期望／共同正概率 AD，以及概率一样本窗全初能顺序极限。对任意单边函数，两组的投影生成元都为 r_j[g(−z)−g(z)]/2；公平平稳初始化使单边完整路径律相同。瞬时全场联合分布不同，不声称保持全场同分布。证毕。

## 可判定的有限构造、趋零私有率与适用边界

<!-- source: docs/appendices/mechanisms-zh.md B.11.33 -->

上述递归使用有限块概率量，不借助待证明的无限非线性耗散来定义块长。对于有理 r、θ，Ψ 可通过有限个有理数线性方程精确确定。令 G 是 L 个符号的块生成元，π 是其平稳行向量，令 Λ_i 为对角矩阵，其 z 状态下的对角项为

```math
\lambda_{m+i}(z_i)=
\begin{cases}
2,&z_i=-1,\\
4K_{m+i}-2,&z_i=+1,
\end{cases}
\qquad 0\le i<L.
```

取 f_L=1，按 i=L−1,…,0 逆序解

```math
(I+\Lambda_i-G)f_i=\Lambda_i f_{i+1},
\qquad
\Psi_{m,L}(r,\theta)=\pi f_0.
```

这是贴现率 1 的有限后向方程。I+Λ_i−G 严格行对角占优，故可逆；θ<1 时私有翻转使有限块不可约，π 唯一且可由有限有理数方程求得。因此有理 ε 序列给一个每步均有限终止的精确搜索定义。它不是实用复杂度保证，未给出简洁的块长闭式增长率。

这里的退出边界只用于计算辅助首次穿越时间；实际壳模型仍采用原封闭截断，不在区块边界吸收能量。

取一组明确的有理参数

```math
\varepsilon_j=2^{-j^2},\qquad
\theta_j=1-2^{-j^2},\qquad
a_j=\frac{\varepsilon_jr_j}{2}
=\frac{j^2}{2^{j^2+1}}\longrightarrow0.
```

此时不仅私有翻转的相对比例趋零，**每条边的私有翻转率本身也趋零**。同块不同边的平稳不同号概率为

```math
P(\zeta_n(t)\ne\zeta_k(t))
=\frac{\varepsilon_j}{1+\varepsilon_j}
=\frac1{2^{j^2}+1}\longrightarrow0.
```

然而递归有限块环境仍处于全部有限窗零耗散侧，完全同步的配对环境处于正侧。任意固定 k 条同块边在单时刻全部相同的概率至少为 1−(k−1)ε_j/(1+ε_j)，故这些固定维统计也趋向完全同步；没有将这扩大为整个增长块的路径接近。

对这组参数，首块 m_1=1、r_1=1、θ_1=1/2。有限有理数计算给 Ψ_(1,L)(1,1/2) 在 L=1,2,3,4 时分别约为 0.769231、0.632479、0.540780、0.474494；以精确值比较 1/2，递归首块长度为 ℓ_1=4。近似数仅供阅读，构造和阈值判断均使用精确量。没有计算或宣称后续全部块长的实际数值。

## 显式等待窗口：逐边独立

<!-- source: docs/appendices/mechanisms-zh.md B.11.13 -->

更具体地，对每个固定 a∈(0,1)，可构造不依 ν 的非负随机时间 τ_a，使

```math
\mathbb E\tau_a\le M_a:=638976\,a^{-2}+6\mathcal S<\infty,
\qquad
Q_\nu(\tau_a+s)\ge
\frac{1-a-\exp(-2s/\nu)}2
\quad(s\ge0,\ 0<\nu\le1).
```

所有 ν 同时使用同一环境和同一 τ_a。对可数个有理 a 取共同概率一事件，即得到第二项及任意严格小于初能的样本窗目标；没有对不可数个单独概率一事件取交。

快侧还存在明确的确定窗口及共同正概率事件：

```math
T_*=1+2M_{1/4},\qquad
\mathbb P(\tau_{1/4}\le2M_{1/4})\ge\frac12,
\qquad
Q_\nu(T_*)>\frac14
\quad(0<\nu\le1)
```

在该事件上同时成立，故 E Q_ν(T_*)≥1/8。这里窗口常数非常保守，旧 r_n=8192K_n⁴ 的较短 T_D 结论仍保留。

## 显式等待窗口：固定共同重置比例

<!-- source: docs/appendices/mechanisms-zh.md B.11.23 -->

以下给 θ>0、p>1 的一个明确有限窗口界。固定 a∈(0,1)，用

```math
q=\frac89,\qquad
d_n=\frac a4\left(\frac34\right)^n,\qquad
h_n=8192a^{-2}q^n,\qquad
C_a=73728A a^{-2}\sup_{j\ge1}\bigl(j^{p+\beta}q^j\bigr)<\infty,
```

并置

```math
M_a(\theta)=
e^{C_a}\left(73728a^{-2}
+\frac2{\theta A}\sum_{j\ge1}j^{-p}\right).
```

存在仅依环境、不依 ν 的随机时间 τ_a，使

```math
\mathbb E\tau_a\le M_a(\theta),\qquad
Q_\nu(\tau_a+s)\ge\frac{1-a-e^{-2s/\nu}}2
\quad(s\ge0,\ 0<\nu\le1)
```

在同一环境事件上同时成立。常数只用于证明有限性，不作优化。取 T_*=1+2M_(1/4)(θ)，事件 {τ_(1/4)≤2M_(1/4)(θ)} 的概率至少 1/2，其上所有 0<ν≤1 都有 Q_ν(T_*)>1/4，故 E Q_ν(T_*)≥1/8。窗口可依赖 θ，不声称 θ↓0 时统一。

## 显式等待窗口：变化的共同重置比例

<!-- source: docs/appendices/mechanisms-zh.md B.11.26 -->

正侧同时给确定有限窗的期望下界和共同正概率路径下界。具体地，固定 a∈(0,1)，沿用

```math
q=\frac89,\qquad d_n=\frac a4\left(\frac34\right)^n,\qquad
h_n=8192a^{-2}q^n,\qquad
H_a^{\rm time}:=\sum_{n\ge0}h_n=73728a^{-2},
```

并置

```math
C_a=73728Aa^{-2}\sup_{j\ge1}\bigl(j^{p+\beta}q^j\bigr)<\infty,
\qquad
\widehat M_a=e^{C_a}\bigl(221184a^{-2}+6\mathcal W\bigr).
```

有仅依环境的随机时间 τ_a，使

```math
\mathbb E\tau_a\le\widehat M_a,\qquad
Q_\nu(\tau_a+s)\ge\frac{1-a-e^{-2s/\nu}}2
\quad(s\ge0,\ 0<\nu\le1)
```

在同一事件上同时成立。因此 T_*=1+2\widehat M_(1/4) 给概率至少 1/2 的共同事件，其上所有 0<ν≤1 均有 Q_ν(T_*)>1/4，且 E Q_ν(T_*)≥1/8。常数未优化，窗口不要求对不同 θ 序列统一。
