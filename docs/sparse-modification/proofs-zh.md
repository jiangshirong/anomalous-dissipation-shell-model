# 零密度系数修改的耗散对照：完整证明

固定同一双通道边图、共同零初值、单位双根外力和黏性权重，周期偶弱奇强配置有固定窗正耗散；仅在零密度壳层集合削弱交换，可使每个固定窗的黏性损失趋零。两侧弱层密度均为二分之一，系数修改幅度较大。以下先建立一般正侧判据，再给周期正例、弱块负例和配对结论。固定黏性的构造、预算与唯一性见[模型基础](model-zh.md)。

## 几何剖面与固定窗耗散充分条件

<!-- source: docs/03-results-zh.md section 7.1 -->

保留式 (L) 的两条纵向边、黏性、两个单位根外力及共同零初值，只在两个方程中同时将 $`h_n`$ 换为 $`2^{n/2}a_n`$、$`\beta`$ 换为 $`\beta_n`$。假定系数固定且独立于时间和黏性，并满足

```math
a_n\ge a_->0,\quad 0\le\beta_n\le b_+<\infty,\quad
H=\sup_n a_n2^{-n/2}<\infty,\qquad
r_n=\exp\!\left[-2\sum_{k\ge0}4^{-k-1}\log a_{n+k}\right],
\quad P=\sum_nr_n^2<\infty.\tag{GP}
```

**充分条件定理。** (GP) 蕴含存在 $`T_*,\varepsilon>0`$，使全部 $`0<\nu\le1`$、全部固定 $`T\ge T_*`$ 满足 $`Q_\nu(T)/T\ge\varepsilon`$。不要求单调、相邻比值受控或与固定幂序列上下可比。[精确稳态判据与动态边界](extensions-zh.md#精确稳态判据与动态边界) 进一步证明：在本系数上、下界类内，$`P<\infty`$ 对有限能量无黏稳态存在及黏性稳态一致有界恰是充要条件；不是动态耗散的充要分类。

原逐层条件 $`S=\sum a_n^{-4/3}<\infty`$ 称为 (GS)。它蕴含 (GP)，但并非必要，详见 [逐层充分条件及稀疏瓶颈实例](extensions-zh.md#逐层充分条件及稀疏瓶颈实例)至[周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散)。原对数族负侧分类不能自动套用到一般序列。

记 $`b=\max(1,b_+)`$。因 $`h_n\le HK_n`$、$`\beta_nh_n\le bHK_n`$，[固定黏性基础与相对能量](model-zh.md#3-固定正黏性的构造及精确预算) 的构造、唯一性、预算及 (R) 适用：节点流出常数用 $`1+bH`$，双线性常数用 $`1+(1+b)H`$；(R) 流出、流入平方和中的 $`1+H`$ 同样换为 $`1+bH`$。其余加权尾界、逐类映射和可积性论证不变。先在每个固定正黏性取得严格正的无限维稳态 $`b^\nu`$，再作以下增长反证；不能在有限截断末层向不存在的坐标迭代。

记 $`I=b^\nu_{w,0}+b^\nu_{z,0}>0`$，本节暂将稳态坐标简写为 $`w_n,z_n`$。全局预算及整层切面给

```math
\nu M_n(w_n^2+z_n^2)\le I,\qquad K_nz_n^2w_{n+1}\le I.
```

有限封闭无黏无迫时仍逐边守恒；极限顺序仍为固定正黏性先取封闭截断层数趋无穷，再在同一个固定窗口取黏性趋零。

### 常通量归一化与两个关键界

<!-- source: docs/03-results-zh.md section 7.2 -->

由 $`\log a_-\le\log a_n\le\log H+(n/2)\log2`$，定义 $`r_n`$ 的级数绝对收敛。移位直接给

```math
r_{n+1}=a_n^2r_n^4,\qquad
cK_n^{-1/3}\le r_n\le a_-^{-2/3},\quad
c=H^{-2/3}2^{-1/9}.
```

下界使用 $`\sum4^{-k-1}=1/3`$、$`\sum k4^{-k-1}=1/9`$。再由 $`r_{n+1}\ge c2^{-1/3}K_n^{-1/3}`$、$`a_n\le H\sqrt{K_n}`$ 得

```math
\sqrt{K_n}a_nr_n^3
=\sqrt{K_n}a_n^{-1/2}r_{n+1}^{3/4}
\ge c^{3/4}2^{-1/4}H^{-1/2},\qquad
d_n:=\frac1{\sqrt{K_n}a_nr_n^3}\le D_g:=2^{1/3}H.
```

这些界尚未使用 $`P<\infty`$，不预设稳态一致有界。$`r_{n+1}=a_n^2r_n^4`$ 是删边链已知常通量形式的归一化，不认领新递推；新命题需要在完整图上控制黏性稳态及同一初值轨道。

### 两个稳态包络

<!-- source: docs/03-results-zh.md section 7.3 -->

强出口的下一层平衡只用 $`h_{n+1}\le HK_{n+1}`$。取 $`A_z^3=8(1+H)`$，则

```math
z_n\le A_z I^{1/3}K_n^{-1/3}.
```

下一层的稳态方程舍去非负反向输入，给出

```math
K_nz_n^2\le w_{n+1}(h_{n+1}z_{n+1}+e_{n+1}z_{n+2}+\nu M_{n+1}).
```

将强边通量界、单坐标黏性预算及 $`M_{n+1}=4M_n`$ 代入，得到

```math
\max(z_{n+1},z_{n+2})\ge
\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}+e_{n+1}}.
```

详细地，若超阈值，上式得到某个较高层振幅与 $`z_n`$ 的比大于 $`4-1/[4(1+H)^2]>2`$；递减的强阈值保留超阈值性质，无限增长与固定黏性稳态的有限能量矛盾。

设

```math
x=A_w^3=1+\frac{8b^3A_z^3}{c^3}+8(bD_g+D_g^2+1).
```

令 $`\rho_n=w_n/(I^{1/3}r_n)`$。若 $`\rho_n>A_w`$，由 $`r_n\ge cK_n^{-1/3}`$、$`x>8b^3A_z^3/c^3`$ 保证 $`w_n>2bz_n`$。包含全部前层及本层 $`w_n`$ 的切面预算给

```math
\tfrac12h_nw_n^2z_n\le
h_nw_nz_n(w_n-\beta_nz_n)\le I,
\qquad z_n\le\frac{2I}{h_nw_n^2}.
```

由 $`z_n`$ 的稳态方程舍弃非负纵向输入，再用上式和单坐标黏性预算，得

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{\beta_nh_n}{K_n}w_n-\frac{I}{K_nw_n^2},
\qquad
\rho_{n+1}\ge\tfrac12\rho_n^4-\beta_nd_n\rho_n-d_n^2\rho_n^{-2}.
```

归一化用 $`r_{n+1}=a_n^2r_n^4`$，必须保留实际的 $`h_n/K_n`$ 而不能先粗换成 $`H`$。因此超阈值时

```math
\frac{\rho_{n+1}}{\rho_n}
>\frac x2-bD_g-\frac{D_g^2}{x}>4.
```

常数的最后一项保证严格不等式。下一层仍超阈值，迭代给 $`\rho_{n+j}>4^j\rho_n`$。虽然 $`r_n`$ 未必单调，它不小于 $`c2^{-n/3}`$，所以真实振幅也指数增长，与固定黏性有限能量矛盾。故

```math
w_n\le A_w I^{1/3}r_n.
```

没有假设无黏常通量尾部能匹配受迫根；$`r_n`$ 只是比较阈值，所比较稳态始终是先行构造的真实正黏性稳态。

### 闭合能量并回到固定时间窗

<!-- source: docs/03-results-zh.md section 7.4 -->

定义

```math
C=\frac{A_z^2}{1-2^{-2/3}}+A_w^2P,\quad
B=2^{1/4}C^{3/4},\quad C_0=2B,\quad
L=1+[1+(1+b)a_0]C_0.
```

两个包络给 $`\|b^\nu\|_2^2\le CI^{2/3}`$；$`I\le\sqrt2\|b^\nu\|_2`$ 闭合为 $`\|b^\nu\|_2\le B`$。由 (R)，共同零初值轨道全时满足 $`\|u^\nu(t)\|_2\le C_0`$。根方程中的负项是 $`-w_0z_1-z_0w_1-(1+\beta_0)a_0w_0z_0-\nu(w_0+z_0)`$；两条纵向项之和不低于 $`-C_0s`$，所以 $`s=w_0+z_0`$ 满足 $`s'\ge2-Ls`$。从 $`s(0)=0`$ 比较并积分，使用精确预算及末端能量上界得

```math
\frac{Q_\nu(T)}T\ge\frac2L-
\frac{2/L^2+C_0^2/2}{T}\ge\frac1L
\quad\text{若 }T\ge T_*:=\frac2L+\frac{LC_0^2}{2}.
```

至此定理成立，$`\varepsilon=1/L`$。各常数不依赖黏性；若要求整个系数类共用常数，只需统一控制 $`H,P,b_+`$（$`a_0\le H`$），而正下界用于定义级数和 [精确稳态判据与动态边界](extensions-zh.md#精确稳态判据与动态边界)。没有先取长期极限，也没有把无黏能量损失替代真实黏性损失。两包络还给一致小尾，故稳态的逐坐标零黏子列强收敛于有限能量正无黏稳态。

## 周期弱交换配置的正耗散

<!-- source: docs/03-results-zh.md section 7.6 -->

取 $`\beta_n=1`$，并令

```math
a_n=\begin{cases}1,&n\text{ 为偶数},\\2^{n/2},&n\text{ 为奇数}.\end{cases}
```

这里一半壳层始终只有 $`h_n=\sqrt{K_n}`$，另一半为 $`h_n=K_n`$；$`a_-=H=1`$。旧条件的 $`S`$ 因每个偶数项等于 1 而发散。直接求未来几何平均却得

```math
\log_2r_n=\begin{cases}
-n/15-17/225,&n\text{ 为偶数},\\
-4n/15-8/225,&n\text{ 为奇数}.
\end{cases}
```

两个几何级数都平方可求和，所以 (GP) 证明这个完整图模型具有共同零初值、固定窗口黏性异常耗散。由此**(GS) 不仅未证必要，而且确实不是必要条件**。并非所有弱交换都无害：全部取 $`a_n=1`$ 时 $`r_n=1,P=\infty`$，且原对数族 $`\alpha=0`$ 已有独立无耗散证明。

本周期实例的平方和可显式写为

```math
P=\frac{2^{-34/225}}{1-2^{-4/15}}
+\frac{2^{-136/225}}{1-2^{-16/15}}<\infty.
```

因此其全部窗口常数均由 [两个稳态包络](proofs-zh.md#两个稳态包络)至[闭合能量并回到固定时间窗](proofs-zh.md#闭合能量并回到固定时间窗) 的明确公式确定，不需以数值轨道估计 P 或耗散起始时间；这些解析常数仍很粗。

周期性也非必要。任取不含相邻整数的固定集合 $`\mathcal B`$，在 $`n\in\mathcal B`$ 取 $`a_n=1`$，其余取 $`2^{n/2}`$。对 $`n\ge1`$，

```math
\log_2r_n=-n/3-1/9+
\sum_{N\in\mathcal B,\,N\ge n}\frac{N}{4^{N-n+1}}
\le-n/3-1/9+\frac{4n}{15}+\frac8{225}
\le-n/15.
```

理由是距离分组 $`\{2\ell,2\ell+1\}`$ 内至多一个瓶颈，而权重 $`(n+k)4^{-k-1}`$ 在 $`n\ge1`$ 时递减；每组用前一项上界，再求几何和。$`r_0\le1`$，故统一有 $`P\le(1-2^{-2/15})^{-1}`$。即使集合不周期、不稀疏，仍可用同一组窗口常数。禁止相邻只是这一推论的充分限制，不是瓶颈密度的最优边界，也不是对动态随机切换的结论。

## 稀疏弱块的零耗散与零密度修改对照

<!-- source: docs/03-results-zh.md section 7.8 -->

仅有弱层数量或渐近密度不足以决定耗散。[周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散) 有一半弱层却仍耗散；这里给出弱层密度为零、几乎所有层都强，却在任意固定窗无耗散的同图模型。此为内部解析结果，切面—通量—守恒方法已有先例，不直接认领强原创性。

固定 $`0\le\beta_n\le b_+<\infty`$，其余设定保持 [几何剖面与固定窗耗散充分条件](proofs-zh.md#几何剖面与固定窗耗散充分条件)。令

```math
N_j=2^{2^j},\quad L_j=2^{j+1},\quad j\ge2,\qquad
\mathcal B=\bigcup_{j\ge2}\{N_j,\ldots,N_j+L_j\},\qquad
a_n=\begin{cases}1,&n\in\mathcal B,\\2^{n/2},&n\notin\mathcal B.\end{cases}
```

弱块两端均包含，互不相交。仍有 $`a_-=H=1`$；块内 $`h_n=\sqrt{K_n}`$，块外 $`h_n=K_n`$。**命题：** 对每个固定 $`T>0`$，共同零初值的真实黏性耗散满足 $`Q_\nu(T)\to0`$。更一般地，块外任取固定的 $`1\le a_n\le2^{n/2}`$，结论仍成立：下文只在弱块内使用交换系数的具体值，其他层仅需基础分析的统一上界。证明不以稳态发散代替动态分析。

**第一步：块内时间积分界。** 任取趋零黏性子列，由固定窗能量界与坐标紧性再取无黏分量极限 $`u`$；其范数不超过 $`R=\sqrt2T`$。令 $`Y_n=K_n\int_0^Tz_n^2dt`$。总有 $`Y_n\le2^nTR^2`$。若 $`n+1\in\mathcal B`$，积分 $`w_{n+1}`$ 的无黏方程，舍弃非负反向输入，并用零初值，得到

```math
Y_n\le R+TR^2+h_{n+1}\int_0^Tw_{n+1}z_{n+1}dt
\le A+B\sqrt{Y_{n+1}},\qquad A=R+TR^2,\quad B=R\sqrt T.
```

最后一步使用 $`h_{n+1}=\sqrt{K_{n+1}}`$。黏性项是在固定坐标的子列极限中消失；不能把这一无黏递推不加修改地写成正黏性估计。

取 $`C=\max(1,2A,4B^2)`$、$`Z_n=Y_n/C`$，则

```math
Z_n\le\tfrac12+\tfrac12\sqrt{Z_{n+1}}
\le\max(1,\sqrt{Z_{n+1}}),\qquad
Z_n\le\max(1,Z_J^{2^{-(J-n)}}).
```

第二式仅在 $`n+1,\ldots,J`$ 都属于同一弱块时迭代。令 $`J=N_j+L_j`$、$`m_j=2^j`$。块的前 $`m_j`$ 层 $`N_j\le n<N_j+m_j`$ 满足 $`q=J-n\ge2^j+1`$ 和 $`J\le2N_j`$，故 $`J/2^q\le2`$。代入末层粗界得

```math
Y_n\le D_T:=4\max(C,TR^2),\qquad N_j\le n<N_j+m_j.
```

常数不依赖块号、黏性子列或极限解。这里没有控制所有壳层，只控制长弱块的一段。

**第二步：选择实际通量趋零的切面。** 记 $`J_n^{(4)}=\int_0^Tw_n^4dt`$，避免与末层号 $`J`$ 混用。在上述前缀内，

```math
F_n:=h_n\int_0^Tw_n^2z_n dt,\qquad
F_n^2\le Y_nJ_n^{(4)},\qquad
\sum_nJ_n^{(4)}\le TR^4.
```

所以每块可选 $`n_j`$ 使 $`F_{n_j}^2\le D_TTR^4/m_j\to0`$。回流积分满足

```math
G_{n_j}:=\beta_{n_j}h_{n_j}\int_0^Tw_{n_j}z_{n_j}^2dt
\le b_+R D_T2^{-n_j/2}\to0.
```

包含所有前层及本层 $`w_{n_j}`$ 的切面还有两个弱出口；其积分分别不超过 $`e_{n_j}TR^3`$、$`e_{n_j-1}TR^3`$，合计不超过 $`3\cdot2^{-n_j}TR^3\to0`$。部分切面恒等式的净通量是 $`F-G`$ 加这两个弱出口，不能遗漏回流。切面沿 $`n_j\to\infty`$ 穷尽全部坐标，故

```math
E(T)=\int_0^T(w_0+z_0)dt.
```

**第三步：回到真实黏性耗散。** 正黏性精确预算、根输入的时间一致收敛及末端能量 Fatou 给

```math
0\le\limsup Q_\nu(T)
\le\int_0^T(w_0+z_0)dt-E(T)=0
```

于该再取子列。任意趋零黏性子列都可这样再取，故整族 $`Q_\nu(T)\to0`$；不要求无黏解唯一或强 $`\ell^2`$ 收敛。

**可复用的弱块条件。** 更一般地，固定 $`1\le a_n\le2^{n/2}`$，若有弱块 $`[N_j,J_j]`$ 且 $`N_j\to\infty`$，块内全取 $`a_n=1`$，且存在整数 $`1\le m_j\le J_j-N_j+1`$ 满足

```math
m_j\to\infty,\qquad
\sup_j\frac{J_j}{2^{J_j-N_j-m_j+1}}=:A_0<\infty,
```

则仍有每个固定窗 $`Q_\nu(T)\to0`$。块不必有先前明确例子的长度，也不必是全部弱层。前 $`m_j`$ 层的后向距离至少 $`J_j-N_j-m_j+1`$，上面的同一递推给 $`Y_n\le2^{A_0}\max(C,TR^2)`$；四阶预算选层、回流与两个弱出口趋零及黏性极限完全同前。选择的切面随无黏子列极限而变是允许的。条件不含 T，因此一条满足条件的固定序列同时适用每个有限 T；不声称最优长度门槛。

**密度与判据核对。** 至第 $`j`$ 块累计弱层数为 $`O(2^j+j)`$；即使计入当前块，除以 $`N_j`$ 仍趋零。因此 $`\mathcal B`$ 的自然密度为零。令 $`s=L_j+1`$，从剖面定义与后续 $`0\le\log_2a_{N_j+k}\le(N_j+k)/2`$ 得

```math
0\ge\log_2r_{N_j}
\ge-4^{-s}\left(\frac{N_j+s}{3}+\frac19\right)\longrightarrow0.
```

所以 $`r_{N_j}\to1`$、$`P=\infty`$，与稳态必要性相容；它不是由 $`P=\infty`$ 推出无耗散。与 [周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散) 的正侧合起来，两例反驳“弱层越稀少越容易耗散”的**仅按密度分类**，不证明一般重排单调性、最优弱块长度或全部 $`P=\infty`$ 情形无耗散。

**同密度、零密度改动的推论。** 另取 $`\widetilde a_n=1`$ 若 $`n`$ 为偶数或 $`n\in\mathcal B`$，否则取 $`2^{n/2}`$，并固定 $`\beta_n=1`$。弱块外仍在上述允许区间，故对该模型每个固定窗均有 $`Q_\nu(T)\to0`$。它与 [周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散) 的耗散模型仅在 $`\mathcal B`$ 内的奇数层不同，差异集合密度为零；两个模型的弱层密度都为 $`1/2`$。方程、强边、弱边、力、黏性、初值及解类均相同，只改变同层交换的固定序列。

因此异常耗散并不在“系数仅改变于零密度集合”这个粗意义下稳定。这不是小幅扰动反例：被改的奇数层有 $`\widetilde a_n/a_n=2^{-n/2}\to0`$，不满足 [有界交换倍率扰动的稳健性](extensions-zh.md#有界交换倍率扰动的稳健性) 的上下有界倍率假设。不称它为任意零密度扰动结论，也不据此认领新基本级联机制。

**选定主命题及证明入口。** 记 [周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散) 周期模型的耗散为 Q_ν^+，上面同密度弱块模型的耗散为 Q_ν^−。两者均采用[模型基础](model-zh.md#1-方程与解类)的非负能量类解、双根单位力、共同零初值、封闭截断极限，系数与 ν 及时间无关。则

```math
\exists\,T_*,\varepsilon>0\quad
\forall\,0<\nu\le1\quad\forall\,T\ge T_*:
\qquad Q_\nu^+(T)/T\ge\varepsilon,
\qquad
\forall\,T>0:\quad\lim_{\nu\downarrow0}Q_\nu^-(T)=0.
```

两固定序列仅在零密度集合不同，弱层密度同为 1/2，边图没有断边；它们不是保持系数多重集合的纯重排。证明依赖是：[固定黏性基础与相对能量](model-zh.md#3-固定正黏性的构造及精确预算) 给两侧共同的固定黏性解与精确预算；[常通量归一化与两个关键界](proofs-zh.md#常通量归一化与两个关键界)至[闭合能量并回到固定时间窗](proofs-zh.md#闭合能量并回到固定时间窗)、[周期弱交换配置的正耗散](proofs-zh.md#周期弱交换配置的正耗散) 给正侧；本节块内积分—选层—极限预算给负侧。无需 [精确稳态判据与动态边界](extensions-zh.md#精确稳态判据与动态边界) 的稳态必要性、[冻结独立二值排列的完整分类](extensions-zh.md#冻结独立二值排列的完整分类) 的随机分类或 [快变量消元的反例与尚未分类的配置](extensions-zh.md#快变量消元的反例与尚未分类的配置) 的形式消元。内部审查的实际覆盖和原创性限制见[核验范围](literature-zh.md#证据范围与当前判断)。
