# 对数交换族：参数范围、轨道估计与开放缺口

## 当前分类与开放区间

取模型基础中的 `h_n=η2^(n/2)(n+1)^α`、共同零初值和单位双根强迫。已证 `α≤1/2` 时每个固定窗零黏损失趋零，`α>3/4` 时足够长固定窗有黏性一致正下界；`1/2<α≤3/4` 的总耗散仍开放。无黏稳态不存在不替代动态零耗散证明。固定黏性基础、符号和预算见[模型基础](model-zh.md)。

下文保留直接证明及独有轨道估计，尤其保留 `α=2/3` 的损失通道定位、条件守恒与未控接收占有项。

```math
K_n=2^n,\quad M_n=4^n,\quad e_n=2^{-n},\quad
h_n=\eta2^{n/2}(n+1)^\alpha.
```


## 对数族的固定窗正耗散

<!-- source: docs/03-results-zh.md section 2 -->

以下取 $`\alpha>3/4`$。定义有限常数

```math
D_\alpha=\sup_{n\ge0}(n+1)^{2\alpha}2^{-n},\qquad
H=\eta\sqrt{D_\alpha},\qquad h_n\le HK_n.
```

固定黏性，先按前篇构造正的有限能量稳态，记 $`I=w_0+z_0`$。这一步没有使用黏性一致界。有限切面及全局预算给强边通量不超过 $`I`$，各坐标黏性耗散不超过 $`I`$。

### 强出口包络

[附录 A4 §A4.5.1](../other-results/exchange-exponents-zh.md)所用的下一层平衡仍给

```math
\max(z_{n+1},z_{n+2})\ge
\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}+e_{n+1}}.
```

令 $`A_z^3=8(1+H)`$。若 $`z_n>A_z(I/K_n)^{1/3}`$，分子为正；用 $`h_{n+1}+e_{n+1}\le2(1+H)K_n`$，较高层振幅超过 $`2z_n`$。阈值递减，迭代与已构造的固定黏性有限能量矛盾。因此

```math
z_n\le A_z I^{1/3}2^{-n/3}.
```

### 弱出口包络

选择

```math
A_w^3=1+8A_z^3D_\alpha+\frac{8(H+D_\alpha+1)}{\eta^2}.
```

假设 $`w_n>A_wI^{1/3}(n+1)^{-2\alpha/3}`$。由于 $`A_w^3>8A_z^3D_\alpha`$，强出口包络保证 $`w_n>2z_n`$。净交换通量及稳态预算给

```math
\frac12h_nw_n^2z_n\le h_nw_nz_n(w_n-\beta z_n)\le I.
```

强出口平衡于是给与前篇相同的下界

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{h_n}{K_n}w_n-\frac{I}{K_nw_n^2}.
```

这里 $`h_n^2/K_n=\eta^2(n+1)^{2\alpha}`$，故超阈值时

```math
\frac{w_{n+1}}{w_n}
>\frac{\eta^2A_w^3}{2}-H-\frac{D_\alpha}{A_w^3}>2.
```

最后一步由 $`A_w^3\ge1`$ 及定义中最后一项直接保证。阈值因 $`\alpha>0`$ 递减，增长反证得到

```math
w_n\le A_wI^{1/3}(n+1)^{-2\alpha/3}.
```

### 能量闭合及固定时间窗

当 $`\alpha>3/4`$，两个包络都可平方求和。可取

```math
C=\frac{A_z^2}{1-2^{-2/3}}
+A_w^2\left(1+\frac1{4\alpha/3-1}\right),\qquad
\|b^\nu\|_2^2\le CI^{2/3}.
```

用 $`I\le\sqrt2\|b^\nu\|_2`$ 闭合得 $`\|b^\nu\|_2\le B=2^{1/4}C^{3/4}`$，独立于黏性。包络还给稳态尾部一致小，逐坐标子列极限是正的有限能量无黏稳态。

相对能量非扩张性给零初值轨道 $`\|u^\nu(t)\|_2\le C_0=2B`$。根部 $`h_0=\eta`$，所以对 $`0<\nu\le1`$，$`s=w_0+z_0`$ 满足

```math
s'\ge2-Ls,\qquad L=1+(1+2\eta)C_0.
```

根输入下界减去末端储能，得到

```math
\frac{Q_\nu(T)}T\ge\frac2L-
\frac{2/L^2+C_0^2/2}{T}\ge\frac1L>0
\quad\text{若 }T\ge2/L+LC_0^2/2.
```

此为共同零初值的固定窗口黏性异常耗散，不需要先取长时间极限。常数很粗，不能当作实际起始时间预测。

**一个明确实例。** 取 $`\eta=\alpha=\beta=1`$，即 $`h_n=(n+1)2^{n/2}`$。有 $`D_1=9/4`$、$`H=3/2`$，可直接用更小的 $`A_z^3=20,A_w=8`$：$`8^3>8\cdot20\cdot9/4`$，增长下界 $`256-3/2-9/2048>2`$。故本节给出一个具体满足异常耗散的候选。

## 对数族的零耗散与局部轨道结果

<!-- source: docs/03-results-zh.md section 3 -->

### 基础估计与四分之一范围

若 $`\alpha\le0`$，$`h_n\le\eta\sqrt{K_n}`$，[低增长交换的证明](../other-results/exchange-exponents-zh.md)直接适用。以下只取 $`0<\alpha\le1/4`$。

固定 $`T>0`$，由正黏性轨道提取逐坐标时间一致的无黏极限，范数不超过 $`R=\sqrt2T`$。定义

```math
Y_n=K_n\int_0^Tz_n^2\,dt,\qquad
V_n=\frac{Y_n}{(n+1)^{2\alpha}}.
```

积分下一层弱出口方程、舍弃非负反向输入，得

```math
Y_n\le A+B(n+2)^\alpha\sqrt{Y_{n+1}},\quad
A=R+TR^2,\ B=\eta R\sqrt T,
\qquad
V_n\le A+B2^{2\alpha}\sqrt{V_{n+1}}.
```

同时 $`V_n\le2^nTR^2`$。附录 A4的四倍增长反证给 $`V_n\le C_T`$，其中可取 $`C_T=2A+16B^2 2^{4\alpha}`$。

对包含前面整层及本层弱出口的有限切面，正交换通量的时间积分为 $`F_n=h_n\int_0^T w_n^2z_n\,dt`$。于是

```math
F_n^2\le\eta^2C_T(n+1)^{4\alpha}\int_0^T w_n^4\,dt,
\qquad \sum_n\int_0^T w_n^4\,dt\le TR^4.
```

因为 $`\sum(n+1)^{-4\alpha}=\infty`$，必有趋于无穷的切面子列使 $`F_n\to0`$；否则上式迫使四次积分之和发散。反向通量由 $`\eta RC_T2^{-n/2}(n+1)^{3\alpha}\to0`$ 控制，两条弱纵向边通量也趋零。沿该子列写有限预算并穷尽坐标，得到极限解的能量等式。再用正黏性精确预算、根输入收敛及末端能量下半连续，得整族 $`Q_\nu(T)\to0`$。

这里仅需要一个切面子列，不声称所有切面通量都趋零；也没有假定无黏解唯一。

### 保留逐层积分，将无耗散区推进到二分之一

上节对 $`V_n`$ 的一致上界实际上对每个固定 $`\alpha>0`$ 都成立；只有最后使用发散级数时才限制到 $`1/4`$。下面先对任意固定 $`\alpha>1/4`$ 证明加权积分可求和，再在最后一步使用 $`\alpha\le1/2`$ 得到无耗散结论。始终研究同一无黏极限轨道，不使用任何稳态估计。

令 $`W_n=\int_0^T w_n^2\,dt`$，则 $`S_W:=\sum W_n\le TR^2`$。积分弱出口方程时不再将 $`w_{n+1}`$ 全部用 $`R`$ 代替，得到

```math
V_n\le d_n+c_\alpha\sqrt{W_{n+1}V_{n+1}},\qquad
c_\alpha=\eta2^{2\alpha},
```

其中

```math
d_n=\frac{w_{n+1}(T)}{(n+1)^{2\alpha}}
+\frac{e_{n+1}}{(n+1)^{2\alpha}}
\int_0^T w_{n+1}z_{n+2}\,dt\ge0.
```

这里用的是 $`h_{n+1}/\sqrt{K_{n+1}}=\eta(n+2)^\alpha`$，以及归一化后 $`((n+2)/(n+1))^{2\alpha}\le2^{2\alpha}`$。末端能量界和 Cauchy–Schwarz 给

```math
D_T:=\sum_nd_n
\le R\left(\sum_{n\ge0}(n+1)^{-4\alpha}\right)^{1/2}+TR^2<\infty.
```

注意此处恰好要求 $`\alpha>1/4`$，端点已由 [基础估计与四分之一范围](logarithmic-zh.md#基础估计与四分之一范围) 处理。取有限部分和 $`S_N=\sum_{n=0}^NV_n`$。先前 $`V_n\le C_T`$ 控制求和右端多出的边界坐标，因此

```math
S_N\le D_T+c_\alpha\sqrt{S_W(S_N+C_T)}
\le D_T+\frac12(S_N+C_T)+\frac12c_\alpha^2S_W.
```

从而 $`S_N\le2D_T+C_T+c_\alpha^2S_W`$，独立于 $`N`$。令 $`N\to\infty`$ 得到新的可求和信息

```math
\sum_{n\ge0}\frac{K_n}{(n+1)^{2\alpha}}\int_0^Tz_n^2\,dt
=\sum_{n\ge0}V_n<\infty.
```

这不是把一个无穷和预先假定有限再吸收：先对有限部分和操作，多出的一项由已证一致上界控制。

现在再次估计正交换通量：

```math
\frac{F_n}{(n+1)^{2\alpha}}
\le\eta\sqrt{V_n}\left(\int_0^T w_n^4\,dt\right)^{1/2}
\le\eta R\sqrt{V_nW_n}.
```

对层号求和，右侧不超过 $`\eta R\sqrt{(\sum V_n)S_W}<\infty`$。另一方面，$`\alpha\le1/2`$ 使 $`\sum(n+1)^{-2\alpha}=\infty`$，所以仍必有切面子列满足 $`F_n\to0`$。反向通量、弱边通量和返回黏性族的步骤完全按 [基础估计与四分之一范围](logarithmic-zh.md#基础估计与四分之一范围) 进行，得到 $`Q_\nu(T)\to0`$，包括 $`\alpha=1/2`$。

结合 [基础估计与四分之一范围](logarithmic-zh.md#基础估计与四分之一范围)，现已证明全部 $`\alpha\le1/2`$ 无固定窗口异常耗散。仍未证明 $`1/2<\alpha\le3/4`$ 的动态结论；稳态不存在性不能填补这个缺口。

### 未解区间中的必要条件：时间集中度不能太低

本节固定式 (L)、原外力和初值，研究 $`1/2<\alpha\le3/4`$ 的无条件分类。新增的是可用于筛选机制的条件命题：若该区间真的有固定窗口异常耗散，则传输不能始终保持受控的逐壳时间集中度。以下仍取固定 $`T>0`$，先分析任一黏性子列的逐坐标时间一致极限。

对弱出口定义

```math
W_n=\int_0^T w_n^2\,dt,\qquad J_n=\int_0^T w_n^4\,dt,
\qquad \mathcal I_n=\frac{T J_n}{W_n^2}\quad(W_n>0).
```

若 $`W_n=0`$，约定 $`\mathcal I_n=1`$，此时 $`F_n=0`$。Cauchy–Schwarz 给 $`\mathcal I_n\ge1`$。它是未中心化的四阶／二阶时间矩之比，不是中心峰度，也不是常通量假设。例如振幅只在长为 $`\ell`$ 的矩形脉冲中非零时，$`\mathcal I_n=T/\ell`$；一般情况下 $`T/\mathcal I_n`$ 只是有效持续时间，不等同于真实支撑长度。

对所有 $`\alpha>1/4`$，[保留逐层积分，将无耗散区推进到二分之一](logarithmic-zh.md#保留逐层积分将无耗散区推进到二分之一) 已给

```math
S_W:=\sum W_n<\infty,\qquad
S_V:=\sum V_n<\infty,\qquad
V_n=\frac{K_n}{(n+1)^{2\alpha}}\int_0^T z_n^2\,dt.
```

保留四次积分，而不用粗界 $`J_n\le R^2W_n`$，可得

```math
F_n=h_n\int_0^T w_n^2z_n\,dt
\le\eta(n+1)^{2\alpha}\sqrt{V_nJ_n}
=\frac{\eta}{\sqrt T}(n+1)^{2\alpha}
\sqrt{\mathcal I_n}\,W_n\sqrt{V_n}.
```

取 $`2/3`$ 次幂，先对有限层号求和，再用指数 $`3/2`$ 和 $`3`$ 的 Hölder 不等式及单调极限，得到

```math
\sum_{n\ge0}
\frac{F_n^{2/3}}{(n+1)^{4\alpha/3}\mathcal I_n^{1/3}}
\le \left(\frac{\eta^2}{T}\right)^{1/3}
S_W^{2/3}S_V^{1/3}<\infty.\tag{TI}
```

**与能量缺陷的对应不能跳过。** 令

```math
\Delta(T)=\int_0^T(w_0+z_0)\,dt
-\frac12\sum_n(w_n(T)^2+z_n(T)^2)\ge0.
```

对包含所有低层及本层 $`w_n`$ 的切面写无黏积分预算。其向外净通量为 $`F_n`$ 减反向交换，再加两条弱纵向边；反向交换的时间积分至多
$`\eta R C_T2^{-n/2}(n+1)^{3\alpha}\to0`$，弱边项至多 $`TR^3(e_{n-1}+e_n)\to0`$。初值为零且该切面最终包含两个根，所以有限部分能量穷尽后确有

```math
F_n\longrightarrow\Delta(T).
```

因此若 $`\Delta(T)>0`$，式 (TI) 强制

```math
\sum_{n\ge0}(n+1)^{-4\alpha/3}\mathcal I_n^{-1/3}<\infty.\tag{NC}
```

这是正能量缺陷的必要条件，不是充分条件。反之，若这个级数发散，必有 $`\Delta(T)=0`$。

**可直接用于黏性族的条件结论。** 若存在 $`C\ge1`$、$`\delta\ge0`$，使所有充分小黏性和所有充分大层号均满足

```math
T\int_0^T (w_n^\nu)^4\,dt
\le C(n+1)^\delta
\left(\int_0^T(w_n^\nu)^2\,dt\right)^2,
```

其中 $`C,\delta`$ 和起始层号都独立于黏性，并且 $`4\alpha+\delta\le3`$，则 $`Q_\nu(T)\to0`$。证明：逐坐标时间一致收敛将矩不等式传给每个极限轨道；(NC) 的级数因 $`(4\alpha+\delta)/3\le1`$ 发散，故每个极限的 $`\Delta(T)=0`$。正黏性精确预算、根输入收敛和末端能量下半连续性给该子列 $`\limsup Q_\nu(T)\le\Delta(T)=0`$；子列反证得到整族结论。不在这里假定无黏演化唯一或末端能量强收敛。

### 保留正黏性：一个可计算但很粗的消失上界

本节固定 $`1/4<\alpha\le1/2`$，直接估计正黏性轨道，不经过无黏子列，也不使用 [未解区间中的必要条件：时间集中度不能太低](logarithmic-zh.md#未解区间中的必要条件时间集中度不能太低) 的额外时间矩假设。仍取 $`R=\sqrt2T`$，暂略各量的上标 $`\nu`$。结论加强的是已知无耗散侧的定量控制，不扩大无条件分类区间。

**第一步：在黏性尚可控制的有限壳带内建立积分上界。** 令

```math
J_\nu=\left\lfloor\frac12\log_2(1/\nu)\right\rfloor,
\qquad N=\lfloor J_\nu/2\rfloor-1,
```

以下令黏性充分小，使 $`J_\nu\ge10`$、$`N\ge4`$。对 $`0\le n<J_\nu`$ 有 $`\nu4^{n+1}\le1`$。积分下一层弱出口方程时保留正黏性项，得到

```math
V_n\le A+B\sqrt{V_{n+1}},\qquad V_n\le2^nTR^2,
```

```math
A=R+TR^2+TR,\qquad
c_\alpha=\eta2^{2\alpha},\qquad B=c_\alpha R\sqrt T,
\qquad C=2A+16B^2+TR^2.
```

其中 $`TR`$ 是新保留的 $`\nu4^{n+1}\int w_{n+1}\,dt/(n+1)^{2\alpha}`$ 的上界；不是把黏性项丢掉。若某个 $`n\le\lfloor J_\nu/2\rfloor`$ 满足 $`V_n>C`$，则递推连续给 $`V_{n+1}>4V_n`$，并一直推到 $`J_\nu`$。于是

```math
V_{J_\nu}>4^{J_\nu-n}C
\ge2^{J_\nu}C\ge2^{J_\nu}TR^2,
```

与终端的粗界矛盾。因此 $`V_n\le C`$ 对 $`0\le n\le N+1`$ 成立。这里特意留出外层壳带作为增长反证的余量；没有将无黏无限层递推直接照搬到正黏性。

**第二步：有限积分和的统一控制。** 用与 [保留逐层积分，将无耗散区推进到二分之一](logarithmic-zh.md#保留逐层积分将无耗散区推进到二分之一) 相同的有限求和，但增加黏性余项，记

```math
D=R\sqrt{1+\frac1{4\alpha-1}}+TR^2,
\qquad
\mathcal E_{\nu,N}
=\sum_{n=0}^N\frac{\nu4^{n+1}}{(n+1)^{2\alpha}}
\int_0^T w_{n+1}\,dt
\le\frac{16}{3}TR\nu4^N.
```

幂级数的积分比较给上式 $`D`$ 中的显式常数。设 $`S_N=\sum_{n=0}^N V_n`$，则

```math
S_N\le D+\mathcal E_{\nu,N}
+c_\alpha\sqrt{TR^2(S_N+C)},
```

从 Young 不等式和 $`\nu4^N\le1`$ 得

```math
S_N\le S_*:=2D+C+c_\alpha^2TR^2+\frac{32}{3}TR.
```

因此正向交换通量的有限加权和满足

```math
\sum_{n=0}^N\frac{F_n}{(n+1)^{2\alpha}}
\le L_*:=\eta R\sqrt{TR^2S_*}.
```

所有常数只依赖固定的 $`T,\alpha,\eta`$，不依赖黏性、所取壳带或 $`\beta\in[0,1]`$。

**第三步：切面预算直接控制全系统黏性耗散。** 对 $`1\le n\le N`$，把全部前层及本层 $`w_n`$ 列入内侧。全局预算减去内侧预算，得到外侧储能加黏性损失等于净跨面输入。舍弃外侧储能和负的反向交换，低壳黏性用 $`4^n`$ 控制，便有

```math
Q_\nu(T)\le\nu4^nTR^2+F_n
+TR^3(e_{n-1}+e_n)
\le\nu4^nTR^2+F_n+3TR^3 2^{-n}.
```

这是整个无限系统的真实黏性耗散上界，而不是只对低壳耗散的估计。任取 $`1\le m\le N`$，用 $`(n+1)^{-2\alpha}`$ 归一化平均，得到可计算的有限参数界

```math
0\le Q_\nu(T)\le
\nu4^NTR^2+3TR^3 2^{-m}
+\frac{L_*}{H_{m,N}},\qquad
H_{m,N}=\sum_{n=m}^N(n+1)^{-2\alpha}.\tag{QV}
```

另有平凡上界 $`Q_\nu(T)\le T^2`$，可与 (QV) 取较小者。整个论证只做有限层求和和精确预算，不假定末端能量强收敛。

**渐近读法。** 令 $`m=\lfloor\sqrt N\rfloor`$，则 $`\nu4^N\le\sqrt\nu/4`$，且 $`N`$ 与 $`\log(1/\nu)`$ 同量级。若 $`1/4<\alpha<1/2`$，积分比较给 $`H_{m,N}`$ 与 $`N^{1-2\alpha}`$ 同量级；若 $`\alpha=1/2`$，有 $`H_{m,N}\ge\log[(N+2)/(m+1)]`$。故

```math
Q_\nu(T)=
\begin{cases}
O_{T,\alpha,\eta}\!\left((\log(1/\nu))^{-(1-2\alpha)}\right),
&1/4<\alpha<1/2,\\
O_{T,\eta}\!\left(1/\log\log(1/\nu)\right),
&\alpha=1/2.
\end{cases}
```

这里都是充分小黏性下的**上界**，不是渐近等价式、下界或最优速度。不能说实际耗散一定按双对数下降，也不能仅凭此归因数值平台。

**切面位置：$`m=1`$ 已近最优，指数无法由此改进（2026-09-29 审计）。** (QV) 中 $`m`$ 是唯一自由参数。三项代价里 $`\nu4^NTR^2`$ 与 $`m`$ 无关，$`3TR^32^{-m}`$ 随 $`m`$ 指数减小，$`L_*/H_{m,N}`$ 随 $`m`$ 增大。在如下精确算例 $`T=50,\eta=1,\alpha=1/2,\nu=10^{-14}`$（$`J_\nu=23,N=10`$）上按精确有理数逐项计算，取 $`m=1`$ 得总上界 $`1.01\times10^8`$，而取 $`m=\lfloor\sqrt N\rfloor=3`$ 得 $`1.34\times10^8`$；$`m=1`$ 即本例最小值。

更重要的是，**不能指望由此改进指数**。因为 $`H_{m,N}\le H_{1,N}\le\log(N+2)`$，而本节取 $`N=\lfloor J_\nu/2\rfloor-1`$ 故 $`N`$ 与 $`\log(1/\nu)`$ 同量级，于是

```math
H_{m,N}\le\log(N+2)=O\!\left(\log\log\frac1\nu\right)
\qquad\text{对一切 }1\le m\le N.
```

这正是 $`H`$ 的硬上界，故 (QV) 给出的 $`O(1/\log\log(1/\nu))`$ 在本证明结构内已是最优；想再收紧必须改进 $`L_*`$ 或 $`D`$ 中的常数或不等式本身，而不是重选 $`m`$。这也解释了为什么本例的界永远弱于平凡界 $`T^2`$：$`L_*\asymp T^{19/4}`$ 而 $`H`$ 只有对数增长，上界要优于 $`T^2`$ 需 $`\log(1/\nu)>T^{2.75}`$。所以本节确实证明最终消失，却仍不能预测本次计算范围内的耗散大小或平台消失位置；这也是一条负面结论——**在该框架内改善定量速率此路不通**。

这是 [保留逐层积分，将无耗散区推进到二分之一](logarithmic-zh.md#保留逐层积分将无耗散区推进到二分之一) 的有限正黏性版本与加权切面预算的组合，方法仍属已有能量估计框架。定向检索双对数／零黏收敛速度没有形成对本条精确估计的充分文献排重，不将无命中当作原创性证据，也不因有了定量界就宣称达到强研究原创性目标。

### 对数族的新时间积分包络及集中度缺口

固定式 (L) 中 η=β=1、α>0，初值、外力与极限顺序不变。以下对任一固定窗无黏分量极限成立，既有存在性、紧性和 [基础估计与四分之一范围](logarithmic-zh.md#基础估计与四分之一范围) 的粗包络作为前提。新增结论是

```math
Y_n=K_n\int_0^Tz_n^2dt\le C_{T,\alpha}(n+1)^{2\alpha/3}.
```

这改善原来的 O((n+1)^(2α)) 上界，但本身不扩大已经证明的动态分类区间。特别是 α=2/3 时得到 Y_n≤C_T(n+1)^(4/9)，尚未得到 [未解区间中的必要条件：时间集中度不能太低](logarithmic-zh.md#未解区间中的必要条件时间集中度不能太低) 所需的时间集中度。

**证明。** 记 R=√2T。旧包络给 Y_n≤C_old(n+1)^(2α)，因此

```math
G_n=h_n\int_0^Tw_nz_n^2dt
\le RC_{\rm old}(n+1)^{3\alpha}2^{-n/2},
\qquad \Gamma_\alpha=\sup_{n\ge1}(n+1)^{3\alpha}2^{-n/2}<\infty.
```

有限半切面预算给 F_n≤I_T+G_n≤L:=2T²+RC_oldΓ_α，n≥1。积分真实 w_n 方程，并像 [四次根递推与弱块长度的精确分界](extensions-zh.md#四次根递推与弱块长度的精确分界) 一样保留三次通量作 Cauchy–Schwarz，得到

```math
Y_{n-1}\le A+B_0(n+1)^{\alpha/2}Y_n^{1/4},
\qquad A=R+TR^2,\quad B_0=L^{1/2}T^{1/4}.
```

取 ρ=2α/3、U_n=Y_n/(n+1)^ρ。因 α/2+ρ/4=ρ，有

```math
U_{n-1}\le\frac{A}{n^\rho}
+B_0\left(\frac{n+1}{n}\right)^\rho U_n^{1/4}
\le A+BU_n^{1/4},\qquad B=2^\rho B_0.
```

置 C=max(1,2A,(2B)^(4/3))、X_n=U_n/C。固定 m，先进行有限 k 次后向迭代：

```math
X_m\le\max(1,X_{m+k}^{4^{-k}}).
```

末端只使用粗能量界 Y_(m+k)≤TR²2^(m+k)，故 log⁺X_(m+k)=O_(T,α,m)(1+k)，乘 4^(−k) 后趋零。令 k→∞ 得 X_m≤1，证明完成；常数不依赖 m 或所取极限，没有预设无穷和有限。

**真实下降估计仍留下两个缺口。** 记

```math
\lambda_n=h_nz_n+e_nz_{n+1},\qquad
\Lambda_n=\int_0^T\lambda_n^2dt,\qquad
W_n=\int_0^Tw_n^2dt,\quad J_n=\int_0^Tw_n^4dt.
```

正源项给 w_n′≥−λ_nw_n。将平方振幅的不等式从 t 积至 T，再用 Cauchy–Schwarz，得 w_n(t)²≤w_n(T)²+2√(Λ_nJ_n)。乘 w_n(t)² 并积分，随后用 Young 不等式，严格得到

```math
J_n\le2w_n(T)^2W_n+4\Lambda_nW_n^2,
\qquad
\mathcal I_n\le2T\frac{w_n(T)^2}{W_n}+4T\Lambda_n\quad(W_n>0).
```

新包络只能给

```math
\Lambda_n\le2(n+1)^{2\alpha}Y_n+2e_n^2TR^2
\le C_{T,\alpha}(n+1)^{8\alpha/3}.
```

在 α=2/3 上，这一幂次是 16/9，仍高于目标 1/3。末端 ℓ² 尾也不能直接控制 w_n(T)²/W_n，因为分母可能更快趋零。即使假设正缺陷 d>0，现有 F_n→d、F_n²≤(n+1)^(4α) V_nJ_n 和 J_n≤R²W_n，仅结合新包络只能给 W_n≥c_(T,d)(n+1)^(−16/9)，仍不足以消除这个比值。本节没有将均值、均方根或不同阶时间矩互换。

### 局部真实脉冲：仅凭正通量不能控制时间集中度

本节给一个有限、无黏、无迫的真实轨道反例，精确排除“只用局部方程、有界能量及正累计通量即可推出集中度界”的中间路线。它改变了原问题的初值及局部边界，**不是**共同零初值无限强迫模型的反例，不决定 α=2/3 的动态，也不产生黏性耗散。

固定 A,T>0，在高层 n,n+1 取封闭两层，保留双向同层交换、强纵向边及弱旁路。令 K=2^n、a=(n+1)^(2/3)、h=√K a、e=K^(−1)、g=h_(n+1)，四个坐标满足

```math
\begin{aligned}
w'&=h(z^2-wz)-ewb,&z'&=h(w^2-wz)-Kzy,\\
y'&=Kz^2+g(b^2-yb),&b'&=ew^2+g(y^2-yb),
\end{aligned}
\qquad (w,z,y,b)(0)=(A,0,A,A).
```

逐边守恒给能量恒等于 3A²/2，所有坐标非负且不超过 √3A；在 y=A 或 b=A 的边界上导数向内，故 y,b≥A。后层初始已有储能是本例的明确条件。

**不变区间与衰减。** 有限时间内 w>0，记 r=z/w，则精确有

```math
r'=hw(1-r)(1+r^2)-Kry+erb.
```

取 n 充分大，使 2h/K≤1/2 且 K²>2√3。在区域 w≤A、0≤r≤2h/K、y,b≥A 的边界 r=2h/K 上，利用 (1−r)(1+r²)≤1，得到 r′≤hA(−1+2√3/K²)<0；边界 w=A 上 w′≤0。故该区域不变，w 单调不增，并有 z≤(2h/K)w。

设 λ=A(h+√3K)、τ=(log 2)/λ。由 z′≥h w²−λz、z(0)=0 和 w 单调性，

```math
z(t)\ge\frac h\lambda(1-e^{-\lambda t})w(t)^2.
```

h/K≤1/4 使 λ≤2KA。因此 t≥τ 时，w′≤−h w z/2≤−a²w³/(8A)；另一方向始终有 w′≥−A(2a²+√3/K)w。令 W=∫₀ᵀw²、J=∫₀ᵀw⁴，对固定 T 和充分大的 n 得

```math
W\le\frac{A\log2}{K}
+\frac{4A}{a^2}\log(1+a^2AT/4),
\qquad
J\ge\frac{\log2}{16(2+\sqrt3)}\frac{A^3}{a^2}.
```

第一式由 w(t)²≤A²/[1+(a²A/4)(t−τ)]（t≥τ）积分得到；第二式在长为 (log 2)/[A(2+√3)a²] 的起始时段使用 w≥A/2，该时段在充分大 n 上包含于 [0,T]。于是

```math
\frac{TJ}{W^2}\ge c_{T,A}\frac{(n+1)^{4/3}}{\log^2(n+1)},
```

其增长快于任何固定常数乘 (n+1)^(1/3)。这是解的时间矩，不是人为拼接的时间函数。

**脉冲承载正通量。** 定义 F=h∫w²z、G=h∫wz²、B=e∫w²b、H=K∫z²y。w 能量预算精确给

```math
F-G=A^2/2-w(T)^2/2-B,
\qquad 0\le G\le(2h/K)F.
```

上面的衰减式给 w(T)→0，且 B≤√3A W/K→0。由 2h/K→0 得 F→A²/2、G→0；z 能量预算给 H=F−G−z(T)²/2→A²/2。这排除了“集中度很大只是因为没有有效传输”的解释。但整个四节点系统始终守恒，正通量不能称为能量耗散。

因此目标集中度证明必须增加来自整链起动历史的实际约束，不能将本节所用局部信息当作充分条件。原共同零初值轨道能否形成相应的下游储能及输入脉冲，仍未证明。新增结论和限定文献读取见[核验范围](literature-zh.md#证据范围与当前判断)。

### 首次通量到达：精确阈值桥及停止点

本节只处理 η=β=1、α=2/3 的既定零初值问题，固定 T 和无黏分量极限，记 R=√2T。令整层累计通量 C_n(t)=∫₀ᵗΦ_n，首次到达时间 τ_n(q)=inf{t:C_n(t)≥q}。C_n 连续非减，零初值有限预算给 C_(n−1)−C_n=(w_n²+z_n²)/2≥0，所以 τ_n(q) 随 n 非减。这一排序是原预算的直接推论；新增量化关系如下。

设 D(T)>q+ε>q>0，取 s=τ_(n−1)(q)、t=τ_n(q+ε)，n≥1。令 c=C_n(s)≤q，则 C_(n−1)(s)=q、C_n(t)=q+ε，且 (w_n(s)²+z_n(s)²)/2=q−c。将 [s,t] 上的 z_n 能量预算与此式相减，精确得到

```math
F_n[s,t]=\varepsilon+\frac{w_n(s)^2}{2}
+\frac{z_n(t)^2}{2}+G_n[s,t]-B_n[s,t],
```

其中 B_n 包含弱输入 e_(n−1)∫w_(n−1)²z_n 与弱出口 e_n∫w_n²z_(n+1)，没有遗漏根历史、回流或旁路。由 [对数族的新时间积分包络及集中度缺口](logarithmic-zh.md#对数族的新时间积分包络及集中度缺口) 的 Y_n≤C_T(n+1)^(4/9)，置 δ=t−s，得

```math
\varepsilon\le R^2\sqrt{C_T}(n+1)^{8/9}\sqrt\delta
+3R^3\,2^{-n}\delta.
```

若 ε≥6TR³2^(−n)，便有真实延迟下界

```math
\tau_n(q+\varepsilon)-\tau_{n-1}(q)
\ge\frac{\varepsilon^2}{4R^4C_T}(n+1)^{-16/9}.
```

它使用了整链零初值，却仍不足以排除有限累积到达：∑n^(−16/9) 有限；固定 ε 的差值又跨不同阈值，不能直接望远镜求和。若改用递增阈值 q_n=q_(n−1)+ε_n<D(T)，则必须有 ∑ε_n<∞，所得下界之和仍有限。同阈值 ε=0 时只剩实际端点暂存量，尚缺 w_n(τ_(n−1)(q)) 等沿移动时刻的联合下界；固定时刻的 ℓ² 预算不能直接控制这些不同时间的分量之和。

**局部预存单元不能直接拼接。** 若原零初值全链在某时刻有 w_n≥A、w_(n+1),z_(n+1)≥A，则 C_n≥A²、C_(n−1)≥3A²/2。以 [局部真实脉冲：仅凭正通量不能控制时间集中度](logarithmic-zh.md#局部真实脉冲仅凭正通量不能控制时间集中度) 单元新增传输量 q=A²/2 计，该状态已经越过 τ_n(2q)、τ_(n−1)(3q)，不能拿来估计首次同阈值差。

此外，全链若在 [s,s+L] 上有 z_(n+1)≥A，令 K=K_n、x=w_(n+2)，真实方程给

```math
x'\ge2KA^2-D_nx,\qquad
D_n=R\left[2\sqrt K(n+3)^{2/3}+\frac1{4K}\right].
```

由 x(s)≥0、x≤R 得 (2KA²/D_n)(1−e^(−D_nL))≤R。若 ρ_n=RD_n/(2KA²)≤1/2，则

```math
L\le\frac{-\log(1-\rho_n)}{D_n}\le\frac{R}{KA^2}.
```

每个固定 A,R 在充分大 n 上均满足此条件。接收强出口坐标维持 A 的时间至多为 O(2^(−n))，不能像封闭单元那样持续整个 O(n^(−4/3)) 脉冲期；完整方程中的 −K_(n+1)z_(n+1)w_(n+2) 正是破坏原下界的不省略项。该结论不排除移动的多层脉冲或衰减中的接收量。

本批停在上述真实时序关系和明确的可求和障碍，α=2/3 动态仍开放。不继续仅用相同预算尝试 MB，也不将不同时间的预存成本相加冒充无穷能量矛盾。

### 零初值轨道的接收屏障与 z 通道黏性一致强尾

固定式 (L) 的 η=β=1、α>0、双根单位力、共同零初值及既有极限顺序，不改变模型。记 a_n=(n+1)^α、h_n=√K_n a_n、K_n=2^n、M_n=K_n²。正黏性无限层解的共同基础作为前提。以下是新轨道估计，不是新的异常耗散分类。

**命题。** 对每个 T>0，令 R=√2T。存在只依赖 α 的 C_α，使所有 ν>0、n≥1 和 0≤t≤T 满足

```math
z_n^\nu(t)\le C_\alpha R
\left(\frac{a_n}{\sqrt{K_n}}\right)^{1/4}.
```

特别地，整个正黏性族的 z 能量尾满足

```math
\sup_{\nu>0}\sup_{0\le t\le T}
\sum_{n\ge N}(z_n^\nu(t))^2
\le C_\alpha^2R^2\sum_{n\ge N}(n+1)^{\alpha/2}2^{-n/4}
\longrightarrow0.
```

因此，沿任何已经逐坐标在 [0,T] 一致收敛的零黏子列，z^ν→z 于 C([0,T];ℓ²)。不要求无黏极限唯一，不声称整族共享一个极限。对每个无黏分量极限还有更快的点态界

```math
z_n(t)\le C_\alpha R
\left(\frac{a_n}{\sqrt{K_n}}\right)^{1/3}.
```

**第一步：一般接收屏障。** 设非负 C¹ 函数 z,x 满足 z′≤A、x′≥Kz²−Bx，其中 A,K>0、B≥0。定义

```math
f(z)=\frac{Kz^3}{3(A+Bz)},\qquad
f'(z)=\frac{Kz^2(3A+2Bz)}{3(A+Bz)^2}\ge0.
```

直接计算给出

```math
Kz^2-Bf(z)-Af'(z)
=\frac{KBz^3(3A+2Bz)}{3(A+Bz)^2}\ge0.
```

故 F=x−f(z) 满足 F′≥−BF；若 x(0)≥f(z(0))，Gronwall 给 x(t)≥f(z(t))。这是有限坐标微分比较，不涉及无限求和。

**第二步：保留完整图与黏性。** 固定 n≥1，取 z=z_n^ν、x=w_(n+1)^ν。共同能量界给所有坐标≤R。真实方程因此满足

```math
\begin{aligned}
(z_n^\nu)'&\le A_n-\nu K_n^2z_n^\nu\le A_n,
& A_n&=(h_n+e_{n-1})R^2,\\
(w_{n+1}^\nu)'&\ge K_n(z_n^\nu)^2-B_n^\nu w_{n+1}^\nu,
& B_n^\nu&=(h_{n+1}+e_{n+1})R+\nu M_{n+1}.
\end{aligned}
```

接收坐标的同层损失和弱纵向出口均计入 B_n^ν，额外正源只改善下界。两坐标初始为零，满足屏障初始条件。结合 x≤R、z≤R，得到

```math
K_n(z_n^\nu)^3
\le3R(A_n+B_n^\nu z_n^\nu)
\le3R(A_n+B_n^\nu R).
```

置 p_n=a_n/√K_n、d_n^ν=νK_n/R。对 n≥1，有 e_(n−1),e_(n+1)≤h_n 及 h_(n+1)/h_n≤√2(3/2)^α。可取 c_α=3[3+√2(3/2)^α]，于是

```math
\left(\frac{z_n^\nu}{R}\right)^3
\le c_\alpha p_n+12d_n^\nu.
```

12 来自 M_(n+1)=4K_n²，不能把这个黏性项直接删去来宣称统一尾界。另一方面，保留 z 方程的实际阻尼并用零初值比较，得到

```math
\frac{z_n^\nu(t)}R
\le\frac{(h_n+e_{n-1})R}{\nu K_n^2}
\le\frac{2p_n}{d_n^\nu}.
```

**第三步：两个黏性区间合并。** 当 p_n≤1、d_n^ν≤p_n^(3/4) 时，p_n≤p_n^(3/4)，屏障给 z_n^ν/R≤(c_α+12)^(1/3)p_n^(1/4)。当 d_n^ν≥p_n^(3/4) 时，阻尼界给 z_n^ν/R≤2p_n^(1/4)。p_n>1 时直接用 z_n^ν/R≤1≤p_n^(1/4)。取 C_α=max(1,2,(c_α+12)^(1/3))，证明黏性一致命题。

先固定 n 沿坐标零黏子列取极限，屏障中的 d_n^ν 消失，再对所得同一极限的全部层号使用点态界，可得 p_n^(1/3) 版本。这个顺序没有删去正黏性高层的阻尼贡献。

尾界的右侧是层号多项式乘指数衰减，故可求和。沿坐标一致收敛子列，先以这个统一尾压低 ∑_(n≥N)|z_n^ν−z_n|²，再在有限头部取极限，得到 C([0,T];ℓ²) 强收敛。根层由有限坐标收敛处理。z 的末端能量因而实际收敛；w 的黏性一致强尾仍未证明。本节尾界本身不控制含 K_n² 的累计黏性积分，不能单凭它推出 Q_z→0 或全向量强收敛；后续 [z 通道真实黏性损失消失及强尾的三次根改进](logarithmic-zh.md#z-通道真实黏性损失消失及强尾的三次根改进) 另用真实通道预算证明 Q_z→0。

本屏障用到了零初值的起动条件，超出任意能量状态的限制。[快变量消元的反例与尚未分类的配置](extensions-zh.md#快变量消元的反例与尚未分类的配置) 的状态反例仍正确，但其高层 z_n=1、w_(n+1)=K_n^(−1/2) 不满足本屏障，不能当作原零初值轨道的可达状态。[局部真实脉冲：仅凭正通量不能控制时间集中度](logarithmic-zh.md#局部真实脉冲仅凭正通量不能控制时间集中度) 的预存接收脉冲初始 z=0、x>0 满足屏障，亦不矛盾。未据此重新采用瞬时快变量消元；导数项及相关性仍须保留。

### 正缺陷下的积分相关式与整体加权测试阻断

本节继续使用 [零初值轨道的接收屏障与 z 通道黏性一致强尾](logarithmic-zh.md#零初值轨道的接收屏障与-z-通道黏性一致强尾) 的设置，只研究 1/2<α≤3/4 的已有无黏分量极限。它给出新的必要信息及一个具体方法反例，没有闭合动态分类。记 Z_n=∫z_n²、W_n=∫w_n²、J_n=∫w_n⁴、Y_n=K_nZ_n。[对数族的新时间积分包络及集中度缺口](logarithmic-zh.md#对数族的新时间积分包络及集中度缺口) 的 Y_n≤Ca_n^(2/3) 及有限整层、半层预算作为前提。

**正缺陷使相对余项消失。** 沿用 [快变量消元的反例与尚未分类的配置](extensions-zh.md#快变量消元的反例与尚未分类的配置) 的 v_n=√K_n z_n/a_n，只作逐坐标变换。对 n≥1 积分真实方程，得到

```math
\begin{aligned}
Y_{n-1}&=a_n^2\langle w_n,v_n\rangle+\mathcal R_n,
&\mathcal R_n&=w_n(T)-h_nZ_n+e_n\int_0^Tw_nz_{n+1}dt,\\
W_n&=\langle v_n,w_{n+1}\rangle+\varepsilon_n,
&\varepsilon_n&=\int_0^Tw_nz_ndt+\frac{z_n(T)}{h_n}
-\frac{e_{n-1}W_{n-1}}{h_n}.
\end{aligned}
```

内积均在 L²(0,T)。ε_n 没有 −Z_n 项；该项曾在代理草推中误加，逐边组装后已纠正。现有积分包络给 ε_n 指数小，而 𝓡_n=w_n(T)+O(2^(−n/2)a_n^(5/3)+2^(−n))。

若正缺陷 d=I_T−E(T)>0，则整层通量 H_(n−1)→d，且 H_(n−1)≤RY_(n−1)，所以高层 Y_(n−1)≥d/(2R)。末端 ℓ² 尾给 w_n(T)→0，故 𝓡_n/Y_(n−1)→0。半切面给 F_n→d，并由 F_n²≤a_n²J_nY_n、J_n≤R²W_n 得

```math
W_n\ge\frac{d^2}{4CR^2}a_n^{-8/3},\qquad
\frac{\varepsilon_n}{W_n}\longrightarrow0.
```

因此定义两条真实 L² 时间相关系数 ρ_n、σ_n∈[0,1] 后，高层确有

```math
Y_{n-1}=a_n\sqrt{W_nY_n}\,\rho_n[1+o(1)],\qquad
W_n=a_n^{-1}\sqrt{Y_nW_{n+1}}\,\sigma_n[1+o(1)].
```

ρ_n 是 w_n 与 v_n 的归一化内积，σ_n 是 v_n 与 w_(n+1) 的归一化内积；零范数时置为 0。正缺陷保证充分高层的实际内积非零。由此可以排除“这些相对余项可能始终同阶”的担忧，但没有可求和误差或 ρ_n,σ_n→1 的证明；不能据 o(1) 直接累计成稳态递推。这也不解决 [对数族的新时间积分包络及集中度缺口](logarithmic-zh.md#对数族的新时间积分包络及集中度缺口) 中不同的 w_n(T)²/W_n 比值。

**一个足够的整体预算。** 若这个极限满足

```math
\mathcal A(T):=\int_0^T\sum_na_n^{4/3}(w_n-z_n)^2dt<\infty,
```

则 d=0。证明：已有 Y 界使 ∑a_n^(4/3)Z_n≤C∑a_n²/K_n<∞，所以 w²≤2(w−z)²+2z² 给 ∑a_n^(4/3)W_n<∞。假设 d>0，上述通量不等式却给

```math
a_n^{4/3}W_n\ge\frac{d^2}{4CR^2}a_n^{-4/3}.
```

α≤3/4 时 ∑a_n^(−4/3) 发散，矛盾。特别是 α=2/3 的指数为 8/9。若正黏性轨道的 𝒜_ν(T) 有黏性一致上界，有限头部收敛及 Fatou 将其传给全部极限，再由已知精确预算和末端 Fatou 推出整族 Q_ν(T)→0。这里没有证明这个预算实际成立，亦不把它等同于旧四阶时间集中度条件。

**自然全状态吸收方法失败。** 为获得该预算，一个自然候选是加权振幅 L_q=∑q_n(w_n+z_n)，q_n=K_n^(−1/2)a_n^(1/3)。对非负有限支撑状态，完整无黏非线性的有限漂移恰为

```math
\begin{aligned}
D_q={}&\sum_nq_nh_n(w_n-z_n)^2\\
&+\sum_nK_n(q_{n+1}z_n^2-q_nz_nw_{n+1})
+\sum_ne_n(q_{n+1}w_n^2-q_nw_nz_{n+1}).
\end{aligned}
```

同层正项正好是目标 a_n^(4/3)(w_n−z_n)²。但取 z_n=w_(n+1)=1、其余为零，E=1 不变，而

```math
D_q=K_n(q_{n+1}-q_n)+q_nh_n
+q_{n+1}h_{n+1}+e_{n+1}q_{n+2}
\sim-(1-2^{-1/2})\sqrt{K_n}a_n^{1/3}\longrightarrow-\infty.
```

所以不存在独立于层号的 C 使全部非负有限能量状态有 D_q≥−C||u||₂²；不能靠总能量对该测试作无条件二次吸收。根力只加有限常数，不改变反例。目标 q 虽属于 ℓ²，却不属于 V，亦不能仅凭现有能量类直接把无限 L_q 当作合法微分测试；须先作有限测试并控制极限。

更一般地，对 q_n=K_n^(−γ)(n+1)^(−s)、γ>0、s∈ℝ，存在这种统一能量半下界，当且仅当 γ>1，或 γ=1 且 s≥0。充分性由舍去交换和流入正项、再用 2xy≤x²+y²，给

```math
D_q\ge-\frac{\sup_nq_nK_n+\sup_nq_ne_n}{2}\|u\|_2^2.
```

其余参数由同一状态反例及 D_q/(q_nK_n)→2^(−γ)−1<0 排除。γ=1,s<0 仍失败，不能只写 γ≥1。可吸收权重的 q_nh_n 已指数衰减，不能提供上述多项式加权预算。这个反例只排除全状态能量吸收，不否定轨道专属控制，也不是共同零初值轨道的反例。该全状态吸收路线未闭合轨道控制；一般 P 发散动力学及 α=2/3 仍开放。新增检查及限定独立范围见[核验范围](literature-zh.md#证据范围与当前判断)。

### z 通道真实黏性损失消失及强尾的三次根改进

固定 [零初值轨道的接收屏障与 z 通道黏性一致强尾](logarithmic-zh.md#零初值轨道的接收屏障与-z-通道黏性一致强尾) 的完整对数族：η=β=1、α>0、双根单位力、共同零初值。对每个 T>0，R=√2T，记 I_*=2T²。既有正黏性无限层解、精确总预算及坐标方程作为前提，

**命题。** 存在 C_(T,α)，使充分小的 ν>0 有

```math
Q_{z,\nu}(T):=\nu\int_0^T\sum_{n\ge0}K_n^2(z_n^\nu)^2dt
\le C_{T,\alpha}\nu^{1/14}(1+\log(1/\nu))^\alpha
\longrightarrow0.
```

这是正黏性整族的真实损失上界，不是无黏子列的降能结论。因 Q_ν=Q_(w,ν)+Q_(z,ν)，任何可能的固定窗异常损失都来自 w 通道。α>3/4 时已有总 Q 的正下界，因此该范围的 w 通道确有异常损失；α=2/3 及其所在中间区间仍未分类。指数 1/14 是此证明给出的上界速度，不声称最优或渐近等价。

**第一步：接收坐标截幅控制正黏性时间积分。** 以下暂略 ν 上标。固定 n≥1，取 x=w_(n+1)，并用 [零初值轨道的接收屏障与 z 通道黏性一致强尾](logarithmic-zh.md#零初值轨道的接收屏障与-z-通道黏性一致强尾) 的真实微分下界

```math
x'\ge K_nz_n^2-B_n^\nu x,\qquad
B_n^\nu=(h_{n+1}+e_{n+1})R+4\nu K_n^2.
```

包含整层 0,…,n 的有限能量预算给

```math
H_n^\nu:=\int_0^TK_nz_n^2x\,dt
\le I_\nu(T)\le I_*.
```

舍去的是非负末端能量、内侧黏性损失及弱出口；并未假定 ∑H_n 有限。对任意 δ>0，将接收不等式在 {x≤δ} 上积分。min(x,δ) 的绝对连续链式法则及 x(0)=0 给

```math
K_n\int_{\{x\le\delta\}}z_n^2dt
\le\min(x(T),\delta)+B_n^\nu\int_{\{x\le\delta\}}x\,dt
\le\delta(1+B_n^\nu T).
```

水平集 {x=δ} 上 x′=0 几乎处处，故 ≤ 版本的指示函数合法。另一方面，在 {x>δ} 上用真实 H_n，得到 K_n∫_{x>δ}z_n²≤H_n/δ。两区间相加并选 δ=√[I_*/(1+B_n^νT)]，有

```math
Y_n^\nu:=K_n\int_0^Tz_n^2dt
\le2\sqrt{I_*(1+B_n^\nu T)}
\le C_{T,\alpha}
\left(1+K_n^{1/4}a_n^{1/2}+\sqrt\nu K_n\right).
```

这里保留了接收端实际黏性；√νK_n 项不得删去。对低层 1≤n<N 几何求和，根层单独用 Q_(z,0)≤νTR²，得

```math
Q_{z,<N}\le C_{T,\alpha}
\left(\nu+\nu K_N+
\nu K_N^{5/4}a_N^{1/2}+\nu^{3/2}K_N^2\right).
```

**第二步：真实 z 能量方程控制高层。** 固定 ν>0，先只对 N≤n≤m 的 z 坐标求和，N≥1。逐层方程给

```math
\frac12z_n(T)^2+\nu K_n^2\int_0^Tz_n^2dt
+\int_0^T\left(h_nw_nz_n^2+K_nz_n^2w_{n+1}\right)dt
=\int_0^T\left(h_nw_n^2z_n+e_{n-1}w_{n-1}^2z_n\right)dt.
```

没有根力或初始尾能量。末端强出口仍在左侧，是可以舍弃的非负项，并非补了吸收边界。用 z≤R，真实总黏性预算 Q_(w,ν)≤I_*，及 ∑∫w_n²≤TR²，得到

```math
Q_{z,[N,m]}\le R\sum_{n=N}^m h_n\int_0^Tw_n^2dt
+R\sum_{n=N}^m e_{n-1}\int_0^Tw_{n-1}^2dt
\le RI_*\sup_{n\ge N}\frac{h_n}{\nu K_n^2}
+\frac{2TR^3}{K_N}.
```

固定 ν 时正源已由这个有限右侧支配，故可以令 m→∞，无须预先假定无穷通道预算。a_(N+j)/a_N≤(j+1)^α 给

```math
Q_{z,\ge N}\le C_{T,\alpha}
\left(\frac{a_N}{\nu K_N^{3/2}}+K_N^{-1}\right).
```

**第三步：两段合并。** 取 N=⌊(5/7)log₂(1/ν)⌋，ν 充分小使 N≥1，故 K_N 与 ν^(−5/7) 只差固定倍数。低层三项分别为 O(ν^(2/7))、O(ν^(3/28)a_N^(1/2))、O(ν^(1/14))；高层为 O(ν^(1/14)a_N)+O(ν^(5/7))。a_N=O_α((1+log(1/ν))^α)，合并即得命题。全过程先在固定正黏性作合法有限求和，再令 ν→0；没有选取无黏子列或使用未证集中度。

**同批改进 [零初值轨道的接收屏障与 z 通道黏性一致强尾](logarithmic-zh.md#零初值轨道的接收屏障与-z-通道黏性一致强尾) 的强尾。** 该节屏障的更精确形式是 K_nz_n³≤3x(A_n+B_n^νz_n)，不能过早用 z_n≤R 替代全部 B_n^νz_n。零初值阻尼比较已给 νK_n²z_n≤A_n，因而

```math
B_n^\nu z_n\le(h_{n+1}+e_{n+1})R^2+4A_n,
\qquad K_nz_n^3\le3R^3(11h_n+h_{n+1}).
```

于是所有 ν>0、n≥1、t∈[0,T] 一致有

```math
z_n^\nu(t)\le\widetilde C_\alpha R
\left(\frac{a_n}{\sqrt{K_n}}\right)^{1/3},\qquad
\widetilde C_\alpha^3=3\left[11+\sqrt2(3/2)^\alpha\right].
```

统一能量尾相应收紧为 C_αR²∑_(n≥N)a_n^(2/3)K_n^(−1/3)。[零初值轨道的接收屏障与 z 通道黏性一致强尾](logarithmic-zh.md#零初值轨道的接收屏障与-z-通道黏性一致强尾) 的四次根界仍正确，但不再是最强已得界。Q_z 证明采用接收截幅与真实能量预算，独立于此强尾改进；不从强收敛直接推带权损失。完整独立范围见[核验范围](literature-zh.md#证据范围与当前判断)。

### 正黏性全层时间积分包络

保持 [z 通道真实黏性损失消失及强尾的三次根改进](logarithmic-zh.md#z-通道真实黏性损失消失及强尾的三次根改进) 设置。另有更强的全层积分估计

```math
Y_n^\nu\le C_{T,\alpha}
\left(a_n^{2/3}+\sqrt\nu K_n\right),
\qquad n\ge0,\quad\nu>0.
```

此项是独立于接收截幅的新信息；不再次复制 Q_z 证明。定义 F_n^ν=h_n∫w_n²z_n、G_n^ν=h_n∫w_nz_n²。包含全部前层及本层 w_n 的正黏性半切面给 F_n≤I_*+G_n，且 G_n≤Ra_nK_n^(−1/2)Y_n。总黏性预算和 Cauchy–Schwarz 给

```math
\nu K_n^2\int_0^Tw_n\,dt
\le\sqrt{TI_*}\sqrt\nu K_n.
```

对 n≥1 积分完整 w_n 方程，负的 −h_n∫z_n² 可舍，弱出口≤TR²；其余同层项由真实三次通量估计

```math
h_n\int_0^Tw_nz_n\,dt
\le\sqrt{F_n}\left(h_n\int_0^Tz_n\,dt\right)^{1/2},
\qquad h_n\int_0^Tz_n\,dt\le a_n\sqrt{TY_n}.
```

所以令 A=R+TR²，有

```math
Y_{n-1}\le A+\sqrt{TI_*}\sqrt\nu K_n
+\sqrt{I_*}\,T^{1/4}a_n^{1/2}Y_n^{1/4}
+\sqrt R\,T^{1/4}a_nK_n^{-1/4}Y_n^{3/4}.
```

置 s_n=a_n^(2/3)+√νK_n、U_n=Y_n/s_n。s_n/s_(n−1)≤max(2,2^(2α/3))，并有

```math
a_n^{1/2}s_n^{-3/4}\le1,\qquad
a_nK_n^{-1/4}s_n^{-1/4}
\le a_n^{5/6}K_n^{-1/4}.
```

后一序列对固定 α 的全部层号有有限上界，因此存在独立于 ν,n 的 A′,B′,D′，使 U_(n−1)≤A′+B′U_n^(1/4)+D′U_n^(3/4)。选 C 充分大，使右侧函数 f(u) 在 u≥C 时≤u/2；在 u≤C 时亦≤C/2。若任何 U_j>C，递推便强迫所有后层 U_(j+k)≥2^kU_j。但对每个固定正 ν，原能量粗界给 U_n≤TR²/√ν，矛盾。故全部 U_n≤C，证明包络。没有在黏性趋零前删去 √νK_n 或混用无黏无限迭代。

### α=2/3 的低层 w 损失定位与移动切面残项

本节只固定 α=2/3、η=β=1、共同零初值和双根单位力，使用 [z 通道真实黏性损失消失及强尾的三次根改进](logarithmic-zh.md#z-通道真实黏性损失消失及强尾的三次根改进)至[正黏性全层时间积分包络](logarithmic-zh.md#正黏性全层时间积分包络) 的新正黏性信息，不重启旧 MB、首次到达或全状态加权测试。对固定 T>0，置

```math
N_\nu=\left\lfloor\frac12\log_2(1/\nu)\right\rfloor,
\qquad W_n^\nu=\int_0^T(w_n^\nu)^2dt,
\qquad Z_n^\nu=\int_0^T(z_n^\nu)^2dt.
```

以下 ν 充分小使 N_ν≥1。新增结论是

```math
Q_{w,\le N_\nu}(T)
\le C_T(1+\log(1/\nu))^{-2/3}\longrightarrow0.
```

因此若总损失在某个固定窗不消失，结合 Q_z→0，其损失只能来自 n>N_ν 的 w 坐标。这不是总耗散分类。

**真实 z 接收方程给头部积分控制。** 暂略上标。完整方程给

```math
z_n'\ge h_nw_n^2-D_n^\nu z_n,\qquad
D_n^\nu=(h_n+K_n)R+\nu K_n^2.
```

这里保留接收端强出口损失，弱流入为非负。对 1≤n≤N_ν，√νK_n≤1，[正黏性全层时间积分包络](logarithmic-zh.md#正黏性全层时间积分包络) 给 Y_n≤Ca_n^(2/3)，故正黏性半切面预算给

```math
F_n\le I_*+G_n\le I_*+CRa_n^{5/3}K_n^{-1/2}\le C_T.
```

最后一项的全层上界有限，常数独立于黏性。对 z_n 使用 [z 通道真实黏性损失消失及强尾的三次根改进](logarithmic-zh.md#z-通道真实黏性损失消失及强尾的三次根改进) 的接收截幅方法：在 z_n≤δ 区间以 min(z_n,δ) 积分，在 z_n>δ 区间用真实 F_n，得到

```math
h_nW_n\le\delta(1+D_n^\nu T)+C_T/\delta
\le2\sqrt{C_T(1+D_n^\nu T)}
```

（最后一步选择最优 δ）。因为 h_n/K_n 的全层上界有限，且 n≤N_ν 时 √νK_n^(1/2)≤ν^(1/4)≤1，有

```math
W_n\le\frac{C_T}{a_n}
\left(K_n^{-1/2}+1+\sqrt\nu K_n^{1/2}\right)
\le\frac{C_T}{a_n}.
```

几何求和给 ∑_(n=1)^N K_n²/a_n≤C K_N²/a_N：用 a_N/a_(N−j)≤(j+1)^α 后与指数尾求和。根层单独用 O(ν)，且 νK_(N_ν)²≤1，故 Q_(w,≤N_ν)≤C_T(ν+a_(N_ν)^(−1))，证明所示 −2/3 对数率。此证明使用实际轨道积分及通量上界，没有使用旧 MB。

**尚未控制的移动切面通量。** 对内侧包含全部前层及 w_N 的有限半切面，正黏性精确预算减去内侧预算，给

```math
E_{\mathrm{out},N}^\nu(T)+Q_{\mathrm{out},N}^\nu(T)
=F_N^\nu-G_N^\nu+\mathcal W_N^\nu,
```

其中外侧为 z_N 及全部 n>N 坐标；两条弱边的积分和 𝒲_N 非负且≤TR³(e_(N−1)+e_N)。这里的外侧损失包含 z_N，不包含 w_N。选 N=N_ν：内侧 Q≤Q_(w,≤N)+Q_z→0，外侧 z 末端能量由 [z 通道真实黏性损失消失及强尾的三次根改进](logarithmic-zh.md#z-通道真实黏性损失消失及强尾的三次根改进) 的一致三次根尾趋零，且

```math
G_N^\nu\le CRa_N^{5/3}K_N^{-1/2}\longrightarrow0.
```

于是得到实际正黏性恒等式的渐近读法

```math
F_{N_\nu}^\nu
=Q_\nu(T)+\frac12\sum_{n>N_\nu}(w_n^\nu(T))^2
+O_T\left((1+\log(1/\nu))^{-2/3}\right).
```

误差中其余项均为 ν 的正幂乘固定对数幂，故可被所示对数上界覆盖。没有假定 w 的黏性一致强尾。新包络在这个切面给 F_N≤I_*+o(1)，但没有 F_N→0；真实通量 Cauchy–Schwarz 仅给 F_N²≤Ca_N^(8/3)J_N，现有 J_N≤R²W_N 不足以推出消失。不能将未控的移动通量、外侧储能或相关性直接删去。

**指定截幅／远尾方法的尺度缺口。** 上述接收截幅把实际 K_nw_(n+1) 以 K_nR 粗估。在 K≤ν^(−b)、固定 b<1 的头部，F_n≤I_*+G_n 有一致上界，这份截幅上界给头部消失的范围为 b≤1/2；临界 b=1/2 由 a_N^(−1) 的对数因子消失，不能误写成严格 b<1/2。

另一方面，对有限 w 能量方程舍去非负项，正源只剩 H_(n−1)+G_n，用真实 Q_z 高尾得到

```math
Q_{w,\ge N}\le\frac{C_T}{\nu K_N}Q_{z,\ge N-1}
\le C_T\left(\frac{a_N}{\nu^2K_N^{5/2}}
+\frac1{\nu K_N^2}\right)
```

（N 充分大）。这份远尾界要求 b>4/5，两者无共同截点。此处只说明指定估计不足，不是原轨道反例或所有方法不可能。实际被粗化的量是接收端 K_nw_(n+1)(t) 的时间占有；新的头部定位没有消除该信息缺口。本批停在上述真实定位与残项，不继续重复同一预算、调截点或分类全部中间区间。限定验证见[核验范围](literature-zh.md#证据范围与当前判断)。

### 精确饱和积分数组与点态能量不相容

本节是一次有限可实现性排除，不是原方程反例或 α=2/3 的动态分类。固定时间区间 (0,1)、a_n=(n+1)^(2/3)，置 τ_n=a_n^(−2)、c_n=τ_n/τ_(n+1)。考察以下拟议标量数组：

```math
W_n=J_n=\tau_n,\qquad Y_n=c_n^2,\qquad
F_n=H_n=c_n,\qquad
\mathcal R_n=c_{n-1}^2-c_n\ (n\ge1),\qquad\varepsilon_n=0.
```

这里 ℛ 只是拟议余项，不是另已构造出的轨道端点；c 也不是[主证明](proofs-zh.md#常通量归一化与两个关键界)中的几何剖面。数组有 ∑W_n=∑J_n<∞、F_n,H_n→1、ℛ_n>0、nℛ_n→4/3，因而 ∑ℛ_n²<∞ 且 ℛ_n/Y_(n−1)→0。若只检查这些数值及 [正缺陷下的积分相关式与整体加权测试阻断](logarithmic-zh.md#正缺陷下的积分相关式与整体加权测试阻断) 的两条相关式，它看似容许非零尾通量。但实际函数定义带来额外约束。

**命题。** 不存在非负可测函数列 w_n,v_n，使上述 W=∫w²、J=∫w⁴、Y=a²∫v²、F=a²∫w²v 同时成立，且对 n≥1 有

```math
a_n^2\langle w_n,v_n\rangle=Y_{n-1}-\mathcal R_n=c_n,
\qquad\langle v_n,w_{n+1}\rangle=W_n=\tau_n,
\qquad\mathop{\mathrm{ess\,sup}}_{t\in(0,1)}\sum_nw_n(t)^2<\infty.
```

**证明。** ∫v_n²=c_n²τ_n，而 〈w_n,v_n〉=c_nτ_n 正好达到 Cauchy–Schwarz 等号，故 v_n=c_nw_n 几乎处处。F_n=c_n 又给 ∫w_n³=τ_n。于是

```math
\int_0^1w_n^2(w_n-1)^2dt
=J_n-2\int_0^1w_n^3dt+W_n=0.
```

因此 w_n=1_(E_n)，|E_n|=τ_n。第二相关式使 c_n|E_n∩E_(n+1)|=τ_n，故交集测度为 τ_(n+1)=|E_(n+1)|；E_(n+1)⊆E_n 相差零集。对任意有限 M≥1，正测度集合 E_M 上，w_1,…,w_M 全为 1，所以 ∑w_n²≥M。M 任意，否定统一点态能量界。只需有限交集，不需要无限交集有正测度。证毕。

平移或拆碎时间支撑不能修复这个精确数组，因为嵌套是相关式强迫的。H_n=c_n 在嵌套实现中也自动成立，却不消除矛盾。形式选择 w_n=1_[0,τ_n]、v_n=c_nw_n 的确实现上述积分值，但违反点态能量；它亦没有满足原方程的零初值、端点及真实 ε 定义。撤回用此数组证明“全部已知必要信息仍不足”的尝试。一般带误差的矩列和实际轨道仍未裁定，不能从精确饱和的排除推出总耗散消失。限定核查见[核验范围](literature-zh.md#证据范围与当前判断)。

### 有限壳块的带权时间相关性障碍

本节先给一个有限函数不等式，再接入 [正缺陷下的积分相关式与整体加权测试阻断](logarithmic-zh.md#正缺陷下的积分相关式与整体加权测试阻断) 的实际无黏轨道。非负函数 w_k,v_k∈L²(0,T)，块为 [n,m]，假设各 W_k=∫w_k²>0、∫v_k²>0，且几乎处处 ∑_(k=n)^m w_k²≤R²。令 J_k=∫w_k⁴、q_k=w_k/√W_k、p_k=v_k/||v_k||₂，定义

```math
\rho_i=\langle q_i,p_i\rangle,\qquad
\sigma_i=\langle p_i,q_{i+1}\rangle,\qquad
\delta_i=(1-\rho_i)+(1-\sigma_i),
\quad S_{n,m}=\sum_{k=n}^mW_k,
\quad B_i=\frac{\sum_{k=i+1}^m(k-n)W_k}{S_{n,m}}.
```

ρ,σ∈[0,1]，0≤B_i≤m−n。没有假设 W 的相邻比值。有限块估计为

```math
\frac{J_n}{W_n}
\le 2R^2\frac{W_n}{S_{n,m}}
+8R^2\sum_{i=n}^{m-1}B_i\delta_i.
```

**证明。** 按 W_k 加权 q_n²≤2q_k²+2(q_n−q_k)²，得

```math
S_{n,m}q_n^2\le2R^2+2\sum_{k=n}^mW_k(q_n-q_k)^2.
```

乘 w_n² 积分，使用 w_n²≤R²，有 J_n/W_n≤2R²W_n/S+2R²∑W_k||q_n−q_k||₂²/S。而

```math
\|q_i-q_{i+1}\|_2^2
\le2\|q_i-p_i\|_2^2+2\|p_i-q_{i+1}\|_2^2
=4\delta_i,\qquad
\|q_n-q_k\|_2^2\le4(k-n)\sum_{i=n}^{k-1}\delta_i.
```

交换有限求和即得命题。它量化了同时活跃的容量与时间波形迁移，不要求精确 Cauchy–Schwarz 等号。

**接入真实通量。** 使用 [正缺陷下的积分相关式与整体加权测试阻断](logarithmic-zh.md#正缺陷下的积分相关式与整体加权测试阻断) 的 v_n=√K_n z_n/a_n，实际 F_n=a_n²∫w_n²v_n 满足 F_n²≤a_n²Y_nJ_n。因此每个高层有限块有

```math
\sum_{i=n}^{m-1}B_i\delta_i
\ge\max\left(0,
\frac{F_n^2}{8R^2a_n^2Y_nW_n}
-\frac{W_n}{4S_{n,m}}\right).
```

若正缺陷 d>0，则充分高层 F_n≥d/2、Y_n≤Ca_n^(2/3)，右侧第一项至少 d²/(32CR²a_n^(8/3)W_n)。原轨道的内积和余项没有被替换；不据此假设相关系数趋 1 或块容量趋无穷。

**带误差的排除范围。** 任意具有统一点态能量界的函数列，若 W_(n+1)/W_n→1 且 ρ_n,σ_n→1，则 J_n/W_n→0。证明是先固定块长度 M=m−n+1，S/W_n→M，相关损失项趋零，得到 limsup J_n/W_n≤2R²/M；再令 M→∞。因此 [精确饱和积分数组与点态能量不相容](logarithmic-zh.md#精确饱和积分数组与点态能量不相容) 的精确数组，以及保持这些渐近条件且 liminf J/W>0 的扰动，均被排除。该数组的 σ=c_n^(−1/2)<1，不能误写成相关损失精确为零。实际 α=2/3 轨道尚未证明上述渐近前提，不能用这个推论分类耗散。

### α=2/3 的端点累计量与条件能量守恒

只固定 α=2/3、η=β=1、共同零初值、双根单位力及一个 T>0。对既有无黏分量极限，记 d(T)=I_T−E(T)≥0。若 d>0，[正缺陷下的积分相关式与整体加权测试阻断](logarithmic-zh.md#正缺陷下的积分相关式与整体加权测试阻断) 的下界保证高层 W_n,Y_n 和两条内积均正。置

```math
b_n=W_nY_{n-1}^2,\qquad
r_n=\frac{\mathcal R_n}{Y_{n-1}},\qquad
s_n=\frac{\varepsilon_n}{W_n},\qquad
\ell_n=-\log(\rho_n\sigma_n)\ge0.
```

这里 r_n 是本节归一化余项，不同于[主证明中的几何剖面](proofs-zh.md#常通量归一化与两个关键界)。真实两条相关式精确给出

```math
\frac{b_{n+1}}{b_n}
=\frac{(1-r_n)^2(1-s_n)^2}{\rho_n^2\sigma_n^2}.
```

**累计误差可以控制，端点本身不能删除。** [正缺陷下的积分相关式与整体加权测试阻断](logarithmic-zh.md#正缺陷下的积分相关式与整体加权测试阻断) 已给 Y_(n−1)≥c_(d,T)>0、W_n≥c_(d,T)a_n^(−8/3)，以及 ℛ_n=w_n(T)+O(a_n^(5/3)K_n^(−1/2)+K_n^(−1))、指数小的 ε_n。末端 w(T)∈ℓ² 于是保证

```math
\sum_nr_n^2<\infty,\qquad
\sum_n\left|r_n-\frac{w_n(T)}{Y_{n-1}}\right|<\infty,
\qquad\sum_n|s_n|<\infty.
```

选固定 L 充分大，使 |r_n|,|s_n|≤1/2。只对 L≤n<N 作有限对数求和，并用 −log(1−x)=x+O(x²)，得到对所有 N>L 一致的

```math
\sum_{n=L}^{N-1}\frac{w_n(T)}{Y_{n-1}}
=\frac12\log\frac{b_L}{b_N}
+\sum_{n=L}^{N-1}\ell_n+O_{T,d,L}(1).
```

这不是把逐层 o(1) 当成可求和误差：平方余项及指数项可求和，不能求和的端点作为左侧实际量保留。∑W_n≤TR²<∞ 保证存在 N_j→∞、N_jW_(N_j)→0。Y_(N_j−1)²≤C N_j^(8/9) 给

```math
\sum_{n=L}^{N_j-1}\frac{w_n(T)}{Y_{n-1}}
\ge\frac1{18}\log N_j
+\frac12\log\frac1{N_jW_{N_j}}
+\sum_{n=L}^{N_j-1}\ell_n-C_{T,d,L}.
```

第二个对数项亦趋于无穷。任何正缺陷因此必须承担至少对数增长的端点累计量，并补偿实际相关性损失。

**条件守恒及真实黏性推论。** 若该极限终点 w(T)∈ℓ¹，则 d(T)=0。否则上述下界使 ∑w_n(T)/Y_(n−1)=∞，却由 Y_(n−1)≥c>0 得该和≤c^(−1)∑w_n(T)<∞，矛盾。因此正缺陷强迫 ∑w_n(T)=∞。

进一步，若正黏性整族在同一个固定 T 满足

```math
\sup_{0<\nu\le\nu_0}\sum_{n\ge0}w_n^\nu(T)<\infty,
```

则 Q_ν(T)→0。任取 ν_j↓0，沿既有坐标紧性取子列，非负 Fatou 给极限终点 ℓ¹，故 d=0；根输入收敛及末端能量 Fatou、正黏性精确预算给 limsup Q_(ν_j)≤d=0。子列反证得到整族结论。同理，若 ν_j→0 且 liminf Q_(ν_j)(T)>0，则 ∑w_n^(ν_j)(T)→∞；否则有终点和有界的子列，沿它得到同一矛盾。和可理解为扩展非负数，不预设每个正 ν 的端点属于 ℓ¹。

本节没有证明实际终点 ℓ¹ 上界，也没有分类 α=2/3。末端 ℓ² 与对数累计量相容，例如 1/n 型非负数列仍平方可和；这只解释尚未形成矛盾，不是满足原方程的例子。有限块新估计和端点判据均有独立限定核查，见[文献与证据中的限定核验范围](literature-zh.md#证据范围与当前判断)。本批停止一般相关性估计的继续加工，后续须取得新的实际端点或时间迁移控制。

### 接收端占有量与发送端的真实衰减下界

本节执行 [α=2/3 的端点累计量与条件能量守恒](logarithmic-zh.md#α23-的端点累计量与条件能量守恒) 后的一项有限轨道估计，不假设终点 ℓ¹ 界或时间相关系数近饱和。仍固定 α=2/3、η=β=1、共同零初值和双根单位力；对 ν>0 的既有无限层解，或 ν=0 的既有分量极限，均使用完整坐标方程。固定 0≤s<t≤T、n≥1，R=√2T，记 w=w_n、z=z_n、x=w_(n+1)、K=K_n、h=h_n、a=a_n，所有坐标≤R。给定接收水平 A>0，置

```math
\Delta=t-s,\qquad c=\frac{h}{KA+\nu K^2},\qquad
B=e_nR+\nu K^2+c e_{n-1}R^2,\qquad
\kappa=c h e^{2cR},\qquad
\mathcal P(s,t)=cK\int_s^tz(r)(A-x(r))_+dr.
```

**命题：保留接收端低于 A 的时间积分。** 若 w(s)>0，则

```math
w(t)\ge
\frac{w(s)\exp[-cR-B\Delta-\mathcal P(s,t)]}
{\sqrt{1+2\kappa w(s)^2\Delta}}.
```

𝒫 非负，是接收端低于水平 A 时实际 z 振幅加权的积分；不能只用接收端的瞬时值代替它。该式也不允许删去发送端 νK² 阻尼。特别地，若

```math
w(t)\le\tfrac12w(s),\qquad
cR+B\Delta+\mathcal P(s,t)\le\tfrac12\log2,
```

则 Δ≥1/(2κw(s)²)。κ>0 在当前 h>0、A>0 的模型中自动成立。

**证明。** 舍去实际发送源及 z 方程的负交换，完整图给

```math
\frac{w'}w\ge-hz-e_nR-\nu K^2,\qquad
z'\le hw^2+e_{n-1}R^2-(Kx+\nu K^2)z.
```

正发送源保证 w(s)>0 后在有限区间始终为正，故对数合法。对 U=w exp(−cz) 精确相减，得到

```math
\frac{U'}U\ge-chw^2-B+cKz(x-A)
\ge-\kappa U^2-B-cKz(A-x)_+.
```

第二步用了 w²=U²exp(2cz)≤U²exp(2cR)。令 p(r)=cKz(r)(A−x(r))_+、Λ(r)=∫_s^r(B+p)。U^(−2) 的微分不等式及积分因子给

```math
U(t)\ge\frac{U(s)e^{-\Lambda(t)}}
{\sqrt{1+2\kappa U(s)^2\int_s^te^{-2\Lambda(r)}dr}}.
```

Λ≥0，故其中积分≤Δ；使用 U(s)≥w(s)e^(−cR)、U(s)≤w(s)、w(t)≥U(t)，得到所示下界。半衰条件令右侧≤w(s)/2，从而 1+2κw(s)²Δ≥4exp[−2(cR+BΔ+𝒫)]≥2，证明半衰期下界。

**占有项的有限接收预算。** 记 L_(n+1)(s,t)=∫_s^t h_(n+1)z_(n+1)，则

```math
\mathcal P(s,t)\le
\frac{aA}{A+\nu K}
\sqrt{A\Delta\left[1+L_{n+1}(s,t)
+e_{n+1}R\Delta+4\nu K^2\Delta\right]}.
```

证明不假设 x(s)=0。真实接收方程给 x′≥Kz²−D(r)x，其中 D=h_(n+1)z_(n+1)+e_(n+1)z_(n+2)+4νK²。对 min(x,A) 使用 AC 链式法则，得 K∫_{x<A}z²≤A(1+∫D)；水平集 {x=A} 上导数几乎处处为零。再用 (A−x)_+≤A1_(x<A) 及 Cauchy–Schwarz，得 𝒫≤cA√K√[AΔ(1+∫D)]。cA√K=aA/(A+νK)，控制 D 的弱项即得结果。保留的是实际接收阻尼积分 L_(n+1)，没有粗替成 h_(n+1)RΔ。

**条件下的非可求和尺度及实际缺口。** 在无黏极限 ν=0，若整个区间 x≥A，则 𝒫=0。取 A=A_n=c_0 a_n^(−2/3)，并假设 0<w_n(s)≤C_0 a_n^(−2/3)。由于 cR=(R/c_0)a_n^(5/3)K_n^(−1/2)→0、B T→0，全部充分高层在 Δ≤T 下满足上述半衰小量条件，且 κ≤2a_n²/A_n。因此任何这样的半衰事件满足

```math
\Delta\ge\frac{A_n}{4a_n^2w_n(s)^2}
\ge\frac{c_0}{4C_0^2}a_n^{-4/3}
=\frac{c_0}{4C_0^2}(n+1)^{-8/9}.
```

这些下界的层号级数发散，但原轨道尚未统一保证接收端持续高于 A_n 或起始振幅上界，各层半衰区间亦可能重叠；不能据发散级数宣布整链传递时间发散、终点 ℓ¹ 界或 Q→0。一般区间中 𝒫 及实际接收阻尼积分仍未控。该引理明确了尾估计所缺的联合时间信息，超出只估总积分或形式消去 z 的路线；到此停止本批，后续须控制实际占有项或区间衔接。限定局部核查见[文献与证据中的限定核验范围](literature-zh.md#证据范围与当前判断)。

## 无黏稳态不存在的参数范围

<!-- source: docs/03-results-zh.md section 4 -->

假设 $`\alpha\le3/4`$ 时有正的有限能量无黏稳态，令 $`I=w_0+z_0>0`$。弱边通量随层号趋零，有限预算使充分大层号满足

```math
h_nw_n^2z_n\ge I/2,\qquad
w_{n+1}\le\frac{4\eta^2}{I}(n+1)^{2\alpha}w_n^4.
```

令 $`\rho=2\alpha/3`$、$`v_n=(n+1)^\rho w_n`$，则

```math
v_{n+1}\le C_*v_n^4,\qquad
C_*=\frac{4\eta^2}{I}2^{\max(\rho,0)}.
```

因 $`\sum(n+1)^{-2\rho}=\infty`$，有限能量要求 $`v_n`$ 在任意远处都能任意小。选充分大的 $`N`$ 使 $`q=C_*^{1/3}v_N<1`$，则 $`v_{N+j}\le C_*^{-1/3}q^{4^j}`$。然而

```math
z_n\ge\frac{I}{2\eta}\,2^{-n/2}(n+1)^{\alpha/3}v_n^{-2},
```

随该迭代超指数增长，与有限能量矛盾。因此此范围不存在有限能量无黏非负稳态；黏性稳态范数也必随黏性趋零而发散，否则有界子列会给出这样的稳态。正根外力和正纵向边排除了非负稳态中的零坐标。

本节本身不能推出动态无耗散。[对数族的零耗散与局部轨道结果](logarithmic-zh.md#对数族的零耗散与局部轨道结果) 已独立处理到 $`\alpha=1/2`$，而 $`1/2<\alpha\le3/4`$ 仍未知。有限时间与长期稳态的区别仍然保留。
