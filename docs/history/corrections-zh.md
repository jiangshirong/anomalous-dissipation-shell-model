# 关键纠错与证据边界

本篇集中保存仍可能影响后续推导的纠错。旧错误只作为被撤回的说法出现，不能从历史标题恢复为有效依据。完整有效证明分别见[第一项成果](../sparse-modification/proofs-zh.md)和[D1](../correlated-environments/proofs-zh.md)。

## 能量预算与时间统计

| 被撤回或需要限定的说法 | 具体问题 | 当前有效替代 |
|---|---|---|
| 根时间均值至少为 1，即可令缺口量非负 | 恒等式 G=2m_w²−m_w−m_z 中仍有 −m_z；m_w=1、m_z=2 给 G=−1 | 另证 m_z 的实际轨道约束；不能仅靠展开式闭合缺口 |
| 时间均值、均方根和二阶时间积分可互换 | 除非时间方差为零，它们是不同量 | 分别用 m_w、r_w 和 W=∫w² 记号，使用实际相关项 |
| 输入等于未加权的根平方积分与非负项之和 | 黏性预算中平方积分前有 ν | 从精确能量预算保留 ν、根外力与边界项 |
| 根能量式中的外力积分可写为 T | 对根方程乘振幅后，实际项为 ∫w_0 或 ∫z_0 | 对方程逐项积分，不以稳态值代替有限时间轨道 |
| 只求和 z 通道也能删除根输入和全部纵向项 | 外力项仍存在，跨通道项不能自动相消 | 使用真实通道预算或总能量预算 |
| 根能量总变差可由无迫式直接估计 | 旧式漏输入，并将 z² 驱动换成 w² 积分 | 撤回该总变差界，不作为对数中间区间的证明 |

上述区别可由封闭单层的精确解 w(t)=z(t)=(1−e^(−νt))/ν 直接检验。有限代数反例否定的是声称不需要动力学前提的归约，不是否定无限模型的主定理。

## 矩、通量与可实现性

四阶集中度 MB 控制 T∫w_n⁴/W_n²；仅含 W_n、Z_n 的恒等式不能推出它。长度 ε 的时间支撑上取 w=ε^(−1/2)、区间外为零，可使二阶积分固定而四阶集中度为 1/ε。这只是反驳纯定义等价的时间剖面，不是原方程轨道。

以 C_n=h_nr_w,n²r_z,n、θ_n=r_w,n(n+1)^α 定义时，正确恒等式为

```math
C_n=\eta\theta_n^2\sqrt{V_n/T},\qquad
V_n=\frac{TC_n^2}{\eta^2\theta_n^4}.
```

若 C_n 按 (n+1)^b、θ_n 按 (n+1)^(−s) 缩放，则 V_n 的指数为 2b+4s。这个恒等式仍不含四阶矩。对数族中，满足既有条件的低集中度上界会推出零耗散，不能被反向解释为正耗散条件。

强边的真实能量通量为 K_n∫z_n²w_(n+1)，而 K_n∫z_n² 是振幅方程源项。均方根乘积通常也不是时间相关乘积的积分。相关性必须由轨道估计控制。

曾用于说明信息不足的精确饱和矩数组，实际强迫相关支撑嵌套，在任意深度的有限交集上违反点态能量界。该构造已撤回；它不能充当统一能量函数列或零初值轨道的反例。带误差数据及实际中间区间仍未裁定，见[进一步结果](../sparse-modification/extensions-zh.md)。

## 稳态、动态与有限计算

- 无有限能量无黏稳态，不推出共同初值轨道在每个固定窗零耗散。几何剖面 GP 对相应稳态问题的充要性，不是一般动态异常耗散的充要分类。
- 有限封闭无黏无迫系统逐边守恒；吸收末端或未计入的截断流出不能充当标准黏性损失。
- 对数族的解析零耗散负对照在有限黏性范围同样出现近似耗散平台。因此平台、精确收支或多个求解器一致均不证明零黏异常耗散。
- 每个固定层的短时渐近和集中度极限不能交换成固定时间窗下的高层一致结论。完整首项推导保留在对数族研究材料中。
- 两个不守恒二次型反例不能推出总能量是唯一二次不变量。β=1 时同层振幅和增加，也不意味着该保守单元自行耗散能量。
- R 的封闭三层回流证书不推出同一无限链轨道的低层回流。A 的快角速度定理不证明原未加快的相位门。

## 已撤回的实现诊断

- 旧脉冲探针在 duty=1 时把恒定根迫项写成 1/T，而正确的单位恒力为 1。由错误迫项生成的数值不能用于比较当前模型；修正版已恢复单位输入。
- 旧通道标号诊断因辅助程序的系数转置，误称 w/z 颠倒。有限差分核验确认偶指标对应 w、奇指标对应 z，标号颠倒断言撤回。这项实现纠错不改变既有解析主证明。

## 模型与原创性主张

局部双通道交换可正交变换为已有 pump gate；“同壳”依赖分组，不能认领新的基本作用律。这个局部变换也没有自动把纵向边、黏性、外力和正锥一起变成已有完整模型。将实变量合并为复变量是可能的，旧“不能复表示”说法已撤回。

关键词扫描零命中、有限坐标投影排除或两个反例均不是全部文献、变换及模型的穷尽排除。证据应指出具体来源、已读公式或定理及实际适用断点。

D1 的目标验收沿用已有证据和固定标准：结果明确且证明闭合；与选定最近工作相比有具体数学增量；增量回答明确动力学问题。2026-10-24 的指定平均化与 dyadic 定理拼接核查完成后，目标已明确认定达成。这个判断不要求所有工具首创，也不认证全球优先权；不得仅凭抽象遗漏可能反复退回待定。新的具体覆盖、等价、反例或证明漏洞应修正其实际影响部分。

## D1 的概率与环境量词

| 容易混淆的结论 | 正确范围 |
|---|---|
| 固定窗正期望或共同正概率下界 | 不升级为该固定窗概率一正耗散；每个预定有限窗仍有正概率零损失事件 |
| 概率一的全初能耗散 | 先取零黏 liminf 或 limsup，再令窗口增长；窗口可以依赖样本 |
| 单边完整时间路径律相同 | 不等于整个系数场的联合时间路径律相同 |
| 原慢快对照 | 保持每个确定时刻的全系数场分布，改变时间相关率 |
| 后续空间相关对照 | 保持每条边完整路径律，改变跨边依赖；全场瞬时联合分布可以不同 |
| 纯生辅助过程爆炸 | 不能单独推出真实正耗散；正侧另用实际能量传递和黏性清除 |
| 同块内分段调度 | 各段保留原共同环境时钟，条件估计在实际停止时刻使用 |
| r=0 冻结、无限尾块 | 不直接纳入要求正速率和全部有限块的统一定理，使用各自补充证明 |

完整量词和边界见[D1 推论与边界](../correlated-environments/consequences-zh.md)。
