# 05 设计决策与下一步

## 1. 研究目标与不可越过的约束

最终目标仍是可证明异常耗散且有实质原创性的模型。已有模型的整体评估见[验证篇 §8.9](04-evidence-zh.md#89-已有候选的原创性评估裁定)；用户随后批准 §4.1 的限定核查，并继续补完所选动态对照的证明依赖，见[验证篇 §8.10–8.11](04-evidence-zh.md#810-同密度动态对照的限定去留核查)。2026 年 10 月 3 日作者已自行完成 JSP 投稿；当前状态和续接边界见[研究交接摘要](../RESEARCH_HANDOFF.md)。新对话先按要求给出 §7 选题，随后用户将目标更新为继续寻找实质原创、可证明异常耗散的模型并允许合理使用子代理；已完成的第一批新研究见 §8。代理外部联络、付费、可见性和历史操作仍未授权；有效证明全部保留。

- R1：有限封闭无黏无迫系统逐边守恒，不靠截断吸收造耗散。
- R2：明确参数、初值、外力、解类、观察窗和极限顺序。
- R3：中文先解释变量与能量转移，再给完整证明及适用范围。
- R4：均值、均方根、二阶积分、四阶集中度与真实通量分开。
- R5：查新比较具体方程、变换、量词和方法，不以零命中宣称首创。
- R6：记录需求—选择—改动—验证—真实版本；记录公开理由，不保存隐藏推理或伪造会话。
- R7：只同步已审阅的允许文件，保持私有，不改历史、不申报平台。

**原创性标准澄清（2026-09-30）：** 用户指出，既然已有耗散证明，剩余应是确认模型或机制的原创性，而非无限扩展研究。沿用已知证明工具不等于结果不原创；目标也不额外要求全新的基本交换律或数学方法。应分别比较完整模型的实质差别、是否可等价归约，以及耗散命题是否被旧定理直接覆盖或明显短推。§8.8 的路线降级是证据不足下的取舍，不是“方法旧所以模型不原创”的判决。下一项交付应是针对已有候选的明确对照判断；仅在找到实质覆盖或无法支撑增量时，才据此提出换路线的理由。不要求补齐所有中间区间或扩展模型后才能评价当前候选，也不把有限查新说成绝对优先权证明。
