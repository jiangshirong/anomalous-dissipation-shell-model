# 外部固定时序的顺序闸门

本构造使用无外力、共同第一壳单位脉冲和独立于黏性的固定开关时序，证明标准黏性下的固定窗真实损失。无限多次开启在有限时间聚集是实质条件；局部 pump 和顺序开启结构已有明确先例。

## B.7. 时间闸门：一个可证的对照，不认领新机制

考虑无外力、共同初值仅第一壳非零的非自治正性链。它是受外部时序控制的数学级联，不声称由流体方程导出。全部开关时序和非线性系数独立于黏性。

<!-- source: docs/appendices/mechanisms-zh.md#b71-方程与固定时序 -->
### B.7.1 方程与固定时序

令 $`k_n=2^n`$，$`n\ge0`$，取

```math
\dot a_n=\kappa_{n-1}(t)a_{n-1}^2
-\kappa_n(t)a_na_{n+1}-\nu4^n a_n,
\qquad a(0)=(1,0,0,\ldots),\quad \kappa_{-1}=0.
```

每一时刻最多开放一条相邻边。具体规定

```math
\tau_n=8(n+1)2^{-n},\qquad
t_n=\sum_{j<n}\tau_j=32-16(n+2)2^{-n},\qquad T_*=32,
```

```math
\kappa_n(t)=
\begin{cases}
2^n\sin^2\!\left(\pi(t-t_n)/\tau_n\right),&t_n\le t\le t_{n+1},\\
0,&\text{其余时刻}.
\end{cases}
```

各坐标系数是时间的 $`C^1`$ 函数，且 $`0\le\kappa_n\le k_n`$、$`\int\kappa_n\,dt=4(n+1)`$。在 $`T_*`$ 之后全部关闭。时间是模型的无量纲时间，不把 32 解释为物理秒数。逐坐标光滑不代表无限维系数具有统一时间正则性：开关速度随尺度增长，无限多个窗口在 $`T_*`$ 聚集，这是构造的实质条件。

有限封闭截断删除跨末端边。每条边的能量贡献 $`a_n(-\kappa_n a_na_{n+1})+a_{n+1}\kappa_n a_n^2`$ 精确相消，即使系数随时间变化也不产生额外项，因为能量定义本身不依赖时间。非自治控制在这个方程中不直接注入能量，但它仍是人为控制，不能说系统自行选择了开关时刻。

**内部命题：** 对该固定模型的正黏性解，记

```math
Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}4^na_n(t)^2\,dt,
```

则 $`\liminf_{\nu\downarrow0}Q_\nu(33)\ge2/9>0`$。初始能量为 $`1/2`$。下面证明真实黏性耗散，不把无黏能量逃向无穷远当作该结论的替代。

### B.7.2 正黏性系统不存在额外的能量漏失

任何 $`t<T_*`$ 之前只经过有限个窗口，非零坐标有限，可依次解二维系统，已离开的低壳只作线性黏性衰减。令 $`A_n=a_n(t_n)`$；进入第 $`n`$ 个窗口时，下一壳尚为零。窗口内记 $`x=a_n,y=a_{n+1},d=\nu4^n`$，则

```math
x'=-\kappa_n xy-dx,\qquad
y'=\kappa_n x^2-4dy,\qquad (x,y)(t_n)=(A_n,0).
```

正性保持。令 $`r=(x^2+y^2)^{1/2}`$，有

```math
-4dr\le r'=-d\frac{x^2+4y^2}{r}\le-dr.
```

因而 $`A_N\le\exp(-D_{\nu,N})`$，其中

```math
D_{\nu,N}=\sum_{n<N}\nu4^n\tau_n
=8\nu[(N-1)2^N+1].
```

对每个固定 $`\nu>0`$，$`D_{\nu,N}\to\infty`$。在 $`t_N`$ 之后没有再从低于 $`N`$ 的壳输入能量；故在 $`T_*`$ 之前，所有编号至少 $`N`$ 的壳总能量至多 $`A_N^2/2`$。这个随 $`N`$ 趋零的尾界加逐坐标极限，给 $`t\uparrow T_*`$ 时的强 $`\ell^2`$ 极限。之后按线性黏性方程延拓。依次唯一的二维演化及该连续延拓也给此解的唯一性。

对有限个窗口先写精确能量等式，再令窗口数趋无穷；强能量收敛和非负耗散积分的单调收敛给

```math
\frac12\sum_n a_n(T)^2+Q_\nu(T)=\frac12
\quad(\nu>0,\ T\ge0).
```

所以在正黏性下，$`T_*`$ 不存在未记入 $`Q_\nu`$ 的能量跳失。

### B.7.3 到达高壳的能量不会在途中全部耗尽

在单个窗口内令 $`s=y/r`$，$`q=\operatorname{arctanh}s`$。因 $`x>0`$，$`0\le s<1`$，直接求导得

```math
s'=(1-s^2)(\kappa_n r-3ds),\qquad
q'=\kappa_n r-3ds.
```

因此在窗口终点

```math
q(t_{n+1})\ge4(n+1)A_n e^{-4d\tau_n}-3d\tau_n.
```

若 $`D_{\nu,N}\le1/32`$ 且 $`A_n\ge1/2`$，对 $`n<N`$ 用 $`e^{-1/8}\ge7/8`$ 得

```math
q(t_{n+1})\ge\tfrac74(n+1)-\tfrac3{32}\ge n+1,
\qquad
A_{n+1}\ge A_n e^{-4d\tau_n}\tanh(n+1).
```

记 $`P_N=\prod_{j=1}^N\tanh j`$。因为 $`1-\tanh j\le2e^{-2j}`$，有限乘积不等式给

```math
P_N\ge1-\sum_{j=1}^N(1-\tanh j)
\ge1-\frac2{e^2-1}>\frac23.
```

这里 $`e^2>7`$。从 $`A_0=1`$ 归纳，所有 $`n\le N`$ 均满足

```math
A_n\ge e^{-4D_{\nu,n}}P_n>\frac78\frac23=\frac7{12}>\frac12.
```

这同时验证了归纳使用的下界，没有预设每一步都能转移几乎全部能量。

### B.7.4 从高壳能量得到黏性耗散下界

取 $`N=N_\nu=\lfloor\tfrac34\log_2(1/\nu)\rfloor`$，只考虑足够小的黏性。则

```math
D_{\nu,N}\le8N\nu^{1/4}\longrightarrow0,
\qquad \nu4^N\ge\tfrac14\nu^{-1/2}\longrightarrow\infty.
```

这个 $`N_\nu`$ 是证明中选取的观察切面，不是改变模型的截断或开关时刻。在 $`t_N`$，高壳尾部的能量恰为 $`A_N^2/2`$。此后跨入尾部的边已永久关闭。由 §B.7.2 的精确预算，尾部能量 $`E_{\ge N}`$ 满足

```math
E_{\ge N}'\le-2\nu4^N E_{\ge N},
\qquad
Q_\nu(33)\ge\frac{A_N^2}{2}
\left(1-e^{-2\nu4^N(33-t_N)}\right).
```

因 $`33-t_N\ge1`$，右侧指数项趋零。结合上一节的乘积下界与 $`D_{\nu,N}\to0`$，即得命题。证明分开控制了前段输运损失和后段真实黏性耗散，没有只凭无黏显式解推断零黏极限。

### B.7.5 哪一部分是机制，哪一部分已有人做过

冻结任意一个时刻的系数，图上最多只剩一条边。对同一第一壳初值，冻结系统始终只涉及有限个非零坐标，固定窗口 $`Q_\nu\to0`$。上述非自治系统却有正下极限。这说明“每个冻结系统都不异常耗散”不能单独推出切换系统也不异常耗散。

但这个对照依赖有限时间内无限多次切换。若仍每次只开放下一条边，而任意有限窗口只发生有限次切换，那么紧支集初值在该窗口内只到达有限个壳。其能量有界，黏性权重在该有限集合上有界，故 $`Q_\nu(T)\le C_T\nu\to0`$。这是一条针对本类顺序闸门的排除结论，不是对任意时变无限网络的定理。

查新已发现强先例：[Tao，arXiv:1402.0290v3](https://arxiv.org/html/1402.0290v3) §5.1 的 pump 及 §5.2 Proposition 5.1、Eqs. (5.5)–(5.7)，已经使用相邻通道依次开启并在有限时间聚集的结构。既有核查实际读了该命题及证明；其目标是指定耗散参数下的强范数爆破，而不是本节的固定初值零黏耗散下界。另有 [Gürcan 的动态网络模型](https://arxiv.org/html/2004.01134v2) §II.1–III，通过定期重连研究级联统计；不能把动态网络本身认作首次。

本节独立补的是固定时序、标准 $`\nu k_n^2`$ 黏性下的输运估计及耗散下界，不能将 Tao 的爆破定理误称为已经证明了这一结论，也不能把其既有结构重新包装成我们的原创机制。本构造作为可检验的非自治对照保留，局部守恒泵与有限时间聚集的顺序开启按上述来源归属。
