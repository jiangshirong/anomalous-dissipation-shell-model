# 常交换激活与幂指数交换的完整分类

本文件研究受迫、共同零初值的双通道模型，保留常交换激活、交换趋零的联合极限、删边对照及幂指数族的完整证明。指定幂指数族的固定窗分界为 γ=1/2；稳态正耗散与固定窗正耗散的极限次序不同。固定黏性基础见[模型与分析基础](../sparse-modification/model-zh.md)。A3、A4 是保留的命题定位编号。

## A3 常交换激活、强度极限与删边检验

本模型的固定黏性构造、预算、唯一性与相对稳态比较使用[双通道基础](../sparse-modification/model-zh.md)，交换上界取本块 h/K 的上界。

<!-- source: docs/appendices/legacy-models-zh.md#a31-明确方程与比较对象 -->
### A3.1. 明确方程与比较对象

每一尺度 $`k_n=2^n`$ 有两个非负实振幅 $`x_n,y_n`$。定义固定系数

```math
K_n=k_n=2^n,\qquad M_n=k_n^2=4^n,\qquad e_n=2^{-n},\qquad
(c_n,d_n)=
\begin{cases}(K_n,e_n),&n\text{ 偶},\\(e_n,K_n),&n\text{ 奇}.
\end{cases}
```

先比较交换开关 $`\theta\in\{0,1\}`$，令 $`h_n=8\theta K_n`$。§A3.5.1 再将同一族扩展到任意固定 $`\theta>0`$，不改变其他系数：

```math
\begin{aligned}
\dot x_n={}&c_{n-1}x_{n-1}^2-c_nx_nx_{n+1}
 +h_n(y_n^2-x_ny_n)-\nu M_nx_n+\delta_{n0},\\
\dot y_n={}&d_{n-1}y_{n-1}^2-d_ny_ny_{n+1}
 +h_n(x_n^2-x_ny_n)-\nu M_ny_n+\delta_{n0}.
\end{aligned}\tag{C}
```

负下标删除，两个根各受单位外力，两侧共同全零初值。所有系数固定且不依赖黏性。外力向量的范数为 $`\sqrt2`$；瞬时输入功率为 $`x_0+y_0`$，不是预设常数，两侧实际功率不必相等。

总能量和累计耗散为

```math
E=\frac12\sum_{n\ge0}(x_n^2+y_n^2),\qquad
Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}M_n(x_n^2+y_n^2)\,dt.
```

局部交换确实守恒：$`x_n h_n(y_n^2-x_ny_n)+y_n h_n(x_n^2-x_ny_n)=0`$。它由两条相反方向的正性守恒边组成，不是松弛耗散项。两个零坐标面上的输入均非负，保持正性。有限封闭截断删除跨末层纵向边、保留末层同尺度交换；无黏无迫时能量精确守恒。

强边与交换现在分别为 $`k_n`$、$`8k_n`$，弱边仍为刻意设计的退化系数 $`k_n^{-1}`$。前两者采用常见的波数一阶量级，不意味着整个模型已从三维 NS 推导出来；非负性、错位弱边及同层交换仍是人为建模选择。常数 8 用于留下增长估计余量，不主张是临界值。

<!-- source: docs/appendices/legacy-models-zh.md#a32-开关关闭两条通道各自无固定窗口异常耗散 -->
### A3.2. 开关关闭：两条通道各自无固定窗口异常耗散

$`\theta=0`$ 时两条链完全独立。$`x`$ 链在所有奇数切面上 $`c_N=2^{-N}\to0`$，$`y`$ 链在所有偶数切面上 $`d_N=2^{-N}\to0`$。

对每条链分别使用[切面判据 §B.3.1](partial-results-zh.md)：共同零初值、单位根外力给有限时间范数界 $`T`$，所以沿各自弱切面

```math
Q_{\nu,x}(T)\le\nu4^NT^3+2^{-N}T^4,
```

$`y`$ 链同理。先固定弱切面令黏性趋零，再移远切面，得到对任意固定有限 $`T`$，

```math
\lim_{\nu\downarrow0}Q_{\nu,x}(T)
=\lim_{\nu\downarrow0}Q_{\nu,y}(T)=0.
```

这不涉及先取长时间极限后的稳态耗散。

### A3.4. 交换开启：稳态能量的一致上界

现在固定 $`\theta=1`$，取 [双通道基础](../sparse-modification/model-zh.md) 已构造的任一正稳态。将每层的弱出口变量记为 $`w_n`$，强出口变量记为 $`z_n`$，只是按奇偶交换 $`x,y`$ 的名称。强边为 $`z_n\to w_{n+1}`$，弱边为 $`w_n\to z_{n+1}`$。

令 $`I=x_0+y_0>0`$，$`m_n=\max(w_n,z_n)`$。精确预算及有限切面预算给

```math
\nu M_nm_n^2\le I,\qquad K_nz_n^2w_{n+1}\le I.
```

**增长反证。** 定义有效阻尼 $`v_n=\nu M_n/K_n=\nu2^n`$。不能把它当成与层号无关的 $`\nu`$。假设某层满足 $`m_n>10(I/K_n)^{1/3}`$，稳态耗散预算给 $`v_n\le I/(K_nm_n^2)<m_n/1000`$。分两种情况：

1. 若 $`w_n\ge2z_n`$，强出口变量的稳态方程给

```math
z_n(w_{n+1}+v_n)
=8w_n(w_n-z_n)+(e_{n-1}/K_n)w_{n-1}^2
+\delta_{n0}/K_n.
```

所有额外输入非负。因此 $`w_{n+1}\ge8w_n-v_n>2m_n`$。

2. 若 $`w_n<2z_n`$，则 $`z_n\ge m_n/2`$。下一层弱出口变量的稳态方程给

```math
K_nz_n^2\le w_{n+1}
\big(8K_{n+1}z_{n+1}+e_{n+1}z_{n+2}+\nu M_{n+1}\big).
```

结合强边通量上界、$`K_{n+1}=2K_n`$、$`v_{n+1}=2v_n`$ 和 $`e_{n+1}\le K_{n+1}`$，有

```math
\max(z_{n+1},z_{n+2})
\ge\frac{K_nm_n^4/(32I)-2v_n}{9}
>\frac{1000/32-2/1000}{9}\,m_n>2m_n.
```

两种情况都在更高的一层或两层产生至少倍增的振幅；阈值 $`10(I/K_n)^{1/3}`$ 随层号下降，$`I,\nu`$ 在本稳态固定。虽然 $`v_n`$ 增长，每个再次越过阈值的层仍由同一个全局耗散预算得到 $`v_n<m_n/1000`$，因此迭代没有漏掉高层阻尼。这个反证只用于已构造的无限稳态，不能在有限封闭系统的末层继续走边。无限倍增与先已知道的有限能量矛盾。于是

```math
m_n\le10I^{1/3}2^{-n/3},\qquad
R^2:=\|b\|_2^2\le C I^{2/3},\qquad
C=\frac{200}{1-2^{-2/3}}<800<1024.
```

又因 $`I\le\sqrt2R`$，可闭合为

```math
R\le2^{1/4}C^{3/4}<256.\tag{U}
```

这里没有预设正输入下界，也没有在取得一致界前假定其成立。最后将两个根的稳态方程相加，利用 $`c_0=d_0=1`$，得到

```math
0=2-\nu I-x_0x_1-y_0y_1+8(x_0-y_0)^2
\ge2-(\nu+R)I.
```

所以对 $`0<\nu\le1`$，$`D_\nu=I\ge2/257`$。普通振幅和中的正平方项不是额外能量源；真正的交换能量贡献始终为零。

<!-- source: docs/appendices/legacy-models-zh.md#a35-共同零初值的固定窗口异常耗散 -->
### A3.5. 共同零初值的固定窗口异常耗散

由式 (R)、(U)，零初值轨道满足 $`\|a^\nu(t)\|_2\le512=:C_0`$。令 $`s(t)=x_0(t)+y_0(t)`$，根方程给

```math
\dot s\ge2-(1+C_0)s=2-513s,
\qquad s(t)\ge\frac2{513}(1-e^{-513t}).
```

积分精确能量预算，扣除末端至多 $`C_0^2/2`$ 的储能，得到

```math
\frac{Q_\nu(T)}T
\ge\frac2{513}-\frac1T\left(\frac2{513^2}+\frac{512^2}{2}\right).
```

因此对每个固定 $`T\ge67239937`$，所有 $`0<\nu\le1`$ 都有

```math
\frac{Q_\nu(T)}T\ge\frac1{513}>0.
```

所需精确阈值为 $`67239936+2/513`$；取上面的整数只是方便。这是很粗的无量纲解析界，不能当作启动时间或建议模拟时长。没有交换长时间与黏性极限，没有让初值或交换系数依赖黏性。

合并 §A3.2：关闭交换时，两条通道各自以及总和在每个固定窗口上耗散趋零；开启交换时，共同零初值在固定足够长窗口有正下界。这是候选欲承载的具体“协同激活”结论，不是单靠稳态发散推断耗散消失。

<!-- source: docs/appendices/legacy-models-zh.md#a351-任意固定正交换强度都足够 -->
#### A3.5.1 任意固定正交换强度都足够

令 $`\eta=8\theta>0`$ 固定，即 $`h_n=\eta K_n`$；其他参数、共同零初值不变。定义

```math
\delta=\frac{\eta}{\eta+4}\in(0,1),\qquad
A_\eta^3=\frac{8(\eta+1)}{\delta^4},\qquad
\sigma=1-2^{-2/3}>0.
```

对 [双通道基础](../sparse-modification/model-zh.md) 构造的正稳态仍有 $`v_nm_n^2\le I/K_n`$。如果 $`m_n>A_\eta(I/K_n)^{1/3}`$，则 $`v_n<m_n/A_\eta^3`$。重新分支：

- 若 $`z_n\le\delta w_n`$，则 $`m_n=w_n`$。强出口方程给 $`w_{n+1}\ge\eta(w_n/z_n-1)w_n-v_n\ge4m_n-v_n>2m_n`$。
- 若 $`z_n>\delta w_n`$，则 $`z_n\ge\delta m_n`$。下一层弱出口方程及强边通量上界给

```math
\max(z_{n+1},z_{n+2})
\ge\frac{K_n\delta^4m_n^4/(2I)-2v_n}{\eta+1}
>\left(4-\frac{2}{A_\eta^3(\eta+1)}\right)m_n>2m_n.
```

这里 $`A_\eta^3>8`$ 保证两个增长倍数均大于 2。阈值随层号递减，故与 §A3.4 同样的无限增长反证给

```math
m_n\le A_\eta I^{1/3}2^{-n/3},\qquad
R^2\le C_\eta I^{2/3},\qquad
C_\eta=\frac{2A_\eta^2}{\sigma},\qquad
R\le B_\eta:=2^{1/4}C_\eta^{3/4}.
```

等价的显式上界是 $`B_\eta=4\sqrt2\,\sqrt{\eta+1}(\eta+4)^2/(\eta^2\sigma^{3/4})`$。这是由估计选择产生的界，不是实际稳态能量渐近。

取 $`C_{0,\eta}=2B_\eta`$、$`L_\eta=1+C_{0,\eta}`$。相对稳态非扩张性及根部普通振幅和的比较与 §A3.5 相同，因为交换和为非负的 $`\eta(x_0-y_0)^2`$。于是

```math
\frac{Q_{\nu,\eta}(T)}T
\ge\frac2{L_\eta}
-\frac1T\left(\frac2{L_\eta^2}+\frac{C_{0,\eta}^2}{2}\right).
```

因此，**对每个固定 $`\eta>0`$**，存在有限的

```math
T_{*,\eta}=\frac2{L_\eta}+\frac{L_\eta C_{0,\eta}^2}{2}
```

使得每个固定 $`T\ge T_{*,\eta}`$、每个 $`0<\nu\le1`$ 都有 $`Q_{\nu,\eta}(T)/T\ge1/L_\eta>0`$。

此结论不要求交换强度大于某个正阈值。但其量词是“每个正强度各有窗口和下界”，不是“所有正强度共享同一窗口和同一下界”。本组粗界在 $`\eta\downarrow0`$ 时退化；不将这解释为实际耗散率的临界指数或启动时刻。

<!-- source: docs/appendices/legacy-models-zh.md#a352-小交换强度的上界固定窗口没有统一正跳跃 -->
#### A3.5.2 小交换强度的上界：固定窗口没有统一正跳跃

有一个与下界互补的检查。对奇数 $`N\ge1`$，不按整层切割，而选

```math
\mathcal A_N=\{x_0,\ldots,x_N\}\cup\{y_0,\ldots,y_{N-1}\}.
```

两个根都在集合内。两条纵向跨界边都是弱边，同层交换只在第 $`N`$ 层跨界。向集合外的净通量为

```math
\Psi_N=e_Nx_N^2x_{N+1}+e_{N-1}y_{N-1}^2y_N
+\eta2^N(x_N^2y_N-y_N^2x_N).
```

最后一项可为负；不能将它误当单向正通量。全局预算减去集合内预算，舍弃末端外部能量，再用全零初值的 $`R_T=\sqrt2\,T`$ 控制振幅，得到对每个奇数 $`N`$：

```math
0\le Q_{\nu,\eta}(T)
\le\nu4^NTR_T^2+\left(3\cdot2^{-N}+\eta2^N\right)TR_T^3.\tag{J}
```

若 $`0<\nu\le1/8`$、$`0\le\eta\le1/4`$，令 $`r=\min(\nu^{-1/3},\eta^{-1/2})\ge2`$（$`\eta=0`$ 时第二项视为无穷），选奇数 $`N`$ 使 $`r\le2^N<4r`$。代入可得

```math
Q_{\nu,\eta}(T)
\le T\left[(16R_T^2+3R_T^3)\nu^{1/3}
+7R_T^3\sqrt\eta\right].\tag{J2}
```

因此固定任何有限 $`T`$ 后，$`\nu\to0`$ 与 $`\eta\to0`$ 的任意联合路径都使累计耗散趋零。这没有反驳 §A3.5.1：那里先固定正 $`\eta`$，允许足够长的窗口依赖它。这里的指数来自粗上界，不主张最优；该结论明确排除了“任意小交换在同一固定窗口保持共同正耗散下界”的夸张解释。

#### A3.5.3 删边压力测试：双向环并非激活所必需

本节只作结构审计，不悄悄替换式 (C)。在奇偶重命名的变量中，把强出口流回弱出口的交换乘以 $`\beta\in[0,1]`$，保留另一方向的强度 $`\eta>0`$：

```math
\begin{aligned}
\dot w_n={}&K_{n-1}z_{n-1}^2-e_nw_nz_{n+1}
 +\eta K_n(\beta z_n^2-w_nz_n)-\nu M_nw_n+\delta_{n0},\\
\dot z_n={}&e_{n-1}w_{n-1}^2-K_nz_nw_{n+1}
 +\eta K_n(w_n^2-\beta w_nz_n)-\nu M_nz_n+\delta_{n0}.
\end{aligned}\tag{C_\beta}
```

负下标项删除。$`\beta=1`$ 是原模型，$`\beta=0`$ 仅删除反向交换，不是关闭全部交换。两种方向各自守恒，所有 $`\beta\in[0,1]`$ 均保持有限系统能量守恒与正性。[双通道基础](../sparse-modification/model-zh.md) 的固定黏性构造、唯一性和相对能量仍适用：每个节点流出系数和不超过 $`(1+\eta)K_n`$，双线性常数仍可取 $`1+2\eta`$。

对任一正稳态，§A3.5.1 的同一组 $`\delta,A_\eta,B_\eta`$ 适用于所有这些 $`\beta`$。证明所需的两条关键式现在为

```math
\begin{aligned}
z_n(w_{n+1}+v_n)
 &\ge\eta w_n(w_n-\beta z_n)
 \ge\eta w_n(w_n-z_n),\\
K_nz_n^2
 &\le w_{n+1}(e_{n+1}z_{n+2}+\eta K_{n+1}z_{n+1}+\nu M_{n+1}).
\end{aligned}
```

第二式舍弃的输入中包括非负的 $`\beta\eta K_{n+1}z_{n+1}^2`$。故两个增长分支、逐层包络及稳态一致界保持成立。这里是重新核对平衡式，不是声称删边后解或耗散量单调变化。

根部振幅和的交换贡献变成 $`\eta(w_0-z_0)(w_0-\beta z_0)`$，可能为负，不能沿用 §A3.5.1 的非负平方。在全过程范数界 $`C_{0,\eta}=2B_\eta`$ 下，舍弃正输入并估计根部损失，仍有

```math
\dot s\ge2-\widehat L_\eta s,\qquad
\widehat L_\eta=1+(1+2\eta)C_{0,\eta}\quad(0<\nu\le1).
```

因此将 §A3.5.1 的 $`L_\eta`$ 换为 $`\widehat L_\eta`$，得到共同零初值在固定足够长窗口的正耗散下界，且该界对 $`\beta\in[0,1]`$ 一致。双向环不是这个激活定理的必要条件。

删边端点 $`\beta=0`$ 还有一个精确重编号：令 $`a_{2n}=w_n,a_{2n+1}=z_n`$，则

```math
\dot a_j=p_{j-1}a_{j-1}^2+r_{j-3}a_{j-3}^2
 -a_j(p_ja_{j+1}+r_ja_{j+3})-\nu m_ja_j+f_j,
```

其中

```math
p_{2n}=\eta2^n,\quad p_{2n+1}=2^n,\qquad
r_{2n}=2^{-n},\quad r_{2n+1}=0,\qquad
m_{2n}=m_{2n+1}=4^n,\quad f_j=\mathbf1_{\{0,1\}}(j).
```

这就是一条带跨度三弱旁路的单向链，主路系数与 $`2^{j/2}`$ 可比。不能直接援引旧主稿只写给跨度二、其他权重和单根外力的覆盖定理；但它表明激活可以依靠一条重新连通的前向路径，不能将双向循环本身包装为不可替代的新机制。原模型 $`\beta=1`$ 并未因删边端点可重编号而与该链等价。

<!-- source: docs/appendices/legacy-models-zh.md#a36-简单约化检查及尚未完成的查新 -->
### A3.6. 简单约化检查及尚未完成的查新

- 同层两个相反方向的边构成有向环，正加权坐标置换不会把它变成单向无环链或一父树。这只排除该类变换。
- 各层能量不能对全部状态自治闭合。例如在第 1 层，取下一层 $`x_2=y_2=1`$；本层 $`(x_1,y_1)=(1,2)`$ 与 $`(2,1)`$ 能量相同，切面通量分别为 $`17/2`$ 和 $`4`$。同层交换不改变这个能量预算差异。
- 若尝试把某条链嵌入全状态子空间 $`y_n=r_nx_n`$、$`r_n>0`$，交换项在 $`\dot y_n-r_n\dot x_n`$ 中留下 $`h_n(1-r_n)(1+r_n^2)x_n^2`$。因此必须 $`r_n=1`$；但下一层不等的纵向系数使 $`x=y`$ 不保持。这排除整族正对角比例子空间，不排除更一般的非线性投影或特殊解对应。

这些检查不构成原创性认证。一般保守网络、双分量壳模型、双向局部交换、耗散激活与耦合系统均需专门对照。证明仍主要依赖正性、增长反证和相对能量，不能因结论比 W/S 更强就声称方法全新。

## A4 幂指数交换的动态与稳态分界

<!-- source: docs/appendices/legacy-models-zh.md#a41-只改变交换的尺度增长率 -->
### A4.1. 只改变交换的尺度增长率

沿用弱出口变量 $`w_n`$、强出口变量 $`z_n`$，固定

```math
K_n=2^n,\quad M_n=4^n,\quad e_n=2^{-n},\quad
h_n=\eta2^{\gamma n},\qquad \eta>0,\quad\gamma\le1,\quad0\le\beta\le1.
```

方程为

```math
\begin{aligned}
\dot w_n={}&K_{n-1}z_{n-1}^2-e_nw_nz_{n+1}
 +h_n(\beta z_n^2-w_nz_n)-\nu M_nw_n+\delta_{n0},\\
\dot z_n={}&e_{n-1}w_{n-1}^2-K_nz_nw_{n+1}
 +h_n(w_n^2-\beta w_nz_n)-\nu M_nz_n+\delta_{n0}.
\end{aligned}\tag{D}
```

负下标项删除；共同零初值，两个根各受单位外力。$`\gamma=1`$ 回到上一候选；$`\beta=1`$ 保留双向交换，$`\beta=0`$ 只保留弱出口到强出口的方向。所有参数固定，不依赖黏性。

因为 $`h_n\le\eta K_n`$，[双通道基础](../sparse-modification/model-zh.md)的正黏性存在性、能量等式、唯一性及正稳态构造仍成立：非线性系数上界、正性及边相消均未变坏。但A3 的黏性一致稳态上界依赖 $`h_n/K_n`$ 的正下界，不能直接搬到 $`\gamma<1`$。

记

```math
Q_\nu(T)=\nu\int_0^T\sum_n M_n(w_n^2+z_n^2)\,dt.
```

<!-- source: docs/appendices/legacy-models-zh.md#a42-有界交换固定窗口耗散确实消失 -->
### A4.2. 有界交换：固定窗口耗散确实消失

**结论。** 对每个固定 $`\gamma\le0`$、$`\eta>0`$、$`\beta\in[0,1]`$ 和有限 $`T`$，共同零初值满足 $`Q_\nu(T)\to0`$。

证明使用多个非整层切面，而不是由稳态性质猜测。令 $`x_n,y_n`$ 仍按 A3 的奇偶关系对应 $`w_n,z_n`$，取奇数 $`N\ge1`$ 的集合

```math
\mathcal A_N=\{x_0,\ldots,x_N\}\cup\{y_0,\ldots,y_{N-1}\}.
```

其向外净通量是

```math
\Psi_N=e_Nx_N^2x_{N+1}+e_{N-1}y_{N-1}^2y_N
+h_N(x_N^2y_N-\beta y_N^2x_N).
```

由 $`h_N\le\eta`$、全过程范数界 $`R_T=\sqrt2T`$，舍弃负通量后有

```math
\Psi_N\le R_T\big[(e_N+\eta)x_N^2+e_{N-1}y_{N-1}^2\big].
```

对 $`N=1,3,\ldots,2m-1`$，右侧涉及的坐标互不重复。故每个时刻

```math
\sum_{N\in\{1,3,\ldots,2m-1\}}\Psi_N
\le(1+\eta)R_T^3.
```

每个切面都包含两个根。外部预算给 $`Q_\nu(T)\le Q_{\nu,\mathcal A_N}(T)+\int_0^T\Psi_Ndt`$；这里用的是外部末端能量非负，而非 $`\Psi_N\ge0`$。将这 $`m`$ 个不等式平均，得到

```math
0\le Q_\nu(T)\le\nu4^{2m-1}TR_T^2+\frac{(1+\eta)TR_T^3}{m}.
```

先固定 $`m`$ 令黏性趋零，再令 $`m\to\infty`$，结论成立。这个平均步骤覆盖了 $`\gamma=0`$；只用单个切面系数趋零不能处理该端点。

<!-- source: docs/appendices/legacy-models-zh.md#a421-动态时间积分估计无耗散区扩展到临界点 -->
#### A4.2.1 动态时间积分估计：无耗散区扩展到临界点

**结论。** 对式 (D) 的每个固定 $`\gamma\le1/2`$、$`\eta>0`$、$`\beta\in[0,1]`$，共同零初值在每个固定有限窗口满足 $`Q_\nu(T)\to0`$。以下单独处理真实动态，不使用稳态能量发散来代替证明。

固定 $`T>0`$，记 $`R=\sqrt2T`$。任意趋零黏性序列都有逐坐标、时间一致收敛的子列：能量界控制所有振幅，固定坐标的导数在 $`0<\nu\le1`$ 一致有界，故可用逐坐标 Ascoli 与对角提取。极限 $`(w,z)`$ 是共同零初值的非负无黏坐标解，满足每个时刻的 $`\ell^2`$ 范数上界 $`R`$。此处不假定无黏解唯一，也不预设其能量等式。

对这条极限轨道定义

```math
P_n=\int_0^Tz_n(t)^2\,dt,\qquad Y_n=K_nP_n.
```

积分下一层的弱出口方程，舍弃非负的反向交换输入，利用零初值及 $`h_{n+1}\le\eta\sqrt{K_{n+1}}`$，得到

```math
\begin{aligned}
Y_n&\le w_{n+1}(T)
+e_{n+1}\int_0^T w_{n+1}z_{n+2}\,dt
+h_{n+1}\int_0^T w_{n+1}z_{n+1}\,dt\\
&\le A+B\sqrt{Y_{n+1}},\qquad
A=R+TR^2,\quad B=\eta R\sqrt T.
\end{aligned}\tag{T1}
```

同时有粗界 $`Y_n\le2^nTR^2`$。令 $`C_T=2A+16B^2`$。若某层 $`Y_n>C_T`$，式 (T1) 迫使

```math
Y_{n+1}\ge\frac{(Y_n-A)^2}{B^2}
>\frac{Y_n^2}{4B^2}>4Y_n.
```

该条件可反复迭代，但 $`4^jY_n`$ 最终超过粗界 $`2^{n+j}TR^2`$，矛盾。因此

```math
K_n\int_0^Tz_n^2\,dt\le C_T\qquad(n\ge0).\tag{T2}
```

这里估计的是时间平方积分，不是把某个稳态振幅界套在动态轨道上。

对奇数 $`N`$ 使用 §A4.2 的非整层切面。交换向外的正部分为

```math
F_N=h_N\int_0^T w_N^2z_N\,dt.
```

Cauchy–Schwarz、$`h_N^2/K_N\le\eta^2`$ 及 (T2) 给

```math
F_N^2\le h_N^2P_N\int_0^T w_N^4\,dt
\le\eta^2C_T\int_0^T w_N^4\,dt.
```

因为 $`\sum_n\int_0^T w_n^4dt\le R^2\int_0^T\sum_nw_n^2dt\le TR^4`$，所以 $`F_N\to0`$，包括 $`\gamma=1/2`$ 端点。反向通量也消失：

```math
0\le\beta h_N\int_0^T w_Nz_N^2dt
\le\eta RC_TK_N^{\gamma-1}\longrightarrow0.
```

两条弱纵向边的时间通量由 $`3\cdot2^{-N}TR^3`$ 控制。因此整个有符号切面通量的时间积分趋零。先写有限集合的精确能量预算，再沿奇数切面穷尽所有坐标，得到极限轨道的受迫能量等式

```math
E_0(T)=\int_0^T(w_0+z_0)\,dt.
```

最后回到正黏性轨道。其根输入沿子列收敛，末端能量满足 $`E_0(T)\le\liminf E_\nu(T)`$。由正黏性精确预算，

```math
0\le\limsup Q_\nu(T)
\le\int_0^T(w_0+z_0)\,dt-E_0(T)=0.
```

以上对任意趋零黏性序列都可提取子列进行，故排除任何正的耗散 $`\limsup`$，结论对整族成立。不需要无黏解唯一或整族轨道收敛，也没有把黏性加权无穷和直接通过极限。全程固定 $`T`$，与先到长期稳态是不同的极限顺序。

<!-- source: docs/appendices/legacy-models-zh.md#a422-临界证明的依赖审计 -->
#### A4.2.2 临界证明的依赖关系

A4.2.1 先用正黏性能量界与坐标紧性提取无黏坐标解，再由有限坐标积分得到 (T1)，通过超阈值增长取得 (T2)，随后证明切面时间通量消失。无黏能量等式在这些步骤之后取得。

返回黏性轨道时，末端能量下半连续给耗散上界。任意趋零黏性序列均可按同样方式提取子列，因此得到整族损失趋零。本证明保留非负坐标、根外无强迫、固定参数及固定观察窗的假设。

<!-- source: docs/appendices/legacy-models-zh.md#a43-更大的障碍区没有有限能量无黏稳态 -->
### A4.3. 更大的障碍区：没有有限能量无黏稳态

**结论。** 对每个固定 $`\gamma\le1/2`$、$`\eta>0`$、$`\beta\in[0,1]`$，式 (D) 不存在非负有限能量的无黏稳态。相应正黏性稳态的范数随 $`\nu\downarrow0`$ 趋于无穷。

**证明。** 假设存在这样的无黏稳态。两个根的外力及严格正纵向系数保证所有坐标严格正。记输入功率 $`I=w_0+z_0>0`$、弱边能量通量 $`L_n=e_nw_n^2z_{n+1}`$。有限整层预算精确给

```math
K_nz_n^2w_{n+1}+L_n=I.
```

有限能量意味着振幅有界且趋零，所以 $`L_n\to0`$。将第 $`n\ge1`$ 个弱出口方程乘以 $`w_n`$，得到

```math
h_nw_n^2z_n
=I-L_{n-1}-L_n+\beta h_nz_n^2w_n.
```

充分大 $`n`$ 时，右侧至少为 $`I/2`$，于是

```math
z_n\ge\frac{I}{2h_nw_n^2},\qquad
w_{n+1}\le\frac{I}{K_nz_n^2}
\le\frac{4h_n^2}{K_nI}w_n^4
\le Cw_n^4,\qquad C=\frac{4\eta^2}{I}.
```

最后一步正是 $`2\gamma-1\le0`$。取足够大的 $`N`$，使 $`q=C^{1/3}w_N<1`$，迭代得到

```math
w_{N+j}\le C^{-1/3}q^{4^j},\qquad
z_{N+j}\ge\frac{IC^{2/3}}{2\eta}\,2^{-\gamma(N+j)}q^{-2\cdot4^j}\longrightarrow\infty.
```

这与有限能量矛盾。论证没有删除弱旁路或反向交换：前者的通量趋零，后者在所需下界中贡献非负。

若正黏性稳态在某个趋零黏性子列上范数有界，则可逐坐标取子列。固定坐标的黏性项趋零、有限个非线性邻项通过极限，Fatou 给有限能量无黏稳态，与上面矛盾。因此不存在有界子列，即稳态范数确实趋于无穷。

**推理边界：** 以上稳态论证本身没有判定共同初值固定窗口的 $`Q_\nu(T)`$。该范围的动态耗散消失由 §A4.2.1 的另一条证明取得，不能省略后者。稳态范数发散也不等于解在有限时间爆破。

<!-- source: docs/appendices/legacy-models-zh.md#a44-为什么这个指数并不自动代表新机制 -->
### A4.4. 为什么这个指数并不自动代表新机制

作一个明确改变方程的诊断：同时删去反向交换和弱纵向旁路，即 $`\beta=0,e_n=0`$。所得系统是交错系数的普通前向链，不再是式 (D)。在没有外力的尾部，若其无黏稳态有正的常通量 $`I`$，则

```math
h_nw_n^2z_n=K_nz_n^2w_{n+1}=I,\qquad
w_{n+1}=\frac{\eta^2}{I}2^{(2\gamma-1)n}w_n^4.
```

设 $`a=(2\gamma-1)/3`$、$`b=(2-\gamma)/3`$。这个递推的一般正解可写为

```math
\log w_n=\log A-an\log2+c4^{n-n_0},\qquad
A^3=\frac{I}{\eta^2}2^{-a},\qquad z_n=\frac{I}{h_nw_n^2}.
```

若 $`c>0`$，$`w_n`$ 超指数增长；若 $`c<0`$，$`z_n`$ 超指数增长。因此有限能量的常通量尾部必须 $`c=0`$，其两支衰减指数分别为 $`a,b`$。两支均可平方求和要求 $`1/2<\gamma<2`$；本文限定 $`\gamma\le1`$，所以在这条简化链上出现的门槛也是 $`1/2`$。

这只是尾部的精确代数；没有声称任意根部设置都能与之匹配，没有由这个删边系统推出完整系统在 $`\gamma>1/2`$ 的存在性或异常耗散。它说明本篇的障碍指数已能由普通前向链的通量匹配解释，不能单凭指数出现就认领新物理机制。

经典常系数 dyadic 的稳态归一化和递推方法可对照 [Cheskidov–Friedlander 作者稿 §2，Eqs. (2.1)、(2.4)](https://arxiv.org/html/0810.3718v1)。该原文不是本篇交错系数定理的直接出处；这里只说明方法先例。原研究阶段定向检索变系数／交错系数未取得直接覆盖式 (D) 的原文，但同词异义结果很多，不能据此认证首创。

<!-- source: docs/appendices/legacy-models-zh.md#a441-正对角缩放不能把交错系数抹平 -->
#### A4.4.1 正对角缩放不能把交错系数抹平

只对上述删边链作精确比较。设 $`a_{2n}=w_n,a_{2n+1}=z_n`$，则

```math
\dot a_j=p_{j-1}a_{j-1}^2-p_ja_ja_{j+1}-\nu m_ja_j+f_j,
\quad p_{2n}=\eta2^{\gamma n},\quad p_{2n+1}=2^n,
\quad m_{2n}=m_{2n+1}=4^n,
\quad f_0=f_1=1.
```

其余外力为零，负下标项删除。取任意固定正对角缩放及公共时间缩放 $`a_j(t)=s_jb_j(ct)`$，其中 $`s_j,c>0`$。变换后的平方输入与乘积输出系数分别是

```math
\frac{p_{j-1}s_{j-1}^2}{cs_j},\qquad
\frac{p_js_{j+1}}c.
```

若要求结果仍是关于标准能量 $`\frac12\sum b_j^2`$ 的保守最近邻链，同一条边在两端必须有同一系数。比较边 $`j-1\to j`$ 即得

```math
\frac{p_{j-1}s_{j-1}^2}{cs_j}
=\frac{p_{j-1}s_j}c,
\qquad s_{j-1}=s_j.
```

因此所有缩放因子必须相同，不能改变相邻边系数的比值。对 $`\gamma<1`$，

```math
\frac{p_{2n+1}}{p_{2n}}=\eta^{-1}2^{(1-\gamma)n}\to\infty,
\qquad
\frac{p_{2n+2}}{p_{2n+1}}=\eta2^\gamma2^{(\gamma-1)n}\to0.
```

它既不是固定公比的几何序列，也不能与一个几何序列上下统一可比。非恒定缩放当然仍可使用，但原能量变成 $`\frac12\sum s_j^2b_j^2`$，黏性耗散也带同样权重；若权重不上下有界，则连有限能量空间都可能改变。不能把变换后的无权重耗散定理当作原问题的结论。

这只排除指定的正对角／公共时间缩放。没有排除非线性变换、增加隐藏变量或更一般的加权理论。经典文献中的稳态归一化也不与此冲突：稳态递推归一化不是整个动态系统在原能量空间内的共轭。

<!-- source: docs/appendices/legacy-models-zh.md#a442-删边后动态分界也仍然存在 -->
#### A4.4.2 删边后，动态分界也仍然存在

原 §A4.4 只计算了常通量尾部。本节补查删边链本身的动力学，发现它也具有相同的固定窗口分界，而不只是相同的稳态指数。这里始终令 $`\beta=0,e_n=0`$，不是完整式 (D)，也不使用任何“删边使耗散单调变化”的推论。

**基础构造。** 保留每对内的正边 $`w_n\to z_n`$ 和层间正边 $`z_n\to w_{n+1}`$。有限封闭截断仍逐边守恒、保持非负；两个根外力给原来的能量界。固定黏性的紧性、精确预算和唯一性沿用[双通道基础](../sparse-modification/model-zh.md)的边估计，因为系数上界及节点度数只减小。有限稳态的球面严格向内条件不变；无限稳态的各坐标由两个根及沿链的正系数逐一保持严格正。相对能量等式也仍逐边成立。

**无耗散侧。** 对 $`\gamma\le1/2`$，无黏极限轨道的弱出口积分式简化为

```math
Y_n=w_{n+1}(T)+h_{n+1}\int_0^T w_{n+1}z_{n+1}\,dt
\le R+\eta R\sqrt T\sqrt{Y_{n+1}}.
```

所以 §A4.2.1 的增长反证仍给 $`\sup_nY_n<\infty`$。取有限链段 $`a_0,\ldots,a_{2N}`$，其唯一出边通量正是 $`h_Nw_N^2z_N`$；同一 Cauchy–Schwarz 估计使它的时间积分趋零。有限预算、末端能量下半连续及子列反证于是给每个固定窗口 $`Q_\nu(T)\to0`$。

**正耗散侧。** 对 $`1/2<\gamma\le1`$，固定黏性正稳态的输入仍记为 $`I=w_0+z_0`$。有限链段预算给 $`h_nw_n^2z_n\le I`$、$`K_nz_n^2w_{n+1}\le I`$ 及逐坐标黏性预算。下一层弱出口和本层强出口的平衡给

```math
z_{n+1}\ge
\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}},
\qquad
w_{n+1}\ge\frac{h_n^2w_n^4}{K_nI}
-\frac{I}{K_nw_n^2}.
```

第一式只在超阈值使分子为正后才估计分母。它们不弱于 §A4.5 用来证明 (Z)、(W) 的不等式，因此同样的包络常数、能量闭合和黏性一致稳态界仍成立。相对能量给零初值轨道范数上界；根振幅和仍满足 §A4.5.3 的保守下界，故同一足够长固定窗口的正耗散下界成立。

因此，同一个 $`\gamma=1/2`$ 动态分界已经出现在**交错系数的标量最近邻链**中。完整模型保留旁路和反向边后分界不变，是可保留的扩展；“复杂网络才产生这个分界”则应排除。

<!-- source: docs/appendices/legacy-models-zh.md#a443-一个可检验的错误判据反例 -->
#### A4.4.3 一个可检验的错误判据反例

取删边链的 $`\eta=1,\gamma=1/4`$。所有 $`p_j\to\infty`$，而且

```math
\sum_{j=0}^\infty p_j^{-2/3}
=\frac1{1-2^{-1/6}}+\frac1{1-2^{-2/3}}<\infty.
```

但 §A4.4.2 已证明其共同零初值、两个单位根外力的每个固定窗口黏性耗散趋零。因此“只要边系数趋于无穷，甚至其负三分之二次幂可求和，就必有固定窗口异常耗散”在任意正系数链中是错误的。该级数只是被检验的猜测条件，不是某篇文献已经声称的定理；也不能由它直接猜测实际稳态为 $`p_j^{-1/3}`$，相邻常通量条件还必须同时满足。

这个反例没有否定要求逐边几何增长或相邻比值受控的经典结果。它进一步把查新问题收紧到剧烈交错系数的动态分类，而不是网络节点数、循环或旁路的存在。以上结论仍是内部推导，未确认首创。

<!-- source: docs/appendices/legacy-models-zh.md#a45-超临界交换完整系统的正耗散充分区 -->
### A4.5. 超临界交换：完整系统的正耗散充分区

本节保留式 (D) 的全部弱旁路和反向交换，不由删边链替代证明。固定 $`1/2<\gamma\le1`$、$`\eta>0`$、$`\beta\in[0,1]`$。取正黏性稳态，记 $`I=w_0+z_0`$。有限切面与全局预算给

```math
K_nz_n^2w_{n+1}\le I,\qquad
\nu M_nw_n^2\le I,\qquad \nu M_nz_n^2\le I.
```

<!-- source: docs/appendices/legacy-models-zh.md#a451-先控制强出口分量 -->
#### A4.5.1 先控制强出口分量

下一层弱出口的平衡给

```math
K_nz_n^2\le w_{n+1}(h_{n+1}z_{n+1}+e_{n+1}z_{n+2}+\nu M_{n+1}).
```

利用 $`M_{n+1}=4M_n`$ 及强边通量界，得到

```math
\max(z_{n+1},z_{n+2})
\ge\frac{K_n^2z_n^4/I-4I/z_n^2}{h_{n+1}+e_{n+1}}.
```

令 $`A_z^3=8(1+\eta)`$。如果 $`z_n>A_z(I/K_n)^{1/3}`$，分子为正；此时才使用分母上界 $`h_{n+1}+e_{n+1}\le2(1+\eta)K_n`$，获得

```math
\max(z_{n+1},z_{n+2})
>\frac{A_z^3-4/A_z^3}{2(1+\eta)}z_n
=\left(4-\frac1{4(1+\eta)^2}\right)z_n>2z_n.
```

阈值随层号下降，迭代违反已经存在的固定黏性有限能量。故

```math
z_n\le A_z I^{1/3}2^{-n/3}.\tag{Z}
```

事实上这一估计对所有 $`\gamma\le1`$ 都成立，只控制强出口分量，不保证弱出口可求和。

<!-- source: docs/appendices/legacy-models-zh.md#a452-再控制弱出口分量 -->
#### A4.5.2 再控制弱出口分量

同层净转移 $`J_n=h_nw_nz_n(w_n-\beta z_n)`$ 在稳态满足 $`J_n\le I`$：对 $`n\ge1`$，弱出口预算将它写成流入强边通量减去弱边流出和黏性耗散；根层则将流入换为 $`w_0\le I`$。

令

```math
a=\frac{2\gamma-1}{3},\qquad
A_w^3=8(1+\eta)(8+\eta^{-2}).
```

这里 $`0<a\le1/3`$、$`A_w\ge2A_z`$。若 $`w_n>A_w I^{1/3}2^{-an}`$，式 (Z) 保证 $`w_n>2z_n`$，所以

```math
\frac12h_nw_n^2z_n\le J_n\le I,
\qquad z_n\le\frac{2I}{h_nw_n^2}.
```

强出口的稳态方程和黏性预算给

```math
w_{n+1}\ge\frac{h_n^2w_n^4}{2K_nI}
-\frac{h_n}{K_n}w_n-\frac{I}{K_nw_n^2}.
```

因为 $`3a=2\gamma-1`$、$`\gamma\le1`$、$`K_n\ge1`$，假设的超阈值振幅使

```math
\frac{w_{n+1}}{w_n}
>\frac{\eta^2 A_w^3}{2}-\eta-\frac1{A_w^3}>2.
```

最后一个常数不等式可由 $`\eta^2A_w^3/2\ge4(1+\eta)`$、$`A_w^3\ge64(1+\eta)`$ 直接核对。阈值递减，继续迭代就与有限能量矛盾。因此

```math
w_n\le A_w I^{1/3}2^{-an}.\tag{W}
```

没有假定真实谱恰好等于这个上界，也没有把两分量视为同一尺度衰减。

<!-- source: docs/appendices/legacy-models-zh.md#a453-能量闭合无黏稳态与共同初值耗散 -->
#### A4.5.3 能量闭合、无黏稳态与共同初值耗散

由两个包络，

```math
R^2\le C_{\eta,\gamma}I^{2/3},\qquad
C_{\eta,\gamma}=\frac{A_z^2}{1-2^{-2/3}}+\frac{A_w^2}{1-2^{-2a}}.
```

结合 $`I\le\sqrt2R`$，有 $`R\le B:=2^{1/4}C_{\eta,\gamma}^{3/4}`$，独立于黏性和 $`\beta\in[0,1]`$。同一逐层包络使趋零黏性稳态族的尾部一致小，逐坐标子列极限为非负有限能量无黏稳态；根部外力和正纵向边进一步保证各坐标为正。没有将完整黏性耗散和直接通过极限。

相对稳态非扩张性给共同零初值轨道 $`\|u^\nu(t)\|_2\le2B=:C_0`$。两个根振幅之和 $`s=w_0+z_0`$ 满足

```math
s'\ge2-Ls,\qquad L=1+(1+2\eta)C_0\quad(0<\nu\le1).
```

这里保守地估计可能为负的根交换和，未将其当成正平方。精确能量预算于是给

```math
\frac{Q_\nu(T)}{T}\ge\frac2L
-\frac1T\left(\frac2{L^2}+\frac{C_0^2}{2}\right).
```

每个固定 $`T\ge2/L+LC_0^2/2`$ 都有 $`Q_\nu(T)/T\ge1/L>0`$。这是 $`1/2<\gamma\le1`$ 的固定窗口黏性异常耗散充分区；时间和下界依赖 $`\eta,\gamma`$，不依赖黏性。$`\gamma\downarrow1/2`$ 时本组能量上界退化，不由此认定实际临界指数。

<!-- source: docs/appendices/legacy-models-zh.md#a46-临界点稳态耗散不随稳态能量发散而消失 -->
### A4.6. 临界点：稳态耗散不随稳态能量发散而消失

取 $`\gamma=1/2`$。上节强出口包络 (Z) 仍成立；弱出口证明也仍成立，因为 $`a=0`$ 时阈值虽不递减，但每次倍增仍保持超阈值。因此

```math
z_n\le A_zI^{1/3}2^{-n/3},\qquad w_n\le A_wI^{1/3}.
```

后一包络不可平方求和，不能用它取得全局能量一致界。设 $`S=A_w+A_z`$，根部反而仍可闭合输入：

```math
I\le SI^{1/3},\qquad I\le S^{3/2}.
```

于是所有坐标均不超过 $`P=A_w\sqrt S`$。在稳态根方程的振幅和中舍弃正项，利用 $`0<\nu\le1`$ 得到

```math
0\ge2-[1+(1+2\eta)P]I,
\qquad
\frac2{1+(1+2\eta)P}\le D_\nu=I\le S^{3/2}.
```

与 §A4.3 合并：**临界点的稳态范数趋于无穷，但稳态真实黏性耗散具有正的黏性一致下界。** 这表明能量有界性的阈值不是稳态耗散出现与否的阈值。此处使用随黏性变化的稳态，不能替代共同零初值的固定窗口结论；后者由 §A4.2.1 独立证明为耗散趋零。

<!-- source: docs/appendices/legacy-models-zh.md#a461-稳态正耗散可扩展到整个参数族 -->
#### A4.6.1 稳态正耗散可扩展到整个参数族

这个临界点现象并不局限于 $`\gamma=1/2`$。对每个固定 $`\gamma\le1`$，仍令 $`a=(2\gamma-1)/3`$，但允许它为负。定义

```math
G_\gamma=2+2^{\max(0,-a)},\qquad
\widetilde A_w^3=64(1+\eta)+\frac{2(G_\gamma+\eta+1)}{\eta^2}.
```

强出口包络 (Z) 不变。若 $`w_n>\widetilde A_w I^{1/3}2^{-an}`$，因 $`a\le1/3`$、$`\widetilde A_w\ge2A_z`$，仍有 $`w_n>2z_n`$。完全相同的稳态不等式给

```math
\frac{w_{n+1}}{w_n}
>\frac{\eta^2\widetilde A_w^3}{2}-\eta-\frac1{\widetilde A_w^3}
>G_\gamma>\max(1,2^{-a}).
```

当 $`a<0`$ 时，阈值逐层增长，不能再说它递减；上式正是补上的检查：振幅增长比阈值增长还快，且振幅本身无限增长。故反证仍成立，得到

```math
w_n\le\widetilde A_w I^{1/3}2^{-an}.
```

此界在 $`a\le0`$ 时不控制总能量，却仍控制根与其邻层。令

```math
\widetilde S=\widetilde A_w+A_z,\qquad
P_{\eta,\gamma}=\widetilde A_w\sqrt{\widetilde S}\max(1,2^{-a}).
```

根输入满足 $`I\le\widetilde S I^{1/3}`$，所以 $`I\le\widetilde S^{3/2}`$；根层及第一层各坐标不超过 $`P_{\eta,\gamma}`$。再次使用根方程，获得

```math
0<c_{\eta,\gamma}:=\frac2{1+(1+2\eta)P_{\eta,\gamma}}
\le D_\nu=I\le\widetilde S^{3/2},\qquad 0<\nu\le1.
```

这些界对 $`\beta\in[0,1]`$ 一致。也就是说，**整个 $`\gamma\le1`$ 族的稳态黏性耗散都有正下界**，尽管 $`\gamma\le1/2`$ 的稳态能量发散。低增长区间的固定窗口结论来自 §A4.2.1，而不是这个稳态下界。

<!-- source: docs/appendices/legacy-models-zh.md#a462-同一零初值轨道上的极限次序差别 -->
#### A4.6.2 同一零初值轨道上的极限次序差别

对每个固定 $`\nu>0`$，设正稳态为 $`b^\nu`$、零初值轨道为 $`u^\nu(t)`$。相对能量等式和 $`M_n\ge1`$ 给

```math
\frac{d}{dt}\|u^\nu-b^\nu\|_2^2
\le-\nu\|u^\nu-b^\nu\|_2^2,
\qquad
\|u^\nu(t)-b^\nu\|_2\le\|b^\nu\|_2e^{-\nu t/2}.
```

因此固定黏性后，根输入收敛于 $`I_\nu`$；轨道能量有界，除以 $`T`$ 趋零。由精确能量预算，

```math
\lim_{T\to\infty}\frac{Q_\nu(T)}T=I_\nu=D_\nu.
```

现在取 $`\gamma\le1/2`$。§A4.2.1 与 §A4.6.1 给同一个方程、同一个全零初值上的严格分离：

```math
\lim_{T\to\infty}\left[\lim_{\nu\downarrow0}\frac{Q_\nu(T)}T\right]=0,
\qquad
\liminf_{\nu\downarrow0}\left[\lim_{T\to\infty}\frac{Q_\nu(T)}T\right]
\ge c_{\eta,\gamma}>0.
```

第二式保留 $`\liminf`$，因为尚未证明整族 $`D_\nu`$ 有极限。固定黏性的指数趋稳估计也没有给黏性一致的趋稳时间。这是“先到长期稳态”不能替代固定窗口异常耗散证明的具体例子，不是两者矛盾。

<!-- source: docs/appendices/legacy-models-zh.md#a463-对上述区别的原文查新 -->
#### A4.6.3 对上述区别的原文查新

重读 [Cheskidov–Friedlander §4 Theorem 4.2](https://arxiv.org/html/0810.3718v1)：其结论明确先取时间平均的长时间极限，再令黏性趋零；不能省略这个顺序。其黏性吸引子收敛机制与本文低增长区的稳态能量发散不同。这是定义与适用范围对照，不声称该文已经证明本文的反例。

更直接的机制先例是 [Mattingly–Suidan–Vanden-Eijnden，math-ph/0607047v1](https://arxiv.org/html/math-ph/0607047v1)。既有记录曾读取 §1.1–1.3、§8 Eq. (41) 与 Theorem 8.1：第一线性模型从有限能量出发在有限时间保持形式能量计算的合法性，而受迫长期状态可以具有无限能量；文中进一步研究加入显式耗散后的平衡态及零耗散极限。确定性常外力见 Eq. (9)，§8 的黏性平衡态论证则针对随机外力。

因此“有限时间行为与无限能量长期耗散状态不同”已有明确先例，不能作为本文首次发现。本文仍须查新的内容是这一差别在固定系数、正性二次双通道族中的具体参数判据；线性／随机与非线性／确定性的差异本身也不足以证明有重大研究增量。没有把所读段落升级为该文对我们全部结论的直接覆盖。

### A4.7. 当前能够证明的范围

| 交换指数 | 共同零初值、固定窗口黏性耗散 | 无黏有限能量稳态 | 正黏性稳态耗散 |
|---|---|---|---|
| $`\gamma\le1/2`$ | 本篇证明每个固定窗口趋零，包括临界点 | 本篇排除 | 黏性趋零时仍有正下界 |
| $`1/2<\gamma\le1`$ | 本篇证明足够长固定窗口有正下界 | 本篇一致逐层包络给出正的有限能量稳态极限 | 黏性趋零时仍有正下界 |

在本文明确限定的族内——$`\gamma\le1`$、固定 $`\eta>0`$、$`\beta\in[0,1]`$、两个单位根外力、共同全零初值——$`1/2`$ 现已成为固定窗口异常耗散的精确分界：下侧每个有限窗口耗散趋零，上侧每个足够长固定窗口有黏性一致正下界。上侧不声称任意短窗口都正耗散。这个分界同时对应有限能量无黏稳态的存在性及黏性稳态能量一致有界性，但不对应稳态耗散消失与否。

这是完整指定参数族的内部证明，不是所有壳模型的一般相图；尚未取得独立数学审阅或确认原创性。新增证明仍使用正性、增长反证、时间积分及相对能量。简化链能解释稳态障碍指数的事实仍然保留，对应的方法比较见 A4.7.1–2。

**可直接选取的一对模型。** 固定 $`\eta=\beta=1`$，取 $`\gamma_-=1/4`$ 与 $`\gamma_+=3/4`$。两者有相同相互作用图、黏性、两个单位根外力和共同零初值，只改变同层交换的尺度增长率；前者没有固定窗口异常耗散，后者在足够长固定窗口有异常耗散。两者的主路交换系数 $`2^{\gamma n}`$ 和纵向系数 $`2^n`$ 各自都随壳层号增大。因此“存在一条每类系数均趋于无穷的前向主路”不足以保证本类动态异常耗散；注意这不意味着交错路径上的系数逐边单调增大。此对照的研究原创性仍待查验，不把具体指数的选取本身当作新意。

**原文对照补充。** 读取 [Bianchi–Morandin，arXiv:1607.01334v2](https://arxiv.org/html/1607.01334v2) §2.1、Theorems 3.1–3.3 及 Remark 6。其变系数树模型已研究稳态正则性门槛；Remark 6 还允许每代的系数组随代改变。因此“系数随尺度改变，稳态存在性出现阈值”本身不构成新意。原文的一父树结构与本文保留合流／同层交换的方程不同，所读结果又是无黏稳态结果，不直接给出这里的共同零初值黏性耗散定理；但尚未排除通过推广其递推覆盖本例。这里只记录已读范围，不把找到方法差异当作首创证明。

#### A4.7.1 时间积分论证的文献位置

既有核查以 [Cheskidov–Dai–Friedlander 的综述](https://arxiv.org/html/2209.10203) §3.1.4 为检索入口，再回到下列原论文。综述仅用于定位，不作为一般变系数定理已覆盖本文的依据。

- [Cheskidov–Zaya，arXiv:1310.7612v4](https://arxiv.org/html/1310.7612v4)：核对 Eq. (1.3)、Theorems 1.1、2.2 及 §3 的紧性构造。研究对象是无外力的标量最近邻几何系数链。Theorem 2.2 通过时间积分通量消失推出能量守恒；因此本文“有限预算—通量消失—守恒”的框架不新。Theorem 1.1 是该标量模型的正则性结果，不直接提供双通道式 (D) 的 (T2)，更不能把本文强出口的时间平方积分界称作更强的点态正则性。
- [Barbato–Morandin，arXiv:1201.2693v1](https://arxiv.org/html/1201.2693v1)：核对引言及 §1 Eq. (1)。其中任意增长率指几何系数中的任意正指数，不是任意系数序列。本文即使删除反向交换和弱旁路，重编号后的主路也交错出现两类系数；只要两类增长指数不同，便不能直接代入该几何链设定。本文完整模型还保留旁路、双根外力及可选反向边。这里不声称其后续证明无法推广，也没有将未读的所有定理排除。

因此，原研究阶段没有取得现成定理直接覆盖完整分类的证据，但也没有取得首创证明。剩余查新对象应收窄为：交错退化的正性级联在共同初值、固定窗口零黏极限下的必要充分参数判据。基础通量法、正性、紧性和增长反证不单列为创新；若已有变系数版本只需直接代入便能给出此判据，则应进一步降低本例的原创性评价。

<!-- source: docs/appendices/legacy-models-zh.md#a472-已有级联时间估计直接显现同一指数 -->
#### A4.7.2 已有级联时间估计直接显现同一指数

进一步核对 [Barbato–Flandoli–Morandin，arXiv:0811.1689v1](https://arxiv.org/html/0811.1689v1) §3 Lemma 7 的证明。原文取几何系数，研究无外力、无黏性链；其局部比较先估计下一坐标，再控制一层能量的转移时间。下面是保留一般正系数后的直接推导，不是该文已经陈述的一般定理，也不是受迫零黏极限的替代证明。

考虑无外力、无黏性的非负链解，初始范数为 $`R>0`$。令

```math
\dot x_j=p_{j-1}x_{j-1}^2-p_jx_jx_{j+1},\qquad
H_j(t)=\sum_{i=0}^j x_i(t)^2,\qquad H_{-1}=0.
```

有限预算直接给 $`H_j'=-2p_jx_j^2x_{j+1}`$，因而所有 $`H_j`$ 非增、$`\|x(t)\|_2\le R`$。这里明确保留系数 2，不沿用网页中个别预算式的遗漏。

若某段时间内 $`x_j^2>\theta_j>0`$，则

```math
\dot x_{j+1}\ge p_j\theta_j-p_{j+1}Rx_{j+1},\qquad
x_{j+1}(t+s)\ge\frac{p_j\theta_j}{p_{j+1}R}
\left(1-e^{-p_{j+1}Rs}\right).
```

对 $`h\ge2/(p_{j+1}R)`$ 积分，得到

```math
H_j(t)-H_j(t+h)
\ge\frac{p_j^2\theta_j^2}{p_{j+1}R}\,h.
```

因此取

```math
h_j=\frac2{p_{j+1}R}
+\frac{R^3p_{j+1}}{p_j^2\theta_j^2}
```

便有 $`H_j(t+h_j)\le H_{j-1}(t)+\theta_j`$：若期间某刻振幅平方降至阈值，用有限部分能量的单调性；否则上式已经移走至少 $`R^2`$，同样得到所需不等式。

**一般正系数的充分条件。** 若

```math
P:=\sum_{j\ge0}\frac1{p_{j+1}}<\infty,\qquad
S:=\sum_{j\ge0}\left(\frac{p_{j+1}}{p_j^2}\right)^{1/3}<\infty,
```

令 $`r_j=(p_{j+1}/p_j^2)^{1/3}`$、$`\theta_j=R^2r_j/(2S)`$，则

```math
\sum_j\theta_j=\frac{R^2}{2},\qquad
T_*:=\sum_jh_j=\frac{2P+4S^3}{R}<\infty.
```

沿 $`t_j=\sum_{i=0}^jh_i`$ 逐层相加，再用 $`H_j(T_*)\le H_j(t_j)`$，可得 $`\|x(T_*)\|_2^2\le R^2/2`$。非负有限能量无黏解可由有限封闭截断及坐标紧性构造。故上述两个级数给无外力、无黏正性链的有限时间能量损失充分条件；它没有证明条件必要，也没有涉及正黏性受迫轨道。

**代入本例。** 交错系数满足

```math
\frac{p_{2n}^2}{p_{2n+1}}=\eta^2 2^{(2\gamma-1)n},\qquad
\frac{p_{2n+1}^2}{p_{2n+2}}
=\eta^{-1}2^{(2-\gamma)n-\gamma}.
```

所以对 $`1/2<\gamma\le1`$，两个级数都收敛；$`S`$ 的偶数支恰好在 $`\gamma=1/2`$ 失去收敛性。临界侧只是这个充分条件失效，不能由此推导无耗散；无耗散仍依赖 §A4.2.1、§A4.4.2 的独立证明。

这比“同属 dyadic 家族”更强地降低了方法原创性评价：已有的逐层时间比较，经直接保留系数，已经显现相同的正侧门槛。它尚未覆盖本文完整的共同初值受迫零黏极限分类，但不能再以“新的传递速率组合或正侧阈值机制”为核心首创点。本组结果保留精确分类及额外边下的有效扩展，方法归属按上述具体比较说明。

另核对 [Kiselev–Zlatoš，arXiv:math/0507129v1](https://arxiv.org/html/math/0507129v1) §2 Proposition 2.4：其基本耦合分类明确要求每项具有共同的逐壳几何因子，不能将其当作任意交错系数的分类定理。这一假设区别不抵消上面已发现的方法重合。
