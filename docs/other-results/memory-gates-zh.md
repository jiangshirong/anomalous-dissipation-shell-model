# 内转子与拥塞记忆门：有限系统自堵及穿越问题

本文件保留来流驱动孤立门的半能量传递、控制器预算、拥塞记忆门的有限链自堵定理和已知估计障碍。原单位角速度 A 只取得局部传递结果；已闭合的快慢 A 变体见[自治相位门](phase-gates-zh.md)。M 的无限链统一穿越时间及实际异常耗散仍开放。

### B.9.6 A 与 M：带有限能量内部状态的自治门

对相邻输运变量 x,y 使用 x′=−kgxy、y′=kgx²，门变量由同尺度转子 (p,q) 给出：

```math
g=\frac{q^2}{p^2+q^2},\qquad
\dot p=-\omega q-\nu K^2p,\qquad
\dot q=\omega p-\nu K^2q.
```

输运变量另各加自身的标准黏性；链上总能量包含全部 x 变量和全部转子的平方。每条输运边及每个转子的非黏部分分别不做净功。每个转子初始半径 r_n>0，选 ∑r_n²<∞，例如 r_n=εK_n^(−2)，与 ν 无关；任意有限时刻半径 r_n exp(−νK_n²t)>0，所以门的比值有定义。转子的实际黏性损失为 ½∑r_n²(1−exp(−2νK_n²T))，固定 T 下由控制收敛趋零，不能把其衰减冒充主级联的异常耗散。

这是一类二次齐次但非多项式的作用律，半径零处奇异。门对很小转子半径仍可敏感，存在分析和建模代价；若要求标准多项式二次壳模型，须另作实现，不能把该要求视为已经满足。

**A，来流触发。** 取 ω=kx，初始 p=r、q=0。孤立无黏单元从 (x,y)=(A,0) 出发，令 x=Acosφ、y=Asinφ，转子角为 θ，则

```math
\dot\theta=kA\cos\phi,\qquad
\frac{d\phi}{d\theta}=\sin^2\theta,\qquad
\phi=\frac\theta2-\frac{\sin2\theta}{4}.
```

θ 到 π/2 时 φ=π/4，恰有一半初始输运能量到了 y；此前 cosφ≥1/√2，因此所需时间不超过 π/(√2 kA)。开启由实际供体驱动，没有外排开关时刻。这个局部估计尚未控制下一门开启时对上一门的反馈，也未给全链非消失的能量比例。要处理全链，还需保留小黏性和邻层扰动的转移估计；每层只保一半再直接相乘会归零，不能用它证明异常耗散。

[自治相位门 A](phase-gates-zh.md)的快旋转变体已取得全链正耗散证明：把角速度改为 Ω_nK_nu_n，Ω_n=1024(n+1)²，仍由实际振幅驱动。原 Ω_n=1 模型没有因此被证明；新证明使用精确平均纠正与 Hardy 估计，不串联上述孤立半传递结论。

**M，拥塞记忆。** 取 κ,b>0，设

```math
\omega=\frac\kappa2(x-by)\frac{pq}{p^2+q^2},\qquad
\dot g=\kappa(x-by)g(1-g).
```

从 0<g_0<1 启动，门在供体占优时打开、接收端拥塞时关闭。孤立无黏单元仍用 φ 参数，a=κ/k，精确积分得

```math
1-g=(1-g_0)e^{-a\phi}(\cos\phi)^{-ab}.
```

存在唯一 φ_*∈(arctan(1/b),π/2)，满足 φ_*+b log cosφ_*=a^(−1)log(1−g_0)。轨道渐近到达 g=0、φ=φ_*，留下正的供体能量；不是在有限时刻把一个正门强行置零。串链后接收端可以继续排空，于是门可能重新开启，历史关闭程度又决定延迟。目标是同一自治规则中的持续级联／自堵对照；下面的三层探针已经闭合，尚未证明无限链关闭延迟可求和或任何异常耗散结论。

**三层无黏单元最终自堵。** 令 k,l,α,b,A>0，初值 (x,y,z)=(A,0,0)、g_0,h_0∈(0,1)，取两个记忆门：

```math
\begin{aligned}
x'&=-kgxy,&
y'&=kgx^2-lhyz,&
z'&=lhy^2,\\
g'&=\alpha k(x-by)g(1-g),&
h'&=\alpha l(y-bz)h(1-h).
\end{aligned}
```

则三个振幅都有严格正极限，且

```math
x_\infty<b y_\infty,\qquad
y_\infty<b z_\infty,\qquad
g(t),h(t)\longrightarrow0,
```

两个门最终均指数关闭。这是对全部上述正参数的有限无黏结论，常数不宣称对链长、参数或黏性统一。

能量 x²+y²+z²=A² 守恒，x 单调减、z 单调增，因此 y² 也有极限。门的 logit 导数分别为 αk(x−by)、αl(y−bz)，故有限时间内门严格属于 (0,1)，并由逐层正传播得 x(t),y(t),z(t)>0（t>0），特别 z_∞>0。

若 y_∞=0，则最终 y−bz≤−b z_∞/4，logit 方程使 h 指数衰减。然而 y'≥−lAhy，故任一充分大 T 后有

```math
y(t)\ge y(T)\exp\!\left[-lA\int_T^t h(s)\,ds\right],
```

给出正的最终下界，矛盾。若 x_∞=0，以已经证明的 y_∞>0 对 g 重复论证，再使用 x' 的精确积分，仍得矛盾。因此三个极限均正。又有

```math
k\int_0^\infty gy\,dt=\log\frac A{x_\infty}<\infty,\qquad
l\int_0^\infty hy^2\,dt=z_\infty<\infty.
```

由 y_∞>0 得 g,h∈L¹；它们的导数有界，所以 g,h→0。logit 方程于是强迫 x_∞≤b y_∞、y_∞≤b z_∞，否则对应门最终持续增加。

严格不等式也可得到。置 D_1=x−by、D_2=y−bz、G=log(g/(1−g))、H=log(h/(1−h))。若两个极限同时取等号，

```math
\left(\frac G{\alpha k}+\frac{bH}{\alpha l}\right)'
=x-b^2z\ge0,
```

因为 x(t)≥x_∞=b²z_∞≥b²z(t)。但两门趋零使括号趋负无穷，矛盾。故至少一个极限严格为负。若 D_(2,∞)<0 而 D_(1,∞)=0，h 指数衰减；利用

```math
D_1'=-kgx(y+bx)+blhyz
```

及终值零，得到 D_1(t)≥−C exp(−ct)。其负部可积，不可能使 G'=αkD_1 的积分趋负无穷，矛盾。相反情形由 D_2'=kgx²−lhy(z+by) 同样排除。因此两个差均有负极限，logit 方程即给两门指数关闭。

**截断层数是实质限制。** 上述“每层都有正残留”推广到任意固定有限链 0,…,N，但不能推出对 N 一致的堵塞。令 k_n>0、各门 g_n(0)∈(0,1)、u_0(0)=A、其余为零，无黏无迫，删除跨末端的完整边。尾平方能量满足

```math
\frac d{dt}\sum_{i=n}^N u_i^2
=2k_{n-1}g_{n-1}u_{n-1}^2u_n\ge0
\quad(1\le n\le N).
```

各尾和收敛，因此各 u_n 有极限。终端极限正；从末端倒推，若 u_(n,∞)=0<u_(n+1,∞)，则 g_n 指数衰减，与 u_n'≥−k_ng_nu_nu_(n+1) 给出的正残留矛盾。所有极限都正，有限累计尾通量再给 g_n∈L¹、g_n→0，故 u_(n,∞)≤b u_(n+1,∞)。能量守恒于是推出

```math
0<u_{0,\infty}^{(N)}
\le\frac A{\sqrt{\sum_{j=0}^N b^{-2j}}}.
```

当 0<b≤1 时，右侧随 N 趋零；b=1 时为 A/√(N+1)。所以有限链的正根残留没有对截断层数一致的正下界。这里先 t→∞、再 N→∞；它既不是固定窗结论，也不等同于先构造无限链再取零黏极限。三层下游排空不足以保证完全传输，同时有限封闭链的最终自堵也不足以判定无限链无 AD。

**穿越时间探针的实际进展与停止点。** 取 α=b=1，记 I_n=K_(n−1)g_(n−1)u_(n−1)²、I_0=0。代换 v_n=u_n(1−g_n) 精确消去局部下游项：

```math
v_n'=(1-g_n)(I_n-I_{n+1}),\qquad
u_0(t)(1-g_0(t))
=\frac12\exp\!\left[-\int_0^t g_0u_0\,ds\right].
```

因此 u_0(t)≥e^(−t)/2，但内部的 I_n−I_(n+1) 没有固定符号。另令 H_n=−log(1−g_n)、F_n=K_ng_nu_n²u_(n+1)，则

```math
u_n^2H_n'=K_ng_nu_n^3-F_n.
```

在门关闭时，u_n²(−H_n')≤F_n；这控制的是乘以供体能量的容量变化。不能将它升级为对负 logit 记忆的时间一致通量控制：单边 N=1 已有 x_∞<y_∞、g→0，故 log(g/(1−g))=∫(x−y)→−∞，而 ∫F=y_∞²/2<1/2。该具体反例使纯通量预算路线停止。

当前没有闭合无限链统一穿越界，也没有证明穿越时间发散。M 的异常耗散保持开放；有限截断诊断不作为统一时间或全部门的正下界证据。

两项都只是已知守恒泵和内转子上的反馈构想；结合 [Tao 的既有电路](https://arxiv.org/html/1402.0290v3#S5)，不能将“用内部变量开门”本身当成原创性保证。它们的可能增量在可证明的脉冲同步、拥塞记忆与真实黏性损失。
