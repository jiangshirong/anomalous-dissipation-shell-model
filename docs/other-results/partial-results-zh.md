# 切面阻断、储能支路与未闭合机制的有效局部结果

这里保留切面预算、结构反例及尚未接成无限链耗散结论的局部结果。各模型分别明确方程、外力、初值和证据范围；有限系统结论只用于其实际证明的范围。默认 K_n=2^n，标准黏性为 −νK_n² 乘各自振幅；另有约定时单列。所有参数与初值独立于 ν。

<!-- source: docs/appendices/mechanisms-zh.md#b2-模型解类与耗散对象 -->
## B.2. 模型、解类与耗散对象

本节只研究已有的正性、跨度至多二的模型族：

```math
\dot a_n=p_{n-1}a_{n-1}^2+q_{n-2}a_{n-2}^2
-a_n(p_na_{n+1}+q_na_{n+2})-\nu4^na_n+F\delta_{n0},
\quad 0<p_n\le4^n,\quad0\le q_n\le4^n.
```

负下标删除，$`F>0`$ 固定。取共同非负初值 $`a^{\rm in}\in\ell^2`$，与黏性无关。使用[附录 A1.4](earlier-models-zh.md#a14-证明链的共同基础)构造的能量类解及其精确能量等式；下面的排除证明只需要该等式（全局能量不等式亦足够）、有限切面等式和非负性；不预设黏性一致的稳态界。

固定任意有限 $`T>0`$，定义

```math
A_0=\|a^{\rm in}\|_2,\qquad R_T=A_0+FT,
\qquad Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}4^na_n^\nu(t)^2\,dt.
```

$`Q_\nu(T)`$ 是累计黏性耗散，不是瞬时耗散；平均耗散是 $`Q_\nu(T)/T`$。从能量预算及 Cauchy–Schwarz 得到 $`\|a^\nu(t)\|_2\le A_0+Ft\le R_T`$。在零范数处可用 $`(\|a\|_2^2+\epsilon)^{1/2}`$ 正则化后令 $`\epsilon\downarrow0`$，不除以零。

<!-- source: docs/appendices/mechanisms-zh.md#b3-切面阻碍累计耗散的定量界 -->
## B.3. 切面阻碍累计耗散的定量界

对 $`N\ge1`$ 定义

```math
\Pi_N=p_Na_N^2a_{N+1}+q_Na_N^2a_{N+2}
       +q_{N-1}a_{N-1}^2a_{N+1},\qquad
C_N=p_N+q_N+q_{N-1}>0.
```

$`C_N`$ 是跨切面系数之和，不是实际通量，也不是必要充分的“传输能力”。记 $`J_N^\nu(T)=\int_0^T\Pi_N(a^\nu(t))\,dt`$。

<!-- source: docs/appendices/mechanisms-zh.md#b31-单个切面的界 -->
### B.3.1 单个切面的界

将全局能量预算减去前 $`N+1`$ 个壳的预算，得到

```math
E_{>N}(T)+\nu\int_0^T\sum_{n>N}4^na_n^2\,dt
=E_{>N}(0)+J_N^\nu(T).
```

若只知道全局能量不等式，上式改为 $`\le`$，后续上界仍成立。根外力在相减时抵消，不在高壳偷偷增加输入。舍弃非负的末端尾能量，再估计低壳耗散，得

```math
0\le Q_\nu(T)
\le\nu4^NTR_T^2+E_{>N}(0)+J_N^\nu(T)
\le\nu4^NTR_T^2+E_{>N}(0)+TC_NR_T^3.\tag{1}
```

因此，若存在 $`N_j\to\infty`$ 使 $`C_{N_j}\to0`$，先固定 $`N_j`$ 令 $`\nu\downarrow0`$，再令 $`j\to\infty`$，便有 $`Q_\nu(T)\to0`$。这不要求逐坐标无黏极限已被识别。

<!-- source: docs/appendices/mechanisms-zh.md#b32-多个切面的加权界 -->
### B.3.2 多个切面的加权界

还可以处理切面系数不趋零的情形。由每个振幅不超过 $`R_T`$，

```math
\frac{\Pi_N}{C_N}
\le R_T(a_N^2+a_{N-1}^2).
```

对任意有限切面集合 $`\mathcal S\subseteq\{M,\ldots,L\}`$，每个源壳最多被右端计算两次，故

```math
\sum_{N\in\mathcal S}\frac{J_N^\nu(T)}{C_N}
\le2TR_T^3.
```

设 $`W_{\mathcal S}=\sum_{N\in\mathcal S}C_N^{-1}`$。用权重 $`C_N^{-1}/W_{\mathcal S}`$ 平均式 (1) 的第一项上界（尚未将 $`J_N`$ 替成 $`TC_NR_T^3`$），得到

```math
Q_\nu(T)\le\nu4^LTR_T^2+E_{>M}(0)
+\frac{2TR_T^3}{W_{\mathcal S}}.\tag{2}
```

**排除命题。** 如果 $`\sum_{N\ge1}C_N^{-1}=\infty`$，那么对每个固定有限 $`T>0`$，

```math
\lim_{\nu\downarrow0}Q_\nu(T)=0.
```

证明：固定 $`M,L`$ 并取 $`\mathcal S=\{M,\ldots,L\}`$，先令 $`\nu\downarrow0`$ 消去式 (2) 的低壳项，再令 $`L\to\infty`$ 消去逆系数和项，最后令 $`M\to\infty`$ 消去共同初值的尾能量。各项非负，所以零上极限给出零极限。整个证明只取有限切面和，未交换未受控的无限求和与黏性极限。

特别地，若 $`C_N`$ 沿无限子列有界，倒数和必发散。这将有界切面的稳态障碍补充为**共同初值、固定窗口的耗散消失结论**。不是说稳态耗散一定消失，也不是说所有能量类无黏极限都已证明强收敛或守恒。

反方向没有证明：倒数和收敛并不自动给出异常耗散。尤其当前 S 的切面系数很大，不能用本判据推断它的固定窗口行为。也不能将上述条件擅自强化为 $`\sum C_N^{-2/3}=\infty`$；时间积分不允许直接交换相应的凹幂与求和。

<!-- source: docs/appendices/mechanisms-zh.md#b4-对原稀疏修复例的实质补充 -->
## B.4. 对原稀疏修复例的实质补充

仍取已有的 $`B=\{j^2:j\ge2\}`$、弱边 $`p_n=2^{-n}`$（$`n\in B`$），其余 $`p_n=4^n`$；只在 $`S\subseteq B`$ 设置 $`q_n=4^n`$，其他 $`q_n=0`$。取 $`F=1`$ 和共同全零初值。

若 $`B\setminus S`$ 无限，每个未修复切面 $`N\in B\setminus S`$ 满足 $`q_N=q_{N-1}=0`$，所以 $`C_N=2^{-N}\to0`$。由式 (1)，**每个固定有限窗口的累计及平均黏性耗散均趋零**。

若 $`B\setminus S`$ 有限，则[覆盖条件和固定窗证明](earlier-models-zh.md)在足够长的固定窗口上有正平均耗散下界。因此，该特定修复族现在可获得固定窗口意义下的有／无对照：

| 修复情形 | 共同零初值的固定窗口结论 |
|---|---|
| 漏修无限处 | 对每个固定 $`T<\infty`$，$`Q_\nu(T)/T\to0`$ |
| 只漏修有限处 | 存在依赖模型但不依赖黏性的 $`T_*,\varepsilon>0`$，对固定 $`T\ge T_*`$ 有下极限至少 $`\varepsilon`$ |

全修复 $`S=B`$ 可使用已得粗界：$`T\ge2113537`$ 时平均耗散下界 $`1/258`$。有限遗漏时常数依赖遗漏位置，不能沿用全修复常数。这里比较的是稀疏修复族，**不是 W/S**；没有改变 W/S 的未知事项。

正侧由[稀疏旁路覆盖证明](earlier-models-zh.md)及共同初值固定窗比较给出，零侧由上述切面预算给出。

## B.5. 两通道协同：先排除同步障碍

考虑每层两个非负振幅 $`x_n,y_n`$，黏性均为 $`-\nu4^n`$ 乘各自振幅，纵向边分别为

```math
x_n\xrightarrow{c_n}x_{n+1},\qquad
y_n\xrightarrow{d_n}y_{n+1}.
```

每条边仍用守恒对 $`(-cuv,+cu^2)`$。允许同层任意强度的此类保守交换，外力只在零层，初值固定且总能量有限。以下陈述以存在非负能量类解并满足相应预算为前提，不用有限恒等式代替一般无限系统的存在性证明。

同层交换在整层切面预算中抵消。净向高层的通量仍为

```math
\Pi_N=c_Nx_N^2x_{N+1}+d_Ny_N^2y_{N+1},
\qquad C_N=c_N+d_N,
\qquad\Pi_N/C_N\le R_T(x_N^2+y_N^2).
```

与 §B.3 相同的证明成立，源层只出现一次，式 (2) 中因子 2 可改为 1。因此，如果 $`\sum_N(c_N+d_N)^{-1}=\infty`$，不论同层交换有多强，都不能产生固定窗口异常耗散。特别是两条通道在无限多个相同尺度同时保持有界的纵向系数时，协同目标不可能通过这种交换实现。

**下一构造的必要筛选：** 若尝试障碍错位，必须先使合并切面逃离上述排除条件；随后还要证明动力学确实把能量输送到可通行的通道。总系数大不是充分条件，已有 S 对照正提醒了这一点。若仅沿错位强边形成一条已知 dyadic 链，则只是路径拼接，不能直接认作新的协同机制。

双向同层交换的开／关证明见[常交换激活](exchange-exponents-zh.md)。它的耦合侧估计不由本篇排除判据推出，需使用单独的增长反证。

## B.8. 保留的分量诊断与结构检查

这些是从旧日志／局部方程提取的有效有限关系，不是中间区间的新证明。

<!-- source: docs/appendices/mechanisms-zh.md#b81-分量差不形成自治标量链 -->
### B.8.1 分量差不形成自治标量链

对[双通道方程](../sparse-modification/model-zh.md)取 β=1、d_n=w_n-z_n，直接相减给

```math
\begin{aligned}
\dot d_n={}&K_{n-1}z_{n-1}^2-e_{n-1}w_{n-1}^2
-e_nw_nz_{n+1}+K_nz_nw_{n+1}\\
&+h_n(z_n^2-w_n^2)-\nu M_nd_n.
\end{aligned}
```

负下标删除；相同根外力抵消。根层预算的历史符号错误见[关键纠错表](../history/corrections-zh.md)。差方程仍依赖 w,z 和邻层；不能由有限扫描宣布全轨道 w≥z，更不能据此补上 MB。

<!-- source: docs/appendices/mechanisms-zh.md#b82-两个非守恒加权量不是唯一性证明 -->
### B.8.2 两个非守恒加权量，不是唯一性证明

有限封闭、无黏无迫时，检查

```math
J_{\rm alt}=\frac12\sum_n(-1)^n(w_n^2+z_n^2),\qquad
J_{\rm diff}=\frac12\sum_n(w_n^2-z_n^2).
```

逐边相消只适用于相同权重。只置 z_0=w_1=1、其余为零，则 J_alt'=-2K_0=-2；只置 w_0=2、z_0=1、其余为零，β=1，则 J_diff'=-4h_0。因此这两个候选均不守恒。

上述两个反例只排除两个具体候选；所有二次型或变量变换没有因此被分类。这些反例可直接代入有限非线性核对。

<!-- source: docs/appendices/mechanisms-zh.md#b93-d同一空间分布的冻结与随机刷新 -->
### B.9.3 D：同一空间分布的冻结与随机刷新

保留原双通道图、共同零初值及双根单位力，将交换系数换为

```math
h_n(t)=\sqrt{K_n}+(K_n-\sqrt{K_n})S_n(t),\qquad
0\xrightarrow{qr_n}1,\quad 1\xrightarrow{pr_n}0,
\quad q=1-p,\quad p\in[1/4,1).
```

各 S_n 为独立、以平稳分布启动的二态 Markov 链。取 r_n=A K_n^(3+δ)，A,δ>0 固定，完全不随 ν 变化。每个确定时刻的弱层概率仍为 p；冻结该时刻的空间样本，已有冻结 iid 定理给几乎处处无固定窗异常耗散。新的待证目标是某些固定 A,T 下，持续刷新模型满足 liminf_(ν→0) E Q_ν(T)>0。这里并未声称每个随机时刻同时满足冻结结论，也未把期望正下界改写成路径上正下界。

有限截断的振幅连续、绝对连续，环境跳变只更换后续作用的系数。每个系数状态都逐边守恒，故路径上仍有 E(T)+Q_ν(T)=∫(w_0+z_0)dt，不存在由振幅随机跳跃产生的额外能量注入。这是随机系数 ODE，不是给振幅直接添加白噪声。

已有第一步：记 χ_n=S_n−q，则 dχ_n=−r_nχ_n dt+dM_n。对连续、适应、绝对连续且在当前有限时间窗有界的 F，乘积公式给

```math
\begin{aligned}
\mathbb E\int_0^T\chi_nF\,dt
=\frac1{r_n}\mathbb E\left[
\chi_n(0)F(0)-\chi_n(T)F(T)
+\int_0^T\chi_n\dot F\,dt\right].
\end{aligned}
```

这是精确相关性校正，不能用 E[χ_nF]=Eχ_n EF 替代。对 n≥1，F=w_n²z_n 或 z_n²w_n，能量界给 ||u(t)||≤R=√2T；逐项估计给 |F|≤R³、|F′|≤12K_nR⁴+3νK_n²R³。令平均系数 h̄_n=p√K_n+qK_n，可得

```math
\left|\mathbb E\int_0^T(h_n-\bar h_n)F\,dt\right|
\le\frac{K_n}{r_n}
\big(2R^3+12TK_nR^4+3\nu TK_n^2R^3\big).
```

根层 K_0=1，系数差本来为零。在 0<ν≤1 下，上式的高层和至多 C_(R,T)A^(−1)∑_(n≥N)K_n^(−δ)，对截断统一。这是有限截断上的已闭合估计；随机无限层构造及将该校正接入具有正确符号的输运下界仍须完成。平均系数模型本身的正耗散不能自动转移给随机轨道。

[Gürcan §II–III](https://arxiv.org/html/2004.01134v2) 已有定期重连网络及移动障碍促进输运的数值讨论。因此目标限定为同一空间边际分布下严格的冻结／刷新零黏对照，不能认领动态网络或移动瓶颈的概念首创。

<!-- source: docs/appendices/mechanisms-zh.md#b94-h正性双守恒量与轨道驱动的手性同步 -->
### B.9.4 H：正性、双守恒量与轨道驱动的手性同步

K_n=λ^n，λ>1；每层有非负 u_n^+、u_n^-。每个供体 x=u_n^σ（σ=±1）与接收器 y=u_(n+1)^+、z=u_(n+1)^- 使用三次单元

```math
\dot x=-c_nxyz,\quad
\dot y=a_\sigma c_nx^2z,\quad
\dot z=b_\sigma c_nx^2y,\qquad
a_\sigma=\frac{1+\sigma/\lambda}{2},\quad
b_\sigma=\frac{1-\sigma/\lambda}{2},\quad c_n=K_n.
```

整条链叠加两种供体的贡献。因为 a_σ+b_σ=1、K_(n+1)(a_σ−b_σ)=σK_n，每个完整单元同时守恒

```math
E=\frac12\sum_n\big((u_n^+)^2+(u_n^-)^2\big),\qquad
H=\frac12\sum_nK_n\big((u_n^+)^2-(u_n^-)^2\big).
```

非负锥不变。但两个接收器同为零时永远不能启动，所以自由衰减研究须使用固定正尾种子，例如 p_n(0)=Cλ^(−sn)，s>0；不能用这个单元声称从紧支集或全零初值自动传播。所有种子与 ν 无关，尾部初始能量也计入总能量。

令 p_n=(u_n^+)²+(u_n^-)²、m_n=((u_n^+)²−(u_n^-)²)/p_n、A_n=√(1−m_n²)。在 p_n>0 处，加入两分量相同的黏性后精确得到

```math
\begin{aligned}
\dot p_n={}&c_{n-1}p_{n-1}p_nA_n
-c_np_np_{n+1}A_{n+1}-2\nu K_n^2p_n,\\
\dot m_n={}&c_{n-1}p_{n-1}A_n(m_{n-1}/\lambda-m_n).
\end{aligned}
```

根部 m_0 不变，完整末端单元删除时同样相消。若初始 |m_n|≤Mλ^(−n)、0<M<1，则各边界导数指向内部，该锥对黏性仍不变。由 K_n|p_nm_n|≤Mp_n，H 在能量有限时绝对可和。再置 z_n=λ^nm_n，得到

```math
\dot z_n=c_{n-1}p_{n-1}A_n(z_{n-1}-z_n).
```

这是由实际能量轨道决定时钟的单向同步方程。值得研究的是离开同步流形后，极化记忆能否消失及其与异常耗散的关系。m_n=m_0λ^(−n) 确实是精确不变流形，其上 p 方程退化为系数修正的标量 Volterra 型链；仅在该流形上证明耗散不足以体现新的手性作用。

后续结构筛查进一步限制了当前锥内的机制解释。记 J_n=c_np_np_(n+1)A_(n+1)，直接对 p_nz_n 求导得到

```math
(p_nz_n)'=J_{n-1}z_{n-1}-J_nz_n-2\nu K_n^2p_nz_n.
```

因此 z 是随能量通量搬运并混合的标量标记；它对 p 的反馈只通过 A_n。当前 |z_n|≤M 的锥给

```math
0\le1-A_n=
\frac{K_n^{-2}z_n^2}{1+\sqrt{1-K_n^{-2}z_n^2}}
\le\frac{M^2K_n^{-2}}{1+\sqrt{1-M^2}}.
```

高层反馈在这一锥内是可和的小系数修正。这不证明整个无限链与标量模型等价，也不证明这些修正对零黏耗散无影响；它使“先证同步就得到新手性机制”的投入理由变弱。孤立两层的极端手性筛选如下。

**孤立两层的统一对数传递界。** 固定 λ=2、c=1、无黏无迫，总平方振幅 p_0+p_1=1。令 p_1(0)=δ∈(0,1/2)，两层初始极化任意属于 [−1,1]；允许接收层一个分量为零。记 p=p_1、q=m_0/2∈[−1/2,1/2]、a=m_1(0)∈[−1,1]。达到 p=1/2 的首次时间满足

```math
\log\frac1{2\delta}\ \le\ T_{1/2}
\ \le\ \frac8{\sqrt3}\operatorname{arcosh}
\sqrt{\frac1{2\delta}}
\ \le\ \frac4{\sqrt3}\log\frac2\delta.
```

证明须从原振幅方程启动。把两个供体记为 x^+、x^-，接收器记为 y、z，则供体共同满足 (x^σ)'=−x^σ yz，故 m_0 恒定；接收方程为

```math
y'=\frac{1+q}{2}(1-p)z,\qquad
z'=\frac{1-q}{2}(1-p)y,\qquad p=y^2+z^2.
```

原多项式系统局部唯一，非负性与能量守恒给全局有界解，且 1−p=p_0>0 在任意有限时刻成立。若 a=1，则 y(0)=√δ、z(0)=0，但 z'(0)=(1−q)(1−δ)√δ/2>0；a=−1 时交换 y、z。两接收分量进入正区后保持正。因此所有初始极化下 p(t)>δ（t>0），没有标量平方根方程可能容许的等待段。

双守恒或直接求导给

```math
m_1=q+\frac{\delta}{p}(a-q),\qquad
p'=p(1-p)\sqrt{1-m_1^2}.
```

置 r=δ/p∈[0,1]，凸组合界给 |m_1|≤(1+r)/2，从而

```math
1-m_1^2\ge\frac{(1-r)(3+r)}4
\ge\frac34(1-r),\qquad
p'\ge\frac{\sqrt3}{4}\sqrt{p(p-\delta)}
\quad(\delta<p\le1/2).
```

从任意正时刻分离积分，再让起始时刻趋零，得到

```math
T_{1/2}\le\frac4{\sqrt3}
\int_\delta^{1/2}\frac{dp}{\sqrt{p(p-\delta)}}
=\frac8{\sqrt3}\operatorname{arcosh}\sqrt{\frac1{2\delta}}.
```

若首次时间无穷，同一不等式会给任意长时间一个有限上界，故也证明了确实到达。使用 arcosh x≤log(2x) 得最后的对数上界；p'≤p 给下界。总平方振幅恢复为 S、边系数恢复为 c 时，对相对种子 δ=p_1(0)/S，所有时间乘 (cS)^(−1)。

固定种子下，极端手性不能使孤立传输任意延迟；种子趋零时的对数代价则不可消除。当前只保留这一局部传递界及其未处理的全链问题。该结论没有处理邻层同时作用，也没有证明 H 全链异常耗散存在或不存在。

该模型主动接受三次非线性这一代价，不宣称由 Navier–Stokes 投影得到。能量、螺旋度、正负手性和正逆级联已有[手性壳模型先例](https://arxiv.org/abs/1602.02553)；此次只用其摘要确认概念先例，没有完成逐方程覆盖检查。

### B.9.5 S 与 L：储能支路及有出口的回接变体

先保留一个已经闭合的阻断原型。固定 ρ>0，零初值、仅 x_0 受固定力 f>0：

```math
\begin{aligned}
\dot x_n={}&K_{n-1}x_{n-1}^2-K_nx_nx_{n+1}
-\rho K_nx_ny_n-\nu K_n^2x_n+f\delta_{n0},\\
\dot y_n={}&\rho K_nx_n^2-\nu K_n^2y_n.
\end{aligned}
```

每个 y_n 是同尺度储能叶；所有原 x 骨架边保留。有限截断保留末层储能叶、删除完整跨层边，逐边能量相消，非负性及 ||u(t)||≤ft 成立。

**固定正黏性解类。** 在 H=ℓ²(x,y)、||u||_V²=∑K_n²(x_n²+y_n²) 中，逐边双线性化给保守的充分界 ||B(a,v)||_(V′)≤(2+ρ)||a||_H||v||_V：纵向移位两项各估一次，同层块估一次。不能把重叠的纵向边冒充互不重叠块。有限能量预算、逐坐标紧性和 Fatou 给 u∈L∞H∩L²V；该界使 u′∈L²V′，链式法则及逐边抵消给 C([0,T];H) 和精确能量预算。差方程利用 ⟨d,B(u,d)⟩=0，另项用 Young 与 ∫||v||_V²<∞ 即得唯一性。这是本新图所需的固定 ν 构造，不依赖新的黏性一致稳态假设。

**实际轨道比较。** D_n=y_n−ρx_(n+1) 满足

```math
\dot D_n+\nu K_n^2D_n
=\rho\nu(K_{n+1}^2-K_n^2)x_{n+1}
+\rho K_{n+1}x_{n+1}(x_{n+2}+\rho y_{n+1})\ge0.
```

所以 y_n≥ρx_(n+1)。令 F_n=∫_0^T K_nx_n²x_(n+1)dt，G_n=∫_0^T ρK_nx_n²y_ndt，则 G_n≥ρ²F_n。x_n 的预算给 F_n+G_n≤F_(n−1)，根输入记为 F_(−1)=∫fx_0≤f²T²/2。归纳得 F_(N−1)≤(1+ρ²)^(−N)f²T²/2。

尾部包含所有 n≥N 的 x、y，唯一跨入口为 F_(N−1)。先在有限截断中作尾预算，再由 Fatou 取固定 ν 极限，结合头部黏性估计，得到

```math
Q_\nu(T)\le\frac{\nu4^{N-1}f^2T^3}{3}
+\frac{f^2T^2}{2}(1+\rho^2)^{-N},\qquad N\ge1.
```

先 ν→0，后 N→∞，即每个固定 T 都有 Q_ν(T)→0。这给出保守分流导致固定窗损失消失的解析原型。

**全部节点有出口的变体。** 增加 y_n→x_(n+1) 的 pump，系数 σK_n，σ>0：x_n 方程多 σK_(n−1)y_(n−1)²，y_n 方程多 −σK_ny_nx_(n+1)。所有节点都有通向无穷的路径，有限能量预算仍成立。D_n 方程却多 −σK_n(y_nx_(n+1)+ρy_n²)，可在锥边界向外，旧比较失效。

对 f=1、ν=0，此回接模型有逐项代入成立的有限能量稳态

```math
x_n=A K_n^{-1/3},\quad y_n=B K_n^{-1/3},\qquad
B=\frac{\rho2^{1/3}}{\sigma}A,\qquad
A^2=\left(2^{-1/3}+\frac{\rho^2 2^{1/3}}{\sigma}\right)^{-1}.
```

该回接变体的零初值动态耗散仍需实际回送估计；显式稳态本身未提供该下界。

### B.9.7 P、C 与 Z：保留高风险方向及已知障碍

**P，自主锁相。** 先写复数守恒泵链

```math
\dot z_n=c_{n-1}z_{n-1}^{2}
-c_n\overline z_n z_{n+1}-\nu K_n^2z_n.
```

闭合能量守恒，通量为 c_n r_n²r_(n+1)cos(2θ_n−θ_(n+1))。孤立接收态 (z_donor,z_receiver)=(0,A)，A>0，供体线性化却为 x′=−cAx、y′=cAy。因此实数正子空间的完整转移对复相位扰动不稳定。光滑纯旋转 iω(z)z 在该点只增加迹为零的斜对称部分，不能让两个线性方向同时具有负实部；这不排除所有非线性稳定机制。下一构想须提出新的保守耦合或不同的输运轨道，目前没有成功的锁相补偿式。

**C，闭环次序。** 取守恒场 P=(-xy,x²,0)、R=(0,−yz,y²)。约定括号 [P,R]=DR·P−DP·R，直接算得

```math
[P,R]=(-xyz,-x^2z,2x^2y),\qquad
(x,y,z)\cdot[P,R]=0.
```

所以沿 P、R 及其反向作用组成一个小闭环时，一阶平均作用可抵消而保留二阶净作用；顺序决定符号。该括号也保持 x²−y²，且 y=z=0 时不能启动。它只是值得尝试的局部构件，不足以从低壳单脉冲产生级联。目标应是自治内部变量驱动的循环次序，或严格的顺序依赖耗散对照；若只外排开关，将退回 B.7 的既有机制。内部变量能量、实现所需非线性次数及高层平均误差必须纳入分析，目前未闭合。

**Z，消失扰动后的分支选择。** 可尝试在一个已有保守骨架上加入能量守恒的随机旋转，用微小相位扰动选择不同的输运方向，再问噪声与 ν 同时趋零时能否留下不同的耗散规律。此处尚无新的具体闭合模型，噪声幅度若随 ν 变化必须作为双参数问题明确列出，不能混入上述固定模型的量词。Stratonovich 形式的逐边旋转可形式保能量，但其 Itô 校正、无限尾及黏性损失必须分别检查。

这不是空白领域：[Barbato–Flandoli–Morandin](https://arxiv.org/abs/1007.1004) 已有随机无黏 dyadic 模型的耗散证明；[Luo–Wang](https://arxiv.org/abs/2207.09631) 已有能量守恒噪声、尺度极限和耗散增强；[Mailybaev 的 Sabra RG 工作](https://arxiv.org/html/2510.01204) 已研究消失噪声下的自发随机性。此次读到该 RG 文末明确把关键固定点吸引性质列为猜想并以数值验证，不能误写成已经完成的全套严格定理。Z 保留为高风险储备，尚不足以进入长证明。
