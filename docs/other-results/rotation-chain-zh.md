# 自治旋转链 R：允许回流的实际黏性异常耗散

### B.9.2 R：自治二次旋转链及孤立输运阈值

令 v_n=(x_n,y_n)，R_n²=x_n²+y_n²，S_n=x_n+y_n，c_n=K_n。先选无外力、共同紧支集初值 v_0=(1,0)、v_n=0（n≥1），考虑

```math
\begin{aligned}
\dot x_n={}&c_{n-1}R_{n-1}^2-a c_{n-1}S_{n-1}y_n
-c_nx_nx_{n+1}-\nu K_n^2x_n,\\
\dot y_n={}&a c_{n-1}S_{n-1}x_n-c_ny_nx_{n+1}-\nu K_n^2y_n.
\end{aligned}
```

负下标项删除。参数 a 固定。层内旋转的功严格相消，跨边能量通量为 c_nR_n²x_(n+1)，因此有限封闭无黏系统守恒 E=½∑R_n²。x_(n+1) 可以为负，这个模型允许回流，不能沿用正性泵的逐边非负通量比较。

先检查一个孤立输运单元：

```math
\dot X=-cXP,\qquad \dot P=cX^2-bcXQ,\qquad
\dot Q=bcXP,\qquad (X,P,Q)(0)=(A,0,0),\quad A,c>0.
```

能量与 Q+bX 分别守恒，故

```math
Q=b(A-X),\qquad
P^2=(A-X)\big[(1-b^2)A+(1+b^2)X\big].
```

起始 P 增加，X 保正。若 |b|<1，X 随时间趋零，接收端取得全部初始能量；若 |b|=1，X 仍趋零，但尾部衰减为代数型。若 |b|>1，X 降到 A(b²−1)/(b²+1)>0 时 P 穿过零，随后反向转移，出现周期往返。这是单元层面的解析结论，不是整条无限链的耗散分类。

供体为二维且没有上游输入时，其方向不变，孤立单元的有效 b=aS_donor/R_donor。整链中上游输入会改变方向；下面的三层证书展示孤立单元阈值不能直接逐层串联，无限链正耗散另由 B.10.2–5 证明。

基本单元不是新发明：[Tao §5.1、§5.4–5.5](https://arxiv.org/html/1402.0290v3#S5) 已有 pump、rotor 及其组合。本链的固定窗实际黏性结论及限定等价检验见下文。

## B.10. 自治旋转链：允许回流的实际黏性异常耗散

以下给出两分量、有符号、自治二次链的完整内部解析证明。三层计算证实局部回流，但无限层正耗散证明不依赖数值计算或逐层接力。构件和加权矩方法有先例；具体原创性边界见本文件“文献与证据范围”，不把内部证明等同于全球优先权认证。

### B.10.1 方程、共同初值与结论

令 n≥0，K_n=2^n，u_n=(x_n,y_n)∈ℝ²，R_n²=|u_n|²，S_n=x_n+y_n，固定 a=1/2。无外力，初值 u_0(0)=(1,0)、u_n(0)=0（n≥1），所有参数和初值独立于 ν：

```math
\begin{aligned}
\dot x_n={}&K_{n-1}R_{n-1}^2-aK_{n-1}S_{n-1}y_n
 -K_nx_nx_{n+1}-\nu K_n^2x_n,\\
\dot y_n={}&aK_{n-1}S_{n-1}x_n
 -K_ny_nx_{n+1}-\nu K_n^2y_n.
\end{aligned}
```

删除负下标项。有限截断保留 0,…,J 层，删除跨 J 与 J+1 的完整保守单元，保留进入 J 层的旋转项，不添加末端吸收。记

```math
H=\ell^2(\mathbb N_0;\mathbb R^2),\qquad
\|u\|_V^2=\sum_{n\ge0}K_n^2|u_n|^2,\qquad
Q_\nu(T)=\nu\int_0^T\|u^\nu(t)\|_V^2\,dt.
```

**定理。** 每个 ν>0 存在唯一全局解 u^ν∈C([0,∞);H)∩L²_loc([0,∞);V)，满足坐标方程与精确预算

```math
\frac12\|u^\nu(t)\|_H^2+Q_\nu(t)=\frac12.
```

存在明确的 T_*,ε_*>0，独立于 ν，使

```math
Q_\nu(T_*)>\varepsilon_*
\quad(0<\nu\le1),\qquad
\liminf_{\nu\downarrow0}Q_\nu(T_*)\ge\varepsilon_*.
```

T_*、ε_* 的定义见 B.10.5，约为 174.877 与 0.000150436；近似值仅帮助理解，证明使用精确表达式，不声称常数最优。先在固定 ν 下构造无限层解，再取 ν↓0。该结论是标准黏性造成的真实损失；不以无黏爆破、末层泄漏或某个无黏弱解的能量缺陷代替。

### B.10.2 固定黏性构造与精确预算

记 J_0(x,y)=(-y,x)，e_x=(1,0)。为避免与截断层 J 混淆，旋转算子写成 J_0。逐边双线性化为

```math
B(p,v)_n=-K_np_n v_{n+1,x}
 +K_{n-1}(p_{n-1}\cdot v_{n-1})e_x
 +aK_{n-1}S(p_{n-1})J_0v_n.
```

于是非线性为 B(u,u)。一条边的供体项与接收项配对相消，旋转项自身无功：

```math
\langle v,B(p,v)\rangle_H=0
\quad(p\in H,\ v\in V).
```

该配对绝对可求和。分别估计输出、输入、旋转三组并使用 K_(n+1)=2K_n，得到

```math
\begin{aligned}
\|B(p,v)\|_H&\le C_0\|p\|_H\|v\|_V,\\
\|B(p,v)\|_{V'}&\le C_0\|p\|_H\|v\|_H,\qquad
C_0=\frac32+\frac{|a|}{\sqrt2}<2.
\end{aligned}
```

第一式三项常数依次为 1/2、1、|a|/√2；第二式依次为 1、1/2、|a|/√2。第一式的供体项用 sup_n K_(n+1)|v_(n+1)|≤||v||_V，旋转项用 |S(p_n)|≤√2|p_n|。没有把重叠边误当成正交块。

有限 Galerkin 系统是多项式 ODE，逐边预算给全局解、sup_t||u||_H≤1 及 ν∫||u||_V²≤1/2。由上述界，固定 ν、T 时导数在 L²(0,T;V′) 一致有界。V 紧嵌入 H，紧性给子列在 L²(0,T;H) 强收敛；H×H→V′ 界使非线性通过极限。由极限方程得到 u′∈L²V′，Hilbert 三元组链式法则给 u∈C([0,T];H)，再配对及相消即得精确预算。这里不是单凭弱收敛把 Galerkin 的黏性积分等式取极限。

若 u、v 为两个能量类解，d=u−v，则

```math
d'=B(u,d)+B(d,v)-\nu A d,\qquad (Au)_n=K_n^2u_n,
```

且

```math
\frac12\frac{d}{dt}\|d\|_H^2+\nu\|d\|_V^2
\le C_0\|v\|_V\|d\|_H^2.
```

第一非线性项配对为零；第二项用 H×V→H 界。||v||_V 在有限时间内可积，Gronwall 给唯一性，故 Galerkin 的全部极限一致。任意有限 T 上重复即得全局解。此部分对所有有限能量初值成立，后续正耗散采用 B.10.1 的共同初值。

### B.10.3 选取方向使矩中的混项抵消

定义

```math
\chi=2^{-1/3},\qquad q=\frac{a\chi}{1-a\chi},\qquad
(C,S)=\frac{(1,q)}{\sqrt{1+q^2}},\qquad e=(C,S).
```

这里 C>0，且 S=aχ(C+S)。写 u_n=α_ne+β_nJ_0e，并取有限加权矩及重标变量

```math
\begin{aligned}
M_N&=\sum_{n=0}^N\chi^n e\cdot u_n,\\
L_n&=\chi C K_n^{2/3},\qquad
z_n=\sqrt{L_n}\alpha_n,\qquad w_n=\sqrt{L_n}\beta_n,\\
\kappa&=a\chi(1-q).
\end{aligned}
```

在 a=1/2 时 0<q<1、0<κ<1。向量 b_n=χ^ne 仅用作测试权，不作为所研究轨道或黏性稳态；特别是根层没有平衡输入。

边 n→n+1 对完整矩的贡献为

```math
\begin{aligned}
K_n\chi^n\big[
 &\chi C(\alpha_n^2+\beta_n^2)-C\alpha_n\alpha_{n+1}\\
 &+\{S-a\chi(C+S)\}\alpha_n\beta_{n+1}
 -a\chi(C-S)\beta_n\beta_{n+1}\big]\\
 &=z_n^2-z_nz_{n+1}+w_n^2-\kappa w_nw_{n+1}.
\end{aligned}
```

因为 √(L_nL_(n+1))=CK_nχ^n，缩放系数恰好匹配。混合的 α_nβ_(n+1) 项严格为零；不要求 α_n、β_n 或 x_n 为正。

将完整内边 n=0,…,N−1 求和，径向部分有恒等式

```math
\sum_{n<N}(z_n^2-z_nz_{n+1})
=\frac12\left[z_0^2+\sum_{n<N}(z_{n+1}-z_n)^2-z_N^2\right].
```

角向部分用 |κ|≤1 和 Young 不等式，至少为 −w_N²/2。另一方面，

```math
M_N=(\chi C)^{-1/2}\sum_{n=0}^N\chi^{2n}z_n.
```

置 d_0=z_0，d_j=z_j−z_(j−1)（j≥1），先交换有限求和，再用 Cauchy–Schwarz 与几何级数：

```math
\begin{aligned}
\left(\sum_{n=0}^N\chi^{2n}z_n\right)^2
&=\left(\sum_{j=0}^N d_j\sum_{n=j}^N\chi^{2n}\right)^2\\
&\le\frac{\sum_{j=0}^N d_j^2}
{(1-\chi^2)^2(1-\chi^4)}.
\end{aligned}
```

因而内边贡献 D_N 满足

```math
D_N\ge cM_N^2-\frac12L_N|u_N|^2,\qquad
c=\frac{\chi C(1-\chi^2)^2(1-\chi^4)}2>0.
```

该离散估计在 N=0 时仍成立。不能直接将 b 当作 V 中测试函数进行无穷配对；下面始终先用有限矩。

### B.10.4 用真实黏性损失控制切面与黏性矩误差

在无限层坐标方程中对 M_N 求导，真实跨切面边只贡献供体项，故

```math
M_N'=D_N-K_N\chi^N\alpha_Nx_{N+1}
 -\nu\sum_{n=0}^N K_n^2\chi^n e\cdot u_n.
```

内边估计的负末端项与跨边项合并，负误差至多

```math
\frac12K_N^{2/3}
\big[(1+\chi C)|u_N|^2+|u_{N+1}|^2\big]
\le K_N^{2/3}(|u_N|^2+|u_{N+1}|^2).
```

对每个 0<ν≤1 固定

```math
N=N_\nu=\left\lfloor\frac34\log_2\frac1\nu\right\rfloor,\qquad
\chi^4<\nu K_N^{4/3}\le1.
```

这是证明使用的切面，模型、初值和边界并不随 ν 改变。由于 K_(N+1)²=4K_N²，以上负误差在 [0,t] 的积分不超过 A_*Q_ν(t)，其中 A_*=χ^(−4)。黏性矩项则满足

```math
\begin{aligned}
\left|\nu\int_0^t\sum_{n=0}^N K_n^2\chi^ne\cdot u_n\,ds\right|
&\le\sqrt{Q_\nu(t)}
 \left(\nu t\sum_{n=0}^NK_n^{4/3}\right)^{1/2}\\
&\le B_*\sqrt{tQ_\nu(t)},\qquad
B_*^2=(1-\chi^4)^{-1}.
\end{aligned}
```

因此对所有 t≤T，M_N(0)=C，且

```math
M_N(t)\ge C+c\int_0^tM_N(s)^2\,ds
 -A_*Q_\nu(T)-B_*\sqrt{TQ_\nu(T)}.
```

同时精确预算给

```math
|M_N(t)|\le\left(\sum_{n=0}^{\infty}\chi^{2n}\right)^{1/2}
\|u(t)\|_H\le(1-\chi^2)^{-1/2}.
```

这里没有假设无黏极限轨道存在或唯一。若直接在有限 Galerkin 系统上使用相同计算，必须先保证最高层 J≥N_ν；不能将 J<N_ν 的封闭系统补零后仍计入已删除的内边。本证明先构造无限解，再对其有限矩计算，避开该问题。

### B.10.5 Riccati 比较闭合正耗散下界

定义

```math
T_*=\frac4{cC},\qquad
\varepsilon_*=
\min\left\{\frac{C}{4A_*},
\frac{C^2}{16B_*^2T_*}\right\}>0.
```

假设 Q_ν(T_*)≤ε_*。B.10.4 的两个误差各不超过 C/4，故在整个 [0,T_*] 上

```math
M_N(t)\ge\frac C2+c\int_0^tM_N(s)^2\,ds=:G(t)>0.
```

于是 G′=cM_N²≥cG²、G(0)=C/2，得到

```math
\frac1{G(t)}\le\frac2C-ct.
```

它与 G≤M_N 及 M_N 一致有界矛盾，因为 2/(cC)<T_*。因此 Q_ν(T_*)>ε_*，定理得证。所有 T≥T_* 也有同一下界，因为 Q_ν 单调。该论证容许反向瞬时通量；所迫使增加的是特定有限加权矩，而不是每一层能量的单调前进。

### B.10.6 封闭三层的严格回流证书

为了检验“孤立单元都能转移，所以整链单向接力”的直觉，取 ν=0，只保留 0、1、2 三层，a=1/2。由于 y_0=0 不变，记 (r,p,q,s,t)=(x_0,x_1,y_1,x_2,y_2)，这里 q、t 是本小节坐标，不是前面的方向比与时间上限。方程为

```math
\begin{aligned}
r'&=-rp,&
p'&=r^2-\tfrac12rq-2ps,&
q'&=\tfrac12rp-2qs,\\
s'&=2(p^2+q^2)-(p+q)t,&
t'&=(p+q)s.
\end{aligned}
```

初值 (1,0,0,0,0)。总平方范数恒为 1。虽然所有孤立供体方向均满足 |b|≤√2a<1，完整三层轨道仍在时间 14 回流。标准库程序 [check_rotation_chain.py](../../tests/check_rotation_chain.py) 给向外舍入的严格区间：

| 量 | 严格包围区间 |
|---|---|
| 时间 2 的 s²+t² | [0.725425726587, 0.725425726588] |
| 时间 14 的 s | [−0.133145604934, −0.133145586740] |
| 时间 14 的 p²+q² | [0.022075617400, 0.022075624002] |
| 时间 14 的 d(s²+t²)/dt=4s(p²+q²) | [−0.011757089248, −0.011757084125] |

最后一行是末层平方范数的导数，末层能量导数为其一半。它是封闭三层的反向传输证据，不能声称无限链的共同初值轨道在同一时刻也反向，更不能用末端反射否定 B.10.5。

**证书的解析前提。** 对三层的复双线性延拓，泵矩阵的 Frobenius 界为 2√2||p||，旋转对角块的算子界为 2√2|a|||p||，故 ||B(p,v)||≤3√2||p||||v||<5||p||||v||。设起点范数≤R=101/100，Taylor 系数递推 (j+1)u_(j+1)=∑_(k=0)^j B(u_k,u_(j−k)) 给 ||u_j||≤R(5R)^j。因此步长 h=1/64、36 阶多项式的尾项至多

```math
\delta=R\frac{(5Rh)^{37}}{1-5Rh}.
```

实轨道的范数守恒，且由双线性配对抵消，真实中心轨道与待认证轨道的距离增长率不超过 3√2R<5，单步放大不超过 e^(5/64)≤64/59。

**整数认证。** 程序以分母 2^256 的整数区间外包全部系数和 Horner 求值，直接验证每个新中心范数≤101/100、完整区间到所选中心的欧氏舍入误差≤2^(−200)。精确有理误差递推给第 j 步

```math
e_j\le(\delta+2^{-200})
\frac{(64/59)^j-1}{64/59-1}.
```

128 步到时间 2、896 步到时间 14，分别认证 e_128<10^(−34)、e_896<9.1×10^(−9)。所有通过／失败判断使用整数或 Fraction；Decimal 仅用于向外舍入的显示。可以单独运行 --certificate-only；该有限证书和前面的无限维解析证明相互独立。

另外，对 |a−1/2|≤10^(−6)、0≤ν≤10^(−7)、六维初值距离基准≤10^(−6) 的真实三层系统，范数≤1+10^(−6)，参数导数界 3、黏性矩阵界 17 和增长率 5 给时间 2 的距离至多

```math
3^{10}10^{-6}
+\frac{3^{10}-1}{5}(3\cdot10^{-6}+17\cdot10^{-7})
=0.11455412.
```

由于基准末层范数>0.85，扰动后末层平方范数仍大于 (0.85−0.11455412)²>0.54。这只证明短时转移对小扰动稳定，不把时间 14 的回流符号扩张到整个参数盒。

### B.10.7 已排除的两种简单标量退化及剩余边界

先检查每层固定方向的乘积子空间 y_n=q_nx_n，允许各 x_n 独立变化。黏性项在法向相消，得到

```math
\left.(y_n'-q_nx_n')\right|_{y_j=q_jx_j}
=K_{n-1}\big[-q_n(1+q_{n-1}^2)x_{n-1}^2
+a(1+q_{n-1})(1+q_n^2)x_{n-1}x_n\big].
```

不变性要求 q_n=0 且 q_(n−1)=−1，跨两条相邻边不能同时满足。垂直方向也不能补救，因为接收层为零时输入沿 e_x。根初值附近 y_1(t)=a t²/2+O(t³)，所以本定理不是在全实轴的不变标量轨道上证明。

再考虑每层独立可逆线性变换，希望其中一个标量分量构成不受其他分量影响的标量泵。把接收层及下一层置零，它的上游源必须满足

```math
K_{n-1}\ell_n^x(x_{n-1}^2+y_{n-1}^2)
=\widetilde K_{n-1}(\ell_{n-1}\cdot u_{n-1})^2.
```

左侧为秩二二次型（或零），右侧为非零秩一二次型，不可能对所有上游状态成立。因此这类逐层可逆线性变换不产生独立标量泵。

上述检查不排除非线性变换、混层变换、依赖振幅约束的特殊流形，也不等于穷尽已有理论。沿任意实际轨道，半径仍满足带角度系数 φ_n=x_(n+1)/R_(n+1)∈[−1,1] 的标量能量包络；零半径处令 φ_n=0。该方程不封闭，但这类包络已有文献先例。此处实质进展是一个已经闭合的具体正耗散定理；其相对于既有模型的研究价值仍需按精确量词与可逆等价关系判断。

### B.10.8 真实下游的短时扇形与回流探针的停止点

无限链低层回流尚未取得证书。以下保留真实下游的局部解析结果与当前尾部控制缺口。

单个接收层写成 x′=P−Ωy−dx、y′=Ωx−dy，其中 P=K_(n−1)R_(n−1)²≥0、Ω=aK_(n−1)S_(n−1)、d=K_nx_(n+1)+νK_n²。令 z=x+iy，D′=d、Φ′=Ω；对零接收初值，

```math
z(t)=\int_0^t P(s)e^{-[D(t)-D(s)]}
 e^{i[\Phi(t)-\Phi(s)]}\,ds.
```

因此所有注入相位差位于 [0,π/2] 时，x,y≥0，不要求下游 d≥0。共同根初值下 x_0=r>0、y_0=0、r≤1，故 Ω_1=r/2，得到真实无限链上 x_1,y_1≥0（0≤t≤π）。利用 Ω_2=x_1+y_1≤√2，另有 x_2,y_2≥0（0≤t≤π/(2√2)）。这些结论对 ν>0 统一成立。

R>0 时，R′=P cosθ−dR、θ′=Ω−(P/R)sinθ。下游虽然从角度公式中显式消失，仍通过 R 改变方向，不能据此去掉真实下游。固定斜率 q_* 的法向量 w=y−q_*x 满足

```math
w'=(q_*\Omega-d)w+(1+q_*^2)\Omega x-q_*P.
```

B.10.3 的矩抵消不使这一逐层法向式定号。

**非负下游阻尼并不足够。** 取根与一个接收层，ν=0、a=1/2：

```math
r'=-rp,\qquad
p'=r^2-\tfrac12ry-dp,\qquad
y'=\tfrac12rp-dy.
```

从 (1,0,0) 先令 d=0，直到 ρ=√(p²+y²)/r=4。孤立单元公式给 r_*=1/√17、sinθ_*=(√17−1)/8，且这一时刻有限。随后取 d=(17/16)p，直到 p 首次为零。令 dτ=r dt，直接计算得到 ρ≡4 和 θ_τ=1/2−sinθ/4≥1/4。到 θ=π/2 的 Δτ<2π，且 r≥r_*exp(−4Δτ)>0，所以物理时间也有限。在到达点 p′=−r²<0，随后取 d=0 就发生回流。整个控制可取非负下游输入 x_2=d/2≥0。

这只排除“非负下游阻尼自动保护方向”的模块推论；没有证明这个输入可由第二接收层自身方程生成，亦未限定该控制反例发生在 [0,20]。

**与封闭探针比较的具体缺口。** 将真实无限解投影到 0,…,m 层，与同初值封闭解 v 比较，唯一额外项为 f_m=−K_mx_(m+1)u_m。能量界只给 ||f_m||≤K_m/2。有限双线性界 β_m=√2(1+a)K_(m−1) 给

```math
\|P_mu(t)-v(t)\|_H
\le\frac{K_m}{2\beta_m}(e^{\beta_mt}-1).
```

它在三层时间 14 远大于回流符号裕量，增加 m 也不会使这个能量界变小。它不是所有尾误差方法均失败的证明，只说明当前证书缺少实际下游控制。

当前有限探针缺少控制真实下游误差的估计，低层回流问题据此收束；已证异常耗散定理保持。
