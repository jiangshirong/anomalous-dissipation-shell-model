# 正性壳网络的异常耗散研究

[English](README.md) | **简体中文**

本项目研究交换强度随尺度变化的正性、保守壳网络。每个尺度有两个非负实振幅 w_n、z_n，波数 K_n=2^n，能量为 (w_n²+z_n²)/2。这是人为设计的数学级联，不是标准 Sabra，也不是三维 Navier–Stokes 的严格约化。

核心问题是在固定观察窗内，黏性趋零时真实黏性损失是否仍不消失。先在每个固定正黏性下构造无限层解，再取零黏极限。有限封闭无黏无迫系统严格守恒；末端泄漏和数值误差不计作异常耗散。

## 核心结果

共同零初值、两个根各受单位外力、黏性权重为 K_n² 时，累计损失满足

```math
Q_\nu(T)=\nu\int_0^T\sum_{n\ge0}K_n^2
\bigl((w_n^\nu)^2+(z_n^\nu)^2\bigr)\,dt,
\qquad E^\nu(T)+Q_\nu(T)=\int_0^T(w_0^\nu+z_0^\nu)\,dt.
```

周期交换配置在足够长的固定窗内有与黏性无关的正耗散下界。只在稀疏的连续块中削弱交换，就能使每个固定 T>0 的 Q_ν(T)→0。两组配置的边图、外力、初值和黏性权重相同，弱层自然密度均为 1/2，系数差异集合的自然密度为零。没有删边，全部交换系数仍随层号增长。

被改壳层的相对系数变化很大；结论不表示任意零密度改动都能消除耗散。[结果篇 §7.6–7.8](docs/03-results-zh.md#76-密集弱交换逐层级数发散却仍有异常耗散)保存命题及完整证明，[验证篇 §8.11](docs/04-evidence-zh.md#811-选定动态对照的证明审查与依赖闭合)标明实际内部复核范围。

## 后续成果与开放问题

| 主题 | 当前结论 |
|---|---|
| 较短弱块 | 指定族 N_j=2^(2^j)、ℓ_j=⌈c log₂N_j⌉、c>0 在 c<1/2 时耗散，c≥1/2 时每个固定窗耗散趋零。 |
| 冻结独立二值系数 | 弱层概率 p<1/4 时几乎必然耗散，p≥1/4 时几乎必然每个固定窗耗散趋零。只抽样一次，此后系数固定，窗口可依实现而定。 |
| 实际交换系数的纯置换 | 可容许置换的位移不超过 c log₂(n+2)+C、c<1/2 时保留耗散；临界尺度存在零密度支撑的无耗散置换，未分类所有临界置换。 |
| 无迫自由衰减 | 共同初值只在两个根取振幅 1：周期侧对所有充分小黏性，在一个黏性无关窗口损失超过初始能量的一半；选定临界置换侧每个固定窗损失趋零。 |
| 对数交换 h_n=η2^(n/2)(n+1)^α | α≤1/2 时固定窗损失趋零，α>3/4 时足够长固定窗有正下界；1/2<α≤3/4 仍开放。 |
| 损失通道定位 | 对数族在 η=β=1、共同零初值下，所有固定 α>0 的 z 通道黏性损失趋零；任何可能的异常损失来自 w。 |

一般几何剖面平方和 P 发散时的动态仍开放。特别是 α=2/3 尚未分类：实际轨道的端点及接收占有条件没有闭合。[设计篇 §19](docs/05-design-zh.md#19-2026-10-04-选题建议固定黏性稳定与零黏耗散不连续)中的固定黏性连续性与零黏耗散不连续性任务仍是建议，没有新定理。

以上是注明验证范围的内部解析结果。保守 pump 单元及部分证明工具已有先例；具体动态对照是贡献候选，全球优先权、实质原创性及同行认可尚未认证。作者已将核心结果提交 JSP，投稿不等于录用。

## 验证方式

使用 Python 3.11 及 `requirements.txt` 中的依赖：

```bash
python -m pip install -r requirements.txt
python tests/check_identities.py
python tests/check_cut_obstruction.py
python audits/logarithmic/check_review_claims.py
python tests/check_repository.py
python tests/check_repository_negative.py
```

仅在明确获准上传时，使用 `python tests/check_repository.py --staged` 检查实际 Git 暂存内容。保留本地论文材料的作者还可运行 `python tests/check_repository.py --local-manuscripts`，复用双语稿件检查；默认研究检查不依赖这些本地文件。

有限代数不证明无限维动力学或原创性。仓库检查验证文件范围和导航，不认证数学真假。当前没有已交付的完整时间积分求解器接口。独立的[第三方 Sabra 历史审查](audits/sabra/README.md)不属于本模型贡献。
